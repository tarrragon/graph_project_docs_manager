## 判定規則

1. **區塊來源**：`pixel_diff.py`（容差 2）的輸出：差異像素聚成 16px 格，取 8 鄰域連通分量的外接矩形。
2. **合併**：兩矩形間的最短距離取歐氏距離（水平與垂直間隙皆為 0 即相交）；距離 ≤32px 就合併成外接矩形，合併後的框再參與比較，反覆合併到沒有可合併的為止。合併後的區塊數為 n。
3. **裁切框**：每個區塊四邊各外擴 max(16px, ⌈該方向邊長 / 4⌉)，夾在影像範圍內；寬或高不足 96px 時，以合併後、外擴前的區塊中心補到 96px（貼邊時往內平移）。基準圖與新圖同框。
4. **送圖尺寸**：裁切長邊 <384px 時以整數倍最近鄰放大，倍數取使長邊 ≥384 的最小整數；長邊 >2,576px 時面積平均縮到 2,576；其餘原尺寸。2,576px 是 Claude Haiku 5.5 與 Claude Opus 5.5 的長邊上限較小值（官方 Vision 文件，2026-10-29 查證；用戶確認）。基準圖與新圖分開送，標「基準」「新」。
5. **多區塊**：每個區塊各取樣 K=5；所有區塊都判為「預期修改」≥4/5，整對才放行。
6. **免看**：`pixel_diff` 回 skip 的對不送模型。缺陷對記為「確定性工具漏掉」，不計入模型結果；預期修改對記為「免看放行」。本資料集沒有 skip 的對。
7. **多區塊對**：n ≥12 時整對改為單一區塊，裁切框為整張圖，依規則 4 送出，只取樣 K=5 一次。門檻 12 固定。本資料集所有對 n ≤6，規則 7 不套用於任何一對；報告的「多區塊對」清單照列 n 與「未套用規則 7」。

## 取樣與放行（465 驗收條件）

- 模型只看差異區塊的裁切對。選項為單 token 代碼「缺陷」「預期修改」「無法判斷」。
- 以 0.5.0-W1-464.1 腳本對 Haiku 取樣 K=5，temperature 1.0。
- 「預期修改」≥4/5 放行；「缺陷」≥4/5 交用戶；其餘轉 Opus，Opus 也未判為預期修改的交用戶。
- 取樣量：缺陷 8 對 n 合計 15、預期修改 6 對 n 合計 11，每個模型 130 次。
