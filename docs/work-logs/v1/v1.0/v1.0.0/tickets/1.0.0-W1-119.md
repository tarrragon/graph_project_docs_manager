**為何不併入 `0.1.0-W3-185`、不 blockedBy `0.1.0-W3-184`**：兩個載體缺口與排程結論的關係不同。

| 問題 | 是否由 `0.1.0-W3-184` 吸收 |
|------|--------------------------|
| 背景完成的通知與其他提示爭用注意力 | **是**——若排程使重要事件不同時發生，爭用消失 |
| 背景完成的通知本身會消失、事後無法回顧 | **否**——即使全 App 只有這一則通知、零爭用，`Motion.snackBar` 到期後一樣消失，使用者離開再回來即無從得知曾經發生過什麼 |
