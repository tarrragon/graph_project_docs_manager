### Context Bundle（L57，2026-11-13 派發前）

- 現況：.claude/project-integration/run_integration_tests.py 的 discover_tests 以 base.rglob("*_test.dart") 遞迴收集，連 integration_test/perf/ticket_list_perf_test.dart 一起收（共 12 檔）。
- CI（.github/workflows/macos-integration.yml）以 `for f in integration_test/*_test.dart` 非遞迴收集，目前頂層 11 檔。
- integration_test/perf/ticket_list_perf_test.dart 檔頭載明為 profile 模式 profiler 探針、由 PM 以 flutter drive 手動執行；其耗時隨負載與前景狀態浮動，553.2.3.3 第 2 次閘門即卡在此檔（34c5954c9ca9，Failed to foreground app 後無輸出至單檔 300 秒逾時）。
- 改法：discover_tests 改為只收 integration_test/ 頂層 *_test.dart（與 CI 同規則），或明確排除 perf/；檔頭註解寫明排除理由與探針的手動執行方式（引用 perf 檔頭的指令，不另創）。docstring 中「與 flutter test integration_test 同規則」需改寫。
- 測試（tests/test_run_integration_tests.py）：以暫存目錄建頂層與 perf/ 下各一個 *_test.dart，斷言 perf/ 不被收集（E2：已知該被排除者確實不在結果中）、頂層照常收集（對照）。
- 執行：uv --directory .claude/project-integration run --with pytest --with pyyaml pytest tests/test_run_integration_tests.py。
- 回報：收集結果對真實 repo 的檔數（應為 11）、紅燈證據、自檢、Phase 4。代理人不改票檔。
