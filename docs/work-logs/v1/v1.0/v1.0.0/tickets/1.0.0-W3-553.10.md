### 實作摘要（parsley，2026-11-12）

新增 lib/edit：write_result.dart（WriteResult 封閉型別、BlockedReason、IoFailure）、edit_git_port.dart（位元組 stdout／stdin 的 git port 與 IoEditGitPort）、edit_file_port.dart（檔案 port 與 IoEditFilePort）、edit_git_runner.dart（-C 根、LC_ALL=C、5 秒逾時加終止）、edit_session.dart（閘門六步、M 更新、暫存檔 rename）、edit_workspace.dart（開啟時 git 探測、唯讀降級、beginEditing）、restore_instruction.dart（取回說明）。

**git port 決定**：不與 History 的 GitProcessRunner 抽共用層。理由：(1) Edit 不依賴 History（edit domain-map §2），抽到共用層需新增跨 domain 目錄並改動 History，超出本票範圍；(2) 現有介面 stdout 為 String，Edit 需要位元組 stdout 與位元組 stdin，介面形狀不同，硬合併會讓 History 背負不需要的能力。兩者各自獨立，日後若出現第三個使用者再抽共用層（需另開票評估）。

**P-9 契約**：寫入函式的唯一路徑入口是 EditWorkspace.beginEditing(WorkspaceRelativePath)（session 之後的 writeField 不再收路徑）。negative.dart.txt／positive.dart 改為呼叫它；negative 維持 .txt 入庫，contract test 的呼叫行定位字串改為 beginEditing(。

### 實作補記與設計決定（parsley）

- **API 形狀**：EditWorkspace.open（開啟時以 `git -C <根> rev-parse --is-inside-work-tree` 探測，非 repo 或無法啟動即 readOnly）→ beginEditing(WorkspaceRelativePath) → EditSession.writeField(field, newValue)。session 持有 M；M 只在開始編輯與 written 時設定。
- **逾時注入**：EditTimer（`Future<void> Function(Duration)`）由 open 注入，EditGitRunner 以 Future.any 在 5 秒計時與 git 結果間競賽，逾時 kill 子行程並回傳 null；測試用 ManualEditTimer 推進虛擬時間。本地檔案 IO 不經計時器（G-23）。
- **show 的三種結果不另分類**：結束碼 0 且位元組相同才不快照；H 不存在（128 加路徑不在 HEAD）、H 無法判定、逾時、無法啟動，結果都是走快照分支，故實作只判「是否等於 H」，不解析 stderr。LC_ALL=C 仍一律設定（G-18、IT-E1-6 斷言），保留給需區分原因的日誌（L 組）使用。
- **hash-object 引數**：`-C <根> hash-object -w --stdin`。S-1 的「恰為 hash-object -w --stdin」解讀為去掉 `-C <根>` 前綴後的子命令與旗標。
- **G-21 的鑑別方式**：不為測試在正式碼加旗標。以「兩個 session 同時開始編輯、其一 written 後另一個仍持有舊 M」重現 M 停在開始編輯時的錯誤實作所見狀態：舊 M 的 session 得 externallyModified，更新 M 的 session 第二次寫入 written。
- **G-6**：Corpus 的 classifyFrontmatter 以 utf8 嚴格解碼整份檔案，內文含非 UTF-8 位元組時改寫即 rewriteNotIsolated，走不到 H 比對。G-6 以注入替身改寫器隔離「W 與 H 的位元組比較」。缺口記於 NeedsContext。
- **IT-E2-1 的 status 斷言**：R0 寫入前乾淨、寫入後必然出現 ` M <目標檔>`，測試設計「四者逐字相同」對 status 在 R0 不可能成立。實作改為 stash、reflog、log 逐字相同，status 只斷言「僅工作區欄出現目標檔、無任何 staged 項目」。缺口記於 NeedsContext。
- **IT-E5-2**：以不存在的執行檔路徑等價「PATH 不含 git」（port 層 executable 參數），因為 Dart 的 Process 以呼叫端環境解析執行檔，無法只替子行程換 PATH。
- **P-9**：見前段；fixture 改呼叫 EditWorkspace.beginEditing。
