| 舊 | 新 |
|---|---|
| requestId String | LogValue.nodeId（空字串落 nodeIdRejected） |
| channel／decision／reason（字串）／outcome／op | 新 enum AttentionLogChannel／Decision／Reason／Outcome／Op |
| 離開類 reason | 既有 AttentionReleaseReason |
| occupancy Map | 攤平 occupancyInFlight、occupancyQueueDepth、occupancyOldestAgeMs（整數，空通道缺席） |

| naturalLifespanRaw Duration? | naturalLifespanRawMs |
| carrierEventId String? | LogValue.nodeId，null 時缺席 |
| arrival、level、requestedLevel、parentLevel | 不變，enumValue |

負載鍵比對 FR-03（AppSnackBar，鍵在 appSnackBarLogKeys）：showId／holderShowId／preemptedShowId 整數；origin、variant、各 level enumValue；reason SnackBarClosedReason enumValue；reason 'projectChange' 改布林 projectChange: true；sameLevelReplace、holderUnknown 布林；message、actionLabel（使用者文字）與 duration token 刪除。
