## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### incident-responder 根因確認（唯讀）

**原始錯誤**（run 43245461900，最新 run 43253693313 同形）：`edit_validation_real_cli_test.dart` setUpAll 第 53 行 `Process.run('uv', ['--version'])` 拋 `ProcessException: No such file or directory / Command: uv --version`，`0 tests passed, 1 failed`，迴圈 `|| exit 1` 中止。

**中止前已跑（全綠）**：app_test（40 passed, 2 skipped）、edit_gate_real_git（8）、edit_path_symlink（3）、edit_readonly_degrade（3）、edit_snapshot_real_git（5）。
**中止後未跑**：history_it_h1_cost_test、history_it_h2_degradations_test、history_real_git_scan_test、real_font_layout_test、uc07_history_test（glob 字母序）。

**根因分類**：環境問題（CI 前置工具缺失）+ 測試前置條件寫法（expect 前先拋裸例外）。產品碼無誤。
- workflow 只裝 Flutter，無 uv、無 doc。
- `IoEditValidatorPort` 預設 `executable = 'doc'`（PATH 解析），cwd 為 fixture repo；fixture（edit_fixture_repo.dart）把 `.claude/skills/doc` 以 symlink 掛進 fixture repo，設計上即依賴 cwd-resolving shim（以 rev-parse --show-toplevel 找專案根 → `uv run --directory <root>/.claude/skills/doc doc`）。
- 即使補 uv，PATH 上仍無 `doc`，第二個 probe 會以同樣裸 ProcessException 失敗。

### 欄位格式追蹤
| 欄位 | 生產者 | 格式 | 範例 |
|------|--------|------|------|
| IoEditValidatorPort.executable | lib/edit/edit_validator_port.dart 建構子預設 | PATH 上可執行檔名 | `doc` |
| doc shim | .claude/scripts/install-skill-clis.py | POSIX sh，裝於 `SKILL_CLI_BIN_DIR`（預設 ~/.local/bin） | 本機 ~/.local/bin/doc |

### 修法建議
1. **uv**：flutter-action 之後加 `- uses: astral-sh/setup-uv@v6`，`with: version: "0.8.13"`（與本機開發機一致，避免 uv.lock 格式漂移；setup-uv 最新 tag v10.3.3，採用時以 tag 釘到 patch）。skill 需 Python >=3.12，可加 `python-version: "3.12"` 固定。
2. **doc**：不另裝副本，以 repo 內安裝器產生 shim：`SKILL_CLI_BIN_DIR="$RUNNER_TEMP/bin" uv run --quiet --script .claude/scripts/install-skill-clis.py`，再 `echo "$RUNNER_TEMP/bin" >> "$GITHUB_PATH"`（~/.local/bin 不保證在 runner PATH）；加一步 `doc --help` 煙霧檢查兼預熱 uv 依賴解析，避免首次解析吃掉單項逾時。安裝器參數實作時以 `--help` 確認。
3. **setUpAll**：uv 與 doc 兩個 probe 以 `try { ... } on ProcessException catch (e)` 包住，捕獲時 `fail('前置條件不足：PATH 上需有 uv 與 doc CLI（test-design v0.5 §2.6；CI 安裝步驟見 macos-integration.yml）：$e')`；exitCode 非 0 維持 expect 附 stderr。不用 skip。
4. **逾時註解**：現有 integration_test/*_test.dart 為 11 檔（註解仍寫 1 檔／3 檔上限），實測每檔建置+執行約 20 秒；加 uv 與 shim 安裝預熱後依檔數重估 timeout-minutes 與註解。
5. 附帶：迴圈 `|| exit 1` 使單檔紅燈遮蔽其後各檔零覆蓋；可改為記錄失敗、跑完全部後再 exit 1（由 PM 裁決是否納入本票）。
