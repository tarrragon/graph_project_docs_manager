## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
合併入 main：ef1a21c6fc（閘門 dart-format／flutter +3768／dart-analyze／flutter-integration +12 全綠）。分支 commit 8d37d24da5、4ffa74d5ff。
範圍：Graph、History git、Parse、StaleOpen、DomainView 五 sink 遷移為泛型 LogSink<E extends Enum>（lib/observability/log_sink.dart：LogSink、defaultLogSink、sharedLogWriter、logLevelFromDevLevel）；新事件 enum ParseLogEvent、StaleOpenLogEvent、DomainViewLogEvent；刪除 GraphLogSink、HistoryLogSink、HistoryLogLevel、ParseLogSink、ParseLogLevel、StaleOpenLogSink、DomainViewLogSink。Workspace、AttentionArbiter、AppSnackBar 移交 553.2.3.5／.6；O4-1 實掃移交 .6。O3-1 fixture 存 .dart.txt，測試時複製至 .dart_tool 再 analyze（避免被專案 analyze 掃到）。行為變動：Parse 預設由靜默改經 writer、StaleOpen 由 developer.log 改經 writer（FR-04 一致）。

負載鍵比對（FR-03 白名單）：
| sink | 原鍵 | 處置 |
|---|---|---|
| Graph | nodeCount 等 9 個計數 | LogValue.integer |
| Graph | reason（enum .name 字串） | LogValue.enumValue，graphReasonFields 反查（1.1.0-W3-682） |
| History | exitCode、commitCount、outputBytes、gitDurationMs、parseDurationMs、eventCount | integer |
| History | head（SHA） | LogValue.commitSha |
| History | category、reason（字面值） | 新 enum HistoryLogCategory、HistoryDegradeReason |
| History | root（絕對路徑）、gitVersion、stderrSummary、launchFailed error.message | 刪除（C-2；gitVersion 評估見 1.1.0-W3-683） |
| History | arguments（list） | argumentCount（int） |
| History | counters（Map） | 攤平為各計數 int 欄位 |
| Parse | path、commit | LogValue.path、LogValue.commitSha（id null 省略） |
| StaleOpen | tag、i18nKey | LogValue.fieldName，不合法退 fieldNameRejected（有正向對照） |
| DomainView | 訊息中原因 | reason 鍵＝EdgeTypeUnavailableReason（null 省略） |
