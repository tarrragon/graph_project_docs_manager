### 盤點：讀現行 docs 的契約測試（驗收 1）

查法：用 flutter_docs_prefix_guard_test 的實讀正規式（File／_readFile／Directory 加上 docs/ 字面或常數），掃描 test/。排除 fixtures 和虛擬檔案系統（addFile）。test/helpers/spec001/corpus_snapshot.dart 讀的是 test/fixtures/spec001/corpus_snapshot，和現行 docs 無關。

| 測試 | 讀的規格 | 耦合型態 | 規劃期改規格時的表現 |
|---|---|---|---|
| test/unit/l10n/spec004_key_table_contract_test.dart | SPEC-004 整張 key 表 | A：差集寫死在 test/（pendingAdditionExemptions 48 個、obsoleteRowKeys） | 新增規格先行 key 就紅（W1-102 這次） |
| test/unit/graph/domain_name_resolution_test.dart（G11-8d） | docs/spec 全部 | A：原本寫死邊數 25 | 1.0.0-W1-089 已改成不變式，新增宣告不再紅 |
| test/unit/screens/gap_report/gap_report_projection_test.dart | SPEC-004 的 gap* 列 | B：規格列與 ARB 逐字對照 | 改既有 key 的文案就紅 |
| test/unit/screens/gap_report_declaration_line_test.dart | SPEC-004 的 6 個 pathDeclaration* 列 | B | 同上 |
| test/unit/app/domain_view_load_failed_test.dart | SPEC-004 §4.0.6 指定列 | B | 同上 |

- A 型：規劃中的差集寫在 test/，PM 改規格時無法同批調整，形成假紅。
- B 型：紅燈本身正確，因為規格改了，實作還沒跟上。問題在於規劃期到實作票合併之間，main 一直是紅的，擋住所有合併。

### 框架判定（驗收 3）

- AND 1 抽象可攜：成立。保護分支的豁免路徑和閘門範圍各自維護，兩者交集內的提交不經閘門就落地。被測試讀取的路徑落在這個交集時，紅燈會延到下一次無關的合併才出現。替換專案名與路徑後仍然成立。
- AND 2 根源在 .claude/ 通用資產：成立。
  - branch-verify-hook 把豁免前綴寫死。
  - merge_gate 只在合併時點讀範圍宣告。
  - ticket track commit 不讀閘門範圍。
- dedup 關鍵字：直推 main、不經閘門、主線程寫 test、規格先行、契約測試、PM 不可寫 test、繞過閘門、prefixes。
  - 命中 tarrragon/claude#117。該 issue 已有同一機制的觀測（本專案 0.5.0-W1-543，L26），當時判定無害，並預測紅燈會延到下一次無關的閘門才出現。
  - 關係判定：重複（同一機制）。本次是該預測的實害第一次發生：main 紅燈擋住所有合併，另外開了 incident 票 W1-135 和 3 張修正票。

## Solution

### 結論

- 驗收 1（盤點）：讀現行規格的契約測試有 6 個檔，分成兩型（表見 Problem Analysis）。
  - A 型：規劃中的差集寫死在 test/。
  - B 型：規格列和實作逐字對照。
  - G11-8d 已由 1.0.0-W1-089 改成不變式。
- 驗收 2（防護方向，用戶裁定，AUQ，2026-11-11）：豁免改讀規格標記。
  - 規格列加上「規格先行：<落地票>」標記，契約測試跳過帶標記的列。
  - 標記還在、但實作已經一致時判紅，提示移除標記。
  - 既有 48 個豁免繼續留在清單，由 1.0 的元件票逐張移除；新的差集一律用標記。
  - 實作票是 1.1.0-W1-108（P1，parsley）。它是測試基礎設施的改善，而 1.0 已凍結，依凍結分流進 1.1.0。
  - 排程：當作 1.1 規劃線的第一張，合併之後才開始修改 1.1 的規格。
  - 未採用的選項：強制子票，因為要靠 PM 記得；規格改動走 worktree 合併，因為每改一次規格就佔一次全套件閘門，而且 PM 仍然要等 parsley。
- 驗收 3（框架判定）：屬於框架問題，兩條 AND 判準都成立。dedup 判定和 tarrragon/claude#117 既有的觀測重複，已 observe 補上實害證據（issuecomment-6797361012），不另開 issue。
