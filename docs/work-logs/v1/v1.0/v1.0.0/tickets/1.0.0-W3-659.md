## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
parsley（commit 89bfe5e0cf）做了三項修改：
- `extractRows` 支援並列多 key 列（`` `a` / `b` ``），key 數與格數不符時拋出 StateError，不再靜默略過。
- E2 改為比對「注入後的違規」減去「baseline 違規」的差集，並新增「baseline 非空時的差集對照」。
- 補上多 key 解析後浮出 4 個 key：radioYes、radioNo 是規格先行，已併入 W1-136 的豁免清單；schemaAppVersionLabel、schemaProjectVersionLabel 在 SPEC-004 的該列註明 ARB 已刻意移除，所以新增 `obsoleteRowKeys`，這兩個不比對，一旦重新出現在 ARB 就判紅。這是派發範圍外的小幅擴充，屬補上多 key 解析的必要連帶，主控接受。
