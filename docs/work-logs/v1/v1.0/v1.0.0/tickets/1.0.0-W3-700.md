### 實機驗證量測（2026-11-14，L57）

**環境**：`fvm flutter run -d macos`（Debug build，HEAD 9ad26d6335）；Info.plist 為 XML 格式，`CFBundleIdentifier=com.example.graphProjectDocsManager`，bundle id 取得成功（非 port: null 降級路徑）。啟動前 `~/Library/Logs/com.example.graphProjectDocsManager/` 不存在，啟動後建立並寫入 `app.jsonl`。

**觸發方式（未改 lib/）**：
- 一般 domain 事件：App 以已保存的 workspace 啟動，自動走 restore／scan／graph build 路徑。
- fatal：經 VM service `evaluate`（targetId = root library `package:graph_project_docs_manager/main.dart`）執行 `Future<void>.delayed(Duration.zero, () => throw StateError('W3700PROBE /Users/probe/secret-path'))`。這是未 await 的 async 例外，由真實的平台層攔截（`PlatformDispatcher.onError`）接住，沒有直接呼叫 `reportFatalError`。例外訊息刻意放入絕對路徑，作為洩漏偵測的正向對照。

**app.jsonl 實際記錄（節錄；共 24 行，同一檔案）**：
```
{"ts":"2026-11-13T18:12:26.485299Z","level":"info","domain":"workspace","event":"restoreIssuing","fields":{"key":"workspacePath"}}
{"ts":"2026-11-13T18:12:27.991185Z","level":"info","domain":"corpus","event":"watchStarted","fields":{}}
{"ts":"2026-11-13T18:12:28.103274Z","level":"info","domain":"edit","event":"editModeDetermined","fields":{"mode":"writable"}}
{"ts":"2026-11-13T18:12:31.486372Z","level":"info","domain":"graph","event":"buildCompleted","fields":{"nodeCount":2884,"edgeCount":4363,"danglingRefCount":9,"malformedRefCount":3,"duplicateIdCount":0,"multiSourceCount":9,"flowDefectCount":0,"resolvedCount":6759,"totalReferences":6771}}
{"ts":"2026-11-13T18:12:48.522103Z","level":"error","domain":"presentation","event":"fatalUncaught","fields":{"interceptor":"platform"},"error_source":"internal","error_type":"StateError"}
```

**洩漏檢查（固定值計數，對全檔）**：
- `grep -c W3700PROBE` = 0（例外訊息原文未落檔）
- `grep -cE '/Users/|/home/|/private/'` = 0（無絕對路徑）
- `grep -c StateError` = 1（僅 `error_type` 欄位的 runtimeType，符合 FR-07「只記 runtimeType」）

**判定**：三條驗收全數通過。fatal 記錄為 domain=presentation、event=fatalUncaught、level=error、error_source=internal，與 workspace／corpus／graph／edit 的 info 記錄寫在同一個 app.jsonl。不需要排進 1.0.1 patch。

**未涵蓋**：只觸發了平台層（interceptor=platform）；framework 與 zone 兩層的實機落檔沒有分別觸發，三層匯流到同一出口由 `test/unit/app/global_error_handling_test.dart` 覆蓋。
