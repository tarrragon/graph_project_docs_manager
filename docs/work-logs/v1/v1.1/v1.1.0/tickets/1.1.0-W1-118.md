<!-- Schema[ANA/Problem Analysis]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 事件

### 框架問題兩條 AND 判準（escalation-flow.md）

1. **抽象後可攜**：成立。抽象後的形態是「有寫入副作用的 CLI 不拒絕未知參數，查詢動作（`--help`、拼錯的旗標）變成寫入動作」。換掉專案名與路徑仍成立：任何 consumer 的代理人或人以 `--help` 探參數都會觸發，寫入對象是使用者層 `~/.local/bin`，跨專案共用。
2. **根源在 `.claude/` 通用資產**：成立。`.claude/scripts/install-skill-clis.py` 隨 sync 擴散（`should_exclude` 回傳 False，2026-11-13 查證），非 `project-integration/` 的專案自有檔，也不在 lib/、docs/。
