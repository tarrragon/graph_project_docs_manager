L52 預讀筆記（2026-11-10，012.18 派發中，尚未實驗驗證）：
- component-contract-design 的 step-3〈容器元件另答排列不變式三項〉只有主軸的一維公式：N × 子件最小尺寸 + (N−1) × 最小間距 ≤ 可用空間。沒有交叉軸檢查，也就是容器有固定高（或固定寬）時，子件固有高（或固有寬）須 ≤ 容器的 slot 高（或寬）。Toolbar.history 的 28 對 32 正好落在這個缺口：012.2 填了「不觸發」，主軸寬度有代入，交叉軸高度沒有對應問句。
- 同一公式用的是「子件最小尺寸」。子件取固有寬、不收縮時（Toolbar.history 的兩個子件就是如此），應代入「最長文案下的固有尺寸」。另外，「不觸發」的代入值要不要同時在測試字型下成立，目前沒有規定。本例的 5.6 以實機字型推得「合計不到可用寬的一半」，但測試字型下約 852 對 748，不成立。
