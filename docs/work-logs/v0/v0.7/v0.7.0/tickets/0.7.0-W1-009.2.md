# Execution Log

## Task Summary

依 SPEC-003 v1.84 §3.8 編輯器選項列改寫偏好設定面板的點選行為：點選值與持久化值（不是選取標示）比對——不同：寫入，寫入成功後關閉面板並顯示 AppSnackBar.plain（preferencesEditorAppliedMessage，editor 為該選項顯示標籤）；寫入失敗：關閉面板、不提示、記錄日誌；相同：關閉面板、不寫入、不提示。EditorPreferenceStore.write 改為回報成敗（現為 Future<void>、失敗只記日誌），供呼叫端分流

## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 派發前盤點（L53，2026-11-09）

- 票面修正：what 的寫入失敗分支由 v1.84「不提示」改為 v1.85「顯示 preferencesEditorSaveFailedMessage」，與 acceptance 第 4 項一致。
- `EditorPreferenceStore.write` 改簽章的影響（grep 全 lib／test／integration_test）：
  - 介面實作者三個：`SharedPreferencesEditorStore`（lib/workspace/editor_preference.dart）、`_FixedStore`（test/unit/workspace/external_opener_test.dart）、`_MemoryStore`（test/widget/screens/preferences_panel_test.dart）。
  - 呼叫端兩處：`_PreferencesPanelState._choose`（preferences_panel.dart）、test/unit/workspace/editor_preference_test.dart。
  - `MacosExternalOpener` 只呼叫 read，不受影響；integration_test 無引用。
  - where.files 已補 editor_preference_test.dart 與 external_opener_test.dart。
- SnackBar 載體：`PreferencesPanel` 掛在 lib/assembly/shell.dart 的 Stack 內（`if (isPreferencesOpen)`），關閉面板會卸載 panel 的 context。送出提示前須先取得 messenger／l10n 再關閉，或於關閉前排程送出。shell.dart 不在本票範圍（L52 的 012.11 正在改），需要動 shell.dart 時停手回報。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
- EditorPreferenceStore.write 改回 Future<bool>（SharedPreferences 實作以 setString 結果或例外判成敗，失敗記 level 900 日誌）；三個實作者同步。
- PreferencesPanel._choose：與開啟時持久化值（snapshot.storedId）比對；相同只關閉；不同寫入後以 AppSnackBar.show（plain，discardable，userInitiated）送出成功／失敗提示，再關閉面板。提示在關閉前送出，SnackBar 掛主視窗 ScaffoldMessenger，面板卸載後續存；未動 shell.dart。移除 _chosenId。
- Phase 4 評估：重構需要=否；技術債務=無（寫入 await 期間面板被 ESC 卸載時，提示被 AppSnackBar 以 skippedUnmounted 略過，屬可接受邊界）；品質 A；結論：無需重構。
