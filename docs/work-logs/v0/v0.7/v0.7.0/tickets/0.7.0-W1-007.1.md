- 主選單：SPEC-003 §3.11 全部 53 項 zh/en 對照（52 既有 + 說明 > 鍵盤快捷鍵），載體 zh-Hant.lproj 的 .strings + InfoPlist.strings，不進 ARB；通道方法名 openKeyboardShortcuts。SPEC-001 §9、SPEC-003 §3.8 入口描述已對齊。
