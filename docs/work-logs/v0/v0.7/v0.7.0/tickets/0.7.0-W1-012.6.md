## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
實作 `lib/history/parse/scan_stream_parser.dart`：位元組分段餵入（`addChunk`／`close`），逐行容錯解碼，依 `@@` 行數消耗 hunk，維護每個 `.md` 路徑全文，commit 結束時重算 frontmatter 範圍並輸出（路徑、前後 frontmatter 文字、created／deleted）；計數：無法解碼行、無法解析版本、失步、YAML 解析次數；追蹤文字量尖峰 `peakTrackedChars`。YAML 解析以可注入的 `parseCheck` 實作（預設 `loadYaml`），失敗時宣告凍結。日誌經 `logSink`（失步 warning、無法解析 debug）。空檔新增／刪除（git 不輸出 ---／+++）以 `diff --git` 行備援取路徑。
測資 helper：`test/helpers/history/synthetic_git_log.dart`（合成 log 與 frontmatter 行建構器，合併於單檔）。
測試：`test/unit/history/parse/scan_stream_parser_test.dart`（S-1～S-18、L-7）。真實 repo 實測：`test/performance/history_scan_real_repo_test.dart`（HISTORY_REAL_SCAN=1 才執行）。
不 import lib/corpus、lib/graph；輸入為位元組，不呼叫 Process。

- `dart analyze` 僅 2 則 info（prefer_initializing_formals、測試 helper 型別可見性）
