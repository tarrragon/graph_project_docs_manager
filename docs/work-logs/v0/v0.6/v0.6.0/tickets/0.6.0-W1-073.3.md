## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
Ticket 清單狀態改由最後完成輪次衍生（ticket_list_providers.dart）：ticketRowsOfRound 以 TicketDetail 取正常票 frontmatter（title 缺席/非字串為「—」，status/priority 非字串為 null，blockedBy 略過非字串元素），損壞票取 EVT-CORPUS-003 nodeType=Ticket（ID 取檔名、title 取檔名含副檔名）；ticketBaseStateOf 判 專案未就緒(reason 優先、無輪次=loading)/無 ticket/正常。ticketListStateProvider 仍是畫面操作唯一寫入點，故 TicketSearchDebouncer._apply 不需改（0.6.0-W3-124 注意事項已處理）；同專案新輪次只替換票列、保留模式/搜尋/篩選/排序，切換專案重置並清 ticketSearchInputProvider。
