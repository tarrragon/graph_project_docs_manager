### i18n 提案表（未改 SPEC-004、未改 ARB，由 072.1 同批加入）

| key | 參數 | zh | en |
|-----|------|----|----|
| gapIsolatedNode | nodeId, nodeType | {nodeType} {nodeId} 沒有任何關聯 | {nodeType} {nodeId} has no relations |
| gapMissingRequiredEdge | nodeId, edgeTypes | {nodeId} 缺少必要的關聯：{edgeTypes} | {nodeId} is missing a required relation: {edgeTypes} |

edgeTypes 為型別表鍵名原值，多值串接 zh「、」、en「, 」（比照 SPEC-001 v1.72 慣例）；EVT 的「或」語意文案是否要另一個 key（例：gapMissingRequiredEdgeAny）待定。

### 待 PM 確認項

1. 識別名：GraphDefectKind.isolatedNode、GraphDefectKind.missingRequiredEdge（規格內無命名依據，標為提案）
2. 同一 UC／EVT 為孤島時，孤島與缺必要邊是否都報（現寫兩者都報，標待確認）
3. 缺必要邊粒度：每條未滿足要求一筆（UC 至多三筆）
4. 上表 key 與 zh／en 文案；EVT「或」要求是否另立 key
5. 項目 id 中邊型清單以 `,` 串接為單一成分
