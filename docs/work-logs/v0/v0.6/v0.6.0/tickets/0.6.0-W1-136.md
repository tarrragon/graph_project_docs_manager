- `fakeRound({...})` 參數含 `nonDomainRead`、`graphOverride` 等，無主題檔讀取結果參數；`CorpusScanResult` 的 `topicFilesRead` 未傳入

- `fakeRound` 加選填參數（例：`TopicFilesReadResult? topicFilesRead`），傳入 `CorpusScanResult`；未傳時行為與現行一致

**紅燈步驟**
1. 先把 A2 改寫成呼叫 `fakeRound(topicFilesRead: ...)`，跑 gap_report_round_test 確認紅燈（參數不存在，編譯失敗）
