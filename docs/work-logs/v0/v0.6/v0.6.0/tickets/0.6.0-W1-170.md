### 實驗發現

- 用戶回報「測試全部通過」，涵蓋上述六步。
- 破洞項顯示的行號是否為 5 沒有逐項回報，涵蓋在「全部通過」之內。
- 驗證過程另得兩項 UI 回饋，都不影響本票驗收：
  1. 設定只能用快捷鍵開啟。UI 上應該有可見的「設定」入口，也應該有列出快捷鍵的「說明」頁，否則第一次使用的人不知道設定功能存在。
  2. 選了選項之後沒有回饋。用戶要求在元件庫 skill 討論：什麼情境要多一個確認按鈕，什麼情境可以直接關閉或給提示。
- 主控查證：SPEC-001 §9 定的入口是選單列「偏好設定…」，MainMenu.xib 的選單項標題卻是英文 Preferences…。另外，SPEC-003 §3.8 依 §2.13 判準 T2 定為「不顯示 SnackBar」。

## Solution
### 結論

070.2 的四項功能，實機驗證全數通過：
- ⌘, 開啟面板
- 只列出查得到 handler 的編輯器
- 開檔定位到行號，含中文與空白路徑
- 重啟後選擇仍保留
