## Solution
commit `f1be15e24d`，改了三個檔：

- `PC-GPD-003`
  - 症狀：改寫為平台檢查（不是專案 hook），附拒絕訊息原文。觸發條件寫成「多行內容或命令替換」加「`;` 串接」的組合。
  - L1 根因：改寫為「平台靜態檢查無法驗證組合結構」，明寫「含換行即拒」的理解不正確。
  - 觸發條件：補第 3 條（組合形態，以及 prompt 要求 `out=$(...); rc=$?` 時容易寫出這種形態），並新增〈觸發判準實測〉四形態表，註明尚未實測的形態。
  - 處置：代理人列補上「依拒絕訊息拆分屬 tool-selection 規則 2 例外」。
  - 預防：補「worktree 派發一律經 `ticket track dispatch --isolation worktree`」與「不要求串接 `echo rc`」。
  - 標題：改為「worktree 隔離檢查拒收多行內容加串接的 CLI 命令……」，檔名不變，避免既有路徑引用失效。
- `error-patterns/README.md` 索引列、`PC-GPD-038` 相關節：同步新標題。`.claude/scripts/tests/fixtures/` 下的兩份樣本是凍結測試資料，不改。

資料來源：0.6.0-W1-190〈重現實驗結果〉。
