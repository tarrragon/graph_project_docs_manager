## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
L49 派發前盤點（2026-11-02，main 含 079 riverpod 3 遷移）：
- blockedBy 0.1.0-W2-003 已完成；票面 where 的 `lib/screens/tickets/` 實際路徑為 `lib/screens/ticket_list/`。
- 現況：`ticket_list_screen.dart` 的 SearchField onChanged 直接 `update((s) => s.copyWith(searchQuery: value))`，寫入 `ticketListStateProvider`（legacy StateProvider<TicketListState>）；`visibleListTickets` 依 `state.searchQuery` 即時過濾；`Motion.searchDebounce` 目前無消費者；SearchField 不含 Timer（0.1.0-W3-105 裁示）。
- 範圍：在 provider／服務層加入防抖（輸入值與「生效的過濾詞」分離，過濾詞延遲 Motion.searchDebounce 才更新），清空輸入立即生效（SPEC-003 §3.4）。輸入框顯示值須即時反映輸入，不可因防抖延遲。
- 並行注意：L48 稍後會改 Ticket 清單畫面接真資料（0.6.0-W1-073 等），本票改動範圍限縮在搜尋防抖，避免擴大與 L48 的同檔衝突面。
- 測試：防抖時序以 fake async（`tester.pump(duration)`／fakeAsync）驅動，禁止真實計時斷言（test-assertion-design D1）。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
