## Problem Analysis
### 問題根因

票面前提需更正：同鏈偵測（0.4.1-W2-006）只實作在 `acceptance-gate-hook.py`，`phase4-decision-enforcement-hook.py` 完全沒有同鏈邏輯，不是清單漏了 add-exempt-marker。PreToolUse 在整串命令執行前觸發一次，本 hook 直接讀鏈前票檔判定延後語意與 exempt marker。

### 影響範圍

- 已驗證（hook 日誌）：0.6.0-W1-177 串接 add-exempt-marker 與 complete 時 blocked=1；拆開後 exempted=1 放行。
- 讀 code 推論、未實跑：append-log --replace 移除延後語句後同鏈 complete 同樣誤擋；同鏈 append-log 新增延後語句則本次漏判。
- 日誌每命令兩筆是 PreToolUse／PostToolUse 雙註冊，非重複觸發，不另立觀測。

### 框架問題兩條 AND 判準

1. 抽象可攜：任何 consumer 在同一 Bash 呼叫內先寫票再 complete 皆重現，與專案內容無關。成立。
2. 根源在 `.claude/` 通用資產：`.claude/hooks/phase4-decision-enforcement-hook.py`、`.claude/skills/ticket/hooks/acceptance-gate-hook.py`。成立。

### 相關 Error Pattern

PC-093（延後語意偵測的來源）；同族觀測 tarrragon/claude#54〈acceptance-gate 對同鏈 complete 子票→父票以鏈前狀態判定〉。

### 查重紀錄

`dedup --keywords add-exempt-marker 同鏈 phase4-decision-enforcement`。關係判定：#54 重複領域（hook 以鏈前狀態判定，已有 acceptance-gate 同族觀測），以 observe 附加；#55／#103 的 add-exempt-marker 命中為命令名列舉，引用關係不處置；其餘為全文雜訊。
