### 結論

commit dd88042472 已把四類註記改為現況，不改任何契約。

| 類別 | 現況 | 處置 |
|---|---|---|
| SPEC-004「provider 尚未建立」19 處 | 由 saffron 唯讀讀碼查證，逐處取得 provider 名稱與檔案 | 全數改為實際承載者。Ticket 清單沒有載入態；節點詳情的損壞外觀在 0.x 不可達（SPEC-001 §6，`1.0.0-W3-656`）。兩者都改寫為「不渲染」 |
| SPEC-005 §2.4、§2.5「實作尚未存在」 | 已讀 `loadRecentProjects`／`addRecentProject`／`saveRecentProjectCounts`／`probeRecentProject` 實作 | 14 列改為 Y／N。唯一的 N 是讀取損壞時的日誌：實作只記一筆 level 900，沒有原始例外與首個不符元素索引 |
| SPEC-005 §三 G-1、G-2 | 三個 adapter 內仍無日誌；原承接票 `0.1.0-W3-135` 已不在票庫 | 新建 `0.6.0-W1-192`（IMP P3）承接，承接欄改為該票 |
| SPEC-004 §6 執法承接 | PostEdit hook `dart-style-guardian-hook.py` 會攔下新增的八種原生元件直用；其餘列沒有工具執法 | 改寫為執法現況，並寫明「目前無承接」 |
