## Problem Analysis
### 問題根因

`async_resource_scanner.py`（dart-test-async-guardian，pre-test-scan hook 呼叫）以檔案層級字面比對判定：(a) 行含 `Duration(seconds: N)` 且 N>=5 而全檔無 `tearDown(` 即報 long_delay_no_cleanup；(b) 行含 `StreamController` 與 `broadcast()` 而全檔無 `.close(` 即報 stream_no_close。兩條規則都不看該資源實際是否被排程、由誰釋放。4 處 FAIL 皆為此規則的誤報，無真實洩漏。
