## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### 實作

- `.claude/settings.json` 新增 `statusLine`：shell 命令先讀 stdin，以 `CLAUDE_PROJECT_DIR`（缺席時 stdin 的 `workspace.project_dir`）定位 `statusline_lane.py`；主命令失敗（腳本缺席、目錄解析不出、非零結束碼）時，把同一份 stdin 交給 `~/.claude/settings.json` 的 `statusLine.command`。不含本機絕對路徑。
- 本專案 `.claude/settings.local.json` 的 `statusLine`（寫死絕對路徑）已移除（gitignored，不進 commit）。
- `statusline_lane.py` 未改：腳本內部的解析失敗本來就只省略前綴；本票補的是腳本外層（找不到腳本、程序崩潰）的退回。
- `references/session-naming.md` §6 改寫為預設啟用，含命令各環節的作法與理由表、以 `settings.local.json` 關閉或覆寫的兩種寫法（覆寫直呼腳本時不具退回保護，已註明）。
- SKILL 1.20.0 → 1.21.0，CHANGELOG 同步。
