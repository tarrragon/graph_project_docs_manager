### 2026-09-24：規劃波 Step 2（SPEC-006）

建立 `docs/spec/corpus/SPEC-006-corpus-parsing-and-gap-classification.md`（FR-01～07、NFR-01）。範圍涵蓋 Corpus（解析）與 Diagnostics（破洞分類）兩個 domain：依 domain-map §2，「這算不算破洞」要同時看解析結果與 carrier，歸 Diagnostics。本版非 UI，Step 2 的 UI 前置檢查不適用。

用戶裁決四項設計決策：

| # | 問題 | 裁決 |
|---|------|------|
| D1 | JSON 的 `carrier` 是人讀描述文字，App 無法比對 | 上游 schema 新增機器可比對的路徑模式欄位（`0.3.0-W1-080`，blockedBy W1-079） |
| D2 | 沒有 frontmatter 的檔案無法用 `id_pattern` 判型，carrier 重疊時（domain-map.md 同時符合 SPEC 與 DomainBundle）歸哪一型 | 具體度較高的模式優先；有 frontmatter 時仍以 `id_pattern` 判型 |
