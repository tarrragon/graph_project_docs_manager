## Solution
<!-- Schema[DOC/Solution]: 免填（DOC 類型以變更摘要取代）（.claude/pm-rules/ticket-body-schema.md） -->
〈Patch 生命週期〉Action 句改為兩種情況：有開放後繼→前移至最近者、不開新 patch；無開放後繼→依溢出算法登記 patch+1（品質類）或 minor+1（能力類，須 confirmed 提案，未定時暫登記 patch+1 並註明待提案）。runbook 入口 B 第 3 步同步改寫，驗收欄改為「check 的前移目標全部指向已登記版本」。

來源：另一專案接手 session 於入口 B 凍結前回報——該專案無任何已登記後繼、亦無下一 minor 提案，原句「不開下一個 patch」與同段引用的溢出算法（無後繼時算 patch+1）互斥。
