## Solution
<!-- Schema[DOC/Solution]: 免填（DOC 類型以變更摘要取代）（.claude/pm-rules/ticket-body-schema.md） -->
三處：入口 A 步驟 2 落差清單前加「查核範圍」（逐一指名納入的規格檔與章節，未納入者只能寫「未查核」不得寫「0 缺口」）；入口 B 第 1 步引用同步；「patch 的第一問」補「待形式化／草稿條款不構成已發布條款，其落差判溢出（先形式化再收斂）」。

來源：另一專案接手 session 發版前發現契約審查漏查一份規格、其中一條待形式化條款查無實作，版本條目卻寫「0 缺口」。
