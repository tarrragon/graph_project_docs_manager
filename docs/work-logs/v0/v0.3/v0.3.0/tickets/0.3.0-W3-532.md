## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
合入 commit 1b9c40add（merge 於 main）。實際改動 7 檔；where.files 所列 parse_failure_event_test.dart 不需修改（只用 factory 與事件欄位）。

- ParseOutcome 改 sealed class，六個 final 子類別（Available／NoFrontmatter／Unclosed／EmptyOrNotMap／YamlSyntaxError／Unreadable）；corpus_scanner 與 parse_failure_event 改用 pattern matching，4 個 lib 消費檔 0 個 `!`、0 個 throw。
- 非字串頂層鍵（YAML `true:`）歸入空或非 map，不再拋 TypeError；正向對照 `"true":` 為 available。
- frontmatter 遞迴轉為一般 Map/List 並以 `Map<String, dynamic>.unmodifiable` 包裝（含巢狀）；顯式型別參數避免推斷為 `UnmodifiableMapView<dynamic,dynamic>`。
- 設計偏離（主線程接受）：ParseResultKind 列舉保留，作為 ScanSummary.failureReasonCounts 的計數鍵；各子類別以非 null 的 `kind` getter 對應。列舉在此是分類標籤而非狀態載體，與 sealed class 不構成兩套 sum type。
