### 重現實驗（2026-09-29，in-situ 觀測＋原始碼追溯）

**觀測**：session 83 執行 `ticket track complete 0.3.1-W1-089.1 --as graph-project-docs-manager-83`，rc=0，輸出如下（逐字）：

```
[auto-commit] 隔離提交失敗（非致命，未留 staged 殘留）：提交範圍自我驗證失敗，預期 ['docs/work-logs/v0/v0.3/v0.3.1/tickets/0.3.1-W1-089.1.md', 'docs/work-logs/v0/v0.3/v0.3.1/v0.3.1-main.md'] 實得 ['docs/work-logs/v0/v0.3/v0.3.1/tickets/0.3.1-W1-089.1.md']
[OK] 已完成 0.3.1-W1-089.1
[WARNING] worklog 中找不到日期標題區段，跳過進度追加
```

**前提查證**：`docs/work-logs/v0/v0.3/v0.3.1/v0.3.1-main.md` 的標題只有 `# v0.3.1 版本工作日誌`、`## 前情提要`、`## 開發日誌`，沒有日期標題，所以追加必定跳過。

**因果鏈**（`lifecycle.py` 的 `complete()` 末段 → `git_ops.commit_files_isolated`）：
1. `append_worklog_progress(...)` 在找不到日期標題時印 WARNING 後 return，不寫檔。它回傳 None，呼叫端無從得知是否寫入。
2. `complete()` 仍無條件把 `_build_worklog_path_for_stage(version)` 加進 `modified_paths`。
3. `commit_files_isolated` 的自我驗證要求 `git diff --name-only` 的結果**等於** `deduped`；工作日誌沒有變更，不相等 → `failed`，整個提交放棄，連票 md 也沒提交。

**同一路徑的其他觸發條件**：工作日誌檔不存在、冪等跳過（該票的完成行已存在）。三者都是「沒有寫入，卻仍被列入提交範圍」。

**尚未做**：受控重現（在 fixture 中讓工作日誌無日期標題，再跑 complete）。由實作者以 RED 測試完成。

### 預期變更

**修法方向**（候選 a，已選）：`append_worklog_progress` 回傳 bool（True＝本次確實寫入）；`complete()` 只在回傳 True 時把工作日誌路徑加進 `modified_paths`。

**未採候選 b**：放寬 `commit_files_isolated` 的自我驗證，改為「實際變更 ⊆ 預期」。不採的理由：自我驗證是隔離提交三要件之一，放寬會影響所有呼叫端，射程遠大於本缺陷。

| 既有測試 | 預期 | 理由 |
|---|---|---|
| `tests/test_complete_auto_stage.py::test_complete_commits_ticket_and_worklog` | 不變（綠），但靠巧合 | 該檔以不帶 return_value 的 `patch(...append_worklog_progress)` 替身，回傳 MagicMock（truthy），會走「有寫入」分支。**應改為明示 `return_value=True`**，並新增 `return_value=False` 的對照案 |
| `tests/test_complete_auto_stage.py` 其餘 | 不變 | — |
| `ticket_system/tests/test_complete_auto_commit.py` | 不變 | 測的是 `_auto_commit_completion_files`，不經過 complete 的路徑組裝 |
| `ticket_system/tests/test_worklog_appender_idempotent.py`／`_concurrency.py` | 不變 | 未斷言回傳值；回傳型別由 None 改為 bool，對既有呼叫端無影響（lifecycle 以外若有其他呼叫端，一併 grep 確認） |
| `tests/test_track_lifecycle.py`、`tests/test_track_complete_body_sync.py`、`ticket_system/tests/test_track_batch.py` | 不變（待實測確認） | 引用了 `append_worklog_progress`，但未見對提交路徑的斷言 |

**新增測試**（E1 對照）：同一 fixture，append 回傳 True／False 各跑一次，斷言提交路徑一個含工作日誌、一個不含。另加一個 appender 單元測試：無日期標題的工作日誌回傳 False 且檔案內容不變。

**驗收命令注意**：部分相關測試在 `.claude/skills/ticket/ticket_system/tests/`，pytest 兩個目錄都要跑。
