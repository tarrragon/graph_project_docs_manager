## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 預期變更

- **預期會變**：`macos/Runner/AppDelegate.swift` 的 `didReceive`（新增 unhide／activate 與 NSLog）；`scan_notification_controller.dart` 的 `_onActivated` 與 `gap_report_screen.dart` 的定位消費點新增日誌；SPEC-003 §2.2「點擊通知的導向」列文字；新增日誌事件的 widget 測試。
- **預期不變**：既有點擊導向 fake 測試的斷言（切頁至 gaps、`returnToProvider` 為 null、定位 rect 交集、`Focus.hasFocus`）全部維持綠燈且不改斷言；`ScanNotifier` 介面不變；其餘既有測試不預期變紅。
- **若有既有測試變紅**：停手寫 NeedsContext，不改既有斷言（因為那代表行為改變，超出本票「前景化＋日誌」範圍）。

### 驗證方式（用戶裁示 2026-09-29）

非權限類行為一律以測試或日誌查詢機械驗證，不倚賴人工目視。權限相關的平台事實已由 0.3.1-W1-028 實機量完。本票的原生前景化以 NSLog 前後狀態為證據；若需實機確認，以腳本觸發並以 `log show --predicate 'process == "graph_project_docs_manager"'` 查 NSLog，不需人工觀察畫面。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->

修改摘要：AppDelegate didReceive 轉送 onActivated 前 NSApp.unhide＋activate，NSLog 記錄前後 isHidden/isActive；scan_notification_controller.dart 新增可注入的 clickPathLogSink 與 click-path: 事件（activated / navigate / locate-set 或 locate-skip），gap_report_screen.dart 補 locate-scroll / locate-focus；SPEC-003 §2.2 點擊導向列改寫並列日誌事件；新增 widget 測試斷言事件順序。
