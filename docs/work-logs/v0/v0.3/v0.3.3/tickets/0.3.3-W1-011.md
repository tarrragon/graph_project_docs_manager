### 呼叫點分類表（Explore 代理人唯讀盤點，2026-09-29；PM 覆核）

分類定義：
- (a) 非 ASCII 路徑會改變結果，需修。
- (a0) 只與固定 ASCII 名稱比對（如 "CHANGELOG.md"），跳脫後的路徑本來就比不中，結果不變，不需修。
- (b) 只判空、計行數、讀狀態欄或只作顯示。
- (n) 非實際呼叫：註解、docstring、訊息文字、argparse 旗標，以及 `worktree list --porcelain`（該命令不套 quotepath）。
- 「間接」：經 `.claude/lib/git_utils.get_uncommitted_files()` 取得，其內部為 `status --porcelain`。
- 部分既有程式碼的 `.strip('"')` 只去掉引號，八進位跳脫仍在，對 CJK 無效。

盤點範圍：146 行候選之外，另以 grep 補出 3 處直接呼叫與 13 處間接呼叫者。全框架只有 context-signals.mjs 的 :102 已加 `-c core.quotepath=false`，沒有任何一處使用 -z。

#### 拆票計畫
- **共用修正點**：`.claude/lib/git_utils.run_git_command` 與 `.claude/lib/hook_io.run_git` 加 `-c core.quotepath=false`，即可覆蓋所有間接列，以及經這兩個函式呼叫 git 的 hook。其餘直接呼叫 subprocess 的地方逐處修。
- **`quotepath=false` 的覆蓋邊界**：只停止跳脫非 ASCII 位元組；含 `"`、`\`、tab 或換行的路徑仍會被加引號。直接解析路徑清單且改得動的地方，優先改用 -z。
  - `status --porcelain -z` 的 rename 以 `new\0old` 表示。
- **子票**：每張不超過 5 個實作檔，各帶 CJK fixture 的 E2 對照。
  1. `.claude/lib` 共用層：git_utils.py、hook_io.py、skill_case_guard.py。一併驗證 worktree skill 的兩處間接列，以及 ticket 經由該 lib 的呼叫已被覆蓋。
  2. ticket skill：git_ops.py（兩處同批）、track_commit.py、ticket_builder.py、ticket-md-auto-commit-hook.py，以及 track_activity.py、lease.py 中未被第 1 張覆蓋者。
  3. 提交守衛：commit-stage-guard-gate-hook.py、git-ref-transaction-content-guard.py、bare-commit-guard-hook.py、hooks-test-gate-hook.py。因與 0.3.3-W1-012 同改 bare-commit-guard，排在它之後。
  4. 其他 hook：parallel-dispatch-verification、skill-cli-sync-check、variable-count-literal-guard、session-start-gitignore-check、experiment_artifact_checker。commit-msg-layer2 經 hook_io，由第 1 張覆蓋，在第 4 張驗證。
  5. scripts 與其他 skill：version_release.py、sync-claude-push.py、sync-claude-pull.py、skill-sync cli.py、context-signals.mjs。
