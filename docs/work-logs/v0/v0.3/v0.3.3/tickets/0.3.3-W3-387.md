### 掃描清單（SPEC-004 第 4 章 42 條「最小尺寸」× 實作內距）

掃描方式：唯讀代理人逐條讀對應 `lib/components/*.dart` 的 `Padding`／`EdgeInsets`，主線程抽查 5 條判漏計者（`nav_item.dart`、`project_switcher_entry.dart`、`recent_project_item.dart`、`document_body.dart`、`app_table_row.dart` 的 `EdgeInsets` 行）確認。

| 條目 | 實作自身內距 | 判定 |
|------|------------|------|
| 4.1 AppText、4.2 AppIcon、4.3 Divider、4.11 PageTitle、4.14 TableColumnHeader、4.17 StepNumber、4.18 ExpanderIcon | 無 | 已涵蓋 |
| 4.4 AppButton、4.6 IssueMarker、4.10 SegmentedControl、4.13 FilterDropdown | 有，但最小尺寸以 `hitTargetMin` 為下界，內距在下界內 | 已涵蓋 |
| 4.5 Badge、4.12 SearchField、4.16 SwimlaneNode、4.19 RelationItem | 內距已在公式（`Space.sm`／`Space.xxs`／`Space.xs`） | 已涵蓋 |
| 4.15 MatrixCell、4.37 MatrixGrid、4.38 SwimlaneGrid | 格內距由容器承載，最小尺寸以固定欄寬／列高 token 表達 | 已涵蓋 |
| 4.21–4.25（EmptyState 系、LoadingState、LoadPrompt）、4.26 AppSnackBar | 公式已含 `2 × Space.sm`／「內距」或以 `ButtonRow` 最小寬為界 | 已涵蓋 |
| 4.27 AppShell、4.28 PageColumn、4.29 SplitRow（1.52 已修）、4.30 Panel、4.31 TwoColumnLayout、4.32 Toolbar、4.33 BadgeRow、4.34 ButtonRow、4.40 ListRow、4.41 Section、4.42 SwitcherOverlay | 公式已含自身內距或以視窗／固定寬定義 | 已涵蓋 |
| **4.7 NavItem** | 水平 `Space.md`（`EdgeInsets.symmetric(horizontal: Space.md, vertical: Space.sm)`） | **漏計寬 → 補 2 × `Space.md`** |
| **4.8 ProjectSwitcherEntry** | `EdgeInsets.all(Space.sm)` | **漏計寬 → 補 2 × `Space.sm`**（原式 2 × `Space.sm` 為內部兩個間距，已註明） |
| **4.9 RecentProjectItem** | `EdgeInsets.symmetric(horizontal: Space.sm, vertical: Space.sm)` | **漏計寬 → 補 2 × `Space.sm`**（高已含） |
| **4.20 DocumentBody** | `EdgeInsets.all(Space.xs)` | **漏計寬高 → 各補 2 × `Space.xs`** |
| **4.35 TableRow** | 整列 `EdgeInsets.symmetric(horizontal: Space.sm)` | **漏計寬 → 補 2 × `Space.sm`**（5.9 空間不足策略原本已含 + 2 × `Space.sm`，兩處因此對齊） |
| 4.36 DataTable、4.39 Tree | 以名稱引用 `TableRow`／`ListRow.tree` 最小寬 | 隨 4.35 生效／4.40 未變 |

### 容器上限公式複核

- 5.1 `AppShell` 空間不足策略：只引用 `ProjectSwitcherEntry` 高、`NavItem` 高——高未變，不受影響。
- 5.5 `TwoColumnLayout`：主欄最小寬原寫「§6：`DocumentBody` 一字元」（展開值）→ 改為引用 4.20 最小寬。
- 5.9 `TableRow`：已含 + 2 × `Space.sm`，與修正後 4.35 一致。
- 5.13 `Tree`：引用 `ListRow.tree` 最小寬（4.40 已涵蓋），不受影響。
- SwitcherOverlay 捲動觸發條件：引用 `RecentProjectItem` 高（高未變），不受影響。
