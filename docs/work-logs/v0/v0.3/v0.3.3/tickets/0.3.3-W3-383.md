### 做法定案與現況（主線程，2026-09-29）

- 矩陣內容來自 App 內建 `lib/screens/domain_view/domain_view_fixtures.dart`，工作資料夾只決定 gate 偵測結果；`test/fixtures/corpus` 五個專案皆不含 `.claude/`（corpus README 定案），gate 一律判 `DomainNotFramework`。故 e1 改採候選 (a)：`DocsManagerApp(repository: <WorkspaceReady 替身>)` + `frameworkSignalProbeProvider` 替身（VERSION 存在、json 存在、json 版本等於內建版本），gate 判 `DomainReady`（矩陣）。
- 注入方式：`_pumpAppAndCollectErrors` 外層 `ProviderScope` 加 `overrides`（`frameworkSignalProbeProvider`）；repository 走 W3-379 已接線的 `DocsManagerApp.repository`。替身的版本字串**不得寫死**，取 `builtinSchemaVersionProvider` 同源值（asset `assets/schema/builtin_schema_version.json`），避免內建版本升級時測試假紅。
- WorkspaceReady 路徑任意（替身不讀磁碟）；以明顯非真實路徑表示（例如 `/fixture/ready-project`）。

### 本測試不涵蓋真實磁碟上的 gate 偵測（acceptance 3）

承擔覆蓋的既有測試：
- gate 判定邏輯：`test/unit/screens/domain_view/gate_detection_notifier_test.dart`（七種訊號組合 → 四種狀態）、`test/integration/gate_manifest_test.dart`（17 列凍結 manifest + 2 邊界案例）。兩者皆以 mock `FrameworkSignalProbePort` 驅動。
- 磁碟讀取：`test/unit/workspace/framework_signal_probe_test.dart` 僅涵蓋 `DefaultFrameworkSignalProbe.readSchemaJsonVersion`（暫存目錄實檔）；`readVersion`、`schemaJsonExists` 無磁碟測試（新發現，已回報 e1）。
