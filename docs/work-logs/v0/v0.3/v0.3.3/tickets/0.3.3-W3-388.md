## Problem Analysis
<!-- Schema[ANA/Problem Analysis]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 現況（主線程，2026-09-29，W1-006 焦點分組已合併 main 79a53c9ec）

- autofocus 來源（grep lib 全檔三處）：`lib/components/matrix_grid.dart` `Focus(autofocus: true, onKeyEvent: _handleKey)`——`_handleKey` 只處理 Esc（有選格時清除選取，SPEC-003 §2.10 Esc 列、SPEC-004 4.37），autofocus 的作用是讓 Esc 不需先點選即生效（建立於 0.1.0-W1-005.39）；另兩處 `switcher_overlay.dart`、`filter_dropdown.dart` 屬浮層／選單展開時的焦點移入，與啟動無關。
- W1-006 分組後的 Tab 走訪：`OrderedTraversalPolicy`，側欄（入口 + 六導覽項）為順位 0、主區為順位 1。
- 啟動狀態依使用者而異：新使用者（Unset）落 `state-domain-unset`，無 MatrixGrid、無 autofocus；已記住資料夾者落 `state-domain-matrix`，MatrixGrid 取得初始焦點。

### 待量測（唯讀拋棄式測試，派代理人）

分組後兩種啟動狀態（Unset、DomainReady 矩陣）各記錄：
1. 啟動後 primaryFocus（無則記 null）。
2. 連按 Tab 20 次的停留序列（每步：祖先第一個 Key、所屬區段 側欄／主區）。
3. 連按 Shift+Tab 5 次的停留序列。
4. 自啟動起需按幾次 Tab 才抵達專案切換入口。

## Solution
<!-- Schema[ANA/Solution]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 量測結果（分組後，唯讀拋棄式 widget 測試，未提交）

| 啟動狀態 | 啟動 primaryFocus | 首次 Tab | 抵達專案切換入口所需 Tab 數 | 走訪形態 |
|---------|------------------|---------|------------------------|---------|
| Unset（新使用者） | 路由層 `_ModalScopeState` FocusScope（不在任何可操作元件上） | `project-switcher-entry` | 1 | 入口 → 六導覽項 → 主區（1 站：選擇資料夾鈕）→ 循環 |
| DomainReady 矩陣（已記住資料夾） | `MatrixGrid` 的 `Focus`（祖先 `state-domain-matrix`，主區） | `action-domain-select-workspace` | 14 | 主區其餘 13 站（4 個 domain 列首鈕 + 各列 UC 格）→ 入口 → 六導覽項 → 主區頁首起始 |

要點：矩陣啟動時使用者從主區中段起步，需先走完主區剩餘 13 站才到側欄；Unset 啟動時第一次 Tab 即入口，符合 §2.10 三區段順序。

### 候選（對鍵盤使用者的影響）

| 候選 | 啟動焦點 | 鍵盤使用者可見效果 | Esc 清除選格（SPEC-003 §2.10） | macOS 慣例 |
|------|---------|------------------|-------------------------------|-----------|
| A 維持 MatrixGrid autofocus | 矩陣（主區） | 矩陣啟動時首次 Tab 在主區中段，14 次才到入口；Unset 啟動不受影響（兩種狀態行為不一致） | 不需先點選即生效（autofocus 的原始用途） | 文件型 App 常把焦點給主內容 |
| B 啟動焦點落在專案切換入口 | 入口（側欄首站），有焦點環 | 兩種狀態一致：首次 Tab 即第一個導覽項，符合 §2.10 起點；啟動時畫面上即出現入口焦點環 | 需先點選或 Tab 進矩陣後才生效（點選格即取得焦點） | 視窗首個控制項取得焦點屬常見預設 |
| C 啟動焦點落在第一個導覽項（nav-item-domain） | 導覽項，有焦點環 | 與 B 相近，但入口需 Shift+Tab 才到 | 同 B | 側欄型 App（如設定程式）常見 |
| D 移除 autofocus，不指定啟動焦點 | 路由 FocusScope（無可見焦點環） | 兩種狀態一致：首次 Tab 即入口（與 Unset 現況相同）；啟動時畫面無焦點環 | 同 B | macOS 預設（「鍵盤導覽」關閉時多數 App 啟動不顯示焦點環） |

B／C／D 皆需修改 `lib/components/matrix_grid.dart` 的 autofocus；Esc 清除選格的前提由「矩陣持有焦點」改為「使用者已與矩陣互動」，須確認 SPEC-003 §2.10 Esc 列的觸發條件寫法（「矩陣已選格時按 Esc」隱含焦點在矩陣內；選格本身來自點擊，點擊即取得焦點，D 下行為可成立，待實作票驗證）。
