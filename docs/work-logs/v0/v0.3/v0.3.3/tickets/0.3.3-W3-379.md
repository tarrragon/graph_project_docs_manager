## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因（主線程獨立重驗，2026-09-29，main 0820b7436）

- `lib/main.dart` `DocsManagerApp` 宣告 `repository` 參數但 build() 全未使用。
- `workspaceRepositoryProvider`（`lib/screens/project_switcher/project_switcher_overlay.dart`）的讀取點：`lib/app/shell.dart` `_restoreWorkspaceAndDetect`、浮層三處。皆 `ref.read(workspaceRepositoryProvider)`，取到的一律是真實 `WorkspaceRepository()`。
- 傳 `repository:` 的呼叫點只有 `integration_test/app_test.dart` 的 `_pumpAppAndCollectErrors`（預設 `_StubWorkspaceRepository(WorkspaceUnset())`，「工作資料夾狀態」群組傳三種 state）。
- `test/helpers/pump_harness.dart` `pumpApp` 只傳 `locale`，不傳 `repository`；test/ 內無其他 `DocsManagerApp(` 呼叫點。

### 執行者 UserDefaults 現況（量測環境：本機，bundle id com.example.graphProjectDocsManager）

- `flutter.workspace.path` = 本專案 repo 根目錄；`flutter.workspace.recentProjects` sha256 前 16 碼 `af1816256cc1a39a`。
- 推論：integration_test 目前 10 則 pump App 的測試，實際都在「真實 restore → WorkspaceReady(本 repo) → gate 偵測」前提下執行，替身 state 全數未生效。
