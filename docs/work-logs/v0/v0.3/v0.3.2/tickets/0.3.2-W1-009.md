## Problem Analysis

### Context Bundle（PM 2026-09-29）

- 規格值：SPEC-004 v1.50 §4.0.6〈1.38 新增〉表 `folderUnavailableMessage`：zh `資料夾無法使用：{reason}`、en `Folder unavailable: {reason}`，placeholder `reason`（String，取 `WorkspaceUnavailable.reason`）。
- M1 核對（PM）：「資料夾無法使用」屬結果陳述，沒有操作指引，也沒有技術細節；`reason` 依 `workspace_types.dart` 的契約只取固定文案常數。**符合 M1，不需改規格值**。
- 呼叫點：`project_switcher_overlay.dart` 的 `_handleChosenState`，`WorkspaceUnavailable(:final reason)` 分支。選擇其他資料夾與點最近專案項兩個入口共用這一段。
- 不動的部分：`main.dart` 的 `_WorkspaceBanner` 是啟動時 restore 的路徑，它用 `workspaceUnavailable(reason)`，這是正確用法。

### 版本契約預期

| 類別 | 預期 |
|---|---|
| 預期變紅 | 無（e1 已核對：沒有斷言 `workspaceUnavailable` 文案的既有測試） |
| 預期新增 | 選定的資料夾不可用時，顯示 `folderUnavailableMessage` 帶入 reason 的值；restore 路徑仍顯示 `workspaceUnavailable`，作為正向對照 |
| 預期改變的值 | 浮層內選定的資料夾不可用時，文案由「無法存取先前的資料夾：{reason}」改為「資料夾無法使用：{reason}」 |
| 預期不變 | gen-l10n 沒有 untranslated；測試總數不低於 1762 |
