## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
實作 commit 3f82fb76b。
argv 對應規則：python3 - a b 時 argv=['-','a','b']；python3 -c CODE a b 時 argv=['-c','a','b']；其間直譯器選項（-u、-I、-B）略過；跑腳本檔、-m 形態不處理。引數以 365.2 的 _expand_vars 用同命令內賦值展開，經 _python_argv 傳入 _ast_write_targets；ast 端 _const_path 新增 sys.argv[n]（直接作目標、p=sys.argv[n] 後使用、os.path.join、Path()/ 皆經既有常數追蹤）。索引超出、argv[0] 皆不構成受限路徑。
$W 判定：同命令內 W=lib/sub 後 python3 - "$W" heredoc 以 sys.argv[1] 寫入，E2 證明 deny。$W 未在同命令內賦值（來自前一個 Bash 呼叫環境）時候選為 "$W"，落在 unresolvable 放行並記入 skipped；此為本票固有邊界，不 fail-closed。
文件反查（skills、references、pm-rules 的 .md）：sys.argv 命中 skill-design-guide SKILL.md、frontmatter-and-description.md、compositional-writing SKILL.md 三處，皆為 open(sys.argv[n]) 唯讀；無以 python heredoc/-c argv 寫受限目錄的例行範例。結果：無。
