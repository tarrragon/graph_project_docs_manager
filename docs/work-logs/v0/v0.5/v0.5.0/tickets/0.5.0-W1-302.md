## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
修改 .claude/lib/ticket_command_parse.py 的 _substitution_masks：新增 depth 參數與 _matching_close；遇到 depth 0 的子 shell 左括號（前一 token 不以 $ 結尾）時，取配對右括號之間的內層 token 遞迴套用同一判斷，內層為 True 即整體 True。超過 _MAX_SCAN_NESTING 時保守回 True；未閉合括號視內層為至尾端。(a; ticket ...) 原本即由 _masked_in_tokens 判為 True；缺口只在 (echo $(...))。is_bash_success 與 hook 未動。

### 自檢結果
- 誤判方向：新增路徑只會把 False 轉 True，不會把遮蔽轉成未遮蔽。
- E2 對照 (ticket track complete X)、(out=$(ticket track complete X))、((...))、(A) && (B) 皆維持 False。
- 無法解析仍由 _is_masked 回 None，未改。
