- **單份派發，不作成對實驗 pair-2**：盤點顯示 App 端已用小寫字面，本票實質是 docs 字面改寫，兩份實作的差異會很小，鑑別力不足。pair-2 留給有 lib 實作量的 Layout 票。

- **全套 flutter test 一律加 `< /dev/null`**；驗收 analyze、全套、integration，加跑 doc CLI 對 usecases 的驗證，記 rc。
