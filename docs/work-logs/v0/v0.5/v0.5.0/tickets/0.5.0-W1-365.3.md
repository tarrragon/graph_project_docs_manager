## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
抽取規則（皆在命令字位置才生效，避免 uv tool install 之類子命令誤判）：dd 取 of=；install 取最後引數或 -t，-d 時全部位置參數；truncate/touch 取扣除 -s/-r/-t/-d 引數後的位置參數；ln 同 cp（最後引數或 -t）；rsync 取最後位置參數（>=2 個，來源不收）；tar 僅 -x/--extract/舊式 x 模式字時取 -C/--directory；patch 取目標檔（有 -d 則合併 DIR/檔）、-o 輸出檔、僅 -d，--dry-run 不收；awk/gawk 僅 -i inplace 時取程式文字之後的檔案引數（略過 var=val）；ruby/perl 以 regex 抽 File.write/binwrite("字面") 與 File.open("字面","w|a")。touch 豁免沿用 _EXEMPT_CLAUDE_ENTRIES（.zhtw-mcp-skip 放行有測試）。
