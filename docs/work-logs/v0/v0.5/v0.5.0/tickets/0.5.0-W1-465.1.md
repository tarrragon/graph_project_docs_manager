## Solution

### 雜訊底線與採用容差

同一 fixture（original，zh+en）以 `fvm flutter test integration_test/research/ux_capture.dart -d macos` 連續擷取 5 次（前景、run-with-timeout 600），5 次 PNG sha256 逐字相同（zh 8c3e8961…、en d0ae2e43…）；pixel_diff 以 tol 0 比對第 1 次與第 5 次 zh，結果 skip=true、零差異區塊。實測雜訊底線：逐通道最大差 0。採用容差 DEFAULT_CHANNEL_TOL=2（實測底線 0 + 餘裕 2，吸收跨機器抗鋸齒；以逐通道差 > tol 判差異，不比雜湊）。

### 行為

- pixel_diff：差異像素聚成 16px 區塊，8 鄰域連通分量取外接矩形；每區塊輸出基準圖/新圖同位置裁切對（外擴 8px）；無差異回傳 skip（免看）；尺寸不同視為整圖差異。CLI 差異時 exit 1。
- geometry_check：非父子（含祖孫）矩形重疊（面積 > 0，邊相接不算）與超出 logicalSize 的元件。實拍 zh.coords.json 可執行，報出 466.2 已知的捲動區過報重疊（17 與 73/74 等）。

### 與 466.2 座標檔格式的缺口

466.2 座標檔的 elements 無父子欄位。geometry_check 讀選填 `parent`（父元素 index），缺欄時所有成對皆視為非父子，會對巢狀可互動元件（如按鈕內 InkResponse 若矩形不同）報重疊。座標檔又已與視口取交集，超出視口檢查對現行檔案恆為空；該兩點需 466.2.1 或後續在座標檔補 `parent` 與未裁切矩形（unclippedRect）才完整，本票未改 466.2 的產生器。
