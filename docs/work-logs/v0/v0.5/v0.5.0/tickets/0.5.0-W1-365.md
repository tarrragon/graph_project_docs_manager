### 設計輸入：373 繞過實例的重現（PM，2026-10-19）

以 PreToolUse payload 直餵已部署守衛（c402324b3 之後的 main），目標 .claude/skills/worktree/scripts/zz_probe.py：

| 案例 | cwd | 命令形態 | 結果 |
|---|---|---|---|
| A | worktree | python heredoc，open('<相對路徑>','w') | DENY |
| B | 主 checkout | python heredoc，open('<sibling worktree 絕對路徑>','w') | ALLOW |
| C | worktree | python heredoc，p = Path('<相對路徑>'); p.write_text(...) | ALLOW |
| D | worktree | python heredoc，p = '<相對路徑>'; open(p,'w') | ALLOW |
| E | 主 checkout | echo x > <sibling worktree 絕對路徑> | ALLOW |
| F | worktree | echo x > <相對路徑> | DENY |

判定：heredoc 正文的 open() 字面路徑有涵蓋（A），假說 (a) 只在路徑經變數傳遞時成立（C、D），屬本票的剩餘寫法，納入盤點表。B、E 是範圍缺口（假說 b），不屬本票，已開 0.5.0-W1-377（P0）。

補充（PM，2026-10-19，377 覆核）：payload cwd 不在任何 checkout 內時（例如 cwd 為暫存區），377 的同 repo 判定沒有比對基準，以絕對路徑寫入 repo 的 lib/、test/、.claude/** 仍放行（修前亦放行）。納入本票盤點；可考慮以 CLAUDE_PROJECT_DIR 所屬 repo 作為 cwd 無 checkout 時的比對基準。
補充（PM，2026-10-19，366 覆核）：366 的判定日誌只有分支級 reason（no_boundary_violation／subagent_no_scope_hit），候選路徑在掃描函式內因「範圍外」或「動態路徑無法靜態解析」被跳過時沒有獨立 reason。本票盤點動態路徑寫法時，評估讓掃描函式回傳逐候選的跳過原因（例如 unresolvable_target），使 fail-open 放行在日誌上可與「無寫入目標」區分。

### 分類

判準：代理人實際用過（已知實例：cat >> heredoc、python heredoc 以變數持有路徑後 write_text，見 0.5.0-W1-373、338.2.5）× 補偵測成本 × 誤擋風險。本守衛定位為防誤用層，不是對抗層。

| 寫法 | 分類 | 理由 | 承接 |
|---|---|---|---|
| python 內嵌腳本以變數持有字面路徑（p='lib/x'; open(p,'w')、Path('lib/x').write_text、字串串接、os.path.join 常數） | 補偵測 | 已知實際繞過的主要形態；以 ast 追蹤常數賦值與寫入呼叫，誤擋低 | 子票 A（P1） |
| bash -c／sh -c／zsh -c、eval 的字面字串參數 | 補偵測 | 票面出現頻繁；沿用 heredoc 正文遞迴解析，成本低 | 子票 B |
| 同命令內 VAR=字面 賦值後 $VAR 作目標；~、$HOME、$(pwd)、`pwd` 前綴 | 補偵測 | 可靜態展開，成本低 | 子票 B |
| cwd 不在任何 checkout 時以絕對路徑寫入 repo | 補偵測 | 以 CLAUDE_PROJECT_DIR 所屬 repo 作比對基準即可，成本低 | 子票 B |
| 逐候選跳過原因（範圍外、無法靜態解析）未入判定日誌 | 補偵測（可觀測性） | 使 fail-open 放行可與無目標區分，改同一函式 | 子票 B |
| dd of=、install、truncate、ln／ln -s、rsync、tar -x -C、patch、awk -i inplace、touch、ruby／perl -e File.write 字面 | 補偵測 | 逐命令抽取目標引數，誤擋低；頻度低但成本低 | 子票 C（P2） |
| 先寫腳本檔再執行（python3 /tmp/x.py、bash /tmp/x.sh） | 殘留風險 | 命令文字不含目標；讀取任意腳本檔會擴大 hook 的檔案 I/O 與熱路徑延遲，且屬刻意兩步驟，超出防誤用定位；366 判定日誌會記下 cmd，可事後稽核 | 無需建票：靜態解析固有邊界 |
| 執行期才決定的路徑（迴圈變數、glob、os.walk、外部輸入、eval 動態字串） | 殘留風險 | 靜態解析不可解：值只在執行時存在 | 無需建票：靜態解析固有邊界 |
