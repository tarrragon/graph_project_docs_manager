## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
判定方法：pull 候選（local==base、remote 動過）且非 suspect_revert 時，clone 發佈庫（blobless/no-checkout）取 ls-tree 的 blob sha；成立條件三項皆須滿足：遠端有本地沒有的檔、本地每檔與遠端 blob 相同（git hash-object）、遠端多出的每個檔在本地 git log --diff-filter=D 有刪除紀錄。成立則 direction=push_prune，報告列 [SHOULD PUSH --PRUNE] 與 skill-sync push NAME --prune。
失敗退回：任何例外（git 不可用、不在倉庫、clone 失敗）寫 stderr 一行並維持 pull。
紅轉綠：test_status_report_suggests_push_prune_when_remote_extra_was_deleted_locally（修前 direction=pull）；E1 對照 test_status_report_still_suggests_pull_when_remote_added_new_file；退回 test_status_report_falls_back_to_pull_and_logs_when_history_unreadable。DivergedSkill 契約測試補 push_prune_command 欄位。
版號 1.24.4 -> 1.25.0（SKILL.md、CHANGELOG、pyproject.toml，uv.lock 由 uv 自動重算）。
Phase 4：重構需要=否；技術債務=無新增；品質=A；結論：新增 helper 皆單一職責。
