## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 派發 context（PM 89，2026-10-13）

**範圍來源**：父票盤點表已由 0.5.0-W1-164.6 補正（該票 Problem Analysis 的呼叫點表）。本票只處理原列的三個檔；差集的另外三檔由 0.5.0-W1-164.6.1 承接，不在本票。

**本票的呼叫點**（以 164.6 盤點為準，接手者仍須自行核對）

| 檔案 | 函式 | git 子命令 | 備註 |
|------|------|-----------|------|
| .claude/hooks/confabulation-audit-hook.py | check_dirty_worktree（經該檔的 run_command） | status --porcelain | 會取 optional lock |
| .claude/skills/worktree/hooks/worktree-commit-before-dispatch-hook.py | main | diff --name-only、diff --staged --name-only | 工作樹側 diff 會取 optional lock |
| .claude/hooks/tracking-schema-json-staleness-guard-hook.py | get_staged_files | diff --cached --name-only | 164.6 判為低風險（依 git 文件推論，未實測）；為慣例一致仍補上 |

**做法**
- 旗標為 git 的全域選項，置於子命令之前；與 -C 並用時寫作 git -C <path> --no-optional-locks <子命令>。
- 既有先例：.claude/lib/git_utils 的 run_git_command 固定帶此旗標。能改走該 helper 且不改變呼叫端行為者可改走，否則就地補旗標；不要為此重構呼叫端的錯誤處理。
- 本票不處理逾時終止方式與逾時日誌（屬 0.5.0-W1-164.6.2）。

**測試要求**
- 每個呼叫點有一則測試，斷言實際送出的 argv 含該旗標且位於子命令之前；先寫測試並確認修改前為紅，再實作。
- 驗收第二項「唯讀 git 慣例有測試或規範承載」以測試承載：測試須在旗標被移除時翻紅。
- 只跑這三個 hook 各自的測試檔，不跑全套件。跑測試前先看 uptime 並把 load 記進 Test Results。

**預期效果的界線**：0.5.0-W1-164.6 的重現實驗中，git status 被終止 42 次、留鎖 0 次，正向對照未成立。本票的目的是降低取鎖面與統一慣例，不應在 Solution 宣稱可消除殘留鎖。

**避開**：.claude/hooks/post-test-hook.py、orphan-test-procs.py 與兩者的測試（另一 session 正在修改）；不得以 --kill 執行 orphan-test-procs.py；不動任何 worktree、分支或 index.lock。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
三處皆就地補旗標（置於子命令前），未改走 helper：各檔以 subprocess.run 或自有 run_command 呼叫，改走 git_utils 會變動錯誤處理與逾時語意，超出票面範圍。
- confabulation-audit-hook.py check_dirty_worktree：git --no-optional-locks status --porcelain
- tracking-schema-json-staleness-guard-hook.py get_staged_files：git --no-optional-locks diff --cached --name-only
- worktree-commit-before-dispatch-hook.py main：工作樹側兩個 diff（--name-only、--staged --name-only）。同檔 origin/main..main 的 diff 與 rev-list 只比對 ref、不在票面呼叫點表，未動。
效果界線：降低取鎖面與統一慣例，不宣稱可消除殘留鎖。
commit：394f6b057（hooks，ticket track commit）、909db4b96（tests，精確 add + 裸 commit；測試檔不在 where.files，ticket track commit 拒絕）。
