## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->

- RED：新測試檔修改前 2 failed（舊版本 IMP 子票、舊版本 ADJ 子票皆回 False）、3 passed（舊版本 ANA 子票、不存在的 ID、同版本子票）。
- GREEN：新測試檔與既有 test_acceptance_auditor.py 共 28 passed。E1 在同一批 fixture 上斷言 found is True、missing is False 且兩者不同。
- 純 bug 修正，CLI 行為不變；SKILL.md 與 pm-rules 無 acceptance_auditor 引用。規則 8：測試 fixture ID 改為版本常數拼接，新增行 0 命中。
- 實地觸發：在 `git clone --no-hardlinks` 的 clone 內，讓一張 0.5.0 的 ANA 的 children 指向一張 0.4.2 已完成的 IMP，執行 `ticket track audit`。「後續任務銜接檢查」修正前（合併前一個 commit）為 FAIL，修正後為 PASS。
