## Solution
### 根因類別（初步，partial）

- 已決策：耗時主因不是冷建置（約 70 秒），是 App 啟動後的測試階段「等待」。分類為**測試／環境交界的設計缺陷**：integration 測試的 pump 依賴真實幀，而閘門下 App 不保證在前景，且整條鏈無逾時。
- 待驗證：幀飢餓為機制（見〈重現實驗結果〉未驗證項）。
