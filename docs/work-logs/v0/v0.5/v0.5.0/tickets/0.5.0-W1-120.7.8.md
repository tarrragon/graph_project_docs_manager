## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
修改 domain-import-lint-hook.py：is_commit_command 改回傳 Optional[bool]；contains_git_word 先篩，commit 用 match_git_commit(exclude_amend=False)（維持原本 amend 也掃描的範圍），merge 用 find_git_invocations({'merge'})；任一命中為 True，否則任一為 None 則 None。None 處置比照 tracking-schema-json-staleness-guard：新增 has_parallel_dispatch（get_active_dispatches，根目錄用 get_shared_state_root，讀取失敗視為非並行），並行期 exit 2 保守擋下，非並行期 stderr 提醒後 exit 0。理由：無法判定時並行期放行會使守衛失效，非並行期擋下干擾單線作業。

實地觸發（本 session）：在 scratchpad 暫存 repo（lib/domain/a.dart 含 flutter import，.claude/hooks 與 lib 以 symlink 指向本專案），以 settings 註冊的啟動方式 uv run hook-dispatcher.py --group PreToolUse:Bash 餵 payload：git -C x commit -m y -> rc=2、stderr 含 domain-import-lint；git -C x merge f -> rc=2；echo git commit -> rc=0 且 stderr 無 domain-import-lint。liveness 驗證方式：暫存 repo 的 .claude/hook-logs/domain-import-lint-hook 日誌出現「domain import lint 阻擋：命中 1 處違規」，_liveness 索引有進入紀錄。失敗語意：判定為 commit 或 merge 且有違規時 fail-closed（exit 2）；無法解析時並行期 fail-closed，非並行期 fail-open 並提醒；CLAUDE_PROJECT_DIR 未設定、stdin 無法解析維持原本放行。
