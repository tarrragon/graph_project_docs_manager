## Solution
<!-- Schema[ANA/Solution]: 必填（.claude/pm-rules/ticket-body-schema.md） -->

### 分析結論

三個候選都要求 components 只依賴 tokens、l10n 與 Flutter（SPEC-002 元件庫可脫離畫面重用的前提）。在這個前提下，components 的 4 條外向邊是共同違規，不受候選選擇影響：

- `app_shell.dart` 對 app 2 條、對 screens 1 條。
- `app_snack_bar.dart` → `attention_level.dart` 1 條。

三個候選的差別在 app 與 screens 的相對位置。

### 層位候選（由下而上，左側為下層）

| 候選 | 層序 | 違規邊數（現況檔案位置） | 修正形態 | 利 | 弊 |
|------|------|------------------------|---------|----|----|
| A：app 按檔分兩層 | components → app 狀態 → screens → 組裝根（`shell.dart` 與 `buildDestinationPage`） | 15 條：components 4、`router.dart` 的畫面組裝 6、`domain_view_loader` → screens 3、`workspace_selection` → screens 2 | 把 `buildDestinationPage` 從 `router.dart` 移到組裝根；`inferredVersionProvider`、`gateDetectionNotifierProvider`、`domainViewStateProvider` 等被 app 讀取的畫面狀態移入 app | 移動的檔案最少，目錄名不變 | 同一目錄內有兩層，守衛要逐檔列名單；新增檔案時要自己判斷屬於哪一層 |
| B：app 只當組裝根，放最上層 | components → screens → app | 52 條：components 4、screens → app 48 | 把十個應用狀態檔與 `project_unready_view` 移出 app，放到新目錄（例如 `lib/app_state/`） | 目錄與層一一對應；app 只剩組裝根，語意最單純 | 移動檔案最多，48 條 import 全部改寫 |
| C：app 是應用狀態層，組裝根移出 | components → app → screens → 組裝根（新目錄或併入 `main.dart`） | 25 條：components 4、app → screens 21 | 把 `shell.dart` 與 `buildDestinationPage` 移出 app（解決 16 條）；loader 與 workspace_selection 依賴的 5 條，比照 A 把畫面狀態移入 app | 目錄與層一一對應；保留 app 現有的多數內容與 48 條 screens → app 邊 | 組裝根需要新目錄名；修正量介於 A 與 B 之間 |

違規邊數的計法：在現況檔案位置下，逐條套用該候選的層序，計數其中向上指的邊。A 把 `router.dart` 視為應用狀態檔，所以它對畫面的 6 條算違規。

**附帶裁決項**：screens 內的功能之間是否允許互相 import。現況有 3 條：

- `gap_report` → `uc_flow`，2 條
- `domain_view` → `project_switcher`，1 條

- 若不允許：這 3 條要改成經由 app 層的共用狀態轉接，另建票處理。
- 若允許：守衛只檢查目錄之間的方向。

### 建議

C。理由：

- 目錄與層一一對應，守衛只要寫目錄規則，不必維護逐檔名單。
- screens → app 的 48 條是現有程式碼的主流方向，C 保留這個方向。
- 實際要動的邊集中在兩個檔：`shell.dart` 與 `router.dart`。

此建議不是定案。依主控指示，選項交由主控以 AUQ 轉給用戶裁決。

### 狀態

用戶已裁決（2026-10-30，經主控轉達，349 記錄於 commit eeb076c6f）：

1. 層序採 C：components → app → screens → 組裝根。目錄即層，守衛寫目錄規則。
2. screens 內的畫面功能之間禁止互相 import。現有 3 條邊的共用部分下沉到 components 或 app。

主控以 grep 複驗六組邊數，與本票盤點一致。AC3 的 children 依此裁決建立，見下方〈Spawn 落地確認〉。
