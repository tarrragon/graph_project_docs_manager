- 直接依賴：shared_preferences 2.5.5→2.5.6、two_dimensional_scrollables 0.5.4→0.5.5

   - 影響範圍：import riverpod 的檔案 lib 35、test 34、integration_test 7；lib 有 28 個檔案用 StateProvider，該 API 在 3.x 移到 legacy.dart。
