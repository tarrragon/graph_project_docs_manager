### 追加實證（PM，2026-10-14）

建立 0.5.0-W1-238.1 時，建票的 auto-commit 回 rc=75（CAS 失敗）：票檔停在 untracked，topic-assignments.txt 多出一行未提交。照補救路徑執行 `ticket track commit 0.5.0-W1-238.1 -m ... <票檔> docs/work-logs/topic-assignments.txt`，被拒絕：「以下檔案不在 ticket where.files 宣告的寫入範圍內」。
