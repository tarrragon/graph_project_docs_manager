- `lib/layout/lane_order.dart`：
  - `BundleOrderEntry = ({String domain, int? layer})`（FR-13 回傳形狀）、`BundleDependencyEdge = ({String from, String to})`。

- low（R-opus）helper import `lib/layout` 的 typedef，L7 群組沿用時連帶依賴 layout：無需建 ticket，test/helpers 依賴 lib/layout 不違反 §1.4（限制的是 lib/layout 不得依賴 corpus／screens／components）。
