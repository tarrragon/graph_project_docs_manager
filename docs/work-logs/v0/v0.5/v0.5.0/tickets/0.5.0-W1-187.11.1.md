### 實作
修改 .claude/scripts/orphan-test-procs.py 與 .claude/scripts/tests/test_orphan_test_procs.py。
- 新增純函式 find_suspect_trees(procs, roots, cwd_of, is_runner_fn)：根須父程序為 1、非殭屍、本身非執行器、cwd 可取得且在專案範圍內，且子孫（含防環）有非殭屍執行器；回傳 SuspectTree(root, members)。
- 新增 format_age（etime 空白印「未知」，不略過該樹）、render_suspects（列各程序編號、命令、根存活時間，並說明本指令不終止、無法確認非刻意背景執行、要處理請核對後 kill <PID> 逐一終止）、_descendants。
- Proc 新增 etime 欄位（預設空字串，相容既有建構）；list_processes 改取 ps 的 etime。
- main：疑似殘留一律只印出；--kill 時另印「疑似殘留 N 棵未處理」，不對其送訊號；統計列為「符合 N 略過 M 疑似殘留 K」。is_runner 與符合類別的認定、終止邏輯未動。
