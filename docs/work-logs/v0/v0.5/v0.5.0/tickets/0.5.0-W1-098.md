## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 重現與根因
重現（worktree 內，cwd=worktree 根）：doc uc verify docs/usecases -> rc=2「指定路徑不存在: docs/usecases」；同路徑為絕對路徑 -> rc=0。根因：shim 以 uv run --directory <skill_dir> 啟動，行程 cwd 與環境變數 PWD 皆被改為 skill 目錄（實測 PWD 不可信），相對路徑以 skill 目錄解析。與 CLAUDE_PROJECT_DIR 無關。
### 與 canonical #24 關係
同根（引用，非重複）：#24 主體即此現象；本地採 #24 候選 (b)：shim 於切換目錄前把呼叫者 cwd 傳入 SKILL_CLI_CALLER_CWD，doc CLI 讀回 chdir。#24 的 ticket/worktree shim 部分仍待處理（shim 已統一匯出該變數，但兩者 CLI 端尚未消費）。
### 同型位置
doc：僅 uc verify [path] 接受路徑引數（已修）。ticket：track register-artifact --path、--files/--where 等路徑類參數、worktree 路徑類參數尚未逐一驗證，交 PM 另開票（需在各 CLI main 入口接 SKILL_CLI_CALLER_CWD）。注意：既有 ~/.local/bin shim 需重跑 install-skill-clis.py 才生效。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
修法（實作 commit ad3e990a0，doc skill 1.24.4，合併入 main）：

- `.claude/scripts/install-skill-clis.py` 的 `shim_body`：`exec uv run --directory` 前以 `SKILL_CLI_CALLER_CWD=$(pwd)` 傳入呼叫者 cwd（7 個 shim 一律匯出，未消費的 CLI 不受影響）
- `doc_system/cli.py` 新增 `restore_caller_cwd()`，`main()` 起始時讀回並 chdir；值非絕對路徑或目錄不存在時不動 cwd
- 同型位置（ticket／worktree 的路徑類參數）由 0.5.0-W1-100 承接；canonical #24 為同根引用關係

### 自檢結果

- E1：`test_caller_cwd.py` 主倉庫與 worktree 情境各一，相對與絕對路徑結果一致
- 正向對照：不存在路徑仍 exit 2，未被 chdir 掩蓋
- 實地觸發：PM 合併後重裝 shim，主倉庫與 worktree 相對路徑 rc=0；舊 shim 形式 rc=2，新形式 rc=0
- commit trailer：Claude Sonnet 5.5，與自報一致

### Phase 4 評估

- 重構需要：否
- 技術債務：發現 1 項，`restore_caller_cwd` 對無效值靜默不動 cwd、無日誌；該分支只在 shim 以外的啟動方式出現，已併入 0.5.0-W1-100 的同型檢查範圍處理
- 程式碼品質：A
- 結論：以環境變數跨越 `uv --directory` 的 cwd 改寫是最小改動，無需重構
