## Problem Analysis
<!-- Schema[ANA/Problem Analysis]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因

`_resolve_shared_lock_path` 有兩個分支會改用票目錄當鎖檔位置：`get_git_common_dir` 回傳 None，或 tickets_dir 不在專案根目錄之下。這兩個分支都直接 return，不呼叫 `_warn_create_lock_degraded`。該警告只在 mkdir 或取鎖失敗時才會印出，所以路徑層的降級完全靜默。`get_git_common_dir` 執行 `git rev-parse --git-common-dir` 時逾時 5 秒（`GIT_TOPLEVEL_TIMEOUT`）即回傳 None。當時 load average 約 75 至 110，子程序逾時是最可能的觸發條件。

### 影響範圍

- 已驗證：票面所述「降級只在 stderr 警告後續行」不成立，兩種條件下 stderr 皆為空（見重現實驗）。
- 已驗證：`.gitignore` 只有 `.claude/**/*.lock`，不涵蓋 `docs/` 下的 `.ticket-create.lock`，因此降級留下的檔案會被廣域 git add 掃入。docstring 所稱「`*.lock` 已在 .gitignore」與現況不符。
- 已驗證：2026-10-14 時該殘留檔已不存在，`.git/ticket-create-locks/` 正常使用中。
- 無法定位觸發的那一次建票：降級靜默、不寫 hook-log、stderr 為空，沒有任何紀錄可回溯。這也是本票要修的缺口之一。

### 相關 Error Pattern

IMP-072（並行建票撞號）是此鎖存在的原因。降級靜默則與 #97「fail-open 放行皆無訊號」同形。

## 重現實驗結果
### 實驗方法

以 monkeypatch 呼叫 `file_lock._resolve_shared_lock_path`，不建票、不取鎖。對照組為正常環境；實驗組有兩個：讓 `get_git_common_dir` 回傳 None，以及讓 `get_project_root` 回傳一個與票目錄無關的暫存目錄。逐一擷取 stderr。

### 實驗執行

- 正常：path=GIT_COMMON，stderr=''
- get_git_common_dir 回 None：path=TICKETS_DIR，stderr=''
- tickets_dir 不在專案根下：path=TICKETS_DIR，stderr=''

### 實驗發現

已驗證：兩種降級條件都會把鎖檔落回票目錄，且沒有任何輸出。未驗證：真實高負載下 `git rev-parse` 是否確實逾時 5 秒；此為最可能的觸發條件，但沒有可回溯的紀錄。

## Solution
<!-- Schema[ANA/Solution]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 結論

鎖的共用位置靠 git 子程序解析，高負載下逾時會靜默退回票目錄。這同時造成三件事：失去跨 worktree 互斥、沒有任何訊號、留下不在忽略範圍內的檔案。修法以檔案系統解析取代子程序，從根本消除逾時；仍需降級的情形改為可見。

### dedup 與關係判定

`section_comment dedup` 以 ticket-create.lock、git-common-dir、create lock、撞號、IMP-072 五組關鍵字查重。結果：#55（ticket CLI 契約缺口叢集）與 #97（fail-open 放行無訊號）有實質相關，關係皆為引用，不是重複。其餘命中與本題無關。框架判準兩條皆成立：抽象可攜（任何並行建票的 consumer 皆適用），且根源在 `.claude/skills/ticket`。

### 方案比較

| 案 | 作法 | 利 | 弊 |
|----|------|----|----|
| A 降級時拒絕建票 | 解析失敗即非零結束 | 不會撞號 | 非 git 環境的單 process 建票也被擋；高負載時建票反覆失敗 |
| B 只讓降級可見 | 警告、寫日誌，並把降級鎖放到已忽略位置 | 有訊號、不留檔 | 仍會失去互斥，只是看得見 |
| C 以檔案系統解析 common dir（採用，並搭配 B） | 讀 `.git` 目錄或 gitdir／commondir 檔，失敗才走子程序 | 去除逾時根因，主 repo 與 worktree 結果一致 | 需處理 gitdir 為相對路徑等格式 |
