## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
計數鍵改 payload session_id；計數檔 .claude/hook-state/compact-count-<消毒後 session_id>（非 [A-Za-z0-9_-] 換 _，截 100 字）。缺/空 session_id fail-open：不計數，寫 .claude/hook-logs/suggest-compact/suggest-compact.log。
殘留處置：由 hook 清除。首次為某 session 建檔時，刪 /tmp 下檔名 fullmatch claude-tool-count-\d+ 的一般檔（排除 symlink），並清逾 7 天的他 session 計數檔。理由：殘留屬 hook 自身造成，自清不需人工步驟，且僅刪符合模式者、每 session 只執行一次。測試用 SUGGEST_COMPACT_LEGACY_TMP_DIR 覆寫目錄以免誤刪。提醒輸出未動。
實地觸發方式（PM 合併後）：在主 checkout 任一 session 呼叫工具，確認 .claude/hook-state/compact-count-<session_id> 出現且遞增、/tmp 不再新增 claude-tool-count-*、既有殘留被清除；門檻用 COMPACT_THRESHOLD=2 之類觀察提醒。
