**規格已修訂（AC1）**：SPEC-004 1.107（63e62f6d9）4.38 `SwimlaneGrid` slot `laneHighlight` 的值改為選取 domain 的 domainId，以 `Lane.domainId` 精確比對，列首字面不參與。**slot 名稱維持 `laneHighlight` 不改名**（PM 決定：AC 只要求以 domain id 指定；改名會牽動 SPEC-001 §1 與 SPEC-004 多處現行條文，無行為收益）。測試點新增「兩列同字面只高亮 domainId 相符的一列」與 E1 對照（`laneHighlight` 改為另一列 domainId 時高亮移至該列）。

**實作範圍**
- `lib/components/swimlane_grid.dart`：`_isHighlighted` 改為 `lane.kind == SwimlaneLaneKind.domain && lane.domainId == widget.laneHighlight`；`laneHighlight` 欄位 dartdoc 與類別 slot 表註解（「選中 domain 的泳道名」）改為 domainId 語意；`didUpdateWidget`／定位邏輯中凡以 laneHighlight 比對列者一併確認語意。
- `lib/screens/domain_view/domain_view_screen.dart`：刪除 `_highlightName`；兩處 `laneHighlight: _highlightName(matrix, lanes, state.selectedDomainId)` 改為直接傳 `state.selectedDomainId`。刪除後若 `_SwimlaneBody` 內的 `matrix` 變數只剩 `_ucTitleOf` 使用，保留即可，不擴大改動。
- 現有以字面傳 `laneHighlight` 的測試須改傳 domainId：test/unit/components/swimlane_grid_test.dart、test/unit/screens/domain_view/domain_view_state_driven_test.dart、test/widget/screens/domain_view_goto_swimlane_test.dart、test/widget/screens/domain_view_rescan_behavior_test.dart。
- 新增測試（swimlane_grid_test.dart）：兩列 `name` 相同、`domainId` 不同，`laneHighlight` 指向其一 → 只該列高亮；E1：同 fixture 改指向另一列 → 高亮移動。兩條斷言各為獨立案例。

**局部測試範圍**：上列 4 個測試檔 + test/unit/screens/domain_view_test.dart。
