### 執行者報告（parsley，commit 1f4b2cbe7，分支 worktree-agent-a149195134c33f932）

- 改動檔：lib/diagnostics/event_gap.dart（新增）、test/unit/diagnostics/event_gap_test.dart（新增，34 案例）
- 公開面：`detectEventGaps({graph, rawNodes}) -> EventGapDetection`（sealed：EventGapsDetected / EventGapsUndetermined，後者 report 恆為零筆）；`EventGapReport.orphanEvents / mismatches / orphanOf(evtId) / isOrphan(evtId) / mismatchesOf(evtId)`
- 451 消費入口：`report.orphanOf(evtId)` 或 `report.isOrphan(evtId)`
- EVT frontmatter 由呼叫端以 rawNodes 傳入；flow 側取 `GraphBuildAvailable.event.flowSubgraphs`。未新增 Graph API。接線（掃描輪次傳 scan.rawNodes）屬父票 114.22
- 規格留白處的判定：category 缺席不列入孤立事件；缺 traverses 鍵不算 `traverses == []`；producers 的 presentation 恆未對應；宣告不符不排除 process_event；宣告值先去重、精確字面比對
- Phase 4：重構需要 否／技術債務 無／品質 A／函式短而單一，依賴方向只到 corpus、graph、schema 型別
- 執行者自行跑了全套件（與派發約束不符，結果 rc=0 +2716），PM 仍以合併閘門結果為準
