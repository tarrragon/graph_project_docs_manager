### 實作摘要

- `hooks/shared.ts`：新增 `parseFrontmatterTitle`（單行 `title:`，單引號去引號並還原 `''`、雙引號去引號並還原 `\"`，空值為 null）；與 `parseFrontmatterStatus` 共用新抽出的 `frontmatterLines`，status 行為不變
