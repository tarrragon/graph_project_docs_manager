### 用戶需求補充：看板 plugin 預設載入（2026-10-21，主控經 claude-code-guide 查官方文件）

用戶要求不必再以 `claude --plugin-dir` 啟動，開啟專案就自動載入。官方文件可行的做法：

| 問題 | 答案 | 來源 | 可信度 |
|---|---|---|---|
| 專案設定能否宣告本地 marketplace 並自動啟用 | 可以。`.claude/settings.json` 的 `extraKnownMarketplaces` 宣告 marketplace（source 類型含 `directory`、`file`、`settings`），再用 `enabledPlugins` 寫 `"<plugin>@<marketplace>": true` | https://code.claude.com/docs/en/settings-reference.md 、https://code.claude.com/docs/en/plugin-marketplaces.md | 高（schema）；`directory` 的相對路徑以哪裡為基準，文件沒寫 |
| marketplace.json 位置 | `<marketplace 根>/.claude-plugin/marketplace.json`。plugin 的 source 路徑不得含 `..`，所以 marketplace 根必須是 plugin 目錄的上層 | 同上 | 高 |
| 首次信任 | 在用戶接受該資料夾的 workspace trust 之前，repo 宣告的 marketplace 會被靜默忽略，`-p` 也一樣。相對路徑的 plugin 不需另外安裝 | https://code.claude.com/docs/en/plugins/loading.md | 高 |
| 有沒有和 `--plugin-dir` 等效的設定鍵 | 沒有。環境變數 `CLAUDE_CODE_PLUGIN_DIRS` 有同樣效果，但只限單一 session，路徑必須是絕對路徑或 `~` | https://code.claude.com/docs/en/env-vars.md | 高 |
| repo 內修改 plugin 會不會自動生效 | 本地路徑 marketplace 的相對路徑 plugin 會原地載入、不複製，下次啟動或執行 `/reload-plugins` 就生效。git 來源或複製安裝的則有版本快取 | https://code.claude.com/docs/en/plugins/loading.md | 中高（`directory` 宣告是否算原地載入，文件沒明寫） |

列入 485 的規劃：
- 預設載入的設定，要等框架內的位置定案後才寫，因為 marketplace 根與 plugin 的 source 路徑都取決於位置。
- `.claude/settings.json` 會不會隨 sync 傳到 consumer，決定這個預設載入是本專案專屬，還是所有 consumer 共用。要先查 sync 的涵蓋範圍再決定。
- 原地載入不會自動安裝 npm 依賴，要確認看板程式在 runtime 有沒有依賴需要安裝。
- 驗證：第一次用 `claude plugin marketplace add` 確認相對路徑以哪裡為基準；接受 trust 之後，不帶 `--plugin-dir` 啟動時，側邊欄要出現看板（實機驗證，由用戶確認）。

### 問題根因

看板程式寫在專案 `tools/line-board/`，把本專案的值寫死在程式內，其他 consumer 無法使用；佇列行格式只在 multi-session-orchestration 的 session-naming〈用語〉定義（流程步驟由 0.5.0-W1-484 補）。

### sync 涵蓋（查 `.claude/lib/sync_exclude_manifest.py`）

- `.claude/settings.json` 會 sync 到所有 consumer；`settings.local.json` 不 sync。
- 任何路徑區段為 `project-integration` 的檔不 sync（PER_PROJECT_PATTERNS）。
- `.claude/plugins/` 與 `.claude/skills/` 都會 sync。

### 官方文件查證（2026-10-21，claude-code-guide；loading.md、manifest-reference.md、settings-reference.md、cli-reference.md）

- 專案 `.claude/skills/<name>/` 內有 `.claude-plugin/plugin.json` 時，以 `<name>@skills-dir` 自動載入；須從 repo 根啟動、須接受 workspace trust；是否啟用由 manifest 的 `defaultEnabled` 決定，settings 寫 `"<name>@skills-dir": true/false` 可覆寫。同名時 user 層優先。
- plugin `userConfig` 的值只存在 user 層 `~/.claude/settings.json` 的 `pluginConfigs`，`claude plugin configure` 沒有 `--scope`，無法放專案值。
