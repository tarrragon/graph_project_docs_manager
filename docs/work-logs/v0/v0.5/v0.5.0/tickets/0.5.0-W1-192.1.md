| 案 | 讀碼結果 |
|----|---------|
| A 依 tools 判斷 | acceptance-auditor 的 frontmatter 無 tools 行（繼承全部），general-purpose 亦同；A 擋不住稽核者，真實重現（187.7）恰是該角色 |

### 改動
- dispatch-identity-bind-hook.py：UNBOUND_WHO_VALUES 移除 PM；set-who 改 --current（接 who.history 追加）。PM_AGENT_NAME 保留並與 identity_guard 一致，新增原始碼比對測試。
- identity_guard.py：比對前讓出；deny 訊息移除 --as <who.current> 範例。
- SKILL.md、CHANGELOG.md 同步（CLI 行為變更）。

### E2
修正前以舊碼實跑：ticket_system 2 紅（讓出、deny 範例）、hook 6 紅（含 PM 持有 x 4 代理人、--current、常數一致性之外的 set-who 形狀）。修正後全綠。對照：test_check_identity_hands_over_pm_held_ticket_for_non_complete_command 證明派發實作代理人後首次 --as 寫入仍完成交接。

### Phase 4
