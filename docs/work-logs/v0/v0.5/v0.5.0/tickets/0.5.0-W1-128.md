|---|---|---|
| K1 | 不可定位（現行） | 「不可定位」暗示有路徑但沒命中，與「沒寫路徑」混淆 |

傾向 K2，信心中：沒有路徑就沒有可判定的對象，與「不逐張判定」同義，不新增狀態；原因差異可由逐路徑區（空）看出。
