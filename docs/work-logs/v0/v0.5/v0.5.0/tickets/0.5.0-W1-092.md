### 4. 耦合與風險
- 阻擋 4（間接依賴）：只影響矩陣格關係種類；泳道若取 R1（8 列恆在），空列是否以「間接」呈現會回扣阻擋 4；取 R3 則無耦合。
- 名稱正規化：UC 檔 PascalCase vs 宣告小寫，現況比對 0 命中；正規化落點（資料改寫或解析時 casefold）未定前，任何候選在真資料下都畫不出節點。
- 依賴方向：Layout 只依賴 Graph；泳道需要 FlowStep 的 branch_from／return_to／next，須確認 Graph 公開面有暴露這三欄，否則 Layout 會被迫直讀 Corpus（違反 DAG）。
- 規格聯動：R3、E2、B3 需改 SPEC-001 §1 正常·泳道列描述與 SPEC-004 SwimlaneGrid 條目；E1/C1 為現行行為不需改規格。
- C3 與 E1 組合時列內子槽碰撞與空欄並存，SwimlaneGrid 現為靜態欄寬列高，需改成變動尺寸。
- 計數漂移：CLAUDE.md 39 vs 實測 40。
