## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
刪除 post-test-hook.py 的 pkill -f flutter_tester 與 subprocess import；達 AUTO_KILL_THRESHOLD 改輸出警告（stderr + logger.warning），指向 python3 .claude/scripts/orphan-test-procs.py，說明先列出、確認後再加 --kill；action 由 auto_killed 改為 limit_warning。commit dd9d0ff08。
### 自檢結果
- 零終止程序：測試替換 subprocess.run/Popen/call/check_output 與 os.system，斷言零呼叫。
- 對照：測試把 pkill 呼叫注入原始碼副本，同一 spy 斷言 calls 非空（spy 能偵測到 pkill）。
- 警告含清理指引，stderr 與日誌皆有。
- 範圍外：計時檔每專案單一份，依指示未處理。
