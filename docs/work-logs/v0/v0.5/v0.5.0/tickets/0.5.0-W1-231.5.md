### 撰寫前提：post-test-hook 看不到失敗的測試命令（2026-10-14，派發方轉 F 線查證）

PostToolUse 只在工具成功時觸發，失敗走 PostToolUseFailure，本專案未註冊。post-test-hook 因此只看得到結束碼被 `| tail` 或 `; echo $?` 遮蔽成 0 的失敗；直接失敗的 pytest／flutter test 它看不到。追蹤票 0.5.0-W1-281（P1）。

本票撰寫規則條文時，不得寫成「測試失敗由 hook 回報」之類依賴 post-test-hook 的敘述，除非 0.5.0-W1-281 已完成且結論支持。合併前全綠由 0.5.0-W1-231.3 的合併閘門讀取結束碼保證，不依賴 post-test-hook，可直接引用。
