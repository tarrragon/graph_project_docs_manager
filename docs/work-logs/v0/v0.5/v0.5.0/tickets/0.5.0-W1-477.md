## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
commit 見 worktree HEAD（接在 c39c87b5b 後）。merge-gate.yaml 新增 research-python：prefixes [docs/research/]，command 為 uv run --quiet --with pytest python -m pytest -q -p no:cacheprovider docs/research/common docs/research/ui-vision-choice；summary '^\d+ (passed|failed)'，failure '^FAILED '。
