### transcript 路徑規則（實測）

- 主 session：~/.claude/projects/<編碼>/<CLAUDE_CODE_SESSION_ID>.jsonl，編碼為非英數字元換成 -（實檔 -Users-mac-eric-project-graph-project-docs-manager）。實作以 glob 找 session id，不重算編碼。
