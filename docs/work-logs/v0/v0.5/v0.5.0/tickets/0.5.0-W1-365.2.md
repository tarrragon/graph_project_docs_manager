## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
commit 1b9d2513d（worktree feat/0.5.0-W1-365.2），檔案：bash-write-boundary-guard-hook.py、test_bash_write_boundary_guard_hook.py。

各形態處理：
- bash／sh／zsh -c（含 -lc 等合併旗標、前置 env／sudo 等包裝字）與 eval：命令字位置的單一字面腳本遞迴 _collect_candidates（depth+1，沿用 _MAX_HEREDOC_RECURSION），外層 cd 位移帶入，腳本內 cd 逐候選回填 dirs。
- VAR=字面：純賦值陳述（含 export／declare／local）記入同命令 env；後續候選以 _expand_vars 展開 $VAR／${VAR}，鏈式字面（G=$F）可展開。值含其他變數或命令替換記 None，候選留 $VAR 原樣，於解析階段判 unresolvable。賦值不傳入 -c 子殼（未 export 的行為）。
- ~、$HOME、${HOME}：_resolve_candidate 以環境 HOME 展開；~user、HOME 缺席維持 unresolvable。
- $(pwd)、反引號 pwd：tokenizer 保留為 token 成分，_resolve_candidate 展開為 cwd+cd 位移；變數值內含 $(pwd) 維持 unresolvable（賦值與使用處 cd 可能不同）。
- cwd 不在任何 checkout 且 CLAUDE_PROJECT_DIR 有值：roots 改以其所屬 checkout 計；未設定行為不變（E1）。
- 既有測試 test_dynamic_path_not_resolved 中 $(pwd)／pwd 兩列移除（本票即關閉該殘留風險，改由 TestShellLayerDenied 覆蓋）。

skipped 欄格式：判定行 `decision=... reason=... targets=[...] skipped=['<raw>:out_of_scope', '<raw>:unresolvable'] cmd=...`；raw 為展開變數後、解析前的候選字串；命中者不列；路徑範圍檢查未執行的早退分支為 skipped=[]。放行／阻擋結果不受影響。

收緊前文件反查（.claude/skills、references、pm-rules grep -c／eval／$(pwd)／$HOME／~／變數重導向）：命中皆為唯讀或非專案路徑（~/.claude/ 家目錄讀取、printf > "$D/..." 於 mktemp 目錄且 D 為命令替換故 unresolvable、zellij `bash -c 'go run . 2>&1...'` 為 fd 複製）。會被新判準擋下的例行範例：無。無需改文件。

### 第二輪補修（commit f96428564）
- 解析器為每個陳述記錄 before（與前一陳述間全部邊界字元）與 after（終結邊界，&&／|| 分辨）。_assignment_is_certain：括號深度 0、before 不含 |／&&／反引號、after 非 |／&／反引號才記入 env；其餘賦值把變數設 None（unresolvable）。
- HOME、CLAUDE_PROJECT_DIR 不由 _expand_vars 展開，維持「展開前」形式交 _resolve_candidate 以真實值解析；若命令內有賦值，另追加「展開後」候選（_expand_assigned_specials），兩形式任一命中即擋。HOME 賦值為 None 時展開後形式為不可解析標記（unresolvable），展開前形式仍檢查真實 HOME。
- (CLAUDE_PROJECT_DIR=/tmp); echo x > $CLAUDE_PROJECT_DIR/lib/a 與 true && 、|| 、管線右側同形：deny。
- L7 實例（代理人、真實 git worktree 同層、T=<worktree>/.claude/skills/worktree/tests; sed -i ... $T/x.py）：deny reason=scope_violation。此案在第二輪 main 上本即 deny（變數展開已在第一輪），補為回歸 E2。
