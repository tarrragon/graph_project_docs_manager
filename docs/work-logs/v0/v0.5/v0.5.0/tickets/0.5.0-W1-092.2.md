#### 第 1 項：層的推導公式

| 候選 | 作法 | 依賴分屬不同層時 | 代價 |
|---|---|---|---|
| 1a 維持（max+1，最長路徑分層） | 無出邊 L0；其餘為依賴最大層 +1 | 每個依賴都嚴格在上方，列序可讀作「上層被下層依賴」 | 層數可能較深 |
| 1b min+1 | 依賴最小層 +1 | 可能與某依賴同層或在其上方，違反「依賴在上」的讀法 | 無 |
| 1c 規格不定義 | 交實作 | 兩實作可能不同序，測試無期望值 | 與 1c 裁決要「可逐值比對」相反 |

傾向：1a。這是分層圖的標準作法（longest-path layering），而且是唯一能保證「每條依賴邊都朝上」的選項；R1 顯示本專案資料不受影響。

#### 第 2 項：同層字母序的比較方式

| 候選 | 作法 | 代價 |

| 2a 維持「字面字母序」不再細化 | — | 未定碼點或語系，含連字號時兩實作可能分歧 |
| 2b 明訂碼點序（Unicode code point；Dart `String.compareTo` 同義） | `-`（0x2D）排在字母前 | 與人眼語系序在連字號上可能不同 |
| 2c 語系排序 | 依顯示語系 | 中英切換可能使列序變動，違反「換 UC 列序不變」的穩定性精神 |

傾向：2b，一句話補定即可；R7 顯示現況無影響。
