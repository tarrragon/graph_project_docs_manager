## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
重跑盤點後，直接輸出 deny 的 PreToolUse 守衛共 7 支，盤點表在 how.strategy。處置分三類：
- 等價遷移到 emit_hook_output：presence-detection、proposal-evaluation-gate、ticket-path-guard，deny 與 allow 輸出逐位元組等價。ticket-path-guard 原本整個 main 包在 except Exception 內回 allow；遷移後 SystemExit(2) 不再被吞成放行。
- 自行兜底：task-dispatch-readiness-check（2 處 deny，抽出 `write_deny_or_exit2`）、acceptance-gate、agent-ticket-validation。三支輸出為 indent=2 或含額外欄位，改用 emit_hook_output 會改變輸出；只在決定為 deny 且輸出失敗時寫 stderr 並 SystemExit(2)，allow 輸出失敗照舊。
- 不改：branch-verify 已以 run_hook_safely(fail_closed=True) 使輸出失敗回 exit 2，加測試鎖定現況。
lib 未改。commit 30f36f45c，合併 78bebd975。
