## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
_is_view_statement 的 command 判定改為只掃 command 自身選項（命令名之前、以 - 開頭，遇第一個非選項 token 即停），其中含 -v/-V 才豁免。command pkill -v、command killall -V、command -p pkill -v 改為被擋；command -v pkill、command -V killall 仍放行。

### 自檢結果
- 單一職責、Python 3.9 相容、未改 .claude/lib、fail-open 語意未動。

### Phase 4 結論
重構需要：否；技術債務：無；程式碼品質：A；結論：最小變更，無需重構。
