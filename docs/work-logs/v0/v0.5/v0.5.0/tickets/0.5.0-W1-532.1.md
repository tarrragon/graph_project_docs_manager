## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 來源與條件（0.5.0-W1-532 拆分，主控裁示 2026-10-30）

- 現況與三種重複寫法見 `0.5.0-W1-532` Problem Analysis〈現況〉：外層 `Semantics(container: true)` 包元件後 pump；沿 `parent` 走訪判定是否在 live 子樹；以畫面高度判定 live rect 非全畫面。
- 本票選 missing_source_state（一般 pump）與 loading_state（需 `settle: false`）兩檔驗證 helper 介面，涵蓋兩種 pump 路徑。
- 主控條件 1：helper 內不得寫死外層 Rect 的畫面尺寸（如 640），改由呼叫端傳入或自外層節點讀取。
- 主控條件 2：E2 重驗，2 檔都要驗，逐條獨立案例；拿掉元件 container 時斷言須轉紅，Expected／Actual 原文入 Test Results（以 `--reporter expanded` 輸出存檔後逐字擷取）。
- LoadingState 測試不可用 `pumpAndSettle`（skeleton shimmer 與 indeterminate 動畫不停會逾時），helper 的 pump 需支援 `settle: false` 後 `pump()`。
- 保持逐條獨立的測試結構：531.3 證實同一 testWidgets 多條斷言時 E2 只看到首條紅燈，重構不得把拆開的斷言合併。

### helper 介面設計（PM，2026-10-30，派發前定案）

新檔 `test/helpers/live_region_semantics.dart`，由 `helpers.dart` 加一行 `export` 並在表格補一列。三項函式：

| 函式 | 簽章 | 行為 |
|------|------|------|
| 外層 container pump | `Future<void> pumpInSemanticsContainer(WidgetTester tester, {required Widget child, WindowSize size = WindowSize.min, bool settle = true})` | 呼叫 `pumpHarness(tester, size: size, settle: settle, child: Semantics(container: true, child: child))`；`settle: false` 時再 `await tester.pump()` |
| live 子樹判定 | `bool isInSemanticsSubtree(SemanticsNode node, SemanticsNode root)` | 由 `node` 沿 `parent` 往上，遇 `root.id` 回 true |
| 非全畫面判定的比較基準 | `Size logicalViewSize(WidgetTester tester)` | 回 `tester.view.physicalSize / tester.view.devicePixelRatio`；畫面尺寸來自呼叫端 `size` 參數（`setWindowSize`），helper 內無數值常數 |

設計理由：
- 回傳 bool 與 Size，斷言（`expect(..., isFalse)`／`lessThan`）留在各測試案例內——E2 的 Actual 輸出與現行一致，逐條獨立的 testWidgets 結構不變（TEST-GPD-1003）。
- 不包「找 live 節點」：兩檔取 live 節點的 Finder 不同（l10n 文字、計數文字），各檔保留自己的 `pumpAndFindLive`，內部改呼叫 `pumpInSemanticsContainer`。
- `settle: false` 後補一次 `pump()` 吸收 loading_state 現有寫法；blocked_state（532.2）settle 後另有一次 pump，屬呼叫端自理。

兩檔改法：missing_source_state 的 `pumpAndFindLive`、子樹 for 迴圈、`screen` 計算改呼叫 helper；loading_state 的 `pumpAndFindLive`（settle:false）與 `expectOnlyCount` 內的 for 迴圈改呼叫 helper。斷言內容、案例名稱、案例數不變。
