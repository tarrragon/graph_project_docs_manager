## Problem Analysis

### 規格前置（PM 已完成）

SPEC-004 v1.92（commit 5a4bbac4a）：4.38 slot 表新增 `locateColumn`（int?，與列定位同一 post-frame 另做水平 jumpTo，使目標節點 rect 與 viewport 相交；null 不做水平捲動）；locate 列補間接依賴格目標列取來源 X 列；測試點新增目標欄定位與 null 的 E1 對照；§4.0.10 場景 b 同步。acceptance 第 1 項（規格）已由本 commit 滿足。

### 實作現況（PM 查證，供實作參考）

- `lib/components/swimlane_grid.dart` 目前沒有 `locateLane` slot：列定位由 `laneHighlight` 改變觸發，於 post-frame 呼叫 `_jumpToHighlight()`（`_vController.jumpTo`）。規格中的 `locateLane` 一直是「提案」，實作以 laneHighlight 承擔同一職責。
- 本票的實作方式：`locateColumn` 搭配既有的列定位機制，在 `_jumpToHighlight` 同一 post-frame 另做水平 jumpTo。規格「`locateLane` 為 null 時忽略」對應到實作，就是「沒有列定位時忽略」。不要求本票補上 `locateLane` slot。
- 畫面端：114.12 已在 `DomainReady.swimlaneFocus` 提供 `SwimlaneFocus(domainId, column?)`，`domain_view_screen` 兩處 `SwimlaneGrid(` 建構時傳入 `locateColumn: state.swimlaneFocus?.column` 即可。
- 套件限制：`two_dimensional_scrollables` 0.5.4 對大距離 jumpTo 有既有迴避（見 swimlane_grid.dart 檔頭註記），水平 jumpTo 須比照。
