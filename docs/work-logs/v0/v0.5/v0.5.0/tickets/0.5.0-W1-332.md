## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### 判斷規則改法
is_ticket_file 的 pattern 由 `docs/work-logs/[^/]+/tickets/[^/]+\.md$` 改為 `docs/work-logs/(?:[^/]+/)+tickets/[^/]+\.md$`（容許一層以上版本目錄，tickets 之後不得再有子目錄）。
理由：不引入 ticket 系統路徑解析（需 project_root 與 import，hook 僅有 payload 的 file_path）；改動最小，且同時涵蓋單層與階層，tickets 目錄外與 tickets 子目錄內的 md 仍排除。
日誌：setup_logging 改呼叫 lib 的 setup_hook_logging("ticket-creation-validation")，寫入專案 .claude/hook-logs/；lib 不可用時退為 NullHandler，不再寫使用者家目錄。保持模組級 logger（既有 helper 皆直接引用，未動結構）。306.7 的 additionalContext 輸出未動。
