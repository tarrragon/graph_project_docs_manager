## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
組裝根目錄：lib/assembly/（含 shell.dart 以 git mv 移入、新檔 destination_pages.dart 承接 buildDestinationPage）。理由：名稱表達「組裝」職責，不與 lib/app 或 lib/screens 語意重疊，且在層序 components -> app -> screens -> 組裝根 的最上層。
router.dart 只留 AppDestination、NavIntent 與相關 provider／函式，移除全部 screens import，循環解除。main.dart 與四個測試的 import 改指 assembly/shell.dart；app_snack_bar_source_contract_test 的 _shellPath 改為 lib/assembly/shell.dart。
