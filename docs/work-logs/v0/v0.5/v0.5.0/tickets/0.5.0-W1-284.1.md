### 實作（.claude/hooks/bash-write-boundary-guard-hook.py）

兩層檢查：
1. 第一層（主線程與代理人皆適用）：候選寫入路徑以 payload cwd（缺則 os.getcwd()）加命令內 cd 位移解析，realpath 後換算成所在 checkout 根目錄（向上找 .git；worktree 另加其主 checkout）的相對路徑，落在 lib/、test/、integration_test/、.claude/** 即 deny。從主 checkout 寫 .claude/worktrees/<名>/lib/x 會剝掉前綴後同樣命中。
2. 第二層（僅主線程）：既有 check_file_permission 行為不變；開發分支跳過只作用於此層。subagent 不套用 PM 模型，避免擋掉其他合法 *.dart 目的地以外的行為，lib/test 寫入由第一層決定。
3. 附帶修正：_scan_statement_tokens 對 `git mv` 不再抽出目的地（deny 訊息指定的正規做法）；sed -i "" 路徑抽取原本已正確（既有 284.5 測試覆蓋），本票補 deny 正向對照。

### 開發分支跳過的取捨（acceptance 第 4 項）
新檢查不受開發分支跳過影響。理由：/worktree create 建的 feat/* worktree 與代理人 worktree 內，若沿用分支跳過，第一層整個失效，而這正是代理人實際工作的場所；分支跳過原本的立意是「PM 在開發分支上可寫程式碼」，只屬第二層（PM 可寫路徑模型）。連帶影響：原測試 test_dev_branch_allowed 與 test_subagent_environment_allowed 的斷言必然翻轉（對 lib/ 寫入由放行改 deny），已改寫為 test_dev_branch_still_denied_for_scope_write 與 test_subagent_environment_denied_for_scope_write，並新增 test_dev_branch_skips_main_thread_layer_only 鎖住跳過仍作用於第二層。其餘主線程測試未動。

### 豁免清單（每項皆有應放行測試）
- 建置快取：路徑任一層為 .venv、__pycache__、.pytest_cache、.ruff_cache、.mypy_cache、.dart_tool
- .claude 本地執行期產物（對齊 .gitignore 該段）：hook-logs、hook-state、state、logs、plans、handoff、analyses、migration-backups、tool-results、dispatch-active.json／.lock、pm-status.json、settings.local.json 等
- checkout 外：/tmp、scratchpad、/dev/null；$VAR／~／命令替換路徑無法判定，放行
- .git/ 不在阻擋頂層目錄內，自然放行；git worktree add／remove 與 git mv 不產生候選路徑
- ticket／doc CLI 自寫檔：目標路徑不在命令文字內，測試鎖住（append-log、track commit、doc validate 皆放行）

### 產生路徑盤點表（how.strategy 草稿）

| # | 寫入產生路徑 | 覆蓋 | 說明 |
|---|------------|------|------|
| 1 | 重導向 > 與 >>（含 cat／printf／echo 搭配 heredoc） | 是 | 測試：cat >> heredoc、printf >> |
| 2 | tee、tee -a | 是 | |
| 3 | sed -i（GNU／BSD 空字串後綴／--in-place） | 是 | 路徑抽取沿用 284.5，補 deny 正向對照 |
| 4 | cp／mv 目的地 | 是 | 版本控制的 mv 子命令明確豁免 |
| 5 | python／python3 內嵌 open 字面路徑 | 是 | -c 與 heredoc 兩種 |
| 6 | sh／bash／zsh 的 heredoc 正文（含 cat 管線交給 bash） | 是 | 遞迴深度 2；284.5 已有測試 |

| 8 | 絕對路徑、CLAUDE_PROJECT_DIR 前綴、worktree 對主 checkout 的路徑 | 是 | realpath 後換算，symlink 指進範圍也命中 |
| 9 | 其他變數、波浪號、命令替換、反引號組成的路徑 | 否（審查標題 1／2 類） | 靜態解析無法求值，放行。暫存區變數（如 S）是常態用法，擋掉會誤傷 scratchpad |

| 15 | 工具自寫檔（ticket／doc CLI、uv、pytest、版本控制自身） | 不適用 | 非 shell 寫入，命令文字無目標路徑；測試鎖住放行 |
