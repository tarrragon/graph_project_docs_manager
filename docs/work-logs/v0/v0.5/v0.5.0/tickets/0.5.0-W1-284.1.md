## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### PM 派發前補充（2026-10-15）：`.claude/**` 阻擋範圍的必要豁免

方案 A 會對主線程與代理人兩邊都阻擋寫入 `.claude/**`，影響所有線。以下是合法的 Bash 寫入，必須明確豁免，否則會誤擋例行作業：
- `git worktree add .claude/worktrees/<名稱>`、`git worktree remove`：PM 建整合分支與清理 worktree 時使用（2026-10-15 批次 297 即用過）。
- `.claude/hook-logs/**`：hook 自己寫日誌，雖然不經 Bash，但人工 `tail`/`grep` 重導到這裡的情況要確認。
- `.claude/dispatch-active.json` 等執行期狀態檔，以及 `.claude/worktrees/**` 內 git 自身的寫入。
- uv/pytest 在 `.claude/**/.venv`、`__pycache__`、`.pytest_cache` 產生的檔案。

判準建議：豁免改以「被 .gitignore 忽略的路徑」或「明確清單」表達，並為每個豁免寫一筆「應放行」測試。
這次改動屬於行為變更，合併前 PM 會通知 bb 轉告各線。
