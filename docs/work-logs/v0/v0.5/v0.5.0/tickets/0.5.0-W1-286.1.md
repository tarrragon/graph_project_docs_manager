## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
修改 4 檔：
- .claude/lib/ticket_command_parse.py：新增 is_invocation_masked(command) -> Optional[bool]
- .claude/lib/bash_tool_response.py：is_bash_success 新增 command、state_verifier 兩個可選參數（預設 None，行為不變）
- 測試：.claude/hooks/tests/test_bash_tool_response.py、.claude/lib/tests/test_ticket_command_parse.py

遮蔽規則：含 ; | || &（換行等同 ;，尾端 ; 不算）為遮蔽；單一命令、純重導向、&&、單獨 x=$(...)、子 shell 為未遮蔽；shell -c/eval 巢狀字串遞迴判斷；無法解析回 None。
判定順序：未遮蔽即成功 -> 遮蔽且有驗證器以其為準（拋例外退回標記）-> 其餘退回標記。exit_code/interrupted 前置檢查維持在最前。
