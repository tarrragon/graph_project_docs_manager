### 名額鎖目錄安全化（2026-10-14，併入 0.5.0-W1-260）

F 線與 D 線的自動安全審查各自獨立掃到同一問題（slot_gate 預設鎖目錄落在可預測的 /tmp 路徑、makedirs(exist_ok=True) 接受他人預建的目錄或 symlink、holder 檔以 open(path, "w") 寫入會跟隨 symlink）；本 session 的背景安全審查亦回報 run-with-timeout 的 insecure-shared-temp-dir。三方結論一致。

修法定案：

| 項目 | 定案 | 理由 |
|------|------|------|
| 預設目錄 | HOME 底下固定路徑（~/.cache/claude-slot），CLAUDE_SLOT_LOCK_DIR 可覆寫 | HOME 對同一使用者穩定，所有 session 解析到同一處；不採 XDG_RUNTIME_DIR：與 TMPDIR 同為環境變數，不同 session 的值可能不同（macOS 上通常不存在） |
| 目錄驗證 | makedirs 以 0o700 建立後 os.lstat 驗證：S_ISDIR、st_uid == os.getuid()、mode & 0o077 == 0；任一不符即 stderr 並略過閘門 | 群組與其他人連讀取權限都不給；不符時 fail-open，不阻擋命令 |
| holder 檔 | 以 O_CREAT\|O_EXCL\|O_NOFOLLOW、0o600 寫入同目錄暫存檔，再 os.replace 換上 | 不跟隨 symlink，且讀取端不會讀到寫一半的檔案 |
| 鎖檔 | 開啟時加 O_NOFOLLOW | 同上 |
