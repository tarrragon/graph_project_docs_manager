## Problem Analysis
<!-- Schema[ANA/Problem Analysis]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因

(1) 選擇資料夾按鈕：`_UnsetView` 的 `action-domain-choose-folder`（domain_view_screen.dart `_UnsetView.build`）自 0.1.0-W2-001（c1544743e，2026-09-21）起就是佔位實作：只把狀態寫成 `DomainLoading`，從未開啟系統資料夾選擇器。lib 內沒有任何程式監聽 `DomainLoading` 來啟動載入（grep `is DomainLoading`／`DomainLoading>` 零命中）。按下後畫面停在載入中，只能按取消回到未選專案。SPEC-003 §3.1〈互動反應〉對此按鈕定義了四種結果：選定 → 載入中；選擇器被取消 → 留在未選；選擇器打不開 → SnackBar `chooseFolderUnavailableMessage`；資料夾不可讀 → SnackBar `folderUnavailableMessage`。四種結果都沒有實作。
(2) gate 結果繞過世代：`GateDetectionNotifier._apply` 直接寫 `domainViewStateProvider`，不遞增 `DomainViewLoader._generation`。進行中的 `load()` 不會因此失效。

### 影響範圍

已驗證（讀碼）：
- (1) 可達。`DomainUnset` 有三個入口，進入後都會渲染這個按鈕：App 啟動時沒有已存路徑（shell `_restoreWorkspaceAndDetect` 的 `WorkspaceUnset` 分支）、還原失敗（`WorkspaceUnavailable` 分支）、取消載入（`DomainViewLoader.cancelLoading`）。首次啟動時主內容區唯一的主要操作就是這顆按鈕，目前只能改走專案切換浮層。
- 兩個既有測試把佔位行為鎖成了規格：test/unit/screens/domain_view_test.dart「action-domain-choose-folder → 進入載入中」只斷言狀態變成 `DomainLoading`；test/widget/app/shell_test.dart 斷言點按後還原失敗的說明文字消失，而文字消失只是因為狀態轉成了 Loading。
- (2) 可達，條件是載入進行中切換專案。`ScanRoundNotifier` 在工作區變更時會 discard，但被丟棄輪次的等待者要等舊掃描跑完才拿到 `null`（`_runGuarded` 在 `_runRound` 完成後才比對世代）。拿到 `null` 後，舊的 `load()` 進入 `_obtainRound` 迴圈：世代未變、工作區仍是 Ready（已換成新路徑），於是對新路徑開新輪。新專案若是非框架或 schema 不相容，gate 已寫入 `DomainNotFramework` 等阻擋態，舊 load 完成後卻會以 `_unavailableGraph` 寫入 `DomainSchemaIncompatible(projectVersion: null)` 蓋掉它，並記一筆 level 900 log「gate 與輪次不同步」。這違反 SPEC-003 §3.1〈導航跳轉與退出〉「切換專案：中止載入」。
未驗證：(2) 在實機上的時間窗。觸發條件是舊專案的掃描在切換時尚未完成，大型專案較容易命中。
