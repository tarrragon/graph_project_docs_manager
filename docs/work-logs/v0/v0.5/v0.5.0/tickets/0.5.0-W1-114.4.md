### WRAP 評估（快速+，2026-10-08）：破洞是否顯示非字串元素數；位置欄位只有空白

議題 NC-7：`parseFailure` 破洞與報告頁是否帶 `nonStringElementCount`
| 候選 | 規則 | 致命風險 |
|---|---|---|
| G1 | 破洞攜帶計數，報告項目顯示「清單內 N 個非字串元素」（新 i18n key，含單複數） | 多一個 key；無 |
| G2 | 破洞不攜帶，報告只顯示固定原因文字 | A3 為何要帶計數失去承接處，只剩日誌 |
| G3 | 攜帶但只寫日誌 | 同上，使用者看不到 |
傾向 G1，信心中：A3 帶計數就是為了不逐筆報也能說出規模；`doc validate-paths` 負責定位哪一個。

議題 NC-8：`non_domain_paths_file`／`_key` 只有空白（如 `" "`）
事證：這兩欄由 `doc schema export` 從常數寫出，只有手改會出現空白值；規則 1（2A）已定空字串視為缺欄。
| 候選 | 規則 | 致命風險 |
|---|---|---|
| W1 | 去除首尾空白後為空即視為缺欄，回落內建表；非空值不做修剪照原值使用 | 無 |
| W2 | 照原值使用 | 清單檔路徑 `" "` 找不到，非 domain 側變成未宣告，且不發事件——宣告被靜默丟失 |
| W3 | 視為型別表欄位格式錯誤，另發事件 | 需新事件或新子原因，範圍擴大 |
傾向 W1，信心中：與 2A 同一意圖（缺值不當作位置），避免 W2 的靜默丟失。
