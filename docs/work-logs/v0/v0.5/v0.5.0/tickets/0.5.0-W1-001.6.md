## Problem Analysis
### 問題根因

IT-1～IT-3 的凍結測資與實體化器不帶 0.5 新能力所需的輸入：manifest 無 `domain`、無 `depends_on_bundles`、無 UC 本文，凍結型別表缺 `bundle_dependency`。IT 即使呼叫新能力也只會得到空子圖與空索引，故 flowOf、名稱解析、FR-12、FR-13、`bundle_dependency` 進主圖在 IT 層皆零覆蓋。

### 影響範圍

已驗證：零覆蓋屬實；只重跑 `freeze` 覆蓋不到任何一項新能力，因為參照實作 `tool/spec007_reference.py` v1.0.0 的使用中邊型定義落後 SPEC-007。未驗證項見 Solution 末段。

### 相關 Error Pattern

無匹配。相關規則：test-assertion-design-rules E 系列（鑑別力）——參照實作與規格的落差，現有 selftest 與 compute 皆測不出。
