### 實作要點（易錯處）

- 比對集合取 Corpus `rawNodes` 中 `typeName == 'EVT'`、`id` 為非空字串者，不取輕節點：主圖遇重複 ID 兩節點都不建，取輕節點會讓 G10-29 翻紅。`lib/diagnostics/event_gap.dart` 已有同一集合的取法（`eventTypeName`），注意 Graph 不得反向依賴 Diagnostics
- emits／consumes 正規化沿用 FR-10〈步驟屬性〉既有結果（`flowKeyOf`），原始值記元素原值（非字串不轉字串）
- 子類識別名由本票命名（加入 `FlowDefectKind`），回填 SPEC-007 FR-09 識別名段
- `lib/diagnostics` 不得 import `lib/schema/`（461 守衛 `test/unit/diagnostics/diagnostics_import_direction_test.dart`）

### 既有測試的連帶影響（test-design §6.1）
