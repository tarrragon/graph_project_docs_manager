### Rationale Chain
- 0.5.0-W1-187.7 why: 覆核實測：macOS 上對只剩未回收殭屍的程序群組呼叫 killpg，訊號 0、TERM、KILL 皆拋 PermissionError。腳本的送訊號函式只處理 ProcessLookupError，故逾時邊界與正常結束後的殘留清理兩條路徑會以錯誤堆疊與結束碼 1 收場；後者會把成功的命令回報為失敗。另命令不存在時回 1 並印出錯誤堆疊，與命令自身失敗無法區分（來源已完成，結論見 Solution）
- 0.5.0-W1-164.1 why: W1-164 實驗：subprocess.run(timeout) 以 SIGKILL 終止持鎖 git，必留 0 位元組 index.lock；SIGTERM/SIGINT 則 git 自行清鎖。git_ops._run_git 預設 10 秒、worktree-auto-commit 的 git add -A / commit 10 秒皆走此路徑（來源已完成，結論見 Solution）
