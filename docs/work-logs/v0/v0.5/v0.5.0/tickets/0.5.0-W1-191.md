## Solution
<!-- Schema[ANA/Solution]: 必填（.claude/pm-rules/ticket-body-schema.md） -->

### 逐行差異
git_ops `_run_with_graceful_timeout` 與 hook 同名函式本體逐行一致；差異僅：(a) 常數名 `_TERMINATE_GRACE_SECONDS` vs `TERMINATE_GRACE_SECONDS`；(b) docstring 末段 hook 版多「本檔為單檔腳本、無法與 ticket_system 共用模組」。另 lib/git_utils.py 於 9bcd80d4c 新增第三份，本體亦一致，docstring 多「只終止直接啟動的行程」。

### 建立提交與理由
git_ops：519cfbebf（2026-10-13，ticket git 逾時改先 SIGTERM）；hook：a66c18a62（2026-10-13，加契約測試）；lib：9bcd80d4c（2026-10-14，164.6.2）。理由僅見 hook docstring「單檔腳本無法共用」，經查不成立：hook 已 `from lib import`，ticket_system 有 claude_lib_loader。複本為趕工並行修補的產物，非刻意。

### 結論：收斂（非維持、非僅加同步檢查）
依據見 164.6.8 Solution〈收斂方案比較〉採 A：hook 直接匯入、ticket 經 loader 並保留備援。以子票 0.5.0-W1-164.6.8.1 落地，不重複建票。
