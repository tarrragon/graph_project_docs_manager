## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### 修法（worktree commit 9663be069）

- `worktree-branch-check-hook.py` 的 `get_unmerged_branches`：原本解析 `git branch --no-merged main` 給人看的輸出，再以 `strip().lstrip('* ')` 清理；改為 plumbing `git for-each-ref --no-merged=main --format=%(refname:short) refs/heads`，輸出本身不帶 `* `、`+ ` 前綴
- 測試：新增 `TestGetUnmergedBranchesPlumbing`，以真實 git 驗證（tmp 內 init，再用 `git worktree add` checkout 一個未合併分支）；既有 `TestCheckGitStateScenarioB` 的替身比對字面由 `["branch","--no-merged"]` 改為 `["for-each-ref"]`，否則替身會失配

### 自檢結果

- [x] 修改前紅燈：`get_unmerged_branches()` 實得 `['+ feat/wt']`
- [x] 正向對照：已合併分支不列入、未 checkout 的一般未合併分支仍列入（修改前後皆綠）
- [x] 名稱目前只用於顯示，未參與比對，判定行為不變
- 已知邊界：`%(refname:short)` 在分支名與 tag 同名時會輸出 `heads/<name>` 消歧義字面；此情況僅影響顯示，不另處理
- Phase 4：重構需要：否；技術債務：無；程式碼品質：A；結論：以 plumbing 取代 porcelain 解析，函式縮短
