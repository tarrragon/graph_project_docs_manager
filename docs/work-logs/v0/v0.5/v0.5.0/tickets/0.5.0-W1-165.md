**第二列的比對須比抽取規則寬**（該組的要求）：任何標題行（各級 `#`）其文字以 FR 開頭者皆算，不分大小寫，含無連字號（FR01）、空白（FR 01）、全形連字號與 en dash。理由：審查列出的漏放寫法（fr-01、FR01、FR 01、全形連字號）不會被抽取規則抓到，若矛盾檢查沿用抽取規則，這些寫法會被 false 宣告放行。NFR 開頭的標題不算（以字界或前綴排除，NFR-01 不得命中）。

已知殘留（接受，於 SKILL.md 明寫）：宣告 false 的 SPEC 若以完全不含 FR 字樣的標題定義需求（如「功能需求 1」），矛盾檢查抓不到。
