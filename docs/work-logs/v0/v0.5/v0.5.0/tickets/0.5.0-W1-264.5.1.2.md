## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
修改 .claude/hooks/bare-commit-guard-hook.py：新增 _overrides_git_dir（檢查子命令前 token：GIT_DIR=/GIT_WORK_TREE= 前綴含 env 包裝、--git-dir/--work-tree 選項）、_commit_target_checkouts（全部 commit 呼叫目標聯集；任一呼叫帶覆寫或目標無法判定即回 None=不過濾）、_filter_dispatches_for_targets（條目位置等於任一目標即保留）。main() 改呼叫這兩者；_commit_target_checkout 單一目標邏輯不動，不改 .claude/lib/。
失敗語意依據：目標無法判定或帶 git-dir 類覆寫時全數計入（多擋方向）；rev-parse 失敗仍沿用原 fail-open 並雙通道回報，hook 例外時行為不變。已知殘留：事先 export 的 GIT_DIR（值不在命令文字）。

- Python 3.9 相容、logger 沿用 main 內既有傳遞方式、無新增 print 日誌。

### Phase 4 結論
