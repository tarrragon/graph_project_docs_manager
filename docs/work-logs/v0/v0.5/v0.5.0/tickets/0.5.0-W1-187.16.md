## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
is_runner 首詞為絕對路徑時，須為磁碟上存在的一般檔案（新函式 _is_regular_file，測試中可替換）才繼續認定，否則不認定；移除「首詞為執行器且次詞為含斜線直譯器路徑即不認定」的判斷（原始碼 grep cut 無殘留）。非絕對路徑首詞維持原判斷。說明文字補「首詞為絕對路徑但檔案不存在（含執行檔已被刪除）不認定」。認定表測試以替換 _is_regular_file 使除兩個半截路徑外的絕對路徑視為存在；另加 test_absolute_first_token_must_exist 以 tmp_path 真實檔案驗證存在、不存在、目錄三情形。

### 自檢結果
- 五個票面字串：兩個不認定、三個認定，皆在認定表。
- 既有認定表全數通過；未加任何依後方詞推測路徑的規則。
- 未遇到無法判斷的形態。
