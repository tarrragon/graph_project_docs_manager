## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### Context Bundle（-3e，2026-10-19）

- 成因與重現指令見 0.5.0-W1-353 Solution〈PM 定位成因〉。重現方式：`uv --directory <checkout>/docs run --no-project --quiet --with pytest python -m pytest -p no:cacheprovider --rootdir <checkout>/.claude/hooks <checkout>/.claude/hooks/tests/test_bare_commit_guard_hook.py`，修前結果為 3 failed, 141 passed
- **提示字面（主控指定，須一字不差）**：訊息中的正確指令寫作 `uv --directory <checkout>/.claude/hooks run pytest <path>`。0.5.0-W1-358（L6）會讓派發範本與此字面一致
- **既有 conftest 的限制**：`.claude/hooks/conftest.py` 的 `pytest_configure`／`pytest_unconfigure` 只在計時環境變數設定時才綁定（模組末端條件賦值），並從 `testpaths_coverage_warning` 匯入 `pytest_collection_modifyitems`、`pytest_terminal_summary`。新增的依賴檢查不得覆蓋或取消這些 hook，建議用 `pytest_sessionstart` 或在模組載入時檢查
- `pyproject.toml` 的 `testpaths = ["tests", "../lib/tests"]`：確認 `../lib/tests` 經 hooks 入口執行時也受檢查保護
- 檢查清單至少包含 `yaml`；其他第三方依賴依 `.claude/hooks/pyproject.toml` 的 dependencies 決定是否納入，並說明取捨

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
conftest.py 新增 pytest_sessionstart：以 importlib.util.find_spec 檢查 yaml（對應 pyproject dependencies 的 pyyaml，目前唯一第三方依賴），缺則 pytest.exit(returncode=4)，訊息含 uv --directory <checkout>/.claude/hooks run pytest <path>。不動既有條件式 pytest_configure/unconfigure 與兩個匯入 hook；sessionstart 在 collection 前，../lib/tests 同受保護。新增 tests/test_hooks_conftest_env_guard.py（E2 缺 yaml 子程序、E1 正常環境）。
