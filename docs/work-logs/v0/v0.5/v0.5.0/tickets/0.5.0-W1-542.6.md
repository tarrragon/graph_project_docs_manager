## Problem Analysis
### 問題根因

ticket 與 log 的讀者多半是下一個 session 或代理人。讀者讀錯或需要追問時，交接就會失真。asd-ste100 1.0.0 已有 zh-TW pack（句子規則與詞庫），但沒有證據顯示它能讓讀者讀得更準或更快。本票用實測取得這項證據。

### 影響範圍

- 受影響：asd-ste100 skill 的適用範圍、`language-constraints` 規則 1（只有在英文 STE 組明顯勝出時才需要另開票）。
- 已驗證：無。
- 未驗證：zh STE 改寫能提高答對率或減少追問；英文 STE 對 Haiku 讀者是否較易讀。

### 相關 Error Pattern
