## Solution
### 判定：與 169.1.1 無關

1. 靜態不可達：integration_test 的兩個入口（app_test、real_font_layout_test）都注入以 `implements` 實作的 stub，沒有任何路徑建構真實的 `WorkspaceRepository`，也沒有覆寫 `workspaceRepositoryProvider`。169.1.1 的改動只在真實 repository 內。
