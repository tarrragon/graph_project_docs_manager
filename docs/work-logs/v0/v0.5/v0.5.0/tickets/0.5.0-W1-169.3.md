### 169.2 結論轉入（L42，2026-10-31）

- `detect` 位於 `lib/app/gate_detection_notifier.dart`（非 `lib/screens/domain_view/`）。呼叫端兩處：`lib/app/workspace_selection.dart` `select`、`lib/assembly/shell.dart` 啟動還原。浮層的收合順序在 `select` 之後的 `_dismiss`。
