## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
sampler.py: PEP 723 dependencies 改 anthropic==1.17.0；指定 temperature 時改放 params[extra_body]={temperature: 值}，紀錄欄位 temperature 照舊。test_sampler.py: FakeClient._create 簽章比照 SDK 1.17.0（無 temperature 關鍵字，收 extra_body）；E1 對照測試更新；新增 test_fake_rejects_temperature_kwarg。

### 自檢結果（PM 合併後覆核）

- 修改範圍：sampler.py、test_sampler.py 兩檔，與 where.files 一致。
- AC1：PEP 723 為 `anthropic==1.17.0`（diff 確認）。
- AC2：指定 temperature 時 `params["extra_body"] = {"temperature": 值}`，紀錄欄位照舊寫入實際值（diff 確認）。
- AC3（E1）：`test_temperature_omitted_vs_passed` 斷言未指定時請求無 extra_body、指定時 extra_body 為 {"temperature": 0.3}，且兩次請求不相等。
- AC4：替身 `_create` 簽章為 `(*, model, max_tokens, messages, extra_body=None)`，`test_fake_rejects_temperature_kwarg` 為正向對照（關鍵字參數傳 temperature 必須丟 TypeError）。
- AC5：合併閘門 ac0103533 的 research-python 套件 29 passed、flutter 套件 2805 passed。
- 已知限制：替身只記錄已知參數，`"temperature" not in calls[1]` 這條斷言本身無鑑別力；鑑別力由替身簽章（AC4）承擔。
