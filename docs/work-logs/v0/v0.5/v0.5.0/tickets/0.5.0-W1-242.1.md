### 修法

commit a2f0c3a84、d0d4e9ed6：tool_name 為 Bash 且 tool_response 為 dict 時，只取 stdout 與 stderr 以真實換行串接後評估，bashEditDiff 不再參與比對；兩欄位皆缺時 fail-open；其他工具與字串形態維持原行為。綠燈樣式補 pytest -q 摘要（含排除 failed／error 的 lookahead）。

| 綠燈捷徑只要任一處命中即整段放行，多次 pytest 時一次全綠蓋掉其他失敗；新 -q 樣式擴大命中範圍 | 中 | 0.5.0-W1-242.2 |
