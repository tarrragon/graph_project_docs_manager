## Problem Analysis

### 來源與現況（0.5.0-W1-531 重現實驗結果）

- `_buildMessageBlock` 以 `Semantics(header: true, liveRegion: true)` 包「訊息 + 版本（plain 變體的 `version`）」整個 Column，且未設 `container`；併入外層後 live 節點 #4 為全畫面，label：plain 完整為「schema unavailable\n1.0.0\nexplanation text」（explanation 由 build 第 133 行附近的 `AppText.multiLine(explanation!)` 併入）；withDetail 收合為「msg\nexplanation text」、展開為「msg\nexplanation text\nApp 已知版本範圍\n不高於 1.0.0」（詳情面板文字併入），兩顆按鈕皆在 live 子樹。
- SPEC-004 §4.23 無障礙子節：「訊息為 Semantics.header；版本值接續；進入本狀態時訊息以 liveRegion 播報一次；面板展開由 expanded 旗標播報」。對齊方式：header + liveRegion 只包訊息 Text 並加 `container: true`，版本與 explanation 成為朗讀順序接續的獨立節點。
- 注意：withDetail 變體的 #4 另帶 `isFocusable`／`focus` action，來自 Esc 收合用的 Focus（`_onKey`）；改動後該旗標將落到外層節點，須確認 Esc 收合與焦點落點測試（SPEC-003 §2.10、§4.23 測試點「expanded 下 Esc 收合、焦點停在 action-domain-schema-detail」）仍全綠，且 focus 不落在 live 節點。
- 修法與測試寫法比照 `0.5.0-W1-531.1`／`531.2`（`test/unit/components/missing_source_state_test.dart`、`loading_state_test.dart` 的「liveRegion 語意」group）。
- 畫面測試範圍：BlockedState 只用於 domain_view → `test/unit/screens/domain_view_test.dart`、`test/unit/screens/domain_view/`、`test/unit/screens/domain_view_schema_drift_test.dart`。
