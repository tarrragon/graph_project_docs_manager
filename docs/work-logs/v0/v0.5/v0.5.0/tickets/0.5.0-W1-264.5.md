## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### PM 派發前補充（2026-10-14）

- 定義位置：get_active_dispatches 在 .claude/lib/dispatch_tracker.py（簽章 get_active_dispatches(project_root: Path)，project_root 為必填），不在 hook_base；where.files 已更正。
- 匯入方向：hook_base.has_parallel_dispatch（0.5.0-W1-264.4 新增）會呼叫 dispatch_tracker，若 dispatch_tracker 反過來匯入 hook_base.get_shared_state_root，可能形成循環匯入。另一點：get_shared_state_root 以行程 cwd 判斷是否位於 linked worktree，而 get_active_dispatches 已收到 project_root 參數。建議修法改為以傳入的 project_root 為基準，在 dispatch_tracker 內以  推回主倉庫：不依賴 cwd、沒有匯入循環，語意也與 ticket CLI 的 get_ticket_state_root 一致。修法由執行者決定，取捨寫進 Solution。
- 寫入路徑：dispatch_tracker 的登記與清除等寫入函式，是否要同樣改寫到主倉庫，須一併盤點。讀寫不一致時，會造成寫在 worktree、讀在主倉庫的新分裂。

### 更正（PM，2026-10-14）

上一段「建議修法改為以傳入的 project_root 為基準，在 dispatch_tracker 內以 … 推回主倉庫」中的命令，在寫入時被 shell 的反引號命令替換吃掉（PC-079），原句缺字。完整寫法如下：

在 dispatch_tracker 內執行 `git -C <project_root> rev-parse --path-format=absolute --git-common-dir`，取其父目錄作為主倉庫根。
### 盤點（basil-hook-architect，2026-10-14）
