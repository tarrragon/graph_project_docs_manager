### mod 能力查證（來源：CC 2.1.303 內建 plugin-authoring skill 的 reference.md、examples、types/claude-code.d.ts）

| 面向 | 官方能力 | 對看板的意義 |
|------|---------|-------------|
| 形態 | 三個檔：`.claude-plugin/plugin.json`、`hooks/hooks.json`、`hooks/register.tsx`；TS 模組，無 DOM／Node，外界一律經 `$` | 小型單檔實作 |
| 畫面 | `$.ui.open` 開 Pane（fullscreen 終端寬 >= 144 欄時停靠在側邊，其他情況嵌在 prompt 上方）、`AbovePrompt` 橫條、`$.ui.status`、`$.ui.toast`、`$.command.register` 斜線指令；元素含 `Markdown`、`Button` | 側邊面板、一行狀態、一行指令都可行 |
| 讀資料 | `$.fs.read`（任意路徑，單檔上限 4 MiB）、`$.fs.list/stat`（mtime）、`$.process.run`（argv，不經 shell，預設逾時 30 秒，可跑 `ticket`、`git`） | 直接讀 repo，不需要專案 id |
| 定時 | `$.clock.every`，在 `session.start` 啟動，模組 reload 時取消 | 定時更新，不靠各線自律 |
| 狀態 | `$.state`：單一 session 內共用、render 時讀取即訂閱、改值自動重畫；`$.store`：每個 plugin 一個 JSON（上限 4 MiB），跨 session 保留 | 畫面資料放 `$.state` |
| 同儕 | `$.session.send` 傳訊給其他 session；`session.receive` hook 收得到同儕訊息 | 可記錄各線回報（選用） |
| 載入範圍 | dev mods 資料夾只對本 session 生效（hot reload 需用戶在對話框同意）；每個 session 都要載入時，用 `~/.claude/settings.json` 的 `env.CLAUDE_CODE_PLUGIN_DIRS`，或把本地資料夾加為 marketplace 再 install | 正式使用要決定安裝方式 |
| 驗證 | `claude plugin validate <dir>`、`tsc -p <dir>`、`claude plugin test <dir>`（`*.test.ts`） | 驗收可機械化 |
| 穩定性 | API 屬 early access，各版本間會變；權威是型別檔，不是說明文件 | 升版後須重跑 validate |

**W：載入範圍選項**

| 選項 | 做法 | 代價 |
|------|------|------|
| 1 | 只放本 session 的 dev mods 資料夾 | 綁定本 session id，新開 session 不會載入 |
| 2 | mod 放在固定資料夾，看板 session 以 `claude --plugin-dir <資料夾>` 啟動 | 不改任何設定；每次開看板都要帶參數 |
| 3 | 在全域 `~/.claude/settings.json` 的 env 加 `CLAUDE_CODE_PLUGIN_DIRS` | 這台機器所有專案的 session 都會載入，mod 必須自行判斷 repo，不符就不作用；會改到全域設定 |
| 4 | 分兩個 mod：看板 mod 只在看板 session；各線 session 掛一個只負責回報的 mod，把自身狀態寫進共用檔 | 回報 mod 仍須以 2 或 3 的方式載入 |

**盲點（原需求沒有寫到）**

1. 「哪個 session 在等我回答」只能在該 session 內部觀測（turn 開始與結束、AskUserQuestion 的 tool.call）。從外部讀 repo 的看板讀不到這一項，只有選項 4 拿得到
2. 各線的票在 worktree 內修改，main checkout 的票檔可能落後；即時狀態要讀各 worktree（`git worktree list`）
3. Pane 只在 fullscreen 終端且寬度至少 144 欄時停靠在側邊，其他情況會嵌在 prompt 上方、佔三分之一高度；用戶的終端配置未知，需要用最小 mod 實測
4. mod 程式碼的位置：放 dev mods 不會入庫；放 `.claude/` 會被 sync-push 帶到其他 consumer，但本 mod 讀 349 的路徑，屬本專案專屬；放 repo 其他目錄則要改本票 where.files（目前是 `docs/`），且該路徑不在 PM 可寫路徑內
5. API 屬 early access，CC 升版後要重跑 `claude plugin validate`／`test`
6. 成本：mod 讀檔與計時不經模型、不耗 token；Artifact B 每寫一次都耗額度
