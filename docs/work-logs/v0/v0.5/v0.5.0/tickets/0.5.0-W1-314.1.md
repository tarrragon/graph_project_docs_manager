## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
W1-314 補充：記憶體壓力假設未能排除『pageout 尖峰停頓』，閘門紅燈時請同時把 vm_stat（或 memory_pressure）與 swap 用量寫入保留的失敗細節，供 314.3 比對。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
merge_gate.py：紅燈（exit 非 0 且非 124/125）時 save_failure_output 將全輸出寫入 <log_root>/.claude/logs/merge-gate-failures/<commit前12碼>-<suite>.log，檔頭含 suite/exit/時間與 memory_snapshot（memory_pressure free percentage、vm_stat Pageouts、sysctl vm.swapusage）。錯誤訊息失敗項加入 pytest E 行並印出旁置檔路徑。探針失敗 fail-open（stderr WARNING，欄位記「取不到」）。

- Phase 4：重構需要 否；技術債務 無；品質 A；結論：新增函式短小單一責任，無需重構
