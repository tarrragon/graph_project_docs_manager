## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
實測（修前，jq 組 PreToolUse payload 餵 hook，被測命令未執行）：man -Hpkill ls => exit 0、man --html=pkill ls => exit 0，兩者皆繞過，假設成立。
修法：_EXEC_OPTS["man"]["prefix"] 加 "-H"、"--html="；_expand_tokens 對黏寫短選項（-Hpkill、-Ppkill）另加去掉前兩字元的片段，否則整個 token 的 basename 不為 pkill。附帶發現：修前 man -Ppkill ls 同樣繞過，已一併修並加測試。_message 改寫指引補例外句（rg --pre、man -P/--pager/-H/--html=、less + 時閱讀類放行不適用）。
未納入：man -H pkill（選項值分離）不是瀏覽器值（getopt 可選參數只能黏寫），不當執行器；man --html ls 放行並以測試鎖定。
殘留：BROWSER 環境變數，值不在命令文字，靠自律（同票 how 已記）。

### 自檢結果
- 正向對照：man -Hpkill ls、man --html=pkill ls、man -Ppkill ls 皆斷言 exit 2。
- 放行對照：man -H ls、man --html ls 斷言 exit 0。
- 既有 46 筆測試不變。
