## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
函式語意：lib.hook_base.get_shared_state_root(default_root=None)。HOOK_TEST_ISOLATION=1 回 default_root 或 get_project_root；cwd 在 linked worktree 回 git rev-parse --path-format=absolute --git-common-dir 的父目錄（主倉庫，對齊 ticket CLI get_ticket_state_root）；其餘回 default_root，None 時 get_project_root。default_root 讓呼叫端傳入已解析根，既有對 module.get_project_root 的測試替身仍有效。結果依 cwd 快取於獨立 dict（_MAIN_REPO_ROOT_CACHE），不碰 228.1 的 _PROJECT_ROOT_CACHE；clear_project_root_cache 一併清兩者。已由 lib 匯出。
改接：acceptance-gate-hook main 的 project_dir 改為 get_shared_state_root(get_project_root())；hook_ticket.find_ticket_file 與 extract_where_files 的預設根改用 get_shared_state_root。
失敗語意：非 repo 或 git 不可用屬非 worktree，靜默退回 default_root（有測試，無 stderr）。已偵測為 linked worktree 但 common-dir 查詢失敗或逾時：退回 default_root（get_project_root 語意）、寫 stderr 並 logging warning（規則 4），有測試。
實地觸發：scratchpad 暫存 repo（base 分支）加 linked worktree，主倉庫票面 2/2 勾選、worktree 副本 0/2，cwd=worktree、CLAUDE_PROJECT_DIR=主倉庫，以 settings 註冊的 uv run --quiet 啟動 acceptance-gate-hook.py 餵 PreToolUse complete payload：rc=0、allow、日誌「frontmatter acceptance list 全部勾選 (2 項)」，即讀到主倉庫那份。
liveness：hook 日誌照舊落 worktree 的 hook-logs（日誌根未改）；上述日誌行存在即證明該行程實際執行並走到票面讀取。變異確認：把 gate 改回 get_project_root()，test_main_entry_uses_shared_state_root 翻紅，還原後翻綠。

Phase 4：重構需要 否；技術債務 有（find_ticket_file 與 extract_where_files 預設根無 worktree 直接測試；ticket 讀取仍有 264.4 範圍的 process-skip-guard、session-registry 未改接）；程式碼品質 A；結論 無需重構。
