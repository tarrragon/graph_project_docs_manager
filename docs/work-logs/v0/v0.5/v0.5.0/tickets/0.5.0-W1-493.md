- 410.3 Solution〈line-board 的型別檢查〉為「閘門不跑 tsc」的定案出處；`merge-gate.yaml` line-board 套件上方註解同義。
- 候選一的現行手動配方（485.7.1 PM 覆核實測 rc=0、error TS 0、列出 25 個 worktree hooks 檔）：

```json
{
  "extends": "<主 checkout>/tools/line-board/.claude-plugin/types/tsconfig.json",
  "compilerOptions": { "noEmit": true, "typeRoots": ["<主 checkout>/tools/line-board/.claude-plugin/types"] },
  "include": ["<worktree>/tools/line-board/hooks/**/*", "<worktree>/tools/line-board/types/**/*"]
}
```
