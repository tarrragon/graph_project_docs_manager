## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### 實作結論（parsley 於 worktree 實作，L42 驗收；2026-10-31）

合併 commit 046de015d（分支 worktree-agent-a9bbae1b49edf07b0，commit ec8fe286e）。

- `lib/workspace/workspace_repository.dart`：
  - `_persistAndInspect` 先呼叫 `_inspect(path)`。它維持在 try 之外，且只呼叫一次。
  - 結果不是 `WorkspaceReady` 時，不開 handle、不寫入，回 `ChooseFolderSelected(state)`。
  - 可用時才寫入，path 先、版號後（0.2.0-W1-021 的不變式保持）。
  - 新增 `_writeSchemaVersion`：版號回 false 或拋例外時，只記 level 900 日誌，不設 failureReason。`persistCompleted` 只在 path 與版號都成功時記。
  - 結果：`ChooseFolderNotRemembered` 不再攜帶 `WorkspaceUnavailable`（0.5.0-W1-169 候選 X3，用戶裁定採用）。
  - 更新 `_persistAndInspect` 與 `openPath` 的 dartdoc。
- `test/unit/workspace/workspace_repository_test.dart`：
  - 新增 G2c 群組：不可用不寫入，以可用時會寫入作為對照，chooseFolder 與 openPath 各測；版號回 false 或拋例外；偏好替身失敗加探測失敗時不回 NotRemembered。
  - G2b-2 的斷言由「仍寫入」改為「不寫入」，這是本修正預期的語意翻轉。
  - G1-4、G5-5 補上探測替身。這兩則原本靠真實檔案系統探測一個不存在的路徑，改版後會變成不寫入。
- 流程偏差：代理人以 `git add` 兩檔加 `git commit` 提交，沒有用 `ticket track commit --worktree`。範圍經 PM 核對只含 where.files 兩檔，予以接受。
