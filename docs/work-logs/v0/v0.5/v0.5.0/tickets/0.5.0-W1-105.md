## Problem Analysis
<!-- Schema[ANA/Problem Analysis]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因

`doc validate-filenames`（`.claude/skills/doc/doc_system/commands/validate.py` 的 `_check_filename_conventions`）以 `rglob("*.md")` 掃 DOC_TYPE_CONFIG 各 target_dir，並以 inline 正則 `^{PREFIX}-(\d+)` 判檔名、以 `{PREFIX}-{數字}` 比對 frontmatter id。此實作不讀 `tracking_schema.py` 的 `id_pattern` 與 `carrier_path_patterns`，產生兩類框架落後；另有一類為專案檔案 id 違反 schema。
