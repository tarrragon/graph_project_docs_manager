**現況**（`.claude/skills/line-board/hooks/register.tsx`）
- `session.start` 註冊 `/board` 後 `void openIfConfigured($)`
- `openIfConfigured`：`$.session.root()` → `findCheckouts($, root)`（readers.ts，跑 `git worktree list --porcelain`）→ `mainPath = checkoutPaths[0] ?? root` → `readProjectConfig($, mainPath)` → 設定成立才 `startTimer`、`void refresh`、`await $.ui.open(...)`；catch 只 `$.ui.log(..., { to: 'debug' })`

1. 先讀 root：`readProjectConfig($, root)` 成立就立刻 `startTimer`、`void refresh`、`ui.open`，不呼叫 git；不成立（missing／invalid）才走 `findCheckouts`，取 `checkoutPaths[0]`，在 mainPath ≠ root 時再讀一次（worktree session 情境，行為與現行相同）。兩次都不成立時寫 unconfiguredSnapshot，`configPath` 指向 mainPath（與現行相同）
2. 失敗可見：catch 不只寫 debug。可選做法：`$.ui.log` 改送 transcript，或把失敗原因寫進 `$.state` 讓 `/board` 顯示，擇一並在 Solution 說明理由。readers.ts 的 `readProjectConfig` 讀不到時的 debug log 屬正常路徑（無設定），不在此列
