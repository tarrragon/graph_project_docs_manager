## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 派發前盤點（PM，2026-10-30，213.3 合併後）

- 現行違規：app → screens 共 5 條，見 why。gate_detection_notifier 又 import app/domain_view_loader，形成循環。
- 要移的 5 個檔與它們的依賴：
  - `domain_view_state`：無專案內依賴。
  - `domain_view_schema_version`：無專案內依賴。
  - `project_switcher_providers`：只依賴 workspace。
  - `gate_detection_notifier`：依賴 loader、schema、workspace，以及 domain_view 的 providers、schema_version、state。
  - `domain_view_providers`：依賴 `domain_view_projection.dart`（畫面投影），不能整檔移入 app。只把 app 讀寫的 provider 移入 app，依賴投影的 provider 留在 screens。哪些移、哪些留、理由，寫在 Solution。
- 不用 export 轉出，所有引用端都改 import 新路徑。理由：
  - 先例：`domain_view_loader_test` 的 B9 守衛（0.5.0-W1-114.14）明確禁止 project_switcher_providers 轉出 `currentWorkspaceStateProvider`，專案已有不留過渡轉出的先例。
  - 轉出會讓同一個型別有兩個 import 路徑，目錄即層的判讀因此失準。
- where.files：33 個實際 import／export 這 5 檔的引用端，加上 5 個舊路徑與 5 個預定的新路徑（lib/app/ 下同名），共 41 檔。新檔名不同時以 set-where 更正並在 Solution 說明。
- 不碰 uc_flow：547 會改 uc_flow 系列，清單內已確認沒有這些檔。
- 以路徑字面掃描原始碼的測試：`domain_view_loader_test.dart` 的 B9 以 `File('lib/screens/project_switcher/project_switcher_providers.dart')` 讀源碼，要同步改成新路徑並實跑。E2 正向對照的合成樣本不動。
- 只在註解提到舊路徑的檔案（例如 lib/schema、lib/workspace 的 dartdoc）不在本票範圍，搬移後一併交給 213.7。
- 驗證：以 grep 確認 lib/app 內沒有任何 import 指向 lib/screens，結果貼在 Test Results。
- 規模：這張票超過檔案數閾值，屬機械性 import 改寫。真正有設計判斷的只有 domain_view_providers 的切分，所以不拆票。

## Solution

### 移動清單（git mv，所有引用端改新路徑，無 export 轉出）

| 舊路徑 | 新路徑 |
|--------|--------|

### domain_view_providers 切分

- 移入 lib/app/domain_view_providers.dart（新檔）：`domainViewStateProvider`（loader、gate 偵測、shell 讀寫）。
- 留在 lib/screens/domain_view/domain_view_providers.dart：`domainGraphUnavailableProvider`、`domainMatrixProvider`、`domainEmptyLanesProvider`、`firstNodeInLaneQueryProvider`、`domainSwimlaneProvider`。理由：它們回傳 `DomainMatrix`／`DomainLane`／`DomainSwimlaneView`（domain_view_projection 的畫面投影型別），搬入 app 會使 app import screens。
- 以上為 where.files 內的既有路徑，無須 set-where。

### 其他

- 循環解除：gate_detection_notifier 與 loader 同在 app，app 不再 import screens。
- B9 路徑字面測試（domain_view_loader_test）改讀 lib/app/project_switcher_providers.dart；domain_view_projection_test 的 `_allowedFiles`（真實守衛）與其 E2 樣本改為 app 路徑。
- 只在註解提到舊路徑、交給 213.7 的檔案：lib/schema/schema_source_resolver.dart、lib/schema/schema_version.dart、lib/workspace/framework_signal_probe.dart；test/unit/screens/domain_view_schema_drift_test.dart 的檔頭註解已隨批次改寫路徑字串（該檔在 where.files 內，保留）。
