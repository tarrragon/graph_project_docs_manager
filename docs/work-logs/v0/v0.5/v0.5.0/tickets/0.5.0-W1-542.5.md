## Problem Analysis
### 問題根因

asd-ste100〈語言邊界〉把「英文中轉」（先寫英文 STE，再轉成正體中文）列為待實測。英文中轉有兩項風險：詞庫只換詞、不換句型，會留下翻譯腔；用戶只讀得到中文，英文中間稿的錯誤看不到。本票用實測決定預設寫法。

### 影響範圍

- 受影響：`.claude/skills/asd-ste100/SKILL.md`〈語言邊界〉與 `CHANGELOG.md`。
- 已驗證：無。
- 未驗證：兩種寫法在讀者誤讀、追問、長度、詞庫違規上的差異。

### 相關 Error Pattern

PC-168（少量綠燈不等於穩定）：本票 5 則情境、每格 3 名讀者，取樣與判定規則在開跑前寫定。

### 查重紀錄

查重關鍵字：`STE`、`詞庫`、`controlled language`、`翻譯`。dedup 列出 21 個 issue（#48–#109），標題都不涉及受控語言或寫法實測，關係判定：無關，不引用。

**評分方式**：
1. 誤讀數：答錯的作答數（每組 45 個作答）。先用腳本比對答案鍵關鍵詞，不一致的由 PM 在隱藏組別的清單上人工判讀。
2. 追問數：第 4 題中非「無」的條目數。
3. 長度：依 zh-TW-rules 規則 8 計數。
4. 詞庫違規數：以腳本比對 zh-TW-lexicon 的禁用同義詞欄與 `language-constraints` 規則 2 禁用詞。
5. 英文中間稿與 T 版逐句對照，記錄語意漂移處（中間稿有、中文版沒有或意思改變）。

**判定規則**（開跑前定）：
- T 的誤讀數與追問數都比 D 少，而且其中一項少 20% 以上 → 採英文中轉。
- D 的誤讀數不多於 T → 採直接中文（維持現行預設）。
- 其他情形 → 依情境分流：逐則看差異集中在哪一類情境，寫成分流規則；分不出情境時，採直接中文。

**停止條件**：6 名讀者的作答全數收齊即停止。作答格式無法解析時，用同一份題卷重派一次。看過結果後不增減樣本、不改答案鍵。回報漏掉答題所需的事實時照常計分，並記錄漏掉哪一項。
