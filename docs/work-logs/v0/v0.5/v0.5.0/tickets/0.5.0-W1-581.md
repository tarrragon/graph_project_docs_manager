## Solution
### 判定：flaky（環境依賴），非 main 回歸

依據：base 991c9521c 取樣 5 次，E2「永不收斂」5/5 綠；失敗樣本中 `settleGuarded` 不到 1 秒即正常返回（綠燈時約 2 秒觸發逾時），形態指向「不排幀」而非程式碼行為改變。三筆嫌疑 commit（2b99a64b2、164ebfe58、e6cde26e6）無需二分。

計時依賴：該斷言假設 CircularProgressIndicator 持續排幀，使 `pumpAndSettle` 在 2 秒內逾時。幀排程受 macOS 視窗前景／lifecycle 影響；不排幀時 `hasScheduledFrame` 為 false，`pumpAndSettle` 立即返回，正向對照反而變成「已收斂」，斷言 Actual <null>。
