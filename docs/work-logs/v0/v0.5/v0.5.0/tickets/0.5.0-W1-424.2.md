### 調查結果（L16 PM，2026-10-20）

**零產出的原因**：主功能的路徑是「最近修改的 completed 票 → 它的 `chain.root` → 同鏈的 pending 票 → 檔案不重疊者分組」。現行票面沒有這個欄位：

| 量測 | 結果 |
|------|------|
| 0.5.0 票含 frontmatter `chain:` | 22 / 764 |
| 0.1.0 票含 frontmatter `chain:` | 8 / 866 |
| 本 session 新建的 438、424.1、424.3.1 | 皆無 `chain:`，改以 `parent_id` 表達階層 |

`extract_ticket_info()` 讀不到 `chain` 時，以 `root:\s*` regex 掃全文當後備，會命中內文。日誌中被選為鏈根的值（2026-10-13～20，共 146 次）：

| 次數 | 選中的「鏈根」 |
|------|---------------|
| 91 | `0.5.0-W1-002`（該票恰有舊式 `chain:` 欄位，自己是根） |
| 55 | `Path)，project_root 為必填），不在 hook_base；where.files 已更正。`（`0.5.0-W1-264.5` 內文被 regex 誤取） |

**日誌統計**（`.claude/hook-logs/parallel-suggestion-hook/`，7 個日誌檔）：繼續請求判斷 True 147 次、False 2189 次；命中關鍵字為「繼續」89、「下一個」20、「接續」13、「接著做」12、「子任務」8、「任務鏈」3、「批量」2；任務鏈內找到 pending 的次數：146 次全為 0；並行建議 0 次。

**關鍵字來源**：424 量測約 94% 的命中不是用戶輸入。本 session 實例：子代理人交回時的 task-notification 觸發了一次「Wave 收尾」提醒（主 checkout 尚未合併 424.1）。

## Solution
<!-- Schema[ANA/Solution]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 分析結論

採 **退役整支 hook**（實作：`0.5.0-W1-424.2.1`）。424.1 移除收尾提醒後，hook 只剩並行建議主功能，而主功能因讀已停寫的 `chain` 欄位而零產出。

### 候選方案

| 方案 | 做法 | 否決或採用理由 |
|------|------|---------------|
| 退役（採用） | 移除註冊、hook 檔、測試、設計文件，同步規則表 | 現況零產出；需要的資訊已有不依賴關鍵字的入口 |
| 改讀 `parent_id`／`children` | 以父票的 pending 子票為候選分組 | 等於重做 `ticket track runqueue` 與 `parallel-check`；觸發仍是關鍵字 |
| 改寫加來源過濾 | 排除 `<cross-session-message`、`<task-notification>` 等開頭的 prompt | 只減少誤觸發，不修好零產出；過濾清單須追著平台新增的訊息形態維護 |
| 維持 | 不動 | 每次用戶輸入都掃全量 2048 張票，只消耗執行時間 |

### E2 對照：應觸發的用戶輸入

| 情境 | 退役後的承接載體 |
|------|-----------------|
| 用戶說「繼續」想知道下一張票 | `/ticket` 的 dashboard-first 流程、`ticket track runqueue`；UserPromptSubmit 的 Handoff 提醒已列待恢復任務 |
| 想知道哪些票能並行 | `ticket track parallel-check <id>`、`ticket track runqueue` 的分組 |
| 多線分工 | 主控寫入線佇列 |

### 行為變更分級

UserPromptSubmit 只輸出 additionalContext，退役不改任何放行或阻擋結果；7 天內 hook 的實際輸出只有 424.1 已移除的收尾提醒。依 424.1 的同型裁定，`0.5.0-W1-424.2.1` 合併後回報主控。

### Spawn 落地確認

| 項目 | 落地 |
|------|------|
| 退役 parallel-suggestion-hook | `0.5.0-W1-424.2.1`（IMP，children；blockedBy 424.3.1，同改 askuserquestion-rules） |
| 關鍵字來源過濾 | 無需建 ticket：hook 退役後無消費者 |
