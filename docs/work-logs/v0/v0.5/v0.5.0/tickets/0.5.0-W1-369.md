### 設計輸入（PM 盤點，2026-10-19）

**判準**：豁免項只在兩條同時成立時保留——(a) 沒有任何 hook、閘門、CLI 把它當判定輸入，也沒有把內容注入模型 context；(b) 收窄不影響例行作業。守衛只解析命令文字中的寫入目標（重導向、tee、cp/mv、sed -i、perl -i、python open()），ticket／doc CLI、uv、pytest、hook 自身的寫入不經命令文字，收窄後不受影響，要用測試鎖住這一點（E1）。`touch` 不在偵測範圍，不因本票改變。
