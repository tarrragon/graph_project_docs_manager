### 替換對照（PM，2026-10-30，532.1 合併 cfd2f6b61 後）

helper 在 `test/helpers/live_region_semantics.dart`，透過 `helpers.dart` 匯出：`pumpInSemanticsContainer(tester, {child, size, settle})`、`isInSemanticsSubtree(node, root)`、`logicalViewSize(tester)`。可參考 532.1 兩檔（missing_source_state_test、loading_state_test）的改法。

| 檔案 | 要替換的重複寫法 |
|------|----------------|
| empty_state_test | `pumpAndFindLive` 的外層 container pump；按鈕子樹的 for 迴圈；`physicalSize / devicePixelRatio` |
| load_prompt_test | 同 empty_state（按鈕子樹 for 迴圈、畫面尺寸計算） |
| blocked_state_test | `pumpAndFindLive` 的外層 container pump（settle 後另有一次 `pump()`，保留在呼叫端）；`inSubtree(tester, live, finder)` 改成以 `isInSemanticsSubtree(tester.getSemantics(finder), live)` 實作或直接替換。「展開前後 live label 不變」案例使用 `_StatefulHarness`，外層 container 可以改用 helper 包覆 |
| switcher_overlay_test | 回歸測試內的外層 container pump 與 `buttonInLive` 的 for 迴圈 |

約束：
- 斷言內容、案例名稱、案例數不變。blocked_state 的多 expect 案例本票不拆，交給 `0.5.0-W1-534`（534 排在 532 complete 之後，兩票都會改 blocked_state，依序進行不衝突）。
