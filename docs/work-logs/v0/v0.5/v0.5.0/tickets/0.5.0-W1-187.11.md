### 量測環境
macOS Darwin 25.5.0，fvm 4.1.2，Flutter 3.47.1；uptime 1 分鐘平均 9.32（啟動前）、16.46、15.15；對象 fvm flutter test test/unit，啟動後 16-18 秒中斷。orphan-test-procs.py 為 187.16 版（首詞認定），僅用不帶引數列出模式。啟動前基準：3797（父 36427，Simulator app）、4068（父 1，dart development-service，3.38.10），實驗全程未碰。實驗 harness 以 python 內嵌 Popen（start_new_session）啟動，故最上層程序的父為該 python，中斷後最上層成為殭屍（僅 harness 產物，不計入判定）。

### 樹形（中斷前）
形態1 樹：fvm.aot(22237) > dartvm 即 flutter 工具(22321，ppid 22237) > dartaotruntime(22377) + flutter_tester x4(22560-22563)。

形態3 樹：中斷時仍在 fvm 啟動階段（run-with-timeout 32864 > fvm.aot 32865 > git fsck 32912），此後 fvm 繼續跑出 dartvm(35553) 與 flutter_tester；樹形與形態1 相同，只是 fvm 層為被收養者。
