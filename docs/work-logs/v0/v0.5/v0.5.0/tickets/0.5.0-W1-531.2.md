## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 來源與現況（0.5.0-W1-531 重現實驗結果）

- LoadingState：`_messageFooter` 內計數 `Semantics(liveRegion: true)` 只包 `countText` 一個 Text，但未設 `container`，併入外層後 live 節點 #4 為全畫面，label 為「載入中\ndomainLoading\ncount 12」（skeleton；「載入中」為骨架朗讀）或「domainLoading\ncount 12」並帶 value「進度 45 / 100」（progressBar）、cancelling 時帶 role loadingSpinner；取消鈕在 live 子樹。§4.24 規定計數每次更新重播屬規格本意，偏離點是 label 混入訊息、骨架、進度值。
- SwitcherOverlay：`_buildFailureReason` 的 liveRegion 未設 `container`，現有獨立節點 #12（label 只有失敗原因），成因是父節點 #5（scopesRoute）內兄弟節點結構，元件本身無保證（主控裁示併入本票補 container）。
- 修法比照 `0.5.0-W1-530.1`／`0.5.0-W1-531.1`（liveRegion 加 `container: true` 與註解）；測試寫法參考 `test/unit/components/missing_source_state_test.dart` 的「liveRegion 語意」group。
- LoadingState 測試 pump 不可用 `pumpAndSettle`（skeleton shimmer 與 indeterminate 動畫不停，531 探測實測逾時），改 `settle: false` 後 `pump()`。
- SwitcherOverlay E2：外層換成無兄弟結構的容器（只含 SwitcherOverlay 本體或只含失敗原因所在子樹），拿掉 container 時 live 節點須併入而轉紅；對照輸入以傾印確認節點存在。
- 畫面測試範圍：LoadingState 用於 domain_view、gap_report、ticket_list；SwitcherOverlay 用於 `lib/screens/project_switcher/project_switcher_overlay.dart`（`lib/app/shell.dart`）→ `test/unit/screens/domain_view_test.dart`、`test/unit/screens/domain_view/`、`gap_report_test.dart`、`test/unit/screens/gap_report/`、`ticket_list_test.dart`、`project_switcher_test.dart`。
