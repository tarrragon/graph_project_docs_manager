### 問題根因

（本票為實驗票，「根因」欄記錄待驗證的假設與實驗設計。主控於 2026-10-21 與用戶討論後寫定。）

**待驗證假設（主控推論，未量測）**：只輸出一個 token 的決策，取到的是模型在查證之前的事前傾向。在前提尚未查證的題目上，它會以高信心選錯。錯誤出在前提，不出在選項之間的選擇。

**推論依據**：458 題 D 跑了三輪 WRAP。每一次改變答案，都來自 R 階段的查證，而不是在選項之間重新挑選：
- 讀了規則原文，才生出 I7。
- 讀了 `lib/app/scan_round.dart` 的 `rescan()`，發現它是整輪重新解析，才改成 R1。
- 文件混用原記三份，逐份查證後實為兩份。

已修正的前提與被否決的選項，記在 458 Solution〈題 D 裁定〉。

**實驗目的**：用量測取代推論，決定第一層決策模型能不能作為 WRAP 快速／完整模式的分流依據。

### 實驗設計

同一題在三種條件下各取樣：

| 條件 | 給模型的內容 | 量測什麼 |
|---|---|---|
| C0 只有選項 | 只有選項文字 | 模型的事前傾向 |
| C1 查證前情境 | 決策文本加第一輪選項，含當時未查證、事後證明錯誤的前提 | 自動駕駛式決策的實際表現 |
| C2 查證後事實 | 同一題，加上查證後的事實 | 前提補齊後，第一反應能不能選對 |

**判讀**：

| 結果 | 結論 |
|---|---|
| C1 高信心選錯、C2 選對 | 錯誤出在前提。第一層模型只能放在查證之後 |
| C1、C2 都錯 | 連選擇本身都不可靠，第一層模型不可用 |
| C1 就選對 | 假設不成立，第一層模型有加速空間 |

**取樣規則**：
- 選項集合固定加入一項「現有選項不足，需再分析」。用戶在 458 三次回「用 WRAP 思考」，等於否決了全部選項，這類題是重點量測對象。
- 每次取樣都打亂選項順序，抵銷位置偏差。
- 每題每個條件至少取樣 5 次，建議 10 次。依 PC-168，取樣數低於 5 時連續一致可能只是運氣。
- 機率分佈以取樣頻率估計。API 不回傳 logprob。
- 信心值用「首位與次位的頻率差」表示。

**對照組**：至少 5 題在 C1 條件下，以 `claude-opus-5-5` 比較兩種作答方式：只給一個 token，以及允許推理後作答。目的是把「跨模型差距」和「跳過生成造成的差距」分開。

### WRAP 完整模式評估（主控，2026-10-21）

**錨點**
- 客戶：用戶，也就是各個決策的裁定者。
- 目標：判斷第一層決策模型能不能在 WRAP 裡當分流依據或直覺答案的標記。
- 評估單位：跨決策的模式，不針對單一題下結論。

**Step 0 資料充足度**：判為「不足、中風險」。有兩項缺口：
- 50 次 AUQ 中，「查證前出過一輪選項、查證後改答」的題數未知，可能遠少於 15 題。
- 用戶的裁定可能依據文本以外的知識，例如產品方向。

**W 擴增假設**

主控的假設 X：C1 選錯，是因為前提未經查證。

C1 選錯的替代原因與分離方式：

| 替代原因 | 機制 | 分離方式 |
|---|---|---|
| 後見之明偏誤（本票特有，影響最大） | C1 由知道答案的主控事後重寫，措辭會不自覺偏向正解，或刻意誇大錯誤前提以符合假設 | **C1 不重寫**：一律取自逐字稿中當時送出的原文，包括 AUQ 之前那則訊息的前提段落與 AUQ 的題目和選項原文 |
| 條件之間措辭不同 | C1 與 C2 若分別撰寫，差異可能來自措辭而不是事實 | **C2 等於 C1 原文再附加一段事實區塊**，事實區塊取自後續查證的原文引用。兩條件只差這一塊，其餘因素在差分中抵銷 |
| 用戶依文本外的知識裁定 | 文本裡沒有足以推出裁定的資訊 | C2 一致率也偏低時就屬於這種情形，報告中標為「文本不足題」，不計入假設判定 |
| 專案術語 | Haiku 不懂 UC、EVT、traverses 這類專案詞彙 | 三個條件都附上同一份固定的術語表，在差分中抵銷 |
| 位置偏差與標籤偏差 | 偏好 A 或第一個選項 | 每次取樣都打亂選項順序（已在 AC 3） |

方案三類涵蓋：
- 改造既有：WRAP 反向框架由主控人工自檢，現在就這麼做。
- 零工具：由用戶自己標出哪些是直覺答案。
- 新增工具：Haiku 單 token（本票）。

反向思考：如果 Haiku 在 C1 就與裁定高度一致，代表多數決策沒有前提陷阱，第一層模型有加速空間。這個結果同樣有價值，判讀表已涵蓋。

**R 現實檢驗**

- **題數與試水溫**：先從逐字稿篩出「查證前後各有一輪選項」的題目。少於 6 題就停下回報主控，不擴大到其他 session 的逐字稿。不足時，改以本 session 以外的 session 逐字稿補足，要先經主控同意。
- **基本率**：不引用未查證的研究數字。

**A 拉開距離**
