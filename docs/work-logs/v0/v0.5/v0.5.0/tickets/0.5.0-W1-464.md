## Problem Analysis

### 問題根因

（本票為實驗票，「根因」欄記錄待驗證的假設與實驗設計。主控於 2026-10-21 與用戶討論後寫定。）

**待驗證假設（主控推論，未量測）**：只輸出一個 token 的決策，取到的是模型在查證之前的事前傾向。在前提尚未查證的題目上，它會以高信心選錯。錯誤出在前提，不出在選項之間的選擇。

**推論依據**：458 題 D 跑了三輪 WRAP。每一次改變答案，都來自 R 階段的查證，而不是在選項之間重新挑選：
- 讀了規則原文，才生出 I7。
- 讀了 `lib/app/scan_round.dart` 的 `rescan()`，發現它是整輪重新解析，才改成 R1。
- 文件混用原記三份，逐份查證後實為兩份。

已修正的前提與被否決的選項，記在 458 Solution〈題 D 裁定〉。

**實驗目的**：用量測取代推論，決定第一層決策模型能不能作為 WRAP 快速／完整模式的分流依據。

### 實驗設計

同一題在三種條件下各取樣：

| 條件 | 給模型的內容 | 量測什麼 |
|---|---|---|
| C0 只有選項 | 只有選項文字 | 模型的事前傾向 |
| C1 查證前情境 | 決策文本加第一輪選項，含當時未查證、事後證明錯誤的前提 | 自動駕駛式決策的實際表現 |
| C2 查證後事實 | 同一題，加上查證後的事實 | 前提補齊後，第一反應能不能選對 |

**判讀**：

| 結果 | 結論 |
|---|---|
| C1 高信心選錯、C2 選對 | 錯誤出在前提。第一層模型只能放在查證之後 |
| C1、C2 都錯 | 連選擇本身都不可靠，第一層模型不可用 |
| C1 就選對 | 假設不成立，第一層模型有加速空間 |

**取樣規則**：
- 選項集合固定加入一項「現有選項不足，需再分析」。用戶在 458 三次回「用 WRAP 思考」，等於否決了全部選項，這類題是重點量測對象。
- 每次取樣都打亂選項順序，抵銷位置偏差。
- 每題每個條件至少取樣 5 次，建議 10 次。依 PC-168，取樣數低於 5 時連續一致可能只是運氣。
- 機率分佈以取樣頻率估計。API 不回傳 logprob。
- 信心值用「首位與次位的頻率差」表示。

**對照組**：至少 5 題在 C1 條件下，以 `claude-opus-5-5` 比較兩種作答方式：只給一個 token，以及允許推理後作答。目的是把「跨模型差距」和「跳過生成造成的差距」分開。
