### 改法（5 支皆改 emit_model_reminder("PreToolUse", ...)，stderr 不再輸出提醒）

| hook | 分派器群組 | 改法 |
|------|-----------|------|
| dispatch-staging-phrase-guard | 否（settings.json，matcher Agent） | print(hint, stderr) 改 emit_model_reminder |
| uc-reference-validation | 否（settings.json，matcher Edit/Write/MultiEdit/NotebookEdit） | WARNING 改 emit_model_reminder；uc_registry 匯入失敗仍 stderr+日誌（異常路徑） |
| uncommitted-ticket-md-reminder | 是 PreToolUse:Bash | print 改 emit_model_reminder；fallback 補 stub |
| version-release-guard | 是 PreToolUse:Bash | 兩處警告收進 warnings，有警告時單一 emit_model_reminder（取代 approve JSON，避免雙 JSON）；無警告維持 approve |
| worktree-branch-check | 是 PreToolUse:Bash | 目標分支警告與未合併警告合併為單一 emit；fallback 補 stub |

### 實地觸發方式（PM 合併後用）

| hook | 觸發方式 | 需避開的提早返回 |
|------|---------|----------------|
| dispatch-staging-phrase-guard | Agent 工具派發，prompt 含 commit 字樣，且不含精準 staging／diff --cached --name-only／bare commit 片語 | 勿用 isolation=worktree；勿首行 Dispatch-Mode: readonly；subagent_type 勿屬 Explore／Plan／general-purpose／linux 等唯讀類；commit 前勿有否定詞 |
| uc-reference-validation | Edit／Write 一個 .dart／.js／.ts／.py 檔，新增內容含 docs/app-use-cases.md 未定義的 UC-99 | 路徑勿在豁免處（docs/work-logs、docs/spec、測試 fixtures 等）；勿用 UC-Singleton 類大寫字母 token |
| uncommitted-ticket-md-reminder | Bash 執行 commit 命令，且工作樹有未提交的 docs/work-logs/**/tickets/*.md | 命令須被 match_git_commit 解析為 commit（勿 echo、勿未閉合引號）；工作樹須真有 ticket md 變更 |
| version-release-guard | Bash 執行 commit，訊息 feat(v1.2.3): x（或含 release／version 與 vX.Y.Z） | 環境變數 VERSION_RELEASE_SCRIPT 勿為 1（否則僅 pubspec／CHANGELOG 不一致才有輸出） |
| worktree-branch-check | Bash 執行 push（或 merge／cherry-pick），且存在未提交 worktree 或 no-merged 分支 | 勿僅在 description 提到 push；無發現則靜默；目標分支警告僅 merge／cherry-pick 且主倉庫 HEAD 非 main／master |
