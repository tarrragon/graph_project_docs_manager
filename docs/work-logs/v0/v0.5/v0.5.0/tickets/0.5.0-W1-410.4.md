### 補充觀測：worktree 與快照內無法直接型別檢查（PM，2026-10-20，416 合併前）

- 現象：`tools/line-board/tsconfig.json` extends `./.claude-plugin/types/tsconfig.json`。types 目錄要先以 `--plugin-dir` 啟動一次才會產生，並未入庫，所以任何新建的 worktree，包含合併閘門的 detached 快照，都沒有這個目錄，`tsc -p tools/line-board` 無法執行。
- 416 的做法：用 scratchpad 的臨時 tsconfig extends 主 checkout 的 types，include 指向 worktree；以 `--listFiles` 確認檢查的是 worktree 的檔，並以注入的型別錯誤做正向對照（rc=2）。完整紀錄在 0.5.0-W1-416 的 Test Results。
- 對本票的意義：本票宣告 line-board 套件時，要決定閘門是否一併跑型別檢查。若要跑，快照內缺 types 的處理方式（生成或指向主 checkout）也要一併定案，否則型別錯誤只靠 plugin test 載入模組時間接暴露。這個決定交由 410.3 的宣告格式（含「必要產物」欄）承接。
