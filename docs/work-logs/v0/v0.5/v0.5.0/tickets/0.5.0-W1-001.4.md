| 候選 | 規則 | 致命風險 |
|---|---|---|
| S1 | 轉字串比對（同上游 validate）：id 與參照值一律 `str()` 後比對，不報缺陷 | YAML 的 `id: 1.0` 轉成 "1.0"、`true` 轉成 "true" 等邊角值也照收 |
| S2 | 視為無效並回報：非字串 id 不進索引並報缺陷，非字串參照判未解析並報缺陷 | doc validate 通過而 App 報缺陷，兩邊判定不一致，使用者不知以誰為準 |
| S3 | 現行混合：id 靜默不進索引、參照報未解析 | 壞 id 本身不被回報，只在被參照時間接出現 |
