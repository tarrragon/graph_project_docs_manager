### 門檻分母的選擇規則（主控裁定，2026-10-31；583.1 已在用量檔寫齊欄位）

判定「待 compact／待 clear」時，比較門檻用的百分比依 auto-compact 狀態選擇：

| 用量檔 | 用哪個百分比 |
|--------|-------------|
| `autoCompactThreshold` 有值 | `compactPercent` |
| `autoCompactThreshold` 為 null | `percent` |
| 選中的值為 null（compact 後 tokens 缺席） | 不判定 |

測試的正反對照（E2）須包含：
- 同一組 tokens，`compactPercent` 跨過門檻但 `percent` 沒跨：threshold 有值時判定為標記，threshold 為 null 時判定為不標記（兩組輸入的結果必須不同）
- 反向：`percent` 跨過門檻但 `compactPercent` 沒跨，結果與上一組相反
- 選中值為 null 時不標記，不當成 0
### 門檻常數（主控裁定，2026-10-31；依據見 583.1 Solution〈主控裁定：門檻〉）

| 對象 | T_compact | T_clear |
|------|-----------|---------|
| 一般線 | 45 | 30 |
| 主控 | 60 | 不判定 |

- 門檻寫成具名常數，判定與測試都以常數為準，不在判定式裡寫數字
- 測試須涵蓋主控與一般線的差異（E2）：同一個百分比（例如 50，有 in_progress 票）時，一般線判定待 compact、主控不判定；百分比為 35 且沒有 in_progress 票時，一般線判定待 clear、主控不判定
