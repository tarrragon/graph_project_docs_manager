## Problem Analysis
### 問題根因

`check_domain_coverage.py` 的 `locate_domain_map()` 解析鏈為「`--domain-map` → spec 同目錄 `domain-map.md` → `docs/domain-map.md`」，只認單 domain 根層形態與「SPEC 與 map 同目錄」兩種情形。0.5.0-W1-070.1 新增系統層載體（`docs/system-layer.md`）、0.5.0-W1-070.3 拆檔後，根層檔不存在，非 domain 目錄（`docs/spec/ui/`）的 SPEC 退化落空。另兩項結構原因：(1) 系統層模板無 FR → bundle 覆蓋節，通道節標題為「通道」而非 `CHANNEL_SECTION_TITLE_RE` 要求的「通道與協調圖」，單改退化路徑指向依模板新建的系統層仍過不了檢核；(2) 一份 SPEC 可被多份 map 的 `source_specs` 列入（SPEC-006、SPEC-007 各被 3 份列入），同目錄解析只讀一份。

### 影響範圍

已驗證：`docs/spec/ui/` 4 份 SPEC 不帶旗標全數 rc=1；domain 目錄下 SPEC-005/006/007 rc=0。`.claude/` 內 `docs/domain-map.md` 字面共 15 檔命中（`rg -c` 計），分類如下。
