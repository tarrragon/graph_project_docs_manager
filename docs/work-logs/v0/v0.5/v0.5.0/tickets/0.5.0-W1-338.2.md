### 量測方法的修正觀察

票樹根計數會高估「同主題但每輪審查另開新根票」的情形：check_domain_coverage.py 的 11 棵中，多數是同一功能多輪審查的追修票。判準在 reference 中應補「先看 commit 主旨是否屬同一功能」。已記下，於 338.2 結案時回寫 reference。

### 自檢結果

- 分群依據為 2026-10-12 起各檔非 chore 的 commit 主旨。
- 實作的順序以「先收斂重複實作」為先，因為它是其他拆分的共同前置。

### reference 回寫（L37，2026-10-31）
