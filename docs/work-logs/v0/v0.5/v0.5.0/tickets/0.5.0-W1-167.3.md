## Solution
<!-- Schema[ANA/Solution]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 裁定

改規格，不擴充元件：SPEC-004 4.42 `chooseOtherFailureReason` 字級由 `AppText.caption` 改為 `AppText` body 字級、tone `textSecondary`（規格升為 v1.95）。

| 階段 | 內容 |
|---|---|
| W（候選） | A：改規格為 body＋textSecondary；B：擴充 AppText.caption 支援 maxLines |
| R（實測） | lib/components/app_text.dart：caption 註明「單行」；lib/components/recent_project_item.dart：4.9 reason（同為浮層內 2 行常駐原因）已用 body＋maxLines 2＋textSecondary；SPEC-004 4.9 內容政策表未指定 caption |
| A（距離） | A 只改規格一列，已合併的 167.2 實作就是 A，不需改程式；B 要改共用元件契約，影響所有 caption 使用處的單行保證 |
| P（反證條件） | 若視覺審查認定 body 字級在浮層內過大，需另立浮層專用字級；屆時開票，兩處（4.9 reason、4.42）一起改 |

採 A。
