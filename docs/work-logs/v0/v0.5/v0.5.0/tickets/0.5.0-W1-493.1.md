### 查證：gitignore 不需入庫

舊位置 `tools/line-board/.claude-plugin/types/.gitignore`（內容 `*`）從未入庫（`git show HEAD:<path>` 不存在），是 Claude Code 產生型別時一併寫出的檔案。`git check-ignore -v` 顯示它同時忽略自己與 types 內容。所以新位置產生型別時會自帶這個檔案，不需要入庫。493〈建票時已查證的事實〉「types 目錄只有 .gitignore 入庫」與 493〈實驗發現〉「舊位置的 .gitignore 沒有隨搬移帶過來」兩處都是誤判，以本段為準。AC1 改以這段查證扣抵，新位置實際被忽略要等 493.2 產生型別時才能驗證。
