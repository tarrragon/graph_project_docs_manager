## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
在 .claude/lib/ticket_command_parse.py 新增共用輔助函式 is_help_only(args)：動詞後 token 完全等於 -h 或 --help，且位於單獨的 -- 之前，即判為只查說明。complete_statement_args（位置判定）與 _scan_statement（掃描判定，find_complete_invocations / find_ticket_track_invocations 共用）都呼叫它。引號內字面由 tokenizer 併為單一 token，不會相等；--helpful 之類不排除。

### 自檢結果
- 位置判定與掃描判定同源，無重複實作。
- 反向對照（--why '見 --help'、-- --help、--helpful）仍判為收尾。
- 未完成：acceptance 3（合併後實地觸發）、6（端到端 jq payload）屬 PM 合併後驗證。

### Phase 4 結論
重構需要：否。技術債務：無。程式碼品質：A。新增函式 12 行、巢狀深度 2，無需重構。
