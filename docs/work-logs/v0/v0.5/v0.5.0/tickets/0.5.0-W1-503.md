## 重現實驗結果
### 實驗方法

grep 盤點 + 讀 AppButton 渲染分支（lib/components/app_button.dart 的 build）；不跑測試。

### 實驗執行

1. `grep -rn "disabledReason" lib`（排除 app_button.dart 本身）：傳空字串者僅兩處——
   - lib/components/loading_state.dart：`disabledReason: widget.isCancelling ? '' : null`（取消鈕，原因由鈕文案 cancelInProgressAction 承載）
   - lib/screens/domain_view/domain_view_screen.dart（`_GraphUnavailableBody`，`action-domain-rescan`）：`disabledReason: running ? '' : null`（原因由列內 domainGraphUnavailableScanning 承載）
   無第三處。
2. AppButton 渲染：`(widget.enabled || widget.disabledReason == null) ? decoratedButton : Semantics(hint: disabledReason, child: Row[button, SizedBox(Space.xs), Flexible(Text(disabledReason))])`；`semanticExpanded` 非 null 時外層 Semantics 另帶 `hint: widget.disabledReason`。
3. SPEC-004 §4.4 狀態表 disabled 列：`enabled` 為 `false`「此時 `disabledReason` 必填」，資料態欄寫「0.1 唯一停用場景為 4.24 LoadingState 取消鈕」；參數表 `disabledReason` 為「`enabled` 為 `false` 時必填」。

### 實驗發現

- 已驗證：空字串不等於「不顯示」。走 disabled 分支，版面多出 `Space.xs` 間距與一個空 caption Text，語意樹 hint 為空字串（現況缺陷，與方向無關）。
- 已驗證：AppButton 的 assert 只擋 null，不擋空字串，契約可被空字串繞過。
- 已驗證：SPEC-004 §4.4 disabled 列「唯一停用場景」已過期（action-domain-rescan 為第二個停用場景，0.5.0-W1-486.2 引入）。

## Solution
<!-- Schema[ANA/Solution]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 方向候選（待用戶裁決，經主控轉問）

兩個候選都改變使用者可見行為，依主控裁示（2026-10-29）不直接開 DOC 票。

| 面向 | 候選 A：允許省略（原因由同區常駐文案承載時） | 候選 B：兩處補原因文案 |
|------|------|------|
| SPEC-004 §4.4 改動 | disabled 列與參數表改為「`enabled` 為 `false` 時須提供 `disabledReason`，或宣告原因已由同區常駐文案承載」；新增參數列（如 `reasonShownNearby: bool`，預設 false）與適用條件（承載文案須與按鈕同區常駐可見） | 必填規則不變；新增兩個 i18n key 與文案定義；資料態欄列出兩個停用場景 |
| AppButton assert | `enabled \|\| (disabledReason 非空) \|\| reasonShownNearby` | `enabled \|\| (disabledReason 非空)`（加擋空字串） |
| AppButton 渲染 | `reasonShownNearby` 為真時直接回傳按鈕：不包 Row、不加 caption、不設 hint | 不變（disabled 分支照常顯示 caption 與 hint） |
| 取消鈕可見差異 | 移除 xs 間距與空 Text；讀屏只報「停用」，原因靠鈕文案本身（cancelInProgressAction）已讀出 | 鈕右側多一行 caption（文案須與「取消中」鈕文案不同義，否則同列重複）；讀屏 hint 讀出原因 |
| 重新掃描鈕可見差異 | 移除 xs 間距與空 Text；讀屏只報「停用」，原因由列內「掃描中」訊息另一節點承載 | 鈕右側多一行 caption（與列內掃描中訊息語意重疊）；讀屏 hint 讀出原因 |

### 兩方向皆須修的現況缺陷

1. 空字串走 disabled 分支：多出 `Space.xs` 間距、空 caption Text、空 hint（〈重現實驗結果〉已驗證）。修法：assert 擋空字串（兩候選皆含此項），兩處呼叫端改為不傳空字串。
2. SPEC-004 §4.4 disabled 列「0.1 唯一停用場景為 4.24 LoadingState 取消鈕」過期，須補 action-domain-rescan（0.5.0-W1-486.2）。

裁決後建：DOC（SPEC-004 §4.4，含現況缺陷 2）＋ IMP（AppButton assert／渲染 + 兩處呼叫端 + 測試，含現況缺陷 1；候選 B 另含 ARB 新 key）。

### 裁決與落地（2026-10-29）
