### 重現當下的補充脈絡（建票者，2026-10-19）

- 18:24:35 那次 `git push 'x` 經 Bash 工具送出時，同一 dispatcher group 內 domain-import-lint、bare-commit-guard、workspace-wipe-guard、tracking-schema-json-staleness-guard 皆因「命令無法安全解析，並行派發期間保守阻擋」fail-closed 擋下（當時 dispatch-active.json 有 7 筆活躍派發），命令未實際執行；branch-check 仍有執行並落 DEBUG 行

- hook-dispatcher.py 以 runpy.run_path(run_name="__main__") 同程序依序執行 group 內 hook（檔頭說明與 run 路徑）；另有 run_subprocess 路徑，哪支 hook 走哪條未查
