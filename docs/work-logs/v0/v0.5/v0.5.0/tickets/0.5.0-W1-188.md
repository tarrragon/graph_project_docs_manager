### 他專案 session 轉來的實測（flutter_balance，2026-10-13 15:29）

來源為另一個專案的 session 回報，非本票執行者親自量測；量測環境為同一台機器。本票的實測須獨立重做，以下僅作為起點。

- 測試孤兒程序（flutter_tester）為 0 個時，load average 仍為 47.94／52.40／48.96。孤兒清空後負載未下降。
- 交換空間：總量 18432M，已用 18015M，剩 417M。可用記憶體頁約 62MB。
- CPU 佔用前列：端點防護軟體的日誌讀取程序 66%、視窗伺服器 48%、Prowl 40%、Discord 36%、fseventsd 21%、OrbStack 20%、多個 claude 程序各 15 至 20%。
- 代理人三次開跑測試前的 load 為 64.74／29.15／43.79，皆高於派發 prompt 所寫的門檻 24，三次都照常執行。

### 由此得到的待驗證方向

- 佔用前列多數不是本專案工作流的程序，避免方式的候選須分成「本專案可控」與「機器層級」兩類。
- 只寫在 prompt 的資源門檻未產生約束力，執行前檢查若要有效須放在強制層。此項屬測試前 hook 的設計，已轉記至 0.5.0-W1-187.4。
