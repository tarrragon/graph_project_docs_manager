### 問題根因

本票是 0.5.0-W1-465 的正式階段，**只有 465 試水溫結論為「進正式階段」時才執行**；結論為「不做」時本票以 requirement_vanished 關閉。

### 影響範圍

- 讀序：465〈裁定後定案設計〉→ 本票 AC。
- 缺陷注入改用參數網格（類別 × 強度、元件以亂數抽選），產出偵測門檻曲線。
- 注入用的變體註冊表與 466 分檔（466〈464／465 改向後的同步修正〉）。
- 比較對象是用戶逐張看圖的現況，以每次審查需要人工看的張數計。
