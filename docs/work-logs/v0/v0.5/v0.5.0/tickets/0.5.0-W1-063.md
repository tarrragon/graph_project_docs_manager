### WRAP 評估（快速+，e1，2026-10-09）：「mid 一致偏向 sonnet」是否作為新判準

事證（R）：5 組皆合併 opus 份；sonnet 份 mid 每組嚴格多 1（合計 6 對 1），high 只有 pair-1 一組（2 對 0）；三組 lib 改動相同、差異只在測試；opus 份 tokens 多約 17%；盲審者為 opus，同源偏好未控制（LLM 互評的自家偏好是已知現象）。每組 mid 差 1，量級小；本版流程每張 IMP 合併前都有 linux 審查並由原代理人修正（W1-122 的 mid 即如此修掉），所以 mid 多半在合併前被吸收，代價是多一輪往返。
