## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### 修法（worktree commit 0b2ab8160）

- 四支 hook 的 `except ImportError` 在原有 stderr 輸出之後，加入同一段只用 stdlib 的程式，追加一行 ERROR：
  - 檔案：`<CLAUDE_PROJECT_DIR 或 hook 所在 repo 根>/.claude/hook-logs/<hook 名>/<hook 名>-YYYYMMDD.log`
  - 格式：`<時間> - <hook 名> - ERROR - lib import failed, fallback active: <例外>`
- repo 根的推算：`.claude/hooks/` 下的 hook 用 `parents[2]`，`.claude/skills/worktree/hooks/` 下的 hook 用 `parents[4]`，四支都已逐一核對
- 寫檔失敗時只多印一行 stderr「log write failed」，hook 不會崩潰。放行與阻擋結果不受影響
- 四處重複各約 11 行：fallback 觸發時 lib 不可用，無法抽成共用函式，屬刻意重複
- 測試：新增 `.claude/hooks/tests/test_hook_import_fallback_file_log.py`，共 12 個測試（四支 hook 各 3 個：寫入 ERROR、目錄不可寫時不崩潰、匯入成功時不寫 fallback 日誌）

- [x] 修改前 8 個紅（寫入 ERROR、不可寫時不崩潰，四支各兩個），修改後轉綠
- [x] 正向對照：匯入成功時不輸出 `[Hook Import Warning]`，也不寫 fallback 日誌，修改前後都綠
