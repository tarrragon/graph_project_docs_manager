### 結論

isolated-subagent-main-write-guard-hook 對 Edit／Write／NotebookEdit 的命中改為輸出 permissionDecision deny（使用共用的 generate_hook_output），訊息不變；Bash 命中仍只輸出 additionalContext；映射缺失時放行；hook 自身例外時 fail-open。合併 commit 8cd7c9c37（branch commit 26a46eebf）。PM 另補 f0e5c9bf6：介入日誌原本一律標示「warn:」，改為依工具標示 deny 或 warn，讓 liveness 日誌與實際決策一致。

| 檔案 | 變更 |
|------|------|
| .claude/hooks/isolated-subagent-main-write-guard-hook.py | main() 依工具輸出 deny 或 additionalContext；docstring 更新；日誌依決策標示 |
| .claude/hooks/tests/test_isolated_subagent_main_write_guard.py | 舊測試斷言「Edit 命中時不設 permissionDecision」，正是本票要翻轉的行為，已移除；新增 E2 file-tool deny（Edit／Write／NotebookEdit 三組參數）、E2 Bash 維持 warn、E1 無映射放行 |
