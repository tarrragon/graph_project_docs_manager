## Solution
<!-- Schema[ANA/Solution]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 結論

格式要求依用戶裁決定為：只限工作提交；Co-Authored-By 一律要求；有 Claude-Session 網址時兩行須相鄰並位於訊息最末段；落地為 `ticket track commit` 自動補上，加上提交後提示（不阻擋）。

落地的主要限制在「值從哪裡來」：只有模型自己看得到 harness 的歸屬指示，CLI 與 hook 都看不到。

### 一、格式要求（定義）

1. Co-Authored-By 行必須存在，且 `git interpret-trailers --parse` 能把它辨識為 trailer。
2. 若有 Claude-Session 行，須與 Co-Authored-By 相鄰、中間無空行、同在最末段。
3. 豁免：票務 CLI 自動產生的提交（帶 `Session:` 行者）、合併提交、revert。

### 二、提交當下各時點能否取得兩行的值

| 時點 | Co-Authored-By 的值 | Claude-Session 的值 |
|------|-------------------|--------------------|
| 模型撰寫訊息時 | 可：harness 歸屬指示直接提供 | 只有遠端或網頁 session 可取得；本機 CLI session 沒有 |
| PreToolUse(Bash) hook | 不可直接取得。hook 輸入只有 session_id、transcript_path 等欄位；可讀 transcript 取得模型 id（實測本 session 為 `claude-opus-5-5`），但取不到「(1M context)」這類顯示後綴 | 不可 |
| `ticket track commit` 子命令 | 同上：可經 `CLAUDE_CODE_SESSION_ID` 找到 transcript，讀出模型 id 後轉成顯示名稱 | 不可 |
| 子代理人 | 子代理人的 transcript 是另一個檔案，模型可能不同（實測同期有 Sonnet 5.5 的提交）；經父 session ID 取值會取錯 | 不可 |

### 三、落地方式比較與回測

回測樣本：最近 600 筆提交中的 48 筆工作提交。兩行齊全的 15 筆、只有 Co-Authored-By 的 16 筆，皆合格；兩行皆無的 17 筆不合格。

| 案 | 涵蓋 | 漏網 | 取不到值時 | 回測 |
|----|------|------|-----------|------|
| A CLI 自動補（用戶選定） | 經 `ticket track commit` 的工作提交 | 裸 git commit；子代理人經父 session 取值會取錯模型 | 以 transcript 的模型 id 對照表產生顯示名稱，對照不到時只警告、不補 | 17 筆不合格中，經 CLI 提交者可補正；其餘無法由 CLI 判定 |
| B 提交後提示 hook（用戶選定，併用） | 所有裸 git commit | 不阻擋，修正仰賴模型自行 amend，共用 checkout 下 amend 有風險，提示只能要求下一次遵守 | 不需要取值，只檢查格式 | 會對 17 筆發出提示 |
| C 提交前阻擋 | 命令列帶 -m 的 git commit | heredoc 以外的訊息來源；無法自動修正 | 擋下後由模型補行重送 | 會擋 17 筆 |

### Spawn 規劃

| 項目 | 形態 | 優先級 | 落地 |
|------|------|--------|------|
| `ticket track commit` 缺 Co-Authored-By 時自動補（transcript 模型 id 對照表；子代理人以自身 transcript 為準，取不到則只警告） | IMP | P3 | children |
| 提交後提示 hook：工作提交缺 Co-Authored-By，或 Claude-Session 不相鄰時提示 | IMP | P3 | children |

### 框架判準與查重

判準兩條皆成立：(1) 抽象可攜，任何 consumer 皆適用；(2) 根源在 `.claude/`，即 ticket CLI 與 hooks。原 0.5.0-W1-214 判為「不屬框架」，依據是當時沒有任何框架資產產生這兩行；用戶裁示改由框架資產承擔後，判準 (2) 改為成立。查重沿用 0.5.0-W1-214 以 Co-Authored-By、trailer 兩組關鍵字所做的結果，結論為 none。
