### 設計輸入：逾時包裝腳本攔不到的兩條路徑（來自 0.5.0-W1-187.7 的多視角審查）

逾時包裝腳本以程序群組為終止單位，以下兩條路徑它無法攔截，殘留只能由本票的清理指令收拾：

- 包裝腳本自身被強制終止（SIGKILL、記憶體不足時被系統終止）或崩潰：無法轉送訊號，子程序群組存活。
- 子程序自行建立新 session 或新群組而脫離原群組：群組終止對它無效。

對本票的影響：認定條件中的「父程序為 1」可涵蓋第一條；第二條的程序若父程序仍存活則不符該條件，須確認清理指令對此情形的行為並寫明。兩條皆由程式碼推導，尚未實測。
