- 若「無法定位」＝未命中任一 domain：三候選下約 69% 的帶 lib 路徑票被判無法定位，判定訊號失去鑑別力。需先決定 L4/共用是否為獨立判定類別（「非 domain 層」≠「無法定位」）；這是比表形態更前置的決策。
