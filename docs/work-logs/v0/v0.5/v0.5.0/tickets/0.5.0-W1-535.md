traceback 顯示 SIGTERM handler（`_raise`，merge_gate.py 第 451 行當時版本）連續觸發 3 次，每次都打在不同位置：
1. `_run_suites` → `_ensure_artifacts` → `default_runner`：flutter 產物準備中（預期的中止點）。
2. `merge_snapshot` finally → `_remove_snapshot` → `_git`：`git worktree remove` 被打斷。
3. 前一層例外處理 → `_remove_snapshot` → `shutil.rmtree(path, ignore_errors=True)` → `_rmtree_safe_fd`：退路的 rmtree 也被打斷。

（行號屬當時觀測值，僅供對照。）

初步觀察（未驗證）：TaskStop 對背景程序可能不只送一次 SIGTERM，或者程序群組內多個程序各自轉發了訊號。handler 在清理階段沒有解除或遮蔽，每一次訊號都會打斷清理。
