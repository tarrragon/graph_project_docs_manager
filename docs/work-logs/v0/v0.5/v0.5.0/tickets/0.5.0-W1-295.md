## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
cli-error-feedback-hook.py 的 check_general_cli_failure 在 PostToolUse 路徑新增 _masked_stdout_error：僅當 is_invocation_masked(command) 為 True 時檢查 stdout，任一行 lstrip 後以 `[Error]` 開頭才算失敗（非行首字樣不命中）；未遮蔽、None（無法解析）、例外一律 fail-open。命中且 stderr 為空時回傳 PC-005 提醒；ticket/skill 命令不套用 HANDLED_BY_OTHER_HOOKS 的 "ticket "/"skill " 排除（否則該路徑對 ticket 命令永遠無效），其餘 handled 命令仍排除。PostToolUseFailure 路徑未動。
覆蓋表三列皆覆蓋：遮蔽+stdout [Error]、遮蔽+stderr、成功命令 stdout 偶含 [Error]（非行首/未遮蔽不命中）。

- 產生路徑盤點表三列皆有對應測試。
- 未實測 acceptance 3、4（PM 合併後執行）。
