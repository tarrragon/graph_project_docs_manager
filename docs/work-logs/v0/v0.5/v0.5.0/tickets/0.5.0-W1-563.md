## Solution
<!-- Schema[ANA/Solution]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 分析結論

缺口是「閘門的逐檔檢查套件沒有被轉成代理人的本機檢查」。全套件類套件依設計由閘門兜底，不在缺口內。

### 補強位置判定（驗收 2）：框架層

| 候選位置 | 層級 | 判定 | 理由 |
|---|---|---|---|
