## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
策略：子句級判定。以 。；; 與換行切分子句；子句內命中前方有否定詞（不要/禁止/勿/do not 等），或同子句有引用語境詞（測試用/範例/字串/指稱/例如/類別 等），不計為收尾指示。理由：收尾段無固定標記，段落切分易誤判；子句級對 PM 實際寫法（否定收尾句、引用語境句）足夠，且同 prompt 另有真正收尾句時仍提示。判定例外 fail-open：不阻擋、stderr 與日誌記錄。

### 自檢結果
- E1：否定三形態、引用兩形態皆無 additionalContext。
- E2：真正要求 complete/finish 收尾（含先否定他句、後要求收尾）仍提示且 permissionDecision 為 allow。
- fail-open：判定拋例外時無輸出、exit 0。
- 已知限制：關鍵字清單為啟發式，罕見措辭可能漏判（偏向多提示或少提示均為非阻擋）。

Phase 4 評估：重構需要=否；技術債務=啟發式詞表需隨新措辭維護；程式碼品質=A；結論=無需重構。
