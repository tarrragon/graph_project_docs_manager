# Execution Log

## Task Summary

三個 EVT（EVT-DIAGNOSTICS-001、EVT-SCHEMA-002、EVT-LAYOUT-001）的 consumers 列了 Presentation，不在已宣告的 8 個 DomainBundle 內；判定 EVT 是否允許 layer 名、允許時的保留字集合，以及 W1-091 的檢查是否涵蓋 EVT 欄位

---

## Problem Analysis
### 問題根因

EVT 的 producers／consumers 欄位先於 DomainBundle 宣告與阻擋 2 裁決建立，當時以「訂閱者」語意填值，混入 layer 名 `Presentation`。系統層 §1.3 定義畫面狀態為 L4 layer、非 domain，故 `Presentation` 在 domain 值域內無對應。附帶發現：其餘 8 個值全為 PascalCase（`Corpus` 等），與 DomainBundle `domain` 字面（`corpus` 等，小寫）也不一致；W1-090 只改寫 `traverses`，EVT 未涵蓋。

盤點（9 個 EVT，全為 `category: domain_event`）：

| EVT | producers | consumers | 非 domain 值 |
|---|---|---|---|
| EVT-WORKSPACE-001 | Workspace | Schema, Corpus | 無（僅大小寫） |
| EVT-SCHEMA-001 | Schema | Corpus, Graph | 無（僅大小寫） |
| EVT-SCHEMA-002 | Schema | Presentation | Presentation（唯一 consumer） |
| EVT-CORPUS-001 | Corpus | Graph, TicketDetail, Diagnostics | 無（僅大小寫） |
| EVT-CORPUS-002 | Corpus | Corpus | 無（僅大小寫） |
| EVT-CORPUS-003 | Corpus | Diagnostics | 無（僅大小寫） |
| EVT-GRAPH-001 | Graph | Layout, Diagnostics | 無（僅大小寫） |
| EVT-LAYOUT-001 | Layout | Presentation | Presentation（唯一 consumer） |
| EVT-DIAGNOSTICS-001 | Diagnostics | Presentation | Presentation（唯一 consumer） |

**範圍驗證方法**：rg 列舉法（全量 frontmatter 欄位抽取）
**驗證指令**：`grep -rn "consumers" docs/events`；`grep -rn "producers" docs/events`；`grep -h "^domain:" docs/spec/*/domain-map.md`
**已知盲區**：EVT 以外的檔案若以其他欄位名記錄訂閱者（例如散文）不在掃描內。
**盲區影響評估**：本票裁決對象限 EVT frontmatter 兩欄；validate.py 與 SPEC 判準只讀這兩欄，盲區不影響結論。

### 影響範圍

已驗證事實：
- `validate.py` 的 EVT 驗證要求 producers／consumers 非空（「EVT 必須至少一個 consumer」）。三個含 Presentation 的 EVT 中 Presentation 是唯一 consumer，直接刪除即 validate 失敗；且三者皆 `domain_event`，依 tracking_schema 定義必有 consumer。
- SPEC-001 §5／SPEC-003 §3.5 `event-declaration-mismatch`：consumers 每個宣告 domain 須有 `traverses` 包含該 domain 的 FlowStep consumes 該 EVT。`traverses` 只含 domain 名、純畫面步驟為 `[]`，故 `Presentation` 結構上永遠不可能被比中，現行判準下三個 EVT 恆報破洞（屬誤報）。
- SPEC-001／SPEC-003「本 UC 外」會把 consumers 值附列為 domain 顯示。
- W1-091 現行範圍只含 `traverses` 與 `depends_on_domains`，未涵蓋 EVT；若擴及 EVT，Presentation 與全部大小寫不一致值都會報錯。
- App 端 EVT producers／consumers 尚未接線（`lib/screens/uc_flow/uc_flow_fixtures.dart` 註解），無程式碼影響。
- 實際消費者：UC-02 `switch-to-swimlane`（traverses `[layout]`）consumes EVT-LAYOUT-001；EVT-SCHEMA-002 與 EVT-DIAGNOSTICS-001 在 UC 中無任何 consumes 步驟。

未驗證假設：無。

### 相關 Error Pattern

無直接對應既有 error-pattern。性質近似「值域權威定案後下游欄位未全數同步」（W1-090 只改寫 traverses）。
