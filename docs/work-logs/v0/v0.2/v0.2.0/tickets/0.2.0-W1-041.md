### 問題根因

`file_selector.getDirectoryPath()`（NSOpenPanel）是 WorkspaceRepository 三個 driven port 中唯一需人工回應系統 UI 的平台邊界，mock 測試不觸及原生層；App Sandbox 關閉條件下的實際行為（面板呈現、回傳路徑、取消回 null、跨啟動持久化）從未實機驗證（0.2.0-W1-022 盤點）。

### 影響範圍

`lib/workspace/workspace_repository.dart`（chooseFolder／restore）、`lib/screens/project_switcher/project_switcher_overlay.dart`（W1-019 接線）、`lib/app/shell.dart`（W1-042 啟動 restore → detect）。已驗證事實見 Solution 兩張表；未驗證：簽章 .app（Developer ID）下的行為，由 0.2.0-W1-027 承接。

### 相關 Error Pattern

無直接對應；背景 `flutter run` 於 stdin 關閉時自行結束一事屬工具操作觀察，記於 Solution 附帶觀察。
