## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因

`fvm dart analyze lib test` 回報 6 則 `deprecated_member_use`：`SemanticsData.hasFlag`
於 Flutter 3.32 起棄用，`expander_icon_test.dart` 3 處（105/106/121 行）、
`issue_marker_test.dart` 3 處（230/247/271 行）沿用舊 API。

### 影響範圍

僅測試檔：`test/unit/components/expander_icon_test.dart`、
`test/unit/components/issue_marker_test.dart`。不影響 lib/ 實作。

### 相關 Error Pattern

無對應既有 error-pattern，屬 Flutter SDK API 棄用例行維護。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### 修復方式

依 Flutter 3.47 API 將 6 處 `hasFlag(SemanticsFlag.x)` 改為 `flagsCollection`
對應成員：

- `isButton`（bool，5 處）：`data.hasFlag(SemanticsFlag.isButton)` →
  `data.flagsCollection.isButton`
- `isExpanded`（Tristate，2 處）：`hasFlag(...), isTrue/isFalse` →
  `flagsCollection.isExpanded, Tristate.isTrue/Tristate.isFalse`

`isExpanded` 在新 API 下型別為 `Tristate`（`dart:ui`，`none`/`isTrue`/
`isFalse` 三態），非單純 `bool`，故斷言改用 `Tristate.isTrue`/
`Tristate.isFalse` 而非 `isTrue`/`isFalse` matcher；`isButton` 仍為
`bool`，維持 `isTrue` matcher。

改動後 `flutter/semantics.dart` 不再匯出使用中符號，兩檔各移除
`unused_import` 的 `semantics.dart` import；`expander_icon_test.dart`
另需 `import 'dart:ui' show Tristate;`（`Tristate` 由 `dart:ui` 定義，
未經 `flutter/semantics.dart` re-export）。

斷言語意完全不變（原比對「是否具備 isButton/isExpanded flag」，改後
仍比對相同語意，僅 API 呼叫形式更新）。
