## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
方案 C 三項變更落地於 lib/tokens/colors.dart：

1. `_Palette.gray600 = #6A7674`（新原始值，非 artboard 實測，dartdoc 標註）；`AppColors.textSecondary` 改指向 gray600。對 surfaceBase 對比 4.71:1（達 AA 4.5:1）。
2. 新增 `AppColors.textDisabled = _Palette.gray500`（沿用原次要文字色 #8A9694），dartdoc 說明限用範圍（停用態、純裝飾圖示，僅達 SC 1.4.11 非文字對比 3:1，不得用於一般文字）。對 surfaceBase 對比 3.06:1（達 3.0:1 門檻）。
3. `_Palette.surfaceSegmentTrack` 由 #DCE4E2 調淺至 #DEE6E4；`AppColors.surfaceSegmentTrack` 語意層不變（仍指向同名原始值）。對 textPrimary 對比 4.56:1（達 AA 4.5:1）。

三者原始值層與語意層皆有名，AppColors 類別 dartdoc 新增〈無障礙對比調整（2026-09-02）〉小節記三項對比表（含原值畫布實測值、新值、對比結果），surfaceSegmentTrack 常數另補一行 dartdoc 指向該表。

SPEC-002 回填：
- 顏色分佈表兩列加刪節線標記新舊值（textSecondary、surfaceSegmentTrack），新增 textDisabled 一列
- 〈已知的顏色分佈〉節新增〈無障礙對比例外（2026-09-02）〉小節，含三項對比表
- 〈設計約束〉節新增一則例外條款：對比未達 AA 時得偏離 artboard 實測值，需記錄原值/新值/對比結果
- 變更歷史新增 1.5 版列

不改任何元件（lib/app/shell.dart 等消費 AppColors.textSecondary 的既有引用維持不變，語意不變只是底色更深）；不改 SPEC-004（由 W1-060 承接）。

契約測試 test/unit/tokens/colors_test.dart 新建，實作 WCAG 相對亮度公式（純 dart:math，不引入外部套件），三個 test case 對應三項 acceptance 門檻（>= 4.5、>= 4.5、>= 3.0）。

實作前手算三組對比驗證核定值：textSecondary/white = 4.712、textPrimary/surfaceSegmentTrack = 4.561、textDisabled/white = 3.058，與票面聲稱值一致；測試執行結果確認公式實作與手算一致（見 Test Results）。

### 自檢結果（Phase 4）

- 重構需要：否。三個常數值變更 + 一個新常數，改動範圍精確對應 acceptance，無多餘結構調整。
- 技術債務：無新增。既有 gray500 命名維持不變但語意收窄（僅供 textDisabled），dartdoc 已標註轉移時點，不構成技術債。
- 程式碼品質：A（token 三層結構延續既有慣例，對比公式獨立為可測試的純函式，無 magic number 外洩至元件層）。

### Rationale Chain
- 0.1.0-W1-058 why: SPEC-004 第 4 章無障礙子節填「對比」時，依 WCAG 相對亮度公式計算 lib/tokens/colors.dart 的語意色組合（量測對象為 token 值，非畫布）：

| 前景 / 底色 | 對比 | AA 一般字（4.5:1） | AA 大字（3:1） |
|---|---|---|---|
| textPrimary（#5C6866）/ surfaceBase | 約 5.0:1 | 通過 | 通過 |
| textSecondary（#8A9694）/ surfaceBase | 約 3.1:1 | 未達 | 通過 |
| textSecondary / surfaceChip（#E9EEED） | 約 2.6:1 | 未達 | 未達 |
| warning / warningSurface、error / errorSurface、success / surfaceBase、accentStrong / surfaceIconTint、surfaceBase / accent | 5.4～10.6:1 | 通過 | 通過 |

textSecondary 用於 caption 字級（AppFontSize.caption）的次要文字、徽章、欄首、副標，全部是小字，未達 AA 一般字級。畫布實測值即此色（gray500，116 次），屬設計端 token 值問題，非個別元件問題。SPEC-004 §4 各元件的對比欄暫記「含 textSecondary 者未達 AA，待本票核定」，不阻擋元件契約消費（對比要求是 a11y 子節的一列，非待決欄）。

方案：(a) 調深 textSecondary 至對比 ≥ 4.5:1（畫布為準原則的例外，理由是 a11y 硬門檻）；(b) 維持 token，SPEC-004 §1 文字縮放列旁明記 0.1 對次要文字只承諾 AA 大字級；(c) 次要文字改用 textPrimary 加不透明度——否決候選，不透明度疊底色後對比同樣不足。（來源已完成，結論見 Solution）
