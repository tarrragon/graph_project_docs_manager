### 複驗探針設計（PM 定案，2026-09-14；門檻於修補派發前寫死）

**原則**：探針只拿修補後的文件（加一份輸入素材），不給票面、不給修補者說明；探針問「讀出幾種做法」而不是「修好了嗎」。題目在修補派發前固定，修補後逐字重跑（比照 W3-302）。

| 批 | 範圍 | 題目 | 樣本 | 判定門檻 |
|----|------|------|------|---------|
| V1 | 各 skill 矛盾統一票 | 每處原矛盾位置給一份會觸發兩條原規則的輸入，問「依本文件應產出什麼」 | 每位置 3 份 | 3/3 產出一致才算生效；任一不同即未生效 |
| V2 | 各 skill 缺引導票 | 從 W3-332 分歧模擬中每張票抽 3 個位置，給原模擬的輸入，問「產出什麼、依據哪一句」 | 每位置 3 份 | 3/3 產出一致且皆能指出依據句 |
| V3 | 各 skill 缺範例票 | 每張票抽 3 則新範例，問「本範例的驗證段是否只用產出段已定義的欄位、是否含技術相依內容」並另給一份新輸入要求照範例產出 | 每則 3 份 | 驗證段合規 3/3；新輸入產出一致 ≥ 2/3 |
| V4 | SPEC 回寫與稽核 | 以 W3-332.8／.9／.10 同一批猜測點題目重跑盲推導（同樣不給 SPEC-004），逐點判定是否仍需猜 | 每畫面 1 份 | 原猜測點仍需猜者 0；新猜測點逐項歸因，屬 spec 缺描述者建追修票 |

**限制**：3 份樣本只支持全中或全無這種強訊號，2/3 對 1/3 的差距不下結論。
PM 註記（2026-09-14）：複驗 V1–V4 前置條件補兩項——W3-341（FlowStep domain 來源）定案回寫、0.1.0-W3-343（補範例後章節重切）與其實作票完成。探針讀取重切後的最終結構。
