## Problem Analysis
### 問題根因

`0.1.0-W3-575` 的逐題器材 `experiment-0.1.0-W3-575-byq.py` 以一行條件過濾題目：`if TARGET_SEC not in feed: continue`，其中 `TARGET_SEC` 為 `八項判準`、`feed` 為該 `### UX-` 區塊內以 `**餵入**` 起首的那一行。題目檔中沿用上一題餵入範圍的寫法是「**餵入**：同 UX-W8u」，不含該字串，**被丟棄且不留任何輸出痕跡**。

該過濾器另有第二條同型丟棄路徑：區塊內找不到 `**題目**` 標記時亦直接 `continue`。本票實測該路徑的實際發生數為零（261 個 `### UX-` 區塊全部具該標記），但其失效方向與第一條相同。

**失效方向是靜默丟棄**：器材輸出 35 題，讀者無從分辨這是全部、還是全部減去被丟棄的那些。此形態即 `test-assertion-design-rules` 規則 E2 所治——守衛的失效方向是放行，而放行與「輸入本來就沒問題」在輸出上同形。

### 影響範圍

- 受影響的票面宣稱：`0.1.0-W3-575` acceptance 第 2 項「所有仍在流通的 ux 題幹逐題給出新增命中與判定，無一題略過」；其 Solution 第二段的「其餘 26 題判為否」與第四段 (A) 的「零字面通路的既有對照題只有 W8s／W8u」
- 受影響的落檔：`probes/w578-ux-manifest.md`〈一〉節全域、〈逐題判定總計〉；`key/W3-417-b17-ux-A3c.md` 與 `A3c-post.md` 的〈承接題的兩項待復驗〉
- 下游：`0.1.0-W3-552` 的 ⑤ 量測承接題選擇
- 器材：`scratchpad/w3575/experiment-0.1.0-W3-575-byq.py`

**已驗證的事實**：`probes/q/` 的 140 份題目檔、261 個 `### UX-` 區塊與其逐區塊餵入欄；四種餵入欄寫法的區塊數與守恆關係；引用型餵入欄 55 個的逐一指涉解析；六項判準節錄對三次改動十個代表新增字面的逐項計數；修正後器材對全量與 E2 fixture 的輸出；「主張」「條文」在現行八項判準節錄中的出現次數與所在款次。

**仍未驗證的假設**：`0.1.0-W3-575` 對既有 35 題逐題所下的零字面判定本身未重驗——本票只保證沒有第四題是被器材丟棄的。

### 相關 Error Pattern

`test-assertion-design-rules` 規則 E2（守衛的測試必須含正向對照輸入）為直接同型：本器材的過濾條件從未以一個已知該被納入的輸入驗證過，故其失效無聲。規則 E1（明示旗標必須有對照測試）為近鄰——若當初以「沿用寫法的題納入與不納入」做過對照，差異即可見。`PC-162`（接手者應獨立重新驗證數量／範圍）在本票的分母對帳步驟上命中：本票不取工具自報數，改以 `probes/q/` 的實際檔案與區塊為獨立來源重算。
