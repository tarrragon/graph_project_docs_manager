## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
改前：native_component_patterns 的 suggestion 為寫死他專案元件名（如「Use AppCard instead」「Use AppDialog helper instead」），並含他專案規格章節號註解「spec §14.3 禁用對照表」。

改前逐項：
- TextButton( -> Use AppButton instead
- ElevatedButton( -> Use AppButton instead
- Card( -> Use AppCard instead
- AlertDialog( -> Use AppDialog instead
- showDialog( -> Use AppDialog helper instead
- Divider( -> Use AppDivider instead
- Chip( -> Use AppBadge/AppChip instead
- ChoiceChip( -> Use AppChip instead

查證：`.claude/config/dart-style-guardian.json` schema 僅有 tokens/i18n/exempt_markers 三類欄位，無承載「原生元件替代名」的欄位；本專案 lib/components/ 實際存在 app_button.dart 但無 app_card.dart / app_dialog.dart / app_divider.dart 等，確認寫死名不屬本專案，屬他專案殘留。依票面指示不新增校準欄位，改為中性指引。

改後：8 個 pattern 的 suggestion 統一改為常數 `_NATIVE_COMPONENT_GUIDANCE = "改用元件庫封裝版，定義見 component-contract-design step-3〈原生元件禁用對照表〉"`（錨點已核對存在於 .claude/skills/component-contract-design/references/step-3-fill-contract.md）。

另移除 pattern 上方註解「spec §14.3 禁用對照表」中的他專案章節號，改為「Native component direct-use patterns」。native_exclusion_patterns（判斷已遷移元件的正則）未動，屬偵測邏輯非替代建議文字，且本專案 AppButton 確實存在，不在本票範圍。
