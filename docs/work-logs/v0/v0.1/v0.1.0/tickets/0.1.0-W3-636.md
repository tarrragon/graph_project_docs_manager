### 問題根因

SPEC-004 是專案 5 個 spec 檔（SPEC-001/002/003/004/005）中唯一在正文開頭帶「**版本**:」
重複版號行的檔案；其餘 4 檔皆無此行，版號只存在於 frontmatter。該行的變更歷史逐列附註
「檔頭版本段對齊 frontmatter」，證明此為既有、反覆執行成功的人工同步慣例（1.19～1.34 期間
逐版同步無誤），但已兩度長時間失守：1.26–1.32（7 版）停留於 1.25，由 `0.1.0-W3-169`
校正；1.35–1.42（8 版）停留於 1.38，由本票校正。`spec-version-consistency-check-hook.py`
僅比對 frontmatter 與「## 變更歷史」表格最大版號，對正文這行完全不可見——漂移復發是此
盲區的必然結果，不是偶然。

### 影響範圍

僅 `docs/spec/ui/SPEC-004-component-library.md` 正文第 22 行受影響；frontmatter
`version`（1.43）與「## 變更歷史」表格本身皆為一致狀態，未受污染。
