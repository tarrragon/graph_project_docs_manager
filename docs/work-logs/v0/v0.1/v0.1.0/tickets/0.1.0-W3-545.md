### 19c (a) 為何判為鑑別力歸零

第一步，**選列**。改寫後「容器元件」四字在射程判定表五列中**只出現於第五列**（第一列作「同一容器內的兩個子件」，第二至四列作「本元件」「容器或格位」，皆不含「容器元件」）。19c 前言寫「兩個容器元件」、(a) 寫「其他容器元件」，逐字對上。疊加既有通路：前言的「兩個容器」逐字對上第五列括號例示「（如兩個容器之間）」。純字面匹配即可命中第五列，**逐列排除不需發生**。

第二步，**選支**。(a) 題幹「畫面上沒有其他容器元件包住它們」對分支二條件「找不到這樣的容器元件（兩端直接放在頁面上）」——存在性陳述的極性逐字對應。

第三步，**輸出**。收緊後的通過門檻要求三成分（該處缺一個容器元件／須先補上該容器元件／由它承載），三者逐字都在分支二的值裡，照抄即通過。

三步串起來：讀者可在不執行任何逐列排除、不作任何推導的情況下產出滿分作答。**b16 的 r2 已用自己的話寫出這條路**——其「兩種以上可能判定」欄逐字為「否。題目明確『畫面上沒有其他容器元件包住它們』，對應表格第五列情況。」三輪作答（r1／r2／r3）皆直接引第五列，無一輪寫出逐列排除。

### 歸因：W3-533 不是歸零的成因，而是加了一條冗餘通路

誠實的歸因分三層：

1. **「兩個容器」通路在 W3-533 之前就存在**——來自 19c 前言（自 b8 起逐字未動）與第五列括號例示，b12 manifest 將其登記為「語意同類…（不逐字）」，該登記失準：`兩個容器` 四字在兩側逐字共用。
2. **「自行判定有無容器」這一維度是 W3-528.1 主動讓出的**，答案鍵〈已付的代價〉已記明鑑別維度由「辨識兩端型別 + 逐列排除」收為「逐列排除」。
3. **W3-533 收掉的是剩下的那一半**：「容器元件」成為第五列唯一字面，使選列也可純字面完成。

故 W3-533 使 (a) 對「逐列排除」的鑑別力歸零，但它疊在兩道既有的讓渡之上，不是單獨成因。**下批 19c(a) 的 3/3 只能支持一件事：讀者把命中那一支的值輸出完整**（這正是 b16 三輪失敗之處——舊的值是程序句，讀者停在頁面）。它不支持「讀者會逐列排除」，也不支持「讀者會做分支判斷」。

### 處置：不改題幹，改記載，鑑別力由 W3-538 的新子問承接

**為何不改題幹（成本比較）**

| 選項 | 成本 | 效果 |
|---|---|---|
| 改 (a) 題幹用字 | 可比鏈第四次中斷——但此項**成本為零**：`0.1.0-W3-534` 的〈基線重起宣告〉已宣告 b16 及以前與下批不可比，在同一次基線重起內改題幹不額外付可比性代價 | **改不掉**。分支條件是存在性陳述，題幹必須陳述該事實（`0.1.0-W3-528` 已裁定不陳述則本題欠定），而陳述必用容器類詞；換任何措辭只是把通路從「容器元件」換到別的詞。且「兩個容器」通路來自**前言與括號例示**，不在 (a) 那一句內，改 (a) 關不掉它 |
| 另出一題 | 新題無歷史基線——但下批本就另起基線，成本共用 | **已有承接者**：`0.1.0-W3-538` 規劃的分支一對照子問，題材為「兩端分屬不同容器、其共同上層是一個容器元件」，既非括號例示的「兩個容器之間」（故須真的排除第一列），又落在分支一（故與 (a) 構成分支對照）。不需再多開一題 |

**選擇**：不改題幹；(a) 降級記為已知字面通路的查表題，鑑別維度只剩「把命中支的值輸出完整」；逐列排除與分支判斷兩維度由 W3-538 的新子問承接。

**對 W3-538 的追加約束（本票新發現，`0.1.0-W3-574` acceptance 3 承接）**：其子問題幹若逐字寫「共同上層是一個容器元件」，即逐字對上分支一條件，於是兩個子問各自逐字對上自己的分支，配對仍不測分支判斷——`test-assertion-design-rules` 規則 E1 的缺口以字面形態原封復發。題幹須改以「這兩個容器同放在一個 X 容器元件之內」一類措辭，逼讀者自行把「同放在一個 X 之內」對映到「共同上層」。
