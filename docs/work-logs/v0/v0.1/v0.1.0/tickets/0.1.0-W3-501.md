## Problem Analysis
### 問題根因

〈條目標頭與內容角色〉引言連續四次補句（W3-489 辨識法、W3-491 可操作驗證補受詞／辨識法補反向指引／計數單位句補半／第五列與綜上段），b11 實測兩處淨負向。根因不在個別句子的措辭，而在**三個結構位置錯置**：

1. **計數規則不在填表動作的執行路徑上**。計數單位句位於引言第三段；讀者被直接問「這個主張成立嗎」時讀得懂（27a r2、r3 的 (b) 皆正確），需要主動套用到「應填幾項」時不啟動（同兩輪 (a) 皆答 3 項）。j1 明言修法須換軸。
2. **讓步句以列舉方式指名被擊敗的理由**。新增半句的前件是「取自不同的量、彼此獨立」，讀者實際使用的理由詞是「描述不同的內容」；未被指名者被讀成不在否定之列（j2 §4.2 直接實證）。這是列舉形式本身的射程蘊涵，不是前件寫得不夠寬。
3. **反向指引置於一個已可結案的判準之後**。步驟 1 的主判準（「值同步變動、取自同一個量」）後接「成立者…判定至此結束」，凡誤判為成立者不會讀到其後的反向指引。28a 三輪 0/3 取用即此結構的後果；唯一被讀到的一次出現在鄰題 27a 且為跨步驟誤用。

### 影響範圍

**已驗證的事實**（來源：judge-b11-doc-j1.md、judge-b11-doc-j2.md，四題題幹與 b10 sha256 全等，變動全歸因於條文）：
