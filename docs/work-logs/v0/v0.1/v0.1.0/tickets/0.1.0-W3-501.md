## Problem Analysis
### 問題根因

〈條目標頭與內容角色〉引言連續四次補句（W3-489 辨識法、W3-491 可操作驗證補受詞／辨識法補反向指引／計數單位句補半／第五列與綜上段），b11 實測兩處淨負向。根因不在個別句子的措辭，而在**三個結構位置錯置**：

1. **計數規則不在填表動作的執行路徑上**。計數單位句位於引言第三段；讀者被直接問「這個主張成立嗎」時讀得懂（27a r2、r3 的 (b) 皆正確），需要主動套用到「應填幾項」時不啟動（同兩輪 (a) 皆答 3 項）。j1 明言修法須換軸。
2. **讓步句以列舉方式指名被擊敗的理由**。新增半句的前件是「取自不同的量、彼此獨立」，讀者實際使用的理由詞是「描述不同的內容」；未被指名者被讀成不在否定之列（j2 §4.2 直接實證）。這是列舉形式本身的射程蘊涵，不是前件寫得不夠寬。
3. **反向指引置於一個已可結案的判準之後**。步驟 1 的主判準（「值同步變動、取自同一個量」）後接「成立者…判定至此結束」，凡誤判為成立者不會讀到其後的反向指引。28a 三輪 0/3 取用即此結構的後果；唯一被讀到的一次出現在鄰題 27a 且為跨步驟誤用。

## Solution
### 分析結論

三案不是三處獨立補文，是**一次結構重排**：計數規則移到填表動作所在的那一行、步驟 1 的三個零散判準收成兩條必要條件、被證明有害的讓步子句刪除。總字數持平或下降，無新增第五句。

W 階段（選項擴增，三類涵蓋）：改造既有＝移動／合併／刪除既有句（本三案）；零工具＝回退；新增工具＝無（本節不需要新機制）。反向思考檢查——若「補句無效」的判讀本身是錯的、真因是題目太難？已排除：四題題幹與 b10 sha256 全等，兩位判定者獨立同向，19c 同批 2/3→3/3 證明題組並非不可撼動。

### 案 1：計數規則前移到欄位佔位符

**選定做法**。現行佔位符行（範本 `### 4.{N} {ComponentName}` 下第二行）：

```
**內容角色**：{標題 / 內文 / 標籤 / 數值 / 動作 / 容器；先判斷多個內容部分是否合併為同一角色，再判複合角色，兩者見下方引言}
```

草稿：

```
**內容角色**：{標題 / 內文 / 標籤 / 數值 / 動作 / 容器；本欄填的是類別，同一類別只寫一次；先判斷多個內容部分是否合併為同一角色，再判複合角色，兩者見下方引言}
```

同批第三段改為（「本欄填的是角色類別」已前移，讓步子句依回退判斷刪除）：

```
> 角色與 slot 不必一一對應——同一角色可由多個內容部分或多個 slot 承載（如圖示 slot + 文字 slot），slot 數由 slot 契約決定。
```

**涵蓋範圍變化**：計數規則由「陳述式判準，位於引言第三段」變為「填表欄位的填法說明，位於填表那一行」。形式由**讓步句**（列舉被擊敗的理由）改為**正面的輸出單位定義**（本欄的單位是類別，不是內容部分）。後者不列舉理由，故任何「它們不同」的理由詞都推不出「多寫一項」——j2 §4.2 指出的「前件未覆蓋讀者實際理由詞」問題**在形式層消失**，不是被擴寬。

**被放棄選項**（Steelman）：(b) 原地改寫前件為「不論理由為何」——確能消除列舉蘊涵，但仍在第三段、不在執行路徑上，r3 已實證「逐字引用後反向套用」；(c) 整條刪除交由範例承擔——範例在探針餵入中被刪除，且範例本身措辭與錯誤理由詞同族（見措辭紀律）；(d) 做成填表前檢查清單一列——檢查清單在該範本末節，距填表動作比第三段更遠。

### 案 2 ＋ 案 3：步驟 1 收成兩條必要條件（兩案為同一處編輯）

**判定：反向指引不移除、不原地改寫，而是換落點——併入辨識法成為其排除子句；缺口 C 以刪除「同步變動」一詞閉合，而非界定它。**

兩案合併的理由：反向指引與缺口 C 都是對「步驟 1 成立條件」的約束，且都位於一個已宣告「判定至此結束」的主判準之後。凡誤判為成立者兩者皆讀不到——28a r3 正是如此（0/3 取用反向指引；以「同步變動」直覺結案）。分開修會各補一句，合併修是把三個零散判準收成兩條。

現行：

```
> **步驟 1**：先問元件的多個內容部分是否描述同一件事——判準：兩部分的值同步變動、且取自同一個量或
> 同一次量測者，即為描述同一件事（可操作驗證：拿掉任一部分，剩下的那部分仍完整表達被拿掉的那部分
> 所講的；若剩下的只表達得了它自己，即為不成立）。任一部分可由使用者或另一流程獨立設定、不隨另一
> 部分的值改變者，即非取自同一個量。成立者直接歸同一角色，不再逐部分套用下列四類定義，判定至此
> 結束。
```

草稿：

```
> **步驟 1**：先問元件的多個內容部分是否描述同一件事——下列兩條須同時成立，缺一即為不成立：
> (1) 兩部分的值都由同一個量換算得出；任一部分可由使用者或另一流程另行設定，或雖隨該量變化而值
> 本身另有來源者，即非由同一個量換算得出。
> (2) 拿掉任一部分，剩下的那部分仍完整表達被拿掉的那部分所講的；若剩下的只表達得了它自己，即為
> 不成立。
> 兩條皆成立者直接歸同一角色，不再逐部分套用下列四類定義，判定至此結束。
```

**涵蓋範圍變化（四項）**：

1. **刪除「值同步變動」與「同一次量測」**。缺口 C 的閉合方式是移除歧義詞而非定義它——讀不到的詞不會被讀歪。b10-j1 原提的界定式修法經代入誤傷 07c（見重現實驗結果第 3 點），已否決。
2. **反向指引由獨立句降為 (1) 的排除子句**。它原本是主判準之後的補充，現在是成立條件的一部分，凡判 (1) 者必經。同時使其步驟 1 射程顯性（置於「是否描述同一件事」標題下），提高 27a r2 那種跨步驟挪用的成本。
3. **可操作驗證由括號附註升為必要條件 (2)**。28a 兩輪答對靠的就是它（j1 必答 1：翻綠的唯一機制）；升為必要條件使 r3 那種「在 (1) 誤判成立後直接結案」的路徑多一道關卡。
4. **「成立」由單一判準改為連言**，缺一即不成立，去掉「滿足其一即可」的讀法空間。

**被放棄選項**（Steelman）：移除反向指引——目標題零取用看似無損，但 28a 的正解依據正是「值由使用者另行設定」，移除會使該題在條文中失去唯一對應句，探針將無依據可引；原地改寫——不解決可達性，r3 根本沒讀到那一行。**本案三個缺點**：(a) 把 (2) 升為必要條件，等於在目前 3/3 的 07c 上新增一道它從未走過的關卡（見誤傷矩陣）；(b) 「換算得出」是新引入的動詞，本節其他處用「取自」，術語一致性須同批檢查；(c) 刪除「同一次量測」後，若未來出現「同一次量測但不同換算」的題材，條文無對應句。

**07c 的新增風險（本草稿唯一的新增失敗面）**：(2) 由括號附註升為必要條件後，07c 必經 (2)，而該題三輪原本 0/3 取用 (2)。若讀者把 (2) 的受詞滑回「它自己」（j2 §1.5 記錄 r2 在 28a 犯過同型），可能判 (2) 不成立 → 2 項。**列為下批首要觀察項**：07c 若失分且依據句落在 (2)，即為本草稿的缺陷而非題目變難。

**例示情境甲的連帶修改（必要，非可選）**：現行【驗證】問句寫「判準是否為『各部分描述的是動作、對象還是值，同描述一件事者歸同一角色』？預期：是」。新條文下甲不是靠步驟 1 過的，是靠步驟 2 同類別去重。該問句須同批改為以「兩者皆描述觸發後做什麼，同屬動作類別，本欄只寫一次」作答。情境乙的【驗證】句「描述不同的事，歸兩個角色」建議同批改為「分屬不同類別，故列兩項」——「描述不同的事」與 27a 讀者實際使用的錯誤理由詞同族，留著會與佔位符的類別去重規則互相削弱。此兩處雖不在探針餵入內（節錄檔已刪範例區塊），不是本輪失敗的實證來源，但屬同節唯一的權威例示。

### 回退判斷：計數單位句補半應回退

**結論：應回退**——刪除「多個內容部分即使取自不同的量、彼此獨立，只要判為同一角色類別，仍只計一項」整個讓步子句，**不以改寫前件替代**。

三條理由：

1. **有實測基線**。b10 在無該半句時 27a 為 2/3，b11 加入後為 1/3，兩位判定者一致，題幹 sha256 全等。回退是回到一個量過的狀態，不是賭。
2. **機制而非措辭**。讓步句以列舉方式指名被擊敗的理由，產生射程蘊涵：未被指名的理由被讀成不在否定之列。改寫前件（j2 指出「不同的量」未覆蓋「不同的內容」）只把蘊涵邊界外推一格，下一個理由詞仍會落在界外。擴為「不論理由為何」可消除列舉，但該句仍在第三段、不在執行路徑上，r3 已實證逐字引用後反向套用。**問題出在句型與位置，不在前件寬度。**
3. **附帶負向**。該半句的「仍只計一項」措辭已在 28a(b) 產生一次弱形態誤用（j1 必答 3、j2 §4.3 各自獨立登記）。回退同時清除該面。

**回退的功能缺口由案 1 承接**：佔位符的類別去重規則是正面的輸出單位定義，不列舉理由，理由詞覆蓋問題不再存在。

**回退的誤傷（四題逐題）**：07c 三輪 0/3 取用該句 → 零影響；19c 不同檔 → 零影響；28a 為該句的負向來源 → 回退為淨正；27a 唯一通過輪 r1 原引「含新增射程半句」的計數單位句，回退後改引佔位符句，結論相同 → 不退步。**四題零退步。**
