## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
`Section`（`lib/components/section.dart`）為 `StatelessWidget`，依 SPEC-004 4.41 十一欄位契約實作：

- 變體：`SectionVariant.collapsible`（節首含展開器，收合時 items 不渲染入元件樹，用 `_showItems` 條件式建構避免掛入 tree）／`static`（恆展開，忽略 `isExpanded`）
- 修飾參數：`dashedTop`，以 `_DashedTopPainter`（`CustomPainter` 逐段畫短劃）承載，因 Flutter `Border` 不支援虛線樣式；色彩取 `AppColors.borderStrong`，上方內距 `Space.sm`
- 狀態不內存：`isExpanded` 由呼叫端傳入，符合 SPEC-004 §2 傳值 + callback 慣例；本容器自身無互動（展開器互動屬 4.18 `ExpanderIcon`）
- slot 契約：`header`（`Widget`，恰 1）／`items`（`List<Widget>`，0..無上限，型別一致由呼叫端負責——`ListRow`/`TableRow`/`RelationItem` 尚未建立，故以 `Widget` 承接，不提前綁定未存在型別）／`isExpanded`/`onToggle`
- 動畫：`AnimatedSize` + `Motion.transition(context)`，`disableAnimations` 時歸零（token 內建行為）
- 尺寸契約：不設最大高限制，捲動由外層 `Panel.scrollable` 承載（本容器不自設捲動區，符合 5.15「空間不足策略」）

排列不變式（SPEC-004 5.15）：
- 不重疊：`Column` 依序 header → items，垂直堆疊
- 最小間距：`Space.xxs` 插入項目之間；`dashedTop` 上方 `Space.sm`
- 空間不足策略：不自設捲動，交由父 `Panel.scrollable` 捲動（測試以 `SingleChildScrollView` 模擬）

契約無需修改，實測與 SPEC-004 逐項相符，未觸發「契約值實測不成立」的停手改契約流程。
