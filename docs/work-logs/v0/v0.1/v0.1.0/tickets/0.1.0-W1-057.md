### 框架內建機制驗證（ARCH-010）

選單開合、方向鍵走選項、Esc 收合皆為 Flutter Material `MenuAnchor`／`DropdownMenu` 內建能力；本規格只定義可觀察契約（錨點、`onChanged` 呼叫時機、幾何、`SemanticsRole`），不指定實作元件，SPEC-004 §6 已將 `DropdownButton`／`DropdownMenu`／`PopupMenuButton` 列為頁面層禁用、由 `FilterDropdown` 內部封裝。`SemanticsRole.menu`／`menuItem` 已實測存在於 Flutter 3.47.1 的 `dart:ui`（`sky_engine/lib/ui/semantics.dart` 第 441、451 行）。

### 設計決策（供 W1-005 子票代入）

| 決策 | 選擇 | 理由 |
|------|------|------|
| 選取後是否自動收合 | 是 | 單選語意；多選才需維持展開 |
| 選同一項 | 收合且不呼叫 `onChanged` | 避免無意義的 offset 歸零與重繪 |
| 焦點移動是否即時套用 | 否（F5） | 方向鍵瀏覽不應改變清單 |
| 選單是否為焦點陷阱 | 否（Tab 收合並前進） | 選單無需完成的交易，與浮層不同 |
| 點外部 | 吸收不穿透（F7） | 一次點擊一個結果；避免誤觸開票 |
| 排序循環 | `none → asc → desc → none` | 三態可回到載入順序，不需額外「清除排序」控制 |
| 多欄排序 | 不做（S1） | 0.1 無需求；換欄自 `asc` 起算 |
| 播報 | 重建即播報，不另 announce（F6／S4） | 與 SPEC-004 4.13 既有「重建即唸出新值」同機制，避免重複播報 |
| 時間 token | 不新增（`Motion.overlay`／`Motion.feedback`） | 既有十個 token 語意已涵蓋 |
