### PM 裁決（2026-09-15）：採程序指引，不採覆蓋對照表

**理由**
- ColorScheme、TextTheme 的欄位會隨框架版本改動，例如 Material 3 就增刪過欄位。把欄位寫死成清單，版本一更新就會悄悄失效（reference-stability 規則 10 同型）。
- 程序指引只指出權威來源，不會隨版本過期。

**落地內容**
1. 在判準句旁補上方向句：「對應的內建語意插槽存在時用主題插槽，不存在時用 token」。這個方向目前只寫在範例的【產出】段，W3-404 已判定 color Q1 為 C 型，就是缺這一句。
2. 補程序句：「無法確定某語意是否有內建插槽時，查閱當前框架版本的 ColorScheme／TextTheme 官方欄位清單再判定，不憑記憶」。

**判定影響**
- 兩句都只是把範例【產出】裡已有的判定寫成條文，不改變任何判定結果，也不涉及新的程式碼風格選擇。
- 本專案已定案的是「Prefer theme colors」。
