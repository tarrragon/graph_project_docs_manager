### Context Bundle

依 SPEC-004 §4.9 建立 RecentProjectItem：浮層內單一專案選項（圖示 + 名稱 +
摘要 + 健康徽章 slot + disabled 常駐原因）。十一欄位對照 4.0.1 disabled、
4.0.2 帶色表面規則（selected 摘要改 textPrimary）、4.0.3 尺寸推算、4.0.4
TestCopy、4.0.7 操作機制點選列。無 blocking 問題，slot 契約清楚可直接實作。

### 與契約的一處差異

`AppText` 只開放 `secondary` 布林（切換 textPrimary/textSecondary 兩色），
無法表達狀態矩陣要求的 accentStrong（selected）/ textDisabled（disabled）。
`name` / `summary` 改以內部 `Text` 直接依狀態取色渲染，與 `ListRow.sectionHeader`
已記錄的差異同一慣例（見 `list_row.dart` 檔頭）。內容政策（單行、截斷）
不變，僅取色手段不同。已記於 `recent_project_item.dart` 檔頭。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
新增 `lib/components/recent_project_item.dart`（`RecentProjectItem`
StatelessWidget）與 barrel export `lib/components/components.dart`（追加
一行，未重排既有行）。實作依 SPEC-004 §4.9 十一欄位：`name` / `summary`
必填單行截斷、`health`（`Badge.health?`）選填、`enabled` / `isCurrent`
狀態、`reason`（disabled 必填，assert 強制）、`onTap` / `testKey` 必填。
圖示固定 `Icons.folder_outlined`（非呼叫端 slot，契約十一欄位未列圖示為
可變輸入，沿用 `shell.dart` 既有專案圖示慣例）。三態取色（enabled /
selected / disabled）依狀態矩陣與 §4.0.2 帶色表面規則實作；disabled reason
常駐顯示（非 tooltip），最多 2 行。無障礙依 §4.9「朗讀標籤」：
`Semantics.button`，label 為「{name}，{summary}」，selected 附加
`currentProjectA11yLabel`，disabled 時 hint 為 reason。
