## Problem Analysis

### 問題根因

`reference-stability-rule8-guard-hook.py:313`（修改前）的掃描迴圈 `for pattern in (VERSIONED_TICKET_PATTERN, BARE_TICKET_PATTERN)` 只認 ticket ID 兩個樣式；規則 8 條文（`reference-stability-rules.md` 規則 8）以「等」開放列舉「專案層級識別符」，worklog 路徑、docs/spec 路徑等專案檔案路徑同樣落入條文範圍。守衛偵測面窄於規則條文，是「部分覆蓋而會命中」比「不存在的守衛」更容易讓漏網類別通過的具體案例（票面已詳述）。

### 影響範圍

- `.claude/hooks/reference-stability-rule8-guard-hook.py`：新增專案路徑偵測軌
- `.claude/hooks/tests/test_reference_stability_rule8_guard_hook.py`：新增 8 個測試（1 個獨立 WARNING 層測試類 5 個 + 單元函式測試 3 個）

### 相關 Error Pattern

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### 修復方式

新增與 ticket ID 軌並列的「專案路徑軌」，共用既有 marker 逃生閥機制，WARNING-only（不阻擋）：

1. **判準**（寫入程式碼註解，非僅 commit message）：路徑是否在其他 consumer 專案「保證存在」。`.claude/` 開頭路徑跨專案恆存在（框架內部結構，規則 8 明文允許）；`PROJECT_PATH_PREFIXES = ("docs/", "lib/", "test/", "integration_test/")` 所列專案頂層目錄開頭者不保證存在。新增專案類型頂層目錄可直接擴充此 tuple。
2. **偵測**：`PROJECT_PATH_TOKEN_PATTERN` 從最外層邊界（行首/空白/反引號/引號/括號）比對到副檔名結尾，取得完整路徑 token（非任意子字串）——避免 `.claude/skills/lib/foo.py` 中的 `lib/foo.py` 子字串被誤判（完整路徑其實以 `.claude/` 開頭，合法）。新增 `find_project_path_hits_with_lines` / `find_project_path_hits`，結構對稱既有 ticket ID 版本。
3. **DRY 複用**：`diff_new_hits` 與 `filter_marker_exempt` 均新增 `finder` / `hits_with_lines_finder` 參數（預設值保持既有 ticket ID 行為不變），路徑軌呼叫時傳入路徑版 finder，複用同一套淨增量比對與 marker 逃生閥邏輯，不另寫一份幾乎相同的比對函式。
4. **先量後定強度**：對 `.claude/` 全量掃描（用實作後的 `find_project_path_hits` 而非 grep 近似值），量測結果為 **1990 個相異路徑值、分布於 394 個檔案**（原 grep 粗估 1339/331，實作後用精確函式重新量測），規模遠超可承受的一次性阻擋量，故本層級僅 WARNING（exit 0），阻擋層另開票評估（見 Spawn Requests）。
5. **main() 整合**：`build_path_warning_output` 於 `reconstruct_pre_post_text` 之後、ticket ID 判斷之前無條件執行——確保路徑類 WARNING 不受 ticket ID 軌各早期 return 影響，兩軌完全獨立；exit code 仍完全由 ticket ID 軌決定。

### 修改的檔案

- `.claude/hooks/reference-stability-rule8-guard-hook.py`：新增 `PROJECT_PATH_PREFIXES`、`PROJECT_PATH_TOKEN_PATTERN`、`find_project_path_hits_with_lines`、`find_project_path_hits`、`build_path_warning_message`、`build_path_warning_output`；泛化 `diff_new_hits`、`filter_marker_exempt` 新增可選 finder 參數；`main()` 整合路徑軌；docstring 補充路徑軌說明與量測數字。

### 本票的核心不是覆蓋率，是覆蓋率被誤讀

**沉默與命中的可解讀性不對稱**：

| 守衛狀態 | 讀者的合理推論 | 是否仍會自查 |
