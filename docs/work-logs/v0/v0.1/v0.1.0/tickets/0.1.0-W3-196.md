**沉默與命中的可解讀性不對稱**：守衛沉默時，讀者仍可能自行查驗；守衛命中並被滿足時，該規則在讀者心中已結案。因此**部分覆蓋而會命中的守衛，比不存在的守衛更容易讓漏網的那一類通過**——它為未覆蓋的部分提供了合規的外觀。這是本票優先級為 P1 而非 P2 的理由：缺陷不在覆蓋率，在覆蓋率被誤讀為完整。（來源已完成，結論見 Solution）
