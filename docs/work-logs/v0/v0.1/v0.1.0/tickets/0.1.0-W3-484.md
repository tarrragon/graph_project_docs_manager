| 甲-1 | 8.2(2) | 兩點依序判，兩點都成立才算違反，未明示第一點不成立時的動作 | 補「第一點不成立即結束判定，判不違反，不進第二點」 | UX-M2（既有題） |
| 甲-2 | 2.4(2) | 「這一點會在那一次比較中一併檢查」（可讀成系統自動處理） | 改為讀者動作：「讀者須把那一次比較的結果取回這裡用……不是系統自動處理，須讀者自行取回核對」 | UX-R3（既有題） |
