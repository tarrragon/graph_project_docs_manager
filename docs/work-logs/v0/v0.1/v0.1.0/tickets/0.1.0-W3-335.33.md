#### C3（快速模式）
- 裁決：修改後採用。
- 理由：草稿「首次拒絕後可再請求一次」只在 Android 成立。Android 11 起同一權限拒絕兩次後系統對話框不再顯示；iOS 系統對話框只顯示一次，拒絕一次即等同永久拒絕。草稿不分平台，會讓 iOS 規格出現一個點了沒反應的「再次請求入口」。
