## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
建立 `lib/components/app_button.dart`（`AppButton`，`StatefulWidget`）與
`lib/components/components.dart`（barrel，首個 export）。

**公開 API**：`AppButtonVariant`（`primary`/`secondary`/`text`）；`AppButton`
建構子參數 `label`（必填）、`onPressed`（必填）、`testKey`（必填）、
`variant`（預設 primary）、`leading`（僅 text 變體，型別見下方差異說明）、
`enabled`（預設 true）、`disabledReason`（enabled=false 時必填，assert 強制）。

**與契約的一處差異（已於檔頭 dartdoc 記錄，範圍限定於本票）**：slot 契約表
`leading` 型別為 `AppIcon?`，但 `AppIcon`（SPEC-004 4.2）尚未建立，非本票
（4.4）範圍。改以 `Widget?` 承接，語意不變；`AppIcon` 建立後可直接代入，
型別相容，不需改動 `AppButton` 本身。

**實作要點**：
- 底層用 `TextButton` 承載三變體樣式（`TextButton.styleFrom` 依 §4.0.7 取得
  Material 內建 hover/pressed overlay 與 disabled 語意，`ButtonStyleButton`
  子型別滿足測試點「被 ButtonStyleButton 或 InkWell 包覆」）。
- `SizedBox(height: LayoutSize.hitTargetMin)` 外層強制固定高，`minimumSize`
  + `tapTargetSize: shrinkWrap` + `visualDensity: compact` 避免 Material
  預設最小點擊區（48）撐大版面。
- focused 態：`StatefulWidget` 追蹤 `onFocusChange`，用 `DecoratedBox` 包覆
  （`border` 依聚焦與否切換），對應 SPEC-003 §2.10「祖先鏈存在 decoration
  非 null 的 DecoratedBox」斷言慣例。
- disabled 原因：與按鈕同列 `Row` 顯示（非 tooltip），`Semantics(hint: ...)`
  附加於同一節點。
- 所有色彩/間距/字級/圓角/動畫時長皆引用 `lib/tokens/`；僅 `text` 變體
  `background: Colors.transparent` 與 focused 邊框未聚焦時的透明佔位色標
  `color-exempt`（非 token 語意色，屬「無底/無邊框」的結構性表達）。

**測試**（`test/unit/components/app_button_test.dart`，16 tests）：全變體
（3）× enabled/disabled（2）× 兩尺寸（`WindowSize.min`/`design`）× 兩語系
（zh/en）矩陣渲染不溢位；高度契約（恰為 `hitTargetMin`）；`TestCopy.longToken`
/`TestCopy.longZh` 最長文案截斷（`maxLines:1`+`ellipsis`）；`onPressed`
enabled 呼叫恰一次、disabled 零次且無 SnackBar；Space/Enter 鍵盤觸發等價；
`ButtonStyleButton` 元件樹斷言；朗讀標籤等於 label、disabled 時
`isEnabled` semantics flag 為 false；slot 契約 assert（disabled 缺
disabledReason、非 text 變體帶 leading 皆拋 AssertionError）；text 變體帶
leading 圖示語意樹排除驗證。

**Phase 4 自檢結果**：重構需要：否。技術債務：無新增（既有的 `AppIcon`
型別差異已於檔頭記錄並限定範圍，非隱性債務）。程式碼品質：A（`dart
analyze` 0 issues；函式/類別劃分符合單一職責；token 零裸值；無障礙與
disabled 語意皆有測試覆蓋）。結論：AppButton 契約完整落地，無需本票內
重構；`AppIcon` 建立後的型別收斂留給 4.2 票銜接，不視為本票技術債務。
