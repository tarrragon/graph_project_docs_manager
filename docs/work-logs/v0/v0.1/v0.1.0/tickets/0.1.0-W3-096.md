#### D1：掃描在 App 啟動時就跑完，不是在首次可見時

證據鏈：

1. `lib/screens/gap_report/gap_report_provider.dart` 的 `build()` 呼叫 `_scheduleScan()`。
2. `gapReportProvider` 的首次讀取者是 `lib/app/shell.dart:56-60` 的

   （`lib/screens/gap_report/gap_report_screen.dart:26` 的 `ref.watch` 是第二個讀取者。）
3. `lib/app/router.dart:134` 的 `firstVisibleProvider` 已建立且有單元測試
   （`test/unit/app/router_test.dart:81`），但 **`lib/` 內無任何消費者**
   （`grep -rn firstVisibleProvider lib/` 只命中 router.dart 自身與 gap_report_provider.dart

microtask 內，`state` 由 `GapReportScanning` 轉為 `GapReportFound`，
`ScanNotificationController._onGapReportStateChange` 命中
`previous is GapReportScanning && completed` → `_evaluateCompletion`；
此時 `appLifecycleStateProvider` 為初值 `resumed`（`lib/app/app_lifecycle.dart`）、
`selectedDestinationProvider` 為預設 `domain`，故 `_isVisibleForeground()` 回 `false`

`authorizationStatus()` 被呼叫，`notDetermined` 時進而 `requestAuthorization()`。

亦即現行實作不是「不發通知」，而是「使用者還沒看過破洞報告頁就先收到掃描完成通知

**[PM 更正 2026-09-09] why 段的「runtime log 零輸出」不是證據，但結論仍成立——另有決定性證據。**

執行者於 NeedsContext 第 2 項指出票面 why 與其原始碼推導矛盾，該質疑正確，矛盾的來源在 why 段。

**why 段記載的「`flutter run` 的 runtime log 自 App 啟動起零輸出（`MacosScanNotifier` 的授權查詢 log 從未觸發）」，其推論無效。** PM 於 2026-09-09 實機確認：`developer.log` **本來就不進 `flutter run` 的 console**，只進 Dart VM Service 的 Logging stream。console 零輸出因此不能推論「log 從未觸發」——這正是 `0.1.0-W3-078` Problem Analysis 第三項記載的同一個誤判（「PM 曾據 console 零輸出誤判『通知路徑從未執行』」），該誤判在寫入本票 why 段時未被一併更正。

**但本票的結論不受影響，因為有另一項決定性證據。** 同次實機驗證量測 `~/Library/Preferences/com.apple.ncprefs.plist` 中本 App（`com.example.graphProjectDocsManager`）的條目數，App 啟動前後**皆為 0**，且無授權對話框出現。

該值的鑑別力在於：`requestAuthorization` 一旦被呼叫，無論使用者允許或拒絕，系統都會在 `ncprefs` 留下條目。**條目數為 0 是「該呼叫從未發生」的直接證據，不經任何推論。**

由此可回答執行者的疑問：`scan_notification_controller.dart` 的通知路徑在 `previous is GapReportScanning && completed && !cancelled` 這道閘門即已擋下，未抵達後續的 `authorizationStatus()` / `requestAuthorization()`。若曾抵達，`ncprefs` 不可能維持 0。

**兩者的差別值得記**：console 零輸出是「用一個不承載該訊號的管道去證明訊號不存在」；`ncprefs` 條目數是「該事件必然留下的副作用」。前者無鑑別力，後者是固定值。接手者若需再次確認此類事實，優先找**事件必然留下的副作用**，不要找日誌。

結果的同源問題（同樣是「同一 microtask 內完成」時結構性不可達、真實延遲後
才會被打到的伴生風險）。
