**主導模式：盲推導自造元件名。** 12 項對照分歧中 D3/D5/D6/D8/D10/D11 六項為走查者自造元件（CellDetailCard、SwimLaneCanvas、UCBasicInfo、StepTable、TreeNode、BrokenLayerBadge），SPEC-004 皆以通用容器加既有子件組合表達（Panel、DataTable、Tree、ListRow 變體、IssueMarker 變體）。

歸因須拆兩層，彙整時不可合併：

| 層 | 判定 |
|----|------|
| 走查方法人為因素 | 盲推導刻意不讀 SPEC-004，走查者手上沒有通用元件目錄；真實畫面票會有目錄可選。此部分不是 skill 缺口 |
| 真實 skill 缺口 | component-contract-design step-2 路徑 A 描述的正是「元件庫尚未建」的起點，而該路徑下同樣沒有目錄可選。存在必要性檢視只問「通用元件加變體能否涵蓋」，未引導「先嘗試以通用容器加既有子件組合表達，組合不出才立新候選」。路徑 A 的真實使用者會犯同一個錯 |
