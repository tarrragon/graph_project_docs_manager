### 實作概述

依 SPEC-004 §4.21 EmptyState 十一欄位契約建立 `EmptyState`（`lib/components/empty_state.dart`）：

- `EmptyStateVariant`（`page` / `section`）決定置中與動作必填性
- slot：`message`（必填）、`explanation`（選填）、`actions`（`page` 1..3 必填、`section` 可空）、`testKey`（必填）
- `page`：`Center` 包裹、訊息用 `AppText.subtitle`（單行）、置中文字對齊、動作經 `ButtonRow(alignment: center)`
- `section`：靠上對齊、訊息用 `AppText.body`（`maxLines: 2`）、內距 `Space.md`、動作經 `ButtonRow(alignment: start)`
- 說明統一 `AppText.body(secondary: true, maxLines: 4)`
- 間距：訊息—說明 `Space.xs`；說明—動作 `Space.lg`（§4.0 通用約定）
- 文字塊最大寬 `LayoutSize.detailPaneWidth * 2`（`ConstrainedBox`）
- 無障礙：訊息包 `Semantics(liveRegion: true)`（狀態變化播報）
- assert 兩項：`page` 動作非空、`actions.length <= 3`（同 `ButtonRow` 慣例）
- barrel 匯出：`lib/components/components.dart` 依字母序新增 `export 'empty_state.dart';` 一行，未重排既有行
