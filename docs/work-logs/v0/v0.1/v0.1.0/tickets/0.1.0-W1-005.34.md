## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
新增 `MatrixCell`（StatefulWidget，追蹤 focus）：`Relation` 列舉（direct/indirect/none）
承載符號 ● ○ · 與各自未選色（accent/textSecondary/borderStrong，皆取自
`lib/tokens/colors.dart`）；`isSelected` 底改 `accent` 且符號改
`surfaceBase`（成對設計）；`isRowSelected` 底改 `surfaceIconTint`；default
底透明。已選格 `onTap` 傳 `null`（互動反應「單擊已選：無狀態改變」，測試
斷言再點零次）。命中區以 `ConstrainedBox(minWidth: hitTargetMin,
minHeight/maxHeight: rowHeightRelaxed)` 保證，`hitTargetMin` 刻意不套
ScreenUtil scaling（比照 `app_button.dart` / `nav_item.dart` 慣例，
確保 `kMinWindowSize` 下命中區不縮水於契約值）。focused 態沿用
`app_button.dart` 的 `DecoratedBox` 邊框慣例（依 §4.0.1）。Semantics
`button: true`、`selected: isSelected`、`label: semanticLabel`
（呼叫端組字，本元件不知 i18n key）。

測試 `test/unit/components/matrix_cell_test.dart`：3 變體 × 2 selected ×
2 rowSelected × 2 視窗尺寸（24 組）不溢位；命中區斷言；點選行為（未選呼叫
一次／已選呼叫零次／Semantics.selected 一致）；selected 與 rowSelected
底色可區辨（讀 `Container.decoration` 比對 token）；三變體符號與顏色逐一
斷言（讀 `Text.data` / `Text.style.color`）；selected 態符號色改
`surfaceBase`。共 34 組測試，`flutter test test/unit/components/`
全量 810 通過，`dart analyze lib test` 對本票新檔 0 issue（既有
`hasFlag` info 為既存技術債，非本票新增）。

契約無改動：SPEC-004 §4.15 十一欄位如實現。

### 自檢結果
- 命名：`Relation` / `MatrixCell` 語意清楚，無縮寫。
- 常數/token：色彩、間距、字級、圓角、動畫皆取 `lib/tokens/`；無裸值
  （唯一例外 `Colors.transparent` 標 `color-exempt` 註解，比照
  `app_button.dart` 既有慣例，非語意色）。
- 函式長度：`build` 約 40 行含三個局部變數宣告（cellBody/inkCell/
  decoratedCell），符合專案既有元件（`app_button.dart`）同構寫法，
  未再拆分以維持與同儕元件一致的可讀順序。
- i18n：無硬編碼 UI 文字；符號 ● ○ · 依 SPEC-004 §4.15 內容政策為
  「非語意排版字元」，不進 ARB。
- 可觀測性：本元件為純展示 + 回呼，無 catch 區塊、無平台互動，規則
  1/5 不適用。

**Phase 4 結論**：程式碼品質 A（沿用專案既有元件慣例，無新增技術債）；
