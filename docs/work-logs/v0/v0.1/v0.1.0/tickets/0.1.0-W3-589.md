## Task Summary

四格判讀表第三格的括號描述為「停在『由共同上層承載』未補容器」、判讀語為「一律輸出分支一（改寫前舊措辭的殘留形態）」。b21 的 r3 落入該格（19d 通過 + 19c(a) 不通過），但其實況相反：r3 對兩題輸出的是不同分支（19d 分支一、19c 分支二的核心斷言「該處缺一個容器元件」），失分在承載者選言含「頁面根堆疊」。修表使格的判讀語不預設對照題的單一失敗形態

## Problem Analysis
### 問題根因

四格判讀表以「19d 通過／不通過 × 19c(a) 通過／不通過」為軸，並為每格綁一句判讀語。該設計的隱含前提是 **通過 <=> 輸出正確分支**。

b21 的 r3 逐字否證此前提：19c(a) **已斷言分支二的核心成分**「該處缺一個容器元件」，卻因牴觸性補述（承載者選言含「頁面根堆疊」，即條文指名為「缺一個容器元件」的那個狀態）記不通過。

根因一句話：**通過與否是 (選對分支) AND (輸出收斂) 的合取，四格卻把它當作「選對分支」的代理**。合取被當單一變數使用，只要另一個合取項失敗，代理即失效——此時照搬格的判讀語會得出與實況相反的結論。

### r3 實況與第三格括號描述的落差（acceptance 1，逐字）

| 項目 | 逐字內容 |
|---|---|
| 第三格的格描述 | 「19d 通過 + 19c(a) 不通過（**停在「由共同上層承載」未補容器**）」 |
| 第三格的判讀語 | 「**一律輸出分支一**（改寫前舊措辭的殘留形態）。19d 的通過同樣不可歸因於分支判斷」 |
| r3 的 19c(a) 判定欄逐字 | 「這段距離應由頁面根堆疊或新的中間容器承載；判定步驟應先確認兩個元件各為容器、確認它們的共同上層為原生頁面佈局，再根據判別問句判定『該處缺一個容器元件』。」 |
| 落差 1 | 格描述說「停在由共同上層承載未補容器」；r3 **並未停在該處**——它斷言了共同上層為原生頁面佈局（存在性判定已執行），並輸出「該處缺一個容器元件」 |
| 落差 2 | 判讀語說「一律輸出分支一」；r3 對兩題輸出的是**相反**分支（19d 分支一、19c(a) 分支二的核心斷言） |
| 落差 3 | 判讀語把不通過歸因於「舊措辭的殘留形態」；r3 的失分實為**牴觸性補述**（承載者選言含「頁面根堆疊」），與舊措辭無關 |
| 判定者當時的處置 | j2 依規則把 r3 填入第三格，同時**必須逐字寫一段但書說明該格判讀語在 r3 不成立**——但書是表失效的直接證據 |
