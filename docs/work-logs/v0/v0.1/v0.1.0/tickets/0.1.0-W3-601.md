## Problem Analysis
### 問題根因

判定者的可見範圍只有兩處：答案鍵的〈判定者註〉與 `tools/judge_brief_<批次>.md`。判定者不讀 manifest、
不讀另一位判定者的檔案、不讀 `.claude/`。`w590-judgelayer-manifest.md` 的新判讀層若只落在 manifest，
下批判定者仍會照舊四格填格、照舊一句帶入判準判定，b21 的兩個判讀層缺口原樣復發。

### 影響範圍

| 類別 | 項目 |
|---|---|
| 新增（scratchpad，untracked） | `probes/w601-judge-interface-manifest.md`（兩處判定者註與 judge brief 第四／五章的逐字草稿、插入點、下批 manifest 併入來源表） |
| 未動 | b21 的答案鍵、judge brief、題目檔、節錄檔、三輪作答、兩份判定書（歷史記錄不得改寫）；`w590-judgelayer-manifest.md` 本體；全部器材 |
| 已驗證的事實 | 判定者的作業順序四步與可見範圍取自 `tools/judge_brief_b21.md` 逐字；判定者註第 1／3 項的現行全文取自 `key/W3-417-b21-doc-1.md` 逐字；`b21_doc_manifest.py` 的 `CARRY` 現為四節單一來源 |
| 仍未驗證的假設 | 草稿在下批實際併入後是否使兩位判定者收斂——本票只寫定接口，未出題 |

### 本票查出的三個接縫（原票面未涵蓋，須併入草稿）

**接縫一：w574〈題序與帶入方向〉不可整節丟棄。** `w590-judgelayer-manifest.md` 檔頭寫明它取代的是該節
**第三列（判定者責任）**，〈題序〉與〈間隔〉兩列仍生效。若下批把該節整節換掉，「19d 置於 19c 之前」與
「兩題之間至少隔一題非方法論題」兩項規定會被靜默丟失。草稿因此把兩列逐字保留於判定者註第 3 項的包覆
文字，只換第三列。

**接縫二：下批 manifest 的併入來源是雙來源六節，不是單來源四節。** w574 的〈同構比對〉與〈計分紀律〉
未被 w590 取代仍須併入；w590 檔頭要求其〈一〉至〈四〉四節皆併入。故 `CARRY` 須由 `list[str]` 改為
`list[tuple[來源檔, 節名]]`，逐節 sha256 兩側比對的輸出增印來源欄。`b21_doc_manifest.py` 本身不動
（b21 已完成，改它會使 b21 的複驗不可重跑）。

**接縫三：新判定者責任要求執行器材，判定者的工具清單須含 Bash。** 訊號 1 的門檻 B 是全卷兩兩配對的
命中數，無法以閱讀產生；現行 judge brief 未寫任何器材執行步驟。草稿於〈作業順序〉第 3 項後插入一步
（跑帶入器材、stdout 逐字抄入判定書），並明寫不能執行器材者不得擔任該批判定者。器材目前只認 b21
的檔名與題號，泛化已成票 `0.1.0-W3-608`。

### 草稿不重打規範本體的理由

判定者註與 manifest 的本體一律由器材程式複製並逐節 sha256 比對（沿 `b21_doc_key_copy.py`／
`b21_doc_manifest.py` 機制）。把 w590 的本體重打進草稿會產生第二份可各自漂移的副本，正是該複製機制
要防的事。草稿因此只逐字給出**包覆文字**（取代宣告句、射程註記、雙臂語意段、本批落實段）與**插入點**。

### 相關 Error Pattern

`opinionated-default-design` 主張 1（預設行為 > 文件規範）：本票的接口改寫即是把「判定者應該檢查帶入」
這句提醒，換成「判定者跑器材、抄 stdout、填六欄登記表」的預設路徑。
