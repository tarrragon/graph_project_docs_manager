### 實作概述

依 SPEC-004 §4.17 十一欄位建立 `StepNumber`（StatelessWidget）：圓形容器（`BoxShape.circle`，直徑 `LayoutSize.stepNumberSize.r`）、底色 `AppColors.surfaceIconTint`、字色 `AppColors.accentStrong`、字級 `AppFontSize.caption`（三位數以上依內容政策提案縮字級 -2）。`Semantics` 朗讀 `stepNumberA11yLabel`（既有 l10n key，W1-056 已建）、`excludeSemantics: true`、不含 `button` 語意（純顯示，無互動）。`components.dart` 依既有排序（split_row 與 swimlane_node 之間）新增一行 export，未重排既有行。

零裸值：色彩、尺寸、字級全取自 `lib/tokens/tokens.dart`；朗讀文字取 `AppLocalizations`。

### 測試

`test/unit/components/step_number_test.dart` 沿用 `pumpHarness` / `testWidgetsAtEachSize` / `expectNoOverflow` 既有寫法：

- 序號矩陣：1（一般序號）、39（§4.0.4 一般值）、999（§4.0.4 人工值）、1000（觸發三位數以上縮字級分支）× 兩種視窗尺寸，共 8 個測試，逐一斷言不溢位且文字正確渲染
- 朗讀標籤：斷言 `bySemanticsLabel` 命中 `stepNumberA11yLabel(39)`
- 純顯示語意：`flagsCollection.isButton` 為 false（依票面約束改用 flagsCollection，未新增 hasFlag 用法）

### 契約值

契約值（直徑 24、圓形、i18n key、色彩對映）實測皆成立，SPEC-004 §4.17 與 §4.0.6 無需改動。

### 附帶修正

實作過程發現 `lib/components/app_shell.dart`、`blocked_state.dart`、`load_prompt.dart`、`recent_project_item.dart` 等既有檔案的 `AppLocalizations.of(context)!` 屬過時寫法（`of()` 簽章已非 nullable），本票僅修正本票新建檔案內同型寫法，既有檔案不在本票範圍不予修改。
