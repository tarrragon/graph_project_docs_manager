- 0.1.0-W3-552 what: 0.1.0-W3-550 的六輪重測中，8.2(3) 新增五款有三款被引（① 三輪、② 三輪、④ 三輪），③ 文字內容界定與 ⑤ 預設值款**零被引**，導引句「不得只憑該項名稱自行認定」與射程限制句亦零被引。零被引的成因是題材：本批兩題的誘因項（擺放方位、輕晃）分別落在 ① 與 ②④ 的字面射程內，讀者用界定句即可結案，走不到 ⑤ 的舉證責任條款。⑤ 是 0.1.0-W3-530 兩位判定者原本指名「單獨即可擋下 A3-r3」的那一款，其效力目前無任何讀數支撐。本票出一道誘因項落在 ①②③ 界定範圍之外的新題（使讀者只能靠 ⑤ 的舉證責任判定），另出一道以字形／字重／字距為誘因項的題測 ③，各跑三輪取得讀數。

### Rationale Chain
- 0.1.0-W3-598 why: 讀法乙下指派標的必然列在清單上，直接支持自動取得，⑤ 在它唯一承重的那一格（誘因項不在清單內、被指派給無界定句的五項之一）恆放行，成為零效力條文；0.1.0-W3-541 明文以 ⑤ 為線條樣式與填滿與否的終局處置，該決策亦隨之落空。UX-W8v 的 key 正解（違反）在現文下因兩讀並存而不穩定。
- 0.1.0-W3-552 why: 0.1.0-W3-550 的結論「條文已能獨力擋下誤指派」只涵蓋 ①②④ 三款所點名的誘因項；⑤ 是為未點名的誘因項而設的兜底款，本批未觸發即未量測，不能由 ①②④ 的全命中推論 ⑤ 有效。W3-541 已明示「線條樣式」與「填滿與否」不補界定、以 ⑤ 為終局處置，該決策的正確性完全繫於 ⑤ 的實際效力。
