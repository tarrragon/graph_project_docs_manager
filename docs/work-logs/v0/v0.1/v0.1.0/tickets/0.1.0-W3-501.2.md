## Problem Analysis
### 問題根因

DOC-28a 的題幹（b10 起凍結）以「使用者於其他畫面把這支影片設為看完」承載解耦訊號；
W3-501.1（`f44a42ab`）把反向指引「可由使用者或另一流程另行設定」由主判準之後的獨立句
降為步驟 1 必要條件 (1) 的排除子句，該子句因此成為**必經路徑**。兩者共用「使用者」與
「設」二字，重疊由潛在（b11 實測 0/3 未觸發）轉為必然。後果：DOC-28a 本輪若翻綠，
無法分辨讀者是理解「值的來源不同」還是字面對上題幹用詞——該題的讀數失去歸因能力。

### 影響範圍

**已驗證的事實**：

- 題幹用詞機械命中（對 `q/W3-417-b12-doc-1.md` 題幹字串逐詞 count）：DOC-28a「使用者」1、
  「設」1；DOC-28b「使用者」0、「設定」0、「設」0、「流程」0、「背景」0。
- 現行條文 (1) 的排除子句逐字為「任一部分可由使用者或另一流程另行設定，或雖隨該量變化而值
  本身另有來源者，即非由同一個量換算得出。」（節錄檔 `doc--…--b12-4條目標頭與內容角色.md`）
- W3-501.1 的三處條文變動使 b11 答案鍵 37 條引文中失效 12 處／7 條，本批逐條更換。

**仍未驗證的假設**：DOC-28b 對讀者的實際效力。本票只產出題目與答案鍵，未施測；
28b 能否分離「語意取用」與「字面匹配」，要到探針作答與判定書出來才存在讀數。

### 相關 Error Pattern

查詢範圍內未命中既有 PC 編號。本題的形態是「探針題幹與受測條文共用字面，使通過不可歸因」，
屬 `test-assertion-design-rules` 規則 E1（明示旗標必須有對照測試）的同族——單邊斷言沒有
比較對象。本票的處置（同批保留原題為對照、新增零字面重疊的分離題）即該規則的套用，
不新增 error-pattern。
