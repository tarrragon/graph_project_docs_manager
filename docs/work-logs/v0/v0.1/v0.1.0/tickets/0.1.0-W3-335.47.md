## Problem Analysis
### 問題根因

V4 第二輪（`0.1.0-W3-335.46`）探針標為 spec 間矛盾者共 17 項（V4R-01 G09、G20；V4R-02 G04、G06、G16a、G21、G35；V4R-03 G-11、G-30、G-31；V4R-04 G01、G04、G07、G24、G25、G27、G28），另 PM 核對出 SPEC-003 §2.7〈空狀態與阻擋狀態的動線〉三處同步缺漏。直接原因分兩型：(1) 前輪追修（.40／.41／.42）改一處條文未同步引用同一狀態或規則的彙總表（§2.7 對照表、§2.13 對照表、SPEC-004 條目摘要）；(2) UC 文字或 SPEC-001 狀態列措辭早於 SPEC-003／SPEC-004 定案，未回寫。

### 影響範圍

- 已驗證：17 項逐項對 spec 現文（SPEC-001 v1.12、SPEC-003 v1.31、SPEC-004 相關條目、UC-01／02／04／05）核對，矛盾全數仍在；其中 G06、G20、G16a 三項在 SPEC-004 已有一側答案，但 SPEC-003／SPEC-001／UC 端未同步，探針不讀 SPEC-004 故仍需猜。
- 已驗證：V4-04 計數 7 的第 7 項判為 G01（探針初判「spec 未描述」，但其依據即 §2.7 覆蓋清單缺列，與 §2.7 缺漏 A 同一條）。
- 附帶發現（已驗證）：SPEC-003 §2.13〈判準與既有條文的對照〉僅 7 列，`.41` 新增的 5 則 SnackBar 結局未入表，違反 SPEC-003 FR-16(b)。
- W3-335 W2 畫面票解除封鎖依賴第三輪 V4 通過。
