**FD-09a 本意裁定（PM）**
- SKILL.md〈與 orchestration 的協作〉表「既有文件無法回答維度表任一格的產物」的本意是：只要有一格答不出就命中，不要求每格都答不出。
- 依據：examples-process.md 範例驗證段「『任一格』即命中，不要求全部」。
- 這個本意目前只寫在範例裡，條文要改寫成量詞不會讀歪的句子，例如「維度表中至少一格的產物，既有文件答不出」。

**修法方向**（依判定者指出的讀歪結構）
- FD-01b、FD-10b：同一格或同一行內的並列事項、禁止句，拆開並編號。
- FD-05b：「照四種答案填」指明是哪四種；把存在問句改成直接指向答案形態。
- FD-06b：「必須附帶」欄的「無」與答案形態的「無」同字不同義，改用不同字，例如「不需附帶」。
- FD-09b：「其餘」列的反向定義，改成正向寫出條件；「規劃波之後」列補上「該版票已建」的必要條件。
- FD-02a：〈畫布漂移〉補寫「規格也指向 token 名、不複述數值」。這句目前只在 examples.md 引言中，要先查有無既有權威可以路由。
- FD-13a：寫明缺 ticket 系統時降級產物落在哪裡；形態 4 與降級記錄並列之處，拆開寫。
- FD-14b：寫成先後順序的地方，不用「或」並列兩個來源。
