## Task Summary

8.2(2) 第二點「各自旁邊沒有文字標明它代表什麼」與 8.2(4) 第一句「各自旁邊有文字標明語意者不違反 (1)」是同一個條件的正反兩種寫法，差別只在 8.2(4) 另附同時可見的限定。0.1.0-W3-553 的裁決恢復了兩者的可達性，但未消除重合：恢復後仍是第二點單獨即可得出不違反，8.2(4) 第一句不改變任何輸出。UX-Y7a／UX-Y7b 的答案鍵已為此設了容忍條款（只用第二點收尾者判定計通過、記依據不全），等於承認重合存在。本票裁決三件事：(1) 兩者是否應合併為一款，或明寫分工（第二點判有無、8.2(4) 判該文字算不算數）；(2) 合併會不會使兩道凍結題子問 1 的「請逐點寫出 8.2(2) 的兩點分別成立與否」指不到對象，若會則本票的合法終態只能是分工明寫或維持現狀；(3) 8.2(4) 第二句（排除須觸發才出現的文字）在任一方案下皆須保留可達，其唯一實例為 UX-C8t 子問 2
