### PM 裁決：本票的觸發條件已指定為 W3-548 完成，不是模糊的「凍結題退役後」

W3-553 判定案 C（把 8.2(4) 前置為關卡並與第二點合併）**條文結構最乾淨**，但因翻兩道凍結題（UX-Y7a／UX-Y7b 子問 1 逐字要求「逐點寫出兩點分別成立與否」，合併後指不到對象）而否決，改採案 D。

**這裡有一個必須寫明的張力：我們讓量測器材約束了條文設計。** 凍結題是工具不是目的，為了保住工具而選次佳條文，只有在該工具當下不可替代時才成立。現在確實如此——那兩題是 W3-536 案 C 的唯一改檔後驗證 baseline，重出一題等於再走一次「出題→去槓桿→定案 baseline」的完整循環。

但這個理由有明確的到期日。**本票的 trigger 指定為 0.1.0-W3-548 完成**（已掛 relatedTo）：該票是兩道凍結題的最後一次用途，跑完即無保留必要，屆時案 C 與本票的恆冗餘問題應一併重評。

不寫這個 trigger 的後果是：「等凍結題退役」沒有可驗證邊界，而工具會一直有下一個用途，於是案 C 永遠不會被重新評估——條文就這樣長期停在次佳形態，且原因沒有人記得。

### 實驗發現

**已驗證的事實：**

1. 重合只存在於「全部元素皆有標明文字」一格，且該格內 8.2(4) 第一句恆不改變輸出——票面所述的恆冗餘成立，但範圍比票面窄。
