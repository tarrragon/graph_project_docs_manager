# Execution Log

## Task Summary

8.2(3) 清單含「文字內容」，W3-541 增列的界定句 ③ 只寫「指文字寫出來的是哪些字」，未限定為承載語意的那個元素本身的文字；而 8.3(1) 明寫比較對象是畫面上承載語意的所有元素、不限元件邊界。兩者合併的結果：凡是符合 8.2(4) 的相鄰標明文字，同時也構成 8.2(3) 的「文字內容」差異，換色後仍在，第一點恆不成立，依「第一點不成立即結束判定，判不違反，不進第二點」結束——8.2(4) 與 8.2(2) 第二點在所有有標籤的情形下都不會被走到，成為死條文。本票須裁決：文字內容是否限承載語意的元素本身寫出的字，或 8.2(4) 的相鄰文字是否排除於該項之外，並附既有題組誤傷實驗。

## Problem Analysis

### 問題根因

判準檔現行 HEAD 為 `45eab74ef`（第 7 項換軸，W3-536），其前一次變更為 `e8f3bd0e6`／`a0ab92a94`（8.2(3) 增列五款，W3-541）。缺口出在 W3-541 增列的 ③ 與既有的 8.2(4) 之間。

三句在同一條判定路徑上相撞：

1. **8.2(3)③**：「文字內容：指文字寫出來的是哪些字。」——只界定「是哪些字」，未界定「哪個元素寫出的字」。
2. **8.3(1)**：「比較對象是畫面上承載語意的所有元素，不限元件邊界。」——把相鄰的標明文字納入比較對象；該文字既然「標明它代表什麼」，依 8.1(1) 就是使用者用來分辨語意所依據的差異，通過 8.2(3) 引言的對應關係要求。
3. **8.2(2)**：「第一點不成立即結束判定，判不違反，不進第二點。」——一旦有清單內差異剩下，判定在第一點結束。

合併結果：符合 8.2(4) 的相鄰標明文字，同時必然構成 8.2(3)③ 的「文字內容」差異；該差異落在顏色以外那一側（8.2(2)「顏色以外那一側一動不動」），換色後仍在；故第一點必不成立，判定必在第一點結束。

**⑤ 預設值款不但擋不住，還為此背書。** ⑤ 要求歸屬須有「清單的字面，或本款以上的界定句」的直接支持。把「已起藕／待翻塘」這樣的標明文字歸給「文字內容」，同時有清單字面（「文字內容」四字）與界定句（③「指文字寫出來的是哪些字」）兩重直接支持，⑤ 明文放行。反向的收窄主張（限承載語意的元素本身寫出的字）在現行條文中**沒有任何一句可引**——③ 未寫，而同批的 ② 卻寫了「指承載語意的那個元素」，兩款措辭的對比在解釋上反而加強廣義讀法。

## 重現實驗結果
### 實驗方法

本票不跑探針輪次（票面約束：不出題、不跑探針、不改條文）。以兩項可重跑的靜態程序取代：

1. **形式化可達性推導**：列出到達 8.2(4) 與 8.2(2) 第二點所需的全部條件，逐條檢查在其自身適用條件下是否可同時成立。判準是「有沒有一句條文可駁」，不是「讀者會不會這樣讀」。
2. **題材機械掃描**：在 `probes/q/` 全量比對三個字串型態，分出受影響題材與不受影響題材，避免以印象判斷誤傷面。

### 實驗執行

**（一）形式化推導。** 設 L 為「各元素旁邊有一則文字標明它代表什麼，且與所標語意同時可見」（即 8.2(4) 第一句的適用條件）。

到達 8.2(4) 的豁免效果，或到達 8.2(2) 第二點的「不成立」分支，必須全部成立：

| 條件 | 內容 | 在 L 下成立與否 |
| --- | --- | --- |
| C1 | 8.1(2) 未觸發（畫面上確有兩個以上靠視覺差異分辨的語意） | 可成立 |
| C2 | 8.2(2) 第一點**成立**——換色後不剩 8.2(3) 清單內任一項差異 | **必不成立**（見下） |
| C3 | 進入第二點，且第二點不成立（旁邊有文字標明） | 因 C2 失敗而不被走到 |

C2 必不成立的四步，每一步各有一句條文：

1. L 的那則文字兩側寫的字必然不同——若相同即不足以標明兩個不同的語意，L 不成立。
2. 該差異通過 8.2(3) 引言的對應關係要求：引言要求「須是使用者用來分辨這些語意所依據的差異」，而 L 明寫該文字「標明它代表什麼」，對應關係不但成立且是最強的一種。
3. 該差異命中 ③：「文字內容：指文字寫出來的是哪些字。」③ 未限定是哪個元素寫出的字；8.3(1) 明寫「比較對象是畫面上承載語意的所有元素，不限元件邊界」，標明語意的文字即在比較對象內。⑤ 預設值款檢查通過（清單字面與界定句兩重直接支持）。
4. 該差異不隨換色消失：8.2(2)「顏色以外那一側一動不動——換色前是什麼，換色後還是什麼」。

故換色後必剩下清單內的「文字內容」一項，第一點必不成立，依 8.2(2)「第一點不成立即結束判定，判不違反，不進第二點」結束。**L 成立 ⇒ 8.2(4) 第一句與第二點的不成立分支皆不被走到。QED。**

**可達性的精確邊界（本票的修正）**：不可達的是 8.2(4) **第一句**的豁免效果與第二點的**不成立**分支，不是整款 8.2(4)。8.2(4) **第二句**（「須先觸發才出現者（tooltip、長按提示、說明彈窗）不算」）仍可達且仍有決定性作用——觸發型文字不是靜止時的視覺屬性（8.2(3)④ 靜態總則、8.1(1) 的「視覺差異」），③ 不命中，第一點得以成立，此時第二句用來駁回「旁邊有 tooltip 所以第二點不成立」。UX-C8t 的子問 2 即其實例。票面表述「8.2(4) 與 8.2(2) 第二點在所有有標籤的情形下永不被走到」應收窄為此。

第二點本身仍可達，但**只在 L 不成立的分支下被走到，且該分支下它恆為成立**（沒有標明文字）。第二點因此退化為路徑條件下的恆真式，鑑別力為零。

**（二）題材機械掃描。** 於 `probes/q/` 執行三條 grep（全量 130 份題目檔）：

- `[A]` 兩側皆有相鄰標明文字（`標明這一列的圖示代表什麼`）：命中 **2 份**——`W3-417-b18-ux-A1.md`、`W3-417-b19-ux-A1.md`。
- `[B]` 題材明寫畫面上沒有任何文字寫出語意：命中 36 份（涵蓋 b17 全部九份、b15-C2／C3／C4、b15-C1 等）。此類題材 L 不成立，不受本缺口影響。
- `[C]` 含 8.2(4) 但屬否定型子問（`算不算 8.2(4)`）：命中 10 份（UX-C8t 的「45 分」與 UX-C8g 的工項名稱，各批重複）。兩者與語意無對應關係，由 8.2(3) 引言既有的對應關係要求排除，不經 ③ 的射程。

**（三）時序查證。** `git show -s` 取六個 commit 的時間：b18 基準 `38ebb37d`（09:48）、b19 基準 `09012547`（10:13）、W3-541 改文 `a0ab92a94`（11:10）／`e8f3bd0e6`（11:13）、W3-536 改文 `45eab74ef`（判準檔現行 HEAD）。兩份 baseline 皆早於 ③ 落檔。

### 實驗發現

**已驗證的事實：**

1. L 成立時 8.2(4) 第一句與第二點的不成立分支結構上不可達，推導的每一步都有條文句，無一步倚賴自備前提。
2. 現行條文對「標明文字算不算 ③ 的文字內容」給得出的兩答之中，**廣義（算）那一側有依據句與 ⑤ 的背書，狹義（不算）那一側一句可引的都沒有**。兩答並非對稱——這比票面描述的「兩個都有字面支持」更不利。
3. 受影響題材恰為 2 道，皆為凍結題（UX-Y7a、UX-Y7b），且受影響處為同一個逐字相同的子問 1。
4. 兩道凍結題的 baseline 讀數取自 ③ 落檔之前，讀數本身仍有效；不可歸因只發生在改檔後的重跑。

**仍未驗證的假設：** 讀者實際走 ③ 這條路的比率。本票未跑探針，不提供讀數。

## Solution
<!-- Schema[ANA/Solution]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 裁決零（最優先）：UX-Y7b／UX-Y7a 子問 1 的答案鍵在現行條文下不成立

**不成立。** 且不是「兩個都有字面支持」的對稱兩讀——key 記載的那一側在現行條文中一句可引的都沒有。

子問 1 逐字問四件事，兩題完全相同。現行條文（③ 已落檔）下的正解：

| 分項 | key 記載（讀法 A） | 現行條文下的正解 |
| --- | --- | --- |
| 整題是否違反第 8 項 | 不違反 | **不違反（不變）** |
| 8.2(2) 第一點 | 成立 | **不成立** |
| 8.2(2) 第二點 | 不成立 | **不予判定**（第一點不成立即結束判定，不進第二點） |
| 8.2(4) 在本題有沒有作用 | 有作用，直接命中的明文 | **沒有作用**（判定在第一點結束，走不到 8.2(4)） |

依據句（逐字，皆取自現行 HEAD `45eab74ef` 的判準檔）：

- 第一點不成立的四步各有一句：8.2(3) 引言「本清單各項依 8.1(1)，須是使用者用來分辨這些語意所依據的差異」（標明文字正是使用者所依據的差異）→ 8.3(1)「比較對象是畫面上承載語意的所有元素，不限元件邊界」（標明文字在比較對象內）→ 8.2(3)③「文字內容：指文字寫出來的是哪些字」（「已起藕」與「待翻塘」是不同的字，③ 未限定是哪個元素寫出的）→ 8.2(2)「顏色以外那一側一動不動——換色前是什麼，換色後還是什麼」（換色後仍在）。
- 判定結束於此：8.2(2)「第一點不成立即結束判定，判不違反，不進第二點」。
- ⑤ 預設值款不擋反放行：該歸屬同時有清單字面（「文字內容」）與界定句（③）兩重直接支持，⑤ 要求的「直接支持」已滿足。

**反向（key 那一側）在條文中無依據句。** 收窄為「承載語意的元素本身寫出的字」須靠體系解釋（8.2(4) 第一句自述的適用前提「即使換色後沒有剩下 8.2(3) 清單內的任何差異」在廣義讀法下恆空，一個款次不應自述一個恆空的前提），這是解釋論證，不是條文句；而 ⑤ 的門檻只對「主張落在清單內」設限、不對「主張不落在清單內」提供出口。同批的 ② 逐字寫了「指承載語意的那個元素」而 ③ 沒寫，兩款措辭對比在解釋上進一步不利於收窄讀法。

### 裁決一：8.2(4) 的不可達為結構性，且邊界比票面描述窄

形式化推導見〈重現實驗結果〉。結論分三層，逐層精確：

1. **不可達**：8.2(4) **第一句**的豁免效果，與 8.2(2) **第二點的「不成立」分支**。在 8.2(4) 第一句自身的適用條件（各元素旁邊有同時可見的標明文字）下恆不被走到。推導每一步都有條文句，無一步倚賴自備前提。
2. **仍可達**：8.2(4) **第二句**（排除須觸發才出現的文字）。觸發型文字不是靜止時的視覺屬性（8.2(3)④、8.1(1)），③ 不命中，第一點得以成立，第二句此時用來駁回「旁邊有 tooltip 所以第二點不成立」。UX-C8t 子問 2 是其實例。
3. **可達但鑑別力為零**：8.2(2) 第二點本身。它只在「沒有標明文字」的分支下被走到，而該分支下它恆為成立。第二點因此退化為路徑條件下的恆真式。

**票面表述須收窄**：票面寫「8.2(4) 與 8.2(2) 第二點在所有有標籤的情形下永不被走到」。精確說法是上列三層——8.2(4) 不是整款死掉，死的是它的豁免效果；第二點不是走不到，是走到了也沒有分辨力。

**可達實例（票面要求「若可達，給出可達的實例」）**：在**不修改條文**的前提下，8.2(4) 第一句唯一可能被走到的路徑，是主張它不是 8.2(2) 程序內的一步而是獨立的覆蓋款——即使如此，該情形下第一點已先給出「不違反」，8.2(4) 不改變任何輸出，屬恆冗餘而非有作用。**因此無論採哪一種結構讀法，8.2(4) 第一句都不可能改變任一題的判定結果。** 恆冗餘的獨立缺陷已另立 `0.1.0-W3-559`。

### 逐字草案（案 D）

改前，8.2(3) 引言首句：

> 本清單各項依 8.1(1)，須是使用者用來分辨這些語意所依據的差異；與語意無對應關係者不算。

改後（既有句一字未改，其後接續兩句）：

> 本清單各項依 8.1(1)，須是使用者用來分辨這些語意所依據的差異；與語意無對應關係者不算。符合 8.2(4) 的文字——各元素旁邊另有一則文字標明它代表什麼，且與所標語意同時可見——不列入本清單任一項：那則文字是否存在、寫的是哪些字，一律由 8.2(2) 的第二點與 8.2(4) 判，不在第一點內，不使第一點不成立。本句排除的只有元素旁邊的那一則標明文字，元素本身寫出的字（含元件內部的文字）仍依本清單的「文字內容」判；只有一部分元素旁邊有這種文字時，8.2(4) 不成立，本句的排除也不適用。

三句各自承擔一件事，不可刪減任一句：

- 第一句劃出排除範圍，並把該範圍與 8.2(4) 的適用條件逐字綁定（各元素、旁邊、標明它代表什麼、同時可見四項齊備）。
- 第二句指定該文字的去處（第二點與 8.2(4)），使排除不等於落空——這是 ⑤ 預設值款的對稱要求：既然 ⑤ 要求主張落在清單內須有直接支持，排除出清單的東西也須有一個明寫的去處，否則讀者會把它當成「不算數」而非「由別款處理」。
- 第三句守住 ③ 的合法射程（元素本身的字仍算，UX-C8w 的「儲存」「取消」是其實例）並處理單側標明的情形（UX-C8p 丙案）。
