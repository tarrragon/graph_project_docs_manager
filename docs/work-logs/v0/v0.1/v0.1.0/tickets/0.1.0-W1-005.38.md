## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
`AppDataTable`：`Column(header, Expanded(child: 依 variant 選 ListView.builder(itemExtent) 或 ListView))`。`virtual` 用固定 `itemExtent: LayoutSize.rowHeightRelaxed.h` 虛擬化（Ticket 清單）；`plain` 用一般 `ListView`（UC Flow 步驟表）。無自身狀態集，空資料由呼叫端改渲染 `EmptyState`（契約「狀態矩陣」）。`columns` 為明確 slot 欄位（與 `header` 內部攜帶的欄規格一致），供呼叫端與測試直接引用不需反查 `header`。

沿用 `AppTableRow.ticketColumns` / `stepColumns` 既有欄寬 token，未新增 tokens；barrel 只追加一行 export。
