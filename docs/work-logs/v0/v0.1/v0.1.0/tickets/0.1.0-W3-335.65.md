### 逐項評估（WRAP 完整模式）

#### K1（V4R4-02 G08）矩陣圖例存在性與值域

**原文位置**：SPEC-001 §1 正常 · 矩陣顯示欄（無圖例）；SPEC-003 §3.1〈格詳情卡的內容契約〉關係種類列「圖例三值之一…與該格符號一致」；SPEC-004 §3.2 視覺單元盤點 Main 列「底部圖例：● 直接貫穿 ○ 間接依賴 · 無關」、§3.6 §1 正常 · 矩陣列 `Panel`[`MatrixGrid`, `BadgeRow.legend`]；SPEC-001 §1〈矩陣格與泳道列的判定依據〉「traverses 包含即屬該格」。
**現文核對**：兩個子矛盾。(a) 圖例存在性：SPEC-004 畫布與歸屬表皆有，SPEC-001 顯示欄漏——SPEC-001 §1 註記自述顯示欄結構出處為 SPEC-004 §3.2，屬回寫缺漏。(b) 值域：traverses 包含比對只產生「屬／不屬」兩值，`indirect` 無產生式——即 K2。
**選項**：O1 SPEC-001 顯示欄補圖例（改造既有）；O2 SPEC-004 移除矩陣圖例、符號改 tooltip（改造既有，另一端）；O3 反向框架：矩陣不區分關係種類，格只標有／無。
**R 事證**：SPEC-004 §3.6 列與 4.15 `MatrixCell` `indirect` 變體、ARB `legendIndirect` 皆已存在；O2 使格符號無說明（SPEC-003 §2.2 可點性辨識精神）；O3 違反 UC-02 驗收「矩陣的每一格明確區分直接貫穿、間接依賴、無關三種狀態」。
**A**：本項只補 SPEC-001 一格，不預設 K2 結果——即使 K2 定案為 0.1 無 indirect，圖例仍存在。
**裁決**：(a) O1；(b) 併 K2，不裁。
**被放棄選項優點**：O3 使二值判準自洽、無待決依賴。
**選定方案缺點**：K2 定案前圖例列出一個無產生式的值。
**P 失敗訊號**：`W2-001` 實作時無 fixture 能產生 `indirect` 格 → 由 K2 承接票決定 0.1 fixture 是否直接指定關係種類（比照 SPEC-001 §3〈第二跳欄位待決〉「fixture 直接給定」先例）。
**改法**：SPEC-001 §1 正常 · 矩陣顯示欄「+ 右欄格詳情卡區（…）」前補「+ 底部圖例（關係種類：直接貫穿／間接依賴／無關）」。
**同步點**（`grep -rn "圖例" docs/spec/ui/SPEC-001*`）：§1 正常 · 泳道顯示欄「底部圖例」（泳道圖例為 active／inactive，不同值域，不改）。

#### K2（V4R4-02 G09）「間接依賴」判定式

**原文位置**：SPEC-003 §3.1〈格詳情卡的內容契約〉`legendIndirect`；UC-02〈驗收條件〉「矩陣的每一格明確區分直接貫穿、間接依賴、無關三種狀態（「直接貫穿」與「間接依賴」的判定式皆未定義，見 §9）」；`docs/domain-map.md` §2.5「貫穿」定義「經依賴邊間接到達者不列」、§9「`鄰接查詢` 的簽章未定…矩陣的『間接依賴』判定會落在這個 API 上」；CLAUDE.md §6 五項空殼判準之「間接依賴」。
**判定**：依賴 CLAUDE.md §6 現行待決，本票不裁決。綁定票：**無**（全票 `^title: .*定案` 掃描僅 `W3-364`／`W3-365`／`W3-369`／`W3-367` 等，無此項）。
