W3-530 九輪量測證否 W3-524 案一（A3）的未驗證假設：A3-r3 正面主張「朝向差異在換色後仍然存在，屬於 8.2(3) 清單中的『形狀』」並據此判第一點不成立、整題不違反，條文中無一句可駁——8.2(3) 的逐項封閉句只封閉清單成員數、未界定任一項的內涵，8.3(2) 的「換形狀是 8.2(3) 的一種」是充分條件陳述且實測九輪零引用。另有 3 輪把射程列為兩種合法讀法之一、3 輪自補條文沒有的界定（位置指靜止座標）才得以推進，1 輪因無法裁決而停在無結論。須於 8.2(3) 清單句之後增列界定款：形狀（同一圖形的旋轉與擺放方位不算）、位置（隨時間往復移動不算）、文字內容（字形、字重、字距不算），以及靜態總則與「無法判定時視為不在清單內」的預設值款。兩位判定者獨立收斂於同一組建議，且皆指出預設值款單獨即可擋下 A3-r3。

### PM 裁決：A3b 的定案 baseline 為 1/3，引用時必附但書

W3-542 以實驗定案（不是再讀一次原文）：出第三版 A3c 只撤共用名詞「六邊形」、其餘逐字不動，重跑三輪，三項計數與 A3b 逐項相同（正面命中 2、否決 1、以題幹事實作決定性否決 0 輪）。撤走後仍有一輪否決誤指派，且三輪對「六條」「直邊」「形狀相同」「幾何」四詞的使用次數皆為 0——保留的邊數描述完全未被援引。J1 主張的前半（r2 由該名詞起步）成立，後半（撤走即失守）被否證。採 J2，定案 **1/3**。

A2b 的「以自身中心」撤走後仍 3/3、零命中，兩位判定者原本一致的弱訊號判讀獲直接驗證。

**引用本數值時必附但書**：這個 1 不是條文擋下來的。A3 軸三版九輪，**條文零次獨力擋下誤指派**；四次否決全部倚賴讀者自備前提（第一版另有兩輪倚賴題幹事實）；8.3(2) 九輪合計零引用。

本票改文後若得 2/3，對照的 1/3 應讀作「**一輪靠讀者自己補界定而僥倖答對**」，不是「條文已有三分之一效力」。驗收的問句因此不是「通過率有沒有上升」，而是：**否決誤指派的那幾輪，依據句引不引得出本票新增的款次**。引不出來就等於沒改。
