## Problem Analysis
### 問題根因

W3-417〈2.11 與顏色語意的用戶裁示〉P3 記「『顏色不得為唯一區分依據』在 ux 六項判準、color-system、元件契約無障礙欄三處都查無」。逐處查證後，這句話**第三處不成立**：元件契約無障礙欄四處都有這條要求，只是形態為欄位提示而非判準。

真正的缺口是射程缺口，不是條文缺口：規則以「填表時會被問到」的形態存在於元件層，但

1. 沒有判定式——「非視覺替代訊號（顏色不作唯一訊號）」是欄位要填的內容，不是可判不合格的條件；填表者寫「徽章顏色搭配文字標籤」即算填了，沒有任何條文說少了文字標籤就不合格。
2. 只在元件粒度觸發——欄位逐元件填，同一元件的兩個實例用兩種顏色（同一種圓點元件、兩種色）不在任何一格的射程內，而觸發 P3 的 L1 型輸入（色彩圖例）正好長這樣。
3. 觸發時序在後——地基波 UI 維度四塊的順序是 i18n → design-system → UX 審查 → 元件庫（`ux-design-evaluation/SKILL.md`〈與相鄰資產的交界〉version-bootstrap 列「本 skill 是第 3 塊」）。畫面設計在第 3 塊定案，顏色缺口要到第 4 塊填契約時才被問到。

### 實驗發現

- 已驗證：W3-417 P3 的三處查證，**第三處（元件契約無障礙欄）不成立**，該處四個位置都有這條要求。ux 判準層與 color-system 兩處確實查無。
- 已驗證：ux 兩處場景級實例（不可用標示、表單錯誤回饋）存在，但都在 reference 的敘述段而非判準段，M1／M2／M3 皆不在其射程內（M1 的必填標記不是「不可用標示」也不是「錯誤回饋」）。
- 已驗證：元件契約無障礙欄對 M3 型（同一元件兩實例）結構性不可能覆蓋——欄位是逐元件填的，兩個實例共用同一份契約。
- 已驗證：第 7 項（同一圖形）對 M3 會判違反但處置錯配（換圖形 vs 加文字），這與 W3-474.1 已復原的分層一致——第 7 項的來源射程是圖示撞名，不是無障礙。
- 未驗證：新條文的讀者實際判定；落檔後須出探針題。

## Solution
### 一、結論

1. **票面前提須修正一項**：W3-417 P3 記的三處查無，第三處不成立。元件契約無障礙欄在四個位置都寫了「顏色不作唯一訊號」（方法論〈元件契約判準〉無障礙列、`component-contract-design/references/step-3-fill-contract.md` 填寫問句、同 skill 範例、`doc` skill 元件庫規格範本）。ux 判準層與 `color-system.md` 兩處確實查無。
2. **缺的不是條文而是判準**：既有四處是欄位要填的內容，不是可判不合格的條件，且射程限於逐元件填表——同一元件的兩個實例、跨元件的顏色區分、非元件載體（文字色、底色、邊框色）皆不在內。
3. **建議落點：ux-design-evaluation 判準層，新增獨立的第 8 項**，與 W3-474 的第 7 項獨立化同批落檔（W3-478）。元件契約無障礙欄的既有句保留、補一句路由到第 8 項作為判定依據，兩層不重複定義。
4. **`color-system.md` 不是落點，且結構上不該是**：`dart-style-guardian` 是程式碼字面執法工具，本規則的判定需要畫面上的語意對照——同一個 `UIColors.negative` 用在有文字標籤的徽章與無文字的圓點，程式碼字面完全相同。`ux-design-evaluation/SKILL.md`〈與相鄰資產的交界〉dsg 列已寫「它只看程式碼字面，『選中態對比不足』它掃不到」，同一理由適用。
5. **P3（兩個圖形只差顏色算不算同一圖形）的答案是「算」，但這個答案不是顏色規則的落點**，詳見第七節。W3-474.1 草稿 2.11(5) 的後半句建議刪除。

### 三、W：方案（三類涵蓋）

| 方案 | 類別 | 內容 | 需改動的既有字面 |

**方案關聯性**：A 與 F 的判定內容相同，只差條文住址，實質差異只有路由成本；A 與 B 在「兩個圖形只差顏色」時結果相同，只在非圖形載體（文字色、底色、邊框色）與處置句上分開。實質選項數約 4。

**反向思考**：兩個方向都跑過。(1)「這條規則根本不該存在」——不成立，WCAG 1.4.1 是 Level A，本 skill 的參考來源已列 WCAG 2.1 的其他 SC，不是新引進的外部標準。(2)「它本來就不該是判準，只該是欄位要求」——成立且有力，這個方向導出方案 C，並揭露判準與欄位要求不互斥：判準管畫面級審查（發現時判不合格），欄位要求管元件級規格（填寫時被問到），兩者射程不同。結論因此改為「A 為主、既有欄位句保留並路由」，而不是二選一。

- B ← M1：第 7 項的射程由 2.3(3) 界定為圖示與純幾何形狀，必填標籤是文字，完全不在內。把顏色規則掛在「同一圖形」之下，等於宣告只有圖形載體受此要求，而 WCAG 1.4.1 的原文對象是「視覺元素」不限圖形。B 還有第二個問題：它為了讓「加文字標籤」這個處置能通過第 7 項，必須寫「每色旁有文字時算不同圖形」，把文字混進「圖形」的身分判定，與 2.3(3) 純以形狀界定圖形的架構衝突。
- C ← M3：元件契約無障礙欄填一次，填的是「進度條這個元件」，不是「畫面上這兩條」。同一元件的兩個實例用兩種顏色，結構上不可能被逐元件的欄位覆蓋——這不是條文寫得不夠，是粒度不對。C 另有時序問題：UX 審查是地基波第 3 塊、元件庫是第 4 塊，畫面設計定案時此欄尚未填。

8. 顏色不作為唯一區分依據（子項見 8.1～8.5）

### 8.1 前提

- (1) 本項的「區分」指使用者要分辨兩個以上不同語意時所依據的視覺差異。「語意」指該元素代表的事物、狀態或類別。
- (2) 畫面上不存在兩個以上靠視覺差異分辨的語意時，本項不適用。「不適用」只用於整項。
- (3) 本項不限載體：圖示、純幾何形狀、文字顏色、底色、邊框色、線條顏色皆在射程內。

### 8.2 判定

- (1) 兩個以上語意之間，使用者可依據的視覺差異只有顏色時，違反本項。
- (2) 「只有顏色」依序判兩點，兩點都成立才算：把畫面轉為灰階後，這些語意的呈現無法區分；且各自旁邊沒有文字標明它代表什麼。無法實際轉灰階時，改問「把這些元素的顏色全換成同一個顏色後，還分得出哪個是哪個嗎」。
- (3) 灰階後仍可區分者不違反 (1)。可區分的差異有：形狀、大小、位置、圖示、存在與否、填滿與否、線條樣式、文字內容。
- (4) 各自旁邊有文字標明語意者不違反 (1)，即使灰階後不可區分。該文字須與所標語意同時可見；須先觸發才出現者（tooltip、長按提示、說明彈窗）不算。
- (5) 顏色搭配其他差異時不違反 (1)：顏色可以承載語意，本項要求的是它不獨自承載。

### 8.3 射程與交界

- (1) 比較對象是畫面上承載語意的所有元素，不限元件邊界。同一個元件的兩個實例分別用兩種顏色代表兩個語意，也在射程內。
- (2) 本項與第 7 項各自判定。第 7 項治同一圖形承載兩個語意，本項治兩個語意只靠顏色區分；同一組元素兩項都命中時記一項缺口，以本項為準——本項的處置涵蓋第 7 項的處置（換形狀是 8.2(3) 的一種），反之不成立。
- (3) 底色與文字色的成對設計與 WCAG AA 比值屬第 3 項，不在本項。第 3 項問顏色看不看得見，本項問顏色以外還有沒有訊號，兩項對同一組顏色可以一過一不過。
- (4) 可點性的判定屬第 2 項。2.7 已規定底色深淺不作為可點性的比較依據，本項不改變該條。

### 8.4 處置

違反 8.2(1) 時，為每個語意補一項 8.2(3) 所列的差異，或補一則符合 8.2(4) 的文字。**改變顏色本身不構成處置**——換成對比更強的色相、拉開明度差、改用色盲友善色票，都仍是「只有顏色」。

### 8.5 例示

- (1) 表單畫面：必填欄位的標籤以橘色顯示、選填欄位的標籤以一般文字色顯示，兩者旁邊都沒有星號或「必填」字樣。違反 8.2(1)：灰階後兩種標籤只剩明度差而無法區分，且旁邊沒有文字標明（8.2(2) 兩點皆成立）。處置是為必填欄位補星號或「必填」字樣。
- (2) 同一份表單改為必填欄位標籤後加一個橘色星號、選填欄位無星號。不違反：使用者區分兩類欄位所依據的差異是星號的存在與否，屬 8.2(3) 的「存在與否」，灰階後仍可區分。**星號本身是橘色不構成違反**——8.2(1) 問的是使用者可依據的差異是不是只有顏色，此處的差異不是顏色。

### 七、P3 結論：兩個圖形只差顏色時，算不算同一圖形

**算同一圖形。** 逐詞推導：第 7 項「同一圖形」的範圍由 2.3(3) 界定，該條列舉的是形狀類別——「純幾何形狀只有以下幾類：點、直線或直條、圓環、內部不含文字或圖示的純色圓形或方形。其他圖形一律算圖示，含勾號、箭頭、三角形」。全句以形狀界定，無一項以顏色界定；「純色圓形」這個類別名稱本身已把顏色抽掉，紅圓點與藍圓點同屬此類。因此**不需要新增子句**，現行 2.3(3) 已足以推出此答案。

**但這個答案不解決 P3 真正在問的事。** 第 7 項違反的處置是「更換其中一方的圖形」。對色彩圖例而言，換形狀（紅圓與藍方）確實可行，但 WCAG 1.4.1 要的不是換形狀本身，而是顏色以外另有訊號——加文字標籤是另一條同樣有效的處置，第 7 項推不出它。所以顏色的無障礙要求不該掛在第 7 項之下，應為獨立的第 8 項。

**對 W3-474.1 草稿 2.11(5) 的具體建議**：

| 「只差顏色的圖形算同一圖形」 | 刪除。改在第 7 項的例示或理由段加一句「圖形身分只看形狀，顏色不在 2.3(3) 的界定內」作為釐清，不作為新判定 | 已可由 2.3(3) 逐詞推出，寫成子句是複述而非新規則；複述會產生兩處字面，日後 2.3(3) 若增修形狀類別，此處會漏跟 |
