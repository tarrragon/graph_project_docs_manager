## Problem Analysis
### 問題根因

W3-417〈2.11 與顏色語意的用戶裁示〉P3 記「『顏色不得為唯一區分依據』在 ux 六項判準、color-system、元件契約無障礙欄三處都查無」。逐處查證後，這句話**第三處不成立**：元件契約無障礙欄四處都有這條要求，只是形態為欄位提示而非判準。

真正的缺口是射程缺口，不是條文缺口：規則以「填表時會被問到」的形態存在於元件層，但

1. 沒有判定式——「非視覺替代訊號（顏色不作唯一訊號）」是欄位要填的內容，不是可判不合格的條件；填表者寫「徽章顏色搭配文字標籤」即算填了，沒有任何條文說少了文字標籤就不合格。
2. 只在元件粒度觸發——欄位逐元件填，同一元件的兩個實例用兩種顏色（同一種圓點元件、兩種色）不在任何一格的射程內，而觸發 P3 的 L1 型輸入（色彩圖例）正好長這樣。
3. 觸發時序在後——地基波 UI 維度四塊的順序是 i18n → design-system → UX 審查 → 元件庫（`ux-design-evaluation/SKILL.md`〈與相鄰資產的交界〉version-bootstrap 列「本 skill 是第 3 塊」）。畫面設計在第 3 塊定案，顏色缺口要到第 4 塊填契約時才被問到。
