## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因

SwimlaneGrid 泳道名格（_buildLaneCell column 0）只有 Semantics(label:) 包裹，非可點元件；SwimlaneLane 亦無 domainId 欄位，無從得知該列對應哪個 domain。MatrixGrid 已有 onSelectDomain 慣例（_DomainHeaderCell 以 InkWell + Semantics(button:true) 包裝，key 為 action-domain-select-<domainId>）。

### 影響範圍

lib/components/swimlane_grid.dart（新增 SwimlaneLane.domainId、SwimlaneGrid.onSelectDomain、_buildLaneCell 分支）；test/unit/components/swimlane_grid_test.dart（新增對照組測試）。

### 範圍邊界（NeedsContext）

派發 prompt 明確限定「只改 lib/components/ 與 test/unit/components/，不動 lib/screens/、不動 lib/app/」。acceptance 3（Domain 視圖泳道模式下點擊列首可設定選中 domain）需修改 lib/screens/domain_view/domain_view_screen.dart 才能落地，超出本票檔案範圍，已依 quality-baseline 規則 5 建立衍生票 0.1.0-W4-001（source_ticket=0.1.0-W1-075）承接畫面層接線，spawn request SR-1 已 resolve 為 processed。acceptance 1、2 已在元件層完整驗證並勾選；acceptance 3 保留未勾選，待 0.1.0-W4-001 完成。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### 修改內容

lib/components/swimlane_grid.dart：
- SwimlaneLane 新增 `final String? domainId`（預設 null，既有呼叫點不受影響）
- SwimlaneGrid 新增 `final ValueChanged<String>? onSelectDomain`（預設 null）
- _buildLaneCell column 0 分支：`domainId == null || onSelectDomain == null` 時維持原本唯讀 Semantics(label:)；否則包 InkWell + Semantics(key: 'action-domain-select-<domainId>', button: true, excludeSemantics: true)，onTap 呼叫 onSelectDomain(domainId)。點擊區域（Padding + Align + AppText，Space.sm 內距）與 MatrixGrid._DomainHeaderCell 一致，兩模式共用同一「選 domain」互動尺寸與焦點行為

test/unit/components/swimlane_grid_test.dart：新增「onSelectDomain」group 三個測試（不傳時無 button 語意/無 InkWell 對照組；傳入時 button 語意 + 點擊觸發回呼傳出 domainId；domainId 為 null 時即使傳 onSelectDomain 仍維持唯讀），符合 test-assertion-design 規則 E1（傳與不傳對照）
