### Task Reference
- 0.1.0-W3-531 what: b15 判定者 j1 新發現的條文風險：7.2(3) 只就描邊與實心給出變體同一性（描邊與實心變體算同一圖形），對「兩個圖形顏色不同算不算同一圖形」未置一詞。UX-M3 的 r2、r3 兩輪都在第 (3) 欄把這一點登記為條文未明文處，並各自由描邊／實心那一句自行類推補位。兩輪皆指出即使採相反讀法本題子問 4 結論不變，故 b15 未失分、判定值不受影響；但該類推是讀者側供給的，換一題即可能翻面。須評估應否裁決，以及裁決的形態（補一句 vs 換軸），並附對既有題組的誤傷實驗。

### Rationale Chain
- 0.1.0-W3-531 why: 第 7 項治同一圖形承載多個語意，「是不是同一圖形」是該項的入口前提。顏色是圖形最常見的變體維度之一，而第 8 項又明文把顏色排除在可區分差異之外——兩項對顏色的處置若不一致，讀者在第 7 項的入口就得自行裁決。b15 的兩輪自行類推是讀者側供給的證據，不是條文效力。
