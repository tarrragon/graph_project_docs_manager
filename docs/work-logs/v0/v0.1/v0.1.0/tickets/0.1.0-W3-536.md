r1 對兩端的正規化是**不對稱**的：一端寫「鴉青色的**橢圓**圖示」（「橢圓」是題幹沒有的類名，r1 自補），另一端寫「緗色的**上下弧線**圖示」。兩者都是「畫的是什麼」、都不是「它代表的意思」——**案 C ① 現行措辭全部通過，而比對必然得出不同**。一個寫到類名層級、一個停在組成部件層級，兩端不在同一描述層級時，②「寫出的不同即是兩個圖形」這條封閉句就會把描述層級差異當成圖形差異。

### 一、三段改動逐字（改前 → 改後）

#### 第一段：7.2(3) 收斂（移除單獨的變體宣告句）

改前：`「語意」指圖形代表的事物或動作，不含可點與否：同一圖形只差可點與否、代表的事物相同時，不違反 (1)。描邊與實心變體算同一圖形。語意不同指的是所指的事物或動作本身不同（例如「篩選」與「匯出檔案」）。`

改後：`「語意」指圖形代表的事物或動作，不含可點與否：同一圖形只差可點與否、代表的事物相同時，不違反 (1)。語意不同指的是所指的事物或動作本身不同（例如「篩選」與「匯出檔案」）。`

該句逐字移入 (3-2)②，前綴「例如：」，降為全稱封閉句的例示。**保留 byte-exact 是刻意的**——七份凍結答案鍵引的是單句短引文 `⟪描邊與實心變體算同一圖形。⟫`，改寫一字即全部失效（誤傷復驗見第三節）。

#### 第二段：新增 7.2(3-2)（改前無此款）

```
- (3-2) (1) 與 (2) 所稱的「同一圖形」與「兩個圖形」，一律依本款判定，不得以其他方式認定：判 (1) 時，先依本款判畫面上的圖形兩兩是不是同一個，判為同一個的才依 (5) 往下判語意。兩個圖形是不是同一個，依下列兩步判，不得跳步：
  - ① 兩端各自寫出它畫的是什麼，且兩端用同一種寫法。可用的寫法只有下列甲、乙兩種。**只寫畫的是什麼，不得寫它代表的意思**——寫成「篩選圖示」不算完成本步，須寫「漏斗」；依畫面上看到的線條寫，不得由它旁邊的文字或它代表的語意反推。顏色、大小、粗細、比例、朝向、填滿與否、描邊或實心都不是「畫的是什麼」，不寫進這兩句；寫進去了也不列入 ② 的比對。**兩端都寫得出甲才可以用甲；下列任一情形，兩端一律改用乙重寫**，不得拿寫法不同或用詞不同的兩句去比對：(a) 受評的畫面或材料本身沒有指出它畫的是什麼，讀者是為了比對才自行替它歸類出一個名稱（例如把一條封閉曲線叫「橢圓」）；(b) 一端寫出的是指稱整體的名詞，另一端寫出的是線、弧、角、筆畫這類輪廓的組成部分；(c) 兩端寫出的名詞不同，而指不出這兩個名詞在輪廓上的具體差別。
    - 甲、整體名稱：用一個名詞指稱整個圖形——圖示寫它畫的是什麼（例如「漏斗」「音符」），純幾何形狀寫 2.3(3) 的類名。
    - 乙、輪廓走法：不指稱整體，改逐項寫出輪廓本身——由哪幾條線構成（幾條、直的還是彎的、往輪廓的內側還是外側彎）、這些線在哪裡相接、相接處是不是角、有幾個角、閉不閉合、輪廓之內還有沒有別的線。
  - ② 兩端寫出的不同，即是兩個圖形，到此為止；相同，即是同一圖形。用乙寫時，逐項比對乙所列的各項：同一項的內容相同而只是用字不同（例如「三條直線」與「三段直線」），不算不同；內容本身不同，即是不同。乙所列之外的敘述，即使寫了也不列入比對。① 兩句以外的任何差別，皆不使兩者成為兩個圖形，顏色不同、粗細與大小不同都在此列。例如：描邊與實心變體算同一圖形。
```

與 W3-531 草案的差異（PM 裁決要求不得照抄，逐項列出新增的五道防線）：

| # | 新增內容 | 來源讀數 |
| --- | --- | --- |
| 1 | 首句的入口強制：所稱「同一圖形」一律依本款判定，且明寫先判同一性再判語意 | W3-546 三輪**沒有一輪提出**「這兩枚是不是同一個圖形」這個命題；草案的「依下列兩步判」是條件句，讀者不問就不觸發 |
| 2 | 兩端同一種寫法（甲／乙二選一）＋三個改用乙的觸發情形 | r1 一端寫類名、一端寫零件，草案 ① 全部放行而比對必然得出不同 |

#### 第三段：新增 8.3(5)（改前無此款）

```
- (5) 同一個外觀屬性在兩項可以有相反的判定結果，這不是矛盾，各依自己的款次判：填滿與否在 8.2(3) 是使用者可依據的差異，描邊與實心在 7.2(3-2)② 不使兩者成為兩個圖形。本款不使「這兩者是不是同一個圖形」有兩個答案——這個問題只由 7.2(3-2) 回答，本項不判它。兩套判定互不援引——第 7 項判出的「同一圖形」或「兩個圖形」，不作為 8.2(2) 第一點成立與否的理由；8.2(2) 第一點的換色比對與 8.2(3) 的清單，也不作為兩個圖形是不是同一個的理由。要判 8.2(2) 的第一點，依 8.2(2) 與 8.2(3)；要判兩個圖形是不是同一個，依 7.2(3-2)。
```

措辭用「屬性」而非「維度」、「判定結果」而非「處置」：本檔「處置」是 7.3 與 8.4 的專名（指修正動作），此款講的是判定待遇；「視覺屬性」是 8.2(3)④ 既有用語。實質與票面 acceptance 第 3 項相同。

### 四、與 8.2(3) 的射程邊界（PM 強制約束 ③）

W3-541 剛在 8.2(3) 加的射程限制句是**單向**保守切斷（界定句不改變第 7 項對「同一圖形」的判定）。本票的 7.2(3-2) 與 8.2(2) 第一點確實產生交互——兩者都可被讀成「圖形同一性程序」——**本票選擇明確處理而非略過**，處理方式是在 8.3(5) 寫成**雙向**互不援引，並指名各自的權威款次。

三項理由：(1) W3-546 的 r2 在同一份作答內用 8.2(2) 的換色比對得出「形狀相同」、又在子問 2 當成兩個圖形處理且零自覺，這是已量到的實際混用，不是假想；(2) 雙向切斷與 W3-541 的單向切斷同方向，不推翻該票的定案；(3) 不作統一裁決——8.2(3)① 的「轉一轉、翻一翻能重合」是一套獨立可操作的同一性測試，它與 7.2(3-2) 該不該收斂為一套，是 `0.1.0-W3-547` 的標的，本票只確立現階段的互不援引，不預判該票結論。

**對 W3-547 的影響須由該票承辦者知悉**：該票建票時的爭點是「兩套程序並存、方向可相反、條文無交互指引」；本票落地後第三項已不成立（8.3(5) 即指引），該票標的應收窄為「這套指引夠不夠、兩套該不該收斂為一套」。此外本票的對抗審查另指出 8.2(3)① 的定義句「形狀：指這個元素是哪一個圖形」與第 7 項的「同一圖形」字面同謂詞，是該票可直接取用的輸入。
