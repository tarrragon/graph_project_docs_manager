### 問題框架重定義（三層質疑 Level 2）

表頭宣告的軸是「距離的兩端各是什麼」，但五列實際落在的軸是「**兩端與哪個契約主體的歸屬關係**」：

| 列 | 歸屬關係 |
|---|---|
| 第二列 | 兩端同屬本元件（內容對自身邊界） |
| 第三列 | 一端本元件、一端所屬容器 |
| 第四列 | 兩端同屬本元件內部 |
| 第五列 | 兩端不同屬任何已知主體 |
| 第一列 | （應為）兩端同屬某一容器，各為其子件 |

第一列是唯一一格用「型別」而非「歸屬關係」描述兩端者，脫軸點僅此一處。此框架把修法收斂到單一格，不需改表結構——這是主案與另兩個候選方向分歧的依據。

### 三層質疑 Level 3（此問題在什麼條件下不發生）

b8／b10／b11 三批 19c 皆 3/3（j1）。b12／b13 的共同條件是同批他題全部來自另一份節錄檔（doc 範本內容角色題），19c 為批中唯一的方法論題。此孤立性是未控制變數（j2 已列為候選），但它解釋不了失分形態為何穩定落在「引第一列」這一種——形態的跨批穩定性仍指向條文。
