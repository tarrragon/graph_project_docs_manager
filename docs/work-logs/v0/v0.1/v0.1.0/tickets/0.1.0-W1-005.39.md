### 實作方式

`MatrixGrid`（容器，`lib/components/matrix_grid.dart`）依 SPEC-004 4.37 十一欄位契約實作：

- 二維捲動委派 `two_dimensional_scrollables` 的 `TableView.builder`（`pinnedRowCount: 1` 釘欄首列、`pinnedColumnCount: 1` 釘列首欄），子件皆為既有元件（`TableColumnHeader.twoLine`、`MatrixCell`、`AppText`），無新建子件。
- 尺寸契約：列首欄 `LayoutSize.matrixLeadColumnWidth`、UC 欄 `LayoutSize.matrixColumnWidth`（122，已核定）、小計欄 `LayoutSize.matrixSubtotalWidth`，欄首列高為 `rowHeightRelaxed × 2`（twoLine 兩行），資料列以 `rowHeightRelaxed + Space.xxs` 作列間最小間距（內容頂對齊裝入 `rowHeightRelaxed` 固定高，餘量落在列底形成間距）。
- 狀態：`selectedDomainId` 對應列以 `surfaceIconTint` 底 + `Radius.md` 圓角高亮；`Esc`（`selectedCell` 非 `null` 時）經 `Focus(autofocus: true)` 攔截呼叫 `onClearSelection`。
- 列首格由容器包成可點（`Semantics(button:true) + InkWell`，key `action-domain-select-<domainId>`），非獨立元件，符合 slot 契約「列首格由本容器包成可點」。
- 新增 `MatrixRow` 資料類別（`domainId` / `domainName` / `cells` / `subtotal`），slot 契約要求的資料結構，票內未見既有定義故新建。

`lib/tokens/layout.dart`：依步驟 4 移除 `matrixColumnWidth` dartdoc 與摘要表列的「待 PM 核定」字樣，改記 PM 已於 2026-09-02 核定（SPEC-004 §3.7 第 24 項）；122 值與推算依據段落（Main 版面尺寸鏈反推）原樣保留。此為契約明文授權的唯一 tokens 改動，未動其他條目或其他 token。

`lib/components/components.dart`：新增 `export 'matrix_grid.dart';` 一行，插入於既有 `matrix_cell.dart` 之後、`missing_source_state.dart` 之前（字母序），未重排既有行。

契約值皆可直接引用（`matrixColumnWidth` 122 已於 W1-055 定案並經本票核定字樣移除），未發現契約不成立之處，SPEC-004 4.37 / 5.11 未變動。
