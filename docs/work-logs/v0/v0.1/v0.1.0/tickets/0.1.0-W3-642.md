## Task Summary

分析 acceptance 項的射程超出票的範圍邊界時執行者仍勾滿的重複模式，定出可偵測的判準

---

## Problem Analysis
### 問題根因

acceptance 項的射程跨層（元件層加畫面層）但票的範圍邊界只涵蓋一層時，執行者在自身範圍內做完後勾滿全部 acceptance——勾滿與真的達成在票面同形。根因不是欺瞞，而是 acceptance 撰寫時未將跨層射程拆到對應層的票。

### 影響範圍

本版 165 張已完成 IMP 票中，含跨層語意的 acceptance 項共 8 項（分佈於 8 張票）。

漂移項：2 項（W2-001 AC2、W1-074 AC3）。漂移率：2/8 = 25%。以票為單位：2/165 = 1.2%。
正確反例：1 項（W1-075 AC3，PM 收窄射程後正確收尾）。
正常項：5 項（W2-003 至 W2-007，畫面層票，退出路徑在自身範圍內）。

漂移只發生在元件層票承載了畫面層才能驗證的 acceptance。

### 相關 Error Pattern

無已知 error-pattern 直接對應。最接近的是 PC-055（AC 漂移偵測），但不涵蓋 AC 撰寫時射程超出票範圍邊界的形態。

範圍驗證方法：rg regex 法，六個跨層語意 pattern 掃描 165 張已完成 IMP 票的 acceptance 欄位。
已知盲區：跨層語意可能以其他措辭表達，但本版 AC 撰寫風格高度一致（均由同一 PM 撰寫），六個 pattern 覆蓋主要句型。
