## Problem Analysis
### 問題根因

`0.1.0-W3-620` 是出題規格 1.2.0 的首次執行，四項新條文中的「依據句欄須為極小集合」暴露自己的邊界：
遮蔽 span 錨在句粒度（推出本題正解所必需的那幾句），而改動以條為單位。C1 是含多句的一條改動，
只有兩句進入依據句欄，其餘句——特別是「本款的結論只有三種，互斥且窮盡，不得由排除其中一種逕行
認定另一種」——依硬性要求 1 不得列入，因而不被遮，落入「其餘條文」。判定者甲遮掉登載的 span 後
正是靠這一句推得與正解實質相同的結論，1.7 判同向紅，C1 零覆蓋、覆蓋比 0/1、Step 3 下界觸發。
C1 其實有鑑別力：判定者甲的推導要靠 C1 自己的另一句才成立。

另三項：零覆蓋回報欄由兩名判定者填寫而遮蔽推導只由其中一名執行（L29）；1.7 雙向對帳表把同向紅
單一歸因為「無新增內容」，對 C1 這種有新增內容的情形只能改標（丙），而那正是該表第二列自己禁止
的後果；C1 寫入的禁令句在同一輪的遮蔽推導下實測零效力，兩名判定者各自走的正是被它禁止的那條路。

### 影響範圍

- `docs/probes/probe-authoring-spec.md`（1.2.0 至 1.3.0）：1.7 遮蔽 span 標定、同向紅成因分辨、
  判定者 brief 必備項、Step 1 改動類別與 §7 第 21a／21e／24 項。
- `docs/probes/probe-known-limitations.md`（1.7.0 至 1.8.0）：新增 L30／L31／L32。
- `.claude/skills/ux-design-evaluation/references/interaction-feedback-component-semantics.md`
  的 7.2(3-2)②：刪除禁令句一句（本輪唯一的條文層改動 C1'）。

**已驗證的事實**：新標定下 C1 回測由同向紅改為第三格綠；同一標定對 L25 型（D2）仍判同向紅；
本輪 Q01 三輪 3/3、兩名判定者零分歧、1.7 兩側皆判綠。
**仍未驗證的假設**：L30 所述「拆條後各條互為其餘條文」本輪零觀測（C1' 未橫跨款次），依 L4
不得記為「沒發生」。
