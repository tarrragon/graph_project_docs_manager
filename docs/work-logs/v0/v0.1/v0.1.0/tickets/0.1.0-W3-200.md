### 三實例的正例／反例對照（本票的實質內容，升級時直接取用）

| 實例 | 正例套用會攔下嗎 | 反例套用會攔下嗎 |
|------|----------------|----------------|
| 判準句缺前提 | 否——拿一個真的誤用去套，它判對 | **會**——拿一個完全正確的引用去套，它也判「屬實 → 是本骨架」，當場矛盾 |
| 以排序輸出的前十列當母體樣本 | 否——那十列確實都屬同一前綴 | **會**——問「母體若不是這個組成，這個樣本會長得不一樣嗎？」答否即知零鑑別力 |
| 正確結論配錯誤的機制解釋 | 否——結論對，正向驗證通過 | **會**——問「若這個機制不成立，結論會變嗎？」答否即知理由未承重 |

**共通結構**：正例只能確認判準「不會誤殺」，反例才能檢驗它「有沒有在區分東西」。一個恆為真的判準通過全部正例，且看起來運作良好。
