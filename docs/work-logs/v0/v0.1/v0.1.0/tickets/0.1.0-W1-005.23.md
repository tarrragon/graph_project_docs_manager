### 實作摘要

新增 `lib/components/document_body.dart`：`DocumentBody` 為 StatelessWidget，
單一 slot `markdown: String`（必填）+ `testKey`。內部以 `flutter_markdown_plus`
的 `MarkdownBody`（`shrinkWrap: true`，不建立自身捲動容器，捲動交由所在
`Panel.scrollable` 承載）渲染，`selectable: false`，不接 `onTapLink`（連結依
契約渲染為一般文字）。樣式全部經自建 `MarkdownStyleSheet` 映射 token
（`AppColors.textPrimary`/`textTitle`/`surfaceChip`/`border`、
`AppFontSize.body`/`subtitle`/`title`、`Space.xs`/`sm`/`md`、`Radius.md`），
無裸值；`code` 樣式的等寬字族取自 `DefaultTextStyle.of(context).style.fontFamily`
（沿用 App 主題設定，非硬編碼字族名）。`components.dart` barrel 追加一行
export（`divider.dart` 與 `expander_icon.dart` 之間，依字母序）。

程式碼區塊與表格的水平捲動由 `flutter_markdown_plus` package 內建
（`builder.dart` 對兩者皆包 `SingleChildScrollView(scrollDirection: Axis.horizontal)`），
未額外實作。

### 測試

引用區塊、清單、程式碼區塊、表格、連結）；兩種視窗尺寸不溢位；

連結無 `InkWell`；`MarkdownStyleSheet` 各欄位斷言引用 token 常數而非
硬編碼字面值。
