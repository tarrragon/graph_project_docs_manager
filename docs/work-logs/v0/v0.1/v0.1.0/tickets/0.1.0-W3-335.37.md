## Problem Analysis
### 問題根因

W3-335.36 歸因出 20 項 spec 間矛盾，其中 12 項（.36 矛盾清單 #2、#3、#5、#9、#10、#11、#13、#16、#17、#18、#19、#20）標為需裁決。成因分四型：

| 上游文件未隨規格收斂 | UC 描述先於規格，規格定案後 UC 未改 | #16、#19 |
| 冗餘被誤讀為矛盾 | 兩處皆顯示同一資料，實為重複而非衝突 | #9 |
