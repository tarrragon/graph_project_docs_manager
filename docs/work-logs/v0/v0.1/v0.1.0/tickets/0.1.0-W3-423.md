#### E-11 狀態矩陣同步策略欄

**既有權威**：範本第 2 章與方法論〈L2 狀態綁定判準〉「樂觀更新政策」——低風險且可逆（AND）才**允許**樂觀；高風險或不可逆預設等確認。此條只定「可不可以」，不定「某狀態實際採哪一種」。範例的判定依據是 SPEC 描述的顯示時點（先顯示成功再回滾 vs 過程維持 loading），不是政策。
**草稿缺陷**：草稿把「樂觀更新後確認」定義為「符合政策條件的操作觸發之狀態」，會把「允許樂觀但設計為等確認」的狀態誤判；且「本地即時」與另兩項的邊界用「是否涉及伺服器」而另兩項用政策，判準軸不一致，互斥性無從由定義推得。
