**N2r 矛盾推理在新寫法下是否確實不可能寫出（逐步說明）**：

1. 舊寫法：2.8(1) 先定義「動作列」成立條件（(i)／(ii) 任一成立），並在附屬子句補一句「確認來源(ii)不成立不代表來源(i)也不成立」。讀者可以先評估②（頂端列本身按空白處無反應→②不成立），因主線論述在定義「動作列」而非強制依序檢查，讀者可能就地下「不是動作列」的結論而略過①的獨立檢查；即使記得查①，舊文也沒有把(b)值直接寫出，讀者仍須自行完成「不是動作列→依 2.1(2)→屬(b)」的跨款外部連結，r1/r3 正是在這一步把方向寫反成「不屬(b)」。
2. 新寫法：①被列為執行順序的第一格，字面就是「確認指示所在的列上有沒有任何可點元素」——對 N2r 頂端列而言，這一格的答案是可直接讀出的事實（同列有「全部歸還」按鈕），且因為它是第一步而非附屬子句，读者在動筆之前就必須先處理这一眼可見的事實，原先「跳過①、只看②」的路徑被拿掉。
3. ③ 不再要求讀者自行做「不是動作列→屬(b)」的跨款轉換，而是直接列出兩個方向的(b)值（「任一來源成立→不屬(b)；兩來源皆不成立→屬(b)」）。r1/r3 的錯誤是在這個轉換上把方向寫反；新寫法把轉換結果直接寫出，讀者只需代入①②的是非值讀表，沒有自行推導、也就沒有可反向的推導步驟。
4. 兩點合併：①的事實誤讀（因為被前置為必答的第一步而更難迴避）與③的方向誤推（因為結論已直接給出、無需自行轉換）是 r1/r3 錯誤成立的兩個必要條件，新寫法同時拆除兩者，故該矛盾推理在新寫法下不可能以同一形式再現。
