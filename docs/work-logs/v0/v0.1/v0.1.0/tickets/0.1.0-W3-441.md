草稿判準（供 WRAP／PM 裁定，非用戶程式碼風格偏好，不上呈用戶）：可選擇不記錄日誌，須同時滿足三項——(a) 無副作用：純讀取，不修改任何持久狀態；(b) 該結果本身是合法業務狀態，不代表系統異常（如快取 miss 本就是正常路徑）；(c) 呼叫端已有其他機制處理該結果（如回退到來源讀取）。CRUD 寫入操作、任何會導致資料遺失或使用者無法察覺的失敗，不適用本例外，仍須依規則 1 記錄 warning 日誌。
