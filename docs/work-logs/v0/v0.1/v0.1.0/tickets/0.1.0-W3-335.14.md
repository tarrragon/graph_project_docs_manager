### 分析結論

SPEC-004 §3.7 核定記錄 25 條的上游出處稽核完成，同時交叉比對三份走查票的全部 SPEC-004 相關猜測點。

| 出處類型 | 條號 | 數量 |

#### 三、無上游出處清單（交 SPEC 回寫票吸收）

**需回寫 SPEC-001**：
- §4 顯示欄：補列篩選維度（status, priority）、可排序欄位（ID, 標題, 狀態, 優先）、票列欄位組成（ID / 標題 / 狀態文字 / 優先 / 損壞標記）
- §2 顯示欄：補列 UC 基本資訊欄位、步驟表欄位
- §5 顯示欄：補掃描範圍說明的內容結構

**需回寫 SPEC-003**：
- §3.4 篩選/排序列：補列具體 key 清單（filter: status, priority；sort: id, title, status, priority）

**需補入 SPEC-004**：
- §4.0.6 i18n key 表：補「未偵測到破洞」key（S09）

**§3.7 純自我核定的 9 條**（#4,#6,#8,#11,#12,#13,#14,#18,#20）：
這些決策的理由欄自身合理，但缺乏上游追溯——建議在 SPEC 回寫票中為其補充「依據來源」欄（畫布截圖引用或設計原則引用），使後續讀者可驗證而非只信撰寫者判斷。本票不建議改變這些決策本身。

#### 候選方案

**方案 A（建議）**：上述清單全部併入既有的 R06（SPEC-001/003 衛生回寫票 = 0.1.0-W3-335.9），S09 i18n key 併入 R09（SPEC-004 i18n key 補齊 = 0.1.0-W3-335.10）。不另建票。

**方案 B**：§3.7 的 9 條純自我核定另建一張 DOC 票逐條補出處標註。

方案 A 較佳：清單已在本票明確列出，SPEC 回寫票可直接消費；補出處標註的工作量小、不值得獨立票。
