## Problem Analysis
### 問題根因

`0.1.0-W3-619` 以規格 1.2.0 的新界定回測 `0.1.0-W3-618` 的 R2-Q03，判讀由綠翻為反向紅：

不涵蓋整項漏寫。依 1.7 的反向紅判讀，處置是回 Step 1 改條文。

### 實驗發現

**已驗證的事實**：

1. **反向路徑已關閉**。以 R2-Q03 的題材（一端整項漏寫）遮 ①乙 窮盡句重跑遮蔽推導：改文前推得
   「兩個圖形」（與正解牴觸，反向紅）；改文後 ②「用乙寫時不適用前句」關掉該通路、「不得以此作為
   該項內容不同的理由」關掉記不同、三格合成得「本款不輸出結論」——不得分也不牴觸，落第三格判綠。
2. **三輪計分 3/3 全通過**，兩名判定者零分歧；引用 3/3、套用 3/3，無「照做不引」。
3. **1.7 兩側判讀相反**：出題者側判綠（第三格），判定者甲判紅（同向）。依裁決力條款取較嚴的一邊，
   本關判讀為**同向紅**。
4. **同向紅的成因不是「改動沒有引入新判定」**。判定者甲推得結論所依靠的「本款的結論只有三種，
   互斥且窮盡，不得由排除其中一種逕行認定另一種」該句，本身就是改動 C1 的一部分——它未進入
   依據句欄的極小集合，故依 1.7 硬性要求 1 不被遮，落入「其餘條文」。
5. **禁止二分推理的條文句零效力**。C1 明寫「不得由排除其中一種逕行認定另一種」，而判定者甲的
   遮蔽推導正是由排除前兩格認定第三格；判定者乙的粒度敏感度回報亦指出同一條反推路徑。
   該句在遮蔽推導情境下未擋住任何一名判定者。

**仍未驗證的假設**：

- L28 所述的粒度不一致在「一條改動全部句子皆為推出正解所必需」的題材上是否不發生——本輪無此實例。
- 本輪覆蓋題不測 ①乙 的窮盡要求句，故該款次改文後的實際讀數本輪零觀測；依 L4 不得記為「沒發生」。
