## Solution
### 一、Step 1 改條文（改前改後逐字）

**款次**：`.claude/skills/ux-design-evaluation/references/interaction-feedback-component-semantics.md` 的 7.2(3-2)②
**落檔 commit**：`9d07017c`｜**改動總數**：1（記為 C1）｜**類別**：（甲）改判準內容

**改前（逐字）**

> ② 兩端寫出的不同，即是兩個圖形，到此為止；相同，即是同一圖形。用乙寫時，逐項比對乙所列的各項：同一項的內容相同而只是用字不同（例如「三條直線」與「三段直線」），不算不同；內容本身不同，即是不同。同一項的內容以數量、比例、倍數或分數表述時，**先把兩端換算成同一種表述再比**：換算後數值相同者，內容相同，不得因表述形式不同就記為內容不同。兩端各有一項寫「看不出」時，該項不列入比對，其餘各項照常比。乙所列之外的敘述，即使寫了也不列入比對。

**改後（逐字，粗體為新增或改寫處）**

> ② **用甲寫時**，兩端寫出的不同，即是兩個圖形，到此為止；相同，即是同一圖形。**用乙寫時不適用前句**：**一律先逐項比對乙所列的各項，再依比對結果合成本款結論。**同一項的內容相同而只是用字不同（例如「三條直線」與「三段直線」），不算不同；內容本身不同，即是不同。同一項的內容以數量、比例、倍數或分數表述時，**先把兩端換算成同一種表述再比**：換算後數值相同者，內容相同，不得因表述形式不同就記為內容不同。**逐項比對只在該項兩端都寫出內容時進行。兩端都寫「看不出」的項，略去不比，其餘各項照常比，本款結論不因該項受影響。該項只有一端寫出內容，另一端寫「看不出」或整項未寫的，該項無從比對；不得以此作為該項內容不同的理由。本款的結論只有三種，互斥且窮盡，不得由排除其中一種逕行認定另一種。比對結果依下列合成：有任一項比出不同，即是兩個圖形；乙所列各項除略去不比者外全部比出相同，即是同一圖形；有項無從比對而無項比出不同的，本款不輸出兩者是不是同一個圖形的結論。** 乙所列之外的敘述，即使寫了也不列入比對。

**為何不照抄 `0.1.0-W3-619` 第五節 C 項的處置建議**：該建議為「讓整項漏寫在 ② 側也被擋下」。
照抄會把 ①乙 的結論複述到 ②，該改動即屬（丙）複述型；依 L25 的演繹，(a)(b)(c) 皆不適用、只剩 (d)，
覆蓋題當場零覆蓋，改動總數為 1 時 Step 3 下界立即觸發而不得產出布林——等於本輪一開始就放棄可驗證性。
C1 改採另一路：不在 ② 補擋下句，而是**收窄乙寫法的結論產生方式**——第一句不再管乙寫法，乙的結論
改由逐項比對結果合成，且合成有三格而第三格是「不輸出結論」。遮掉 ①乙 窮盡句之後，其餘條文因此
推得「本款不輸出結論」而非「兩個圖形」，落第三格而非反向紅。
