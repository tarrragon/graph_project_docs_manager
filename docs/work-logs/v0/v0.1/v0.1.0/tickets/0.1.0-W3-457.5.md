## Task Summary

評估 UX-09a 定義 1.11.7 落檔後出題者發現六處結構問題：例示與定義衝突、不適用與相同未分、多出要素規則未定義分支、(a) 全畫面 vs (b) 移出動作列射程不一致、單段無編號、圖示界線

## Problem Analysis
### 問題根因

1.11.7 第 2 項把四輪裁示逐句串成一段長文，沒有做句與句之間的交叉檢查。結果有三類問題：
- 例示與定義互相衝突（#1）
- 結果詞沒有定義：「不比較／不成立」要記成什麼（#2）
- 規則之間的射程對不上（#3、#4）

另外，#3 有一處是落檔時的改寫偏離了裁示：
- 裁示原文（W3-457 Problem Analysis〈落檔依據彙整〉U6-C）是「指示與那個按鈕不同時」。
- W3-457.4 的原提案是「在任一軸上不同」。
- 1.11.7 落檔時寫成「在區塊高度軸上不同」。這個收窄沒有出處。
- 19 組推導裡沒有任何一組能區分兩種寫法，所以落檔前的驗證沒有攔下它。

### 影響範圍

- `.claude/skills/ux-design-evaluation/references/interaction-feedback-component-semantics.md`〈六項判準〉第 2 項（本票不改）。
- 落檔時要連動修改同檔〈三段鏈式範例：第 2 項〉。它沿用了「明顯非按鈕形態」「每一種可點元素」這兩個措辭。
- 0.1.0-W3-417 的 b2w 探針（UX-09a／b／c）要等本票結論落檔後才能出題。

已驗證：1.11.7 第 2 項 HEAD 全文；四輪裁示原文（W3-417〈UX-09a 定義第二輪／第三輪用戶裁示〉、第四輪摘要、W3-457〈落檔依據彙整〉）；W3-457.4 的 15 情境原文；b2w 題目檔。
未驗證：各情境的意圖判定來自推理，沒有做過使用者測試。

### 相關 Error Pattern

- DOC-GPD-007（範例被讀成契約全集）：#1 的例示被讀成無條件合格，屬同型。
- ARCH-BAL-004（文件範例與同檔規則矛盾）：落檔時鏈式範例第 2 項必須同步修改。

## 重現實驗結果
### 實驗方法

只拿 1.11.7 第 2 項的字面，對六個問題各構造一個最小輸入，逐詞推導，看字面能不能給出唯一結果。構造輸入避開探針題目與 19 組情境的結構。

### 實驗執行

| # | 最小輸入 | 1.11.7 逐詞推導 | 觀察 |
|---|---|---|---|
| 1 | 不加底色與外框的純文字指示；畫面上有一個文字連結 | 構成要素對連結相同（皆只有文字）；「區塊高度軸只在兩者都有區塊時比較」→ 不比較；「兩軸都與某一種可點元素相同的指示，不屬 (a)」 | 若把不比較讀成相同，結果是不屬 (a)。但同段的「(a) 例示：不加底色與外框的純文字」讀起來是合格，兩處衝突 |
| 2 | 同 #1 | 「不比較」「高度軸不成立」這兩種情況，字面沒有說要記成相同還是不適用 | 讀成相同 → 不屬 (a)；讀成不適用後只看另一軸 → 仍不同不了，但讀者可能改讀成判準不適用 → 無判定。字面兩讀 |
| 3 | 純文字指示「已同步」；可點元素：一排純色色票（純幾何）＋一個帶區塊的填色按鈕 | 對色票：指示多出文字。填色按鈕具備文字，但條件「指示與那個可點元素在區塊高度軸上不同」要求兩者都有區塊，指示沒有區塊 → 無法比較 | 條件成立與否沒有定義 |
| 4 | 指示與某個可點 chip 兩軸都相同，放在沒有可點元素的標題列 | (b)「移出動作列」成立 → 合格；(a) 以全畫面比較 → 不屬 (a) | 兩條合格路徑的比較範圍不同（全畫面 vs 所在列）；段首「按鈕同形混排」、段尾「和按鈕同列」用「按鈕」，定義內用「可點元素」 |
| 5 | 全段 | 一段內含 13 個以上判定句，沒有編號 | 探針與判定者引用時無法指明是哪一句 |
| 6 | 勾號、箭頭、三角形 | 「純幾何形狀不算圖示，圖示指描繪具體事物或符號的圖形」 | 勾號與箭頭可以讀成符號，也可以讀成線段組合；三角形可以讀成播放符號，也可以讀成幾何形狀。字面兩讀 |

補充驗證 #3 的出處：`git grep -F "在區塊高度軸上不同"` 只命中 1.11.7 本檔。W3-457.4 Solution 三原文是「與該按鈕在任一軸上不同」；W3-457〈落檔依據彙整〉U6-C 是「指示與那個按鈕不同時」。

### 實驗發現

- 已驗證：六個問題都能用字面重現。其中 #1、#3、#4 是字面衝突或無結果，不是讀者個人的偏差。
- 已驗證：#3 的收窄出自落檔，不在任何裁示中。
- 已驗證：以 19 組推導時，#3 的三種寫法結果相同（見 Solution 四），所以原驗證攔不下這個收窄。
- 未驗證：#3、#4、#6 各選項的意圖判定屬推理。
