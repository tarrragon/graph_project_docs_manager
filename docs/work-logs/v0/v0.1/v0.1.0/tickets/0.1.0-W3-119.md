why: '跨檔引用一個章節時有兩種錨點形態，失效行為完全不同：


  - **URL fragment**（如 `file.md#port-回饋契約`）：anchor 生成規則由渲染器決定，各消費端不同（GitHub、本地 markdown 渲染器、純文字閱讀各一套）。目標標題被改時，fragment 不報錯、不留痕跡，只是跳不到——**靜默失效**，且失效方式因消費端而異，同一個引用可能在一處還能用、另一處已經壞掉。

  - **標題文字**（引用「Port 回饋契約」這串字）：目標標題被改時，`rg -F` 找得到所有引用點，失效**可被機械偵測**。


  `0.1.0-W3-114` 的執行者在交接 `0.1.0-W3-115` 的三處下游引用時提出此判準並建議只寫標題文字，PM 採納為 115 的約束。此判準跨專案可重現，不限本次的三處引用。


  歸屬：屬 `DOC-V1-001`（位置編號當錨點會 stale）的同一家族——兩者都是「錨點綁定在一個會變、且變了不會報錯的東西上」。位置編號綁的是序位，fragment 綁的是渲染器的 anchor 演算法，失效機制不同但性質相同。'
