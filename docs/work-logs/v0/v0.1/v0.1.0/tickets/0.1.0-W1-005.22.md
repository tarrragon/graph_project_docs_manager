## Solution

### 實作

`lib/components/relation_item.dart`：`RelationItem`（StatefulWidget，
持 FocusNode 以支援 §4.0.1 焦點裝飾）。slot：`id`（必填）、`isMono`
（預設 true）、`onTap`（必填）、`testKey`（必填）。渲染結構：
`Semantics(button:true, label: l10n.relationItemA11yLabel(id))` →
`DecoratedBox`（焦點外框，`AppColors.accent` / 透明）→
`ConstrainedBox(minHeight: LayoutSize.hitTargetMin)` → `InkWell` →
`Container`（`surfaceChip` 底、`Radius.md` 圓角、`Space.sm` 內距）→
`AppText`（mono 或 body 變體，`maxLines: 1`，重用既有元件而非重繪
`Text`，色彩與截斷邏輯與契約一致無需額外指定）。

barrel：`lib/components/components.dart` 依字母序插入一行
`export 'relation_item.dart';`，未重排既有行。
