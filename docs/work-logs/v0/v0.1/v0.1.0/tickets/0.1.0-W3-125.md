**對條文設計的決定性含義**（代理人提出，PM 認為是本票最重要的一句）：

由此推出三件事：

1. **不能依賴「踩到就會學到」**。學習需要錯誤假設被推翻，而假成功會阻斷這條路徑，且假成功的機率不低（殘留實例確實常常是真兇）。
