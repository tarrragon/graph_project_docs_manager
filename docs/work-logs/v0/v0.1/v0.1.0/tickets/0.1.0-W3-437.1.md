### F-16：正例一「外觀差異交狀態集」vs〈共用規則一〉／path-b 步驟 3「外觀差異降為變體」

   `- Q 阻擋狀態列的 i18n key 待決，是否使本畫面票寫法不合格？　預期：否（待決的是 slot 值而非元件契約欄位，step-4 第 1 條不觸發；出口為建前置票、設 blockedBy）`
   `- Q i18n 前置票完成前，本畫面票可否派發？　預期：否（blockedBy 未清）`
