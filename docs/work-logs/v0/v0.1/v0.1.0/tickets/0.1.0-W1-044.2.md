### WAP 三問（claim 時強制）

- **W（Widen）**：候選方案 (1) 逐元件完整填十一欄位 + 逐容器三項不變式（本票採用）；(2) 只填 W1-005 第一波會用到的狀態元件（EmptyState / BlockedState / LoadingState）與其容器，其餘留骨架——否決，skill〈契約齊全的定義〉是全清單的存在性檢查，部分填寫等於全部不可消費；(3) 以 §4.0 通用約定承載跨元件相同的值（互動瞬態視覺、焦點裝飾、對比、測試形態、人工長文案），逐元件條目只寫差異——採用為 (1) 的寫法，減少 26 + 17 條目的重複。
