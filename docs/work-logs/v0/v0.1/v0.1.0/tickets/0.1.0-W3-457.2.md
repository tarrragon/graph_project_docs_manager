## Problem Analysis
### 問題根因

用戶已裁定判準 (a)「明顯非按鈕形態」的「明顯」要有正向定義（W3-417〈b3x TAD、FD-1 判定與 UX-09a 用戶裁示後的處置〉）。W3-457.1 的草稿被否決，原因是 4 個判定詞裡有 3 個推不出判定，而且判定詞用了描邊、填色、圓角，和同段「描邊 vs 實心不是可靠的互動性訊號」衝突。本票重新起草，並評估例示「文字 chip」的去留。

起草前的觀察：同段理由句已經排除了樣式訊號（描邊、實心、圓角、邊框），所以正向定義不能以樣式判定。剩下能判定的只有「構成要素有沒有」，而不是「構成要素長什麼樣」。

### 影響範圍

- `.claude/skills/ux-design-evaluation/references/interaction-feedback-component-semantics.md`〈六項判準〉第 2 項，以及同檔〈三段鏈式範例：第 2 項——非互動指示與按鈕形態的判斷〉（HEAD 版本 1.11.6）
- W3-417 的答案鍵：b2、b2x 批 UX-09b 的預期判定句含補救建議「（文字 chip、圓點）」

已驗證：第 2 項現行全文；鏈式範例第 2 項的輸入與結論（chip 判合格）；CHANGELOG 1.10.1 記載該範例結論原本判「不合格」，後來為了對齊條文例示改成「合格」；UX-09a、UX-09b 題幹原文；答案鍵中引用 chip 的位置。
未驗證：新定義落檔後重跑 UX-09a 的結果；Material Design 3 的 chip 全屬互動元件（依知識，本票未用工具核對）。

### 相關 Error Pattern

- ARCH-BAL-004（文件範例與同檔規則矛盾）：新定義會判 chip 不屬 (a)。若保留 chip 例示，或不改鏈式範例第 2 項，就會形成這個模式。
- DOC-GPD-007（範例被讀成契約全集）：移除 chip 後只剩圓點一個例示，「缺區塊」這一支沒有例子，讀者可能以為只有幾何標記合格。
