### 三處修文前後對照

**1. 8.2(2)（換色正面定義 + 程序問句 + 括號改禁止式）**

- 前：「第一點，把這些元素承載語意的顏色全換成同一個顏色後，還分不分得出哪個是哪個；分不出，第一點成立。……（轉灰階是本問法的近似手段，不是判準：灰階保留明度，只差明度的兩色轉灰階後仍可區分，不足以據此判第一點不成立。）」
- 後：補正面定義「換成同一個顏色，指兩者在顏色的所有維度（色相、明度、彩度、深淺、對比）上完全相同；因此『換色後仍有明度差／深淺差／對比差』不是可成立的敘述，不得作為第一點不成立的理由」；第一點改為程序問句「把這些元素承載語意的顏色全換成同一個顏色後，是否還剩下 8.2(3) 清單內的任一項差異；不剩，第一點成立」；括號改禁止式「（第一點不得以轉灰階或明度比較執行。）」
- 讀法是否改變：否——原判定邏輯（兩點依序判、第一點不成立即停）不變，只封住「換色後仍以明度／灰階經驗判斷」這條讀者自行推翻封堵句的路徑。

**2. 八項判準版面層級齊平**

- 前：僅第 2、7、8 項有 `###` 子節錨點，第 1、3、4、5、6 項為清單單行，無標題層級。
- 後：章首加八項一覽表（項次／標題／子節）；第 1、3、4、5、6 項各升為 `### N. 標題` 同層級標題（內容移至標題下方）；2.10 群、7.4 群、8.5 群結束處各加一條 `---` 分隔線。
- 讀法是否改變：否——純版面重排，八項判準的判定邏輯、條號、內容文字（除上述 8.2(2)、2.8(1) 兩處外）逐字未動。

**3. 2.8(1)（明分兩個動作列來源）**

- 前：「動作列指排有可點元素的列。移出動作列，指指示所在的列上沒有任何可點元素。整列可點時，該列本身即為動作列。」
- 後：「動作列的來源有二，任一成立即為動作列：(i) 列上排有可點元素；(ii) 整列可點（按下列上空白處即觸發動作）。移出動作列，指兩個來源都不成立——列上沒有任何可點元素，且列本身不是整列可點；確認來源 (ii) 不成立（列本身按下空白處無反應）不代表來源 (i) 也不成立，列上是否另排有可點元素須獨立確認。」
- 讀法是否改變：否——兩個來源本就隱含在原文三句中（排有可點元素／整列可點），本次只是把「任一成立即動作列」與「兩來源須分別確認」的推論步驟顯性化，不新增或刪減判定範圍。

### 措辭重疊登記

- 2.8(1) 新增句「（按下列上空白處即觸發動作）」與「確認來源 (ii) 不成立（列本身按下空白處無反應）」，與 UX-N2r 題幹原句「按下這一列的空白處沒有任何反應」構成語意重疊。此重疊為修法本身的必要結果——本題失敗根因正是「列本身不可點」與「列上無可點元素」被讀者混同，條文側修法必須明寫兩者的區分，勢必觸及題幹用語。若後續需要 UX-N2r 保留鑑別力，建議依 j1/j2 建議另行修改題幹措辭（本票範圍為條文，未動 `q/` 題幹檔）。
