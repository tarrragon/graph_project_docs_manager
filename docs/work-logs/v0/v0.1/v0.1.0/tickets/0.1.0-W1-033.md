## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
建立 lib/tokens/motion.dart：Motion 類含十個 SPEC-003 §2.1 時間 token。七個契約類（feedback/spinnerMinVisible/cancelDeadline/progressTick/snackBar/snackBarWithAction/searchDebounce）為 static const Duration，disableAnimations 恆不歸零；三個動畫類（transition/overlay/skeletonCycle）為依 context 求值的 static Duration 方法，disableAnimations=true 時回傳 Duration.zero，經共用私有方法 _animated 統一實作。差異已於檔頭 dartdoc 表格與 SPEC-002 新增〈時間 token〉節雙邊明示。

lib/tokens/tokens.dart barrel 新增 export 'motion.dart'。

SPEC-002：FR-01 驗收句擴充涵蓋 Duration(milliseconds:/Duration(seconds: 字面值；新增〈時間 token〉節說明落地位置、類別與呼叫慣例、不歸零清單；變更歷史新增 v1.4；version 由 1.3 更新為 1.4。

test/unit/tokens/motion_test.dart：7 個契約類值回溯測試 + 3 個動畫類值回溯測試（disableAnimations=false）+ 1 個動畫類歸零測試 + 1 個契約類不歸零測試，共 12 個 test case（含分組）。

grep -rn 'Duration(milliseconds: [0-9]|Duration(seconds: [0-9]' lib/ --include='*.dart' | grep -v '^lib/tokens/' 無命中，符合 acceptance 第 3 項。
