## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
SPEC-001 §5 定義破洞報告三狀態（掃描中／無破洞／有破洞），對應 SPEC-004
§3.6 三行契約元件組合。實作前 `lib/screens/` 目錄不存在（本票為 Wave 2
六張畫面票中第一張落地者），故無既有畫面模式可延用，改以
`test/widget/harness/state_injection_demo_test.dart`（狀態注入基座示範）
與 `lib/app/shell.dart` 既有 PageColumn/SplitRow.header 組裝方式為參照。

發現一處元件庫掛點缺口：SPEC-004 §3.7 核定記錄第 18 項「重新掃描按鈕位置：
SplitRow.header 右側」，但 `lib/app/shell.dart` 的 `pages` 迴圈對六個目的地
共用同一份 `SplitRow.header(leading: PageTitle(...))`，無 per-screen trailing
掛點；同一缺口亦影響 §3.7 第 17 項（節點詳情返回／開啟原始檔按鈕）。此為
架構掛點缺口而非元件庫缺件（`SplitRow`／`ButtonRow`／`AppButton` 元件本身
皆已存在），且修正涉及 `lib/app/shell.dart` 對全部六個目的地的迴圈邏輯，
超出本票「lib/app/ 只加一行接線」的範圍與「不改其他目的地」的約束，故不
就地修正，改於 Solution 記錄折衷處置並提報後續票（見 Spawn Requests）。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
新增 `lib/screens/gap_report/`：`gap_report_models.dart`（sealed
GapReportState：Scanning／NoGaps／Found，及 GapReportItem／Category）、
`gap_report_provider.dart`（Riverpod Notifier，狀態機 + 取消契約 C2/C4/C8）、
`gap_report_screen.dart`（三狀態依 SPEC-004 §3.6 組合）。`lib/app/router.dart`
`buildDestinationPage` 加一個 `if (destination == AppDestination.gaps)` 分支
接線，不改其他目的地。

逐狀態組合：
- 掃描中：`LoadingState.skeleton`（`skeletonLayout: sections`），取消鈕
  `action-gaps-cancel-scan` 呼叫 notifier `cancelScan()`；`Motion.cancelDeadline`
  後依 `returnToProvider` 導向來源畫面或 Domain 視圖（SPEC-001 §5 註記）。
- 無破洞：`EmptyState.page`（說明 slot 放 `noGapsScanScope`；動作
  `action-gaps-rescan`）。
- 有破洞：`Panel.scrollable`[`Section.collapsible`[`ListRow.sectionHeader`,
  `ListRow.item` × N] × N]。重新掃描鈕**未**依 §3.7 第 18 項置於
  `SplitRow.header` 右側，改置於 `Panel.scrollable` 內容頂部的 `ButtonRow`
  ——已於 Problem Analysis 記錄 `lib/app/shell.dart` 尚無 per-screen 頁首
  trailing 掛點，本票範圍不含新增該掛點（詳見 Spawn Requests）。

資料驅動：`gap_report_provider.dart` 內以 8 個常數 `GapReportItem` 表示
`test/fixtures/corpus/book_overview_v1`（真實 repo 快照）已驗證的 8 個缺
frontmatter 樣本（見該語料 `meta.yaml`），歸入單一分類
`missing-frontmatter`；不接真實掃描邏輯，符合 ticket
`decision_tree_path.final_decision`。

開啟原始檔：`dart:io` `File.existsSync()` + `Process.run('open', [path])`
（macOS 原生指令，不新增套件依賴）；檔案不存在時走
`sourceFileNotFoundSnackbarMessage` 分支（帶重新掃描動作）。0.1 的破洞項
路徑為相對路徑字面值，執行期在使用者機器上通常不存在，故實機預期主要
走「檔案不存在」分支；此為 0.1 範圍下的已知簡化（尚無真實工作資料夾根目錄
串接），非缺件。

多語系：新增 `gapCategoryMissingFrontmatter`、`gapItemLineLabel` 至
`lib/l10n/app_zh.arb`（僅樣板語系，依既有慣例不強制補 `app_en.arb`），並
執行 `flutter gen-l10n` 重新產生 `app_localizations*.dart`。其餘所需字串
（`gapReportScanning`／`noGapsMessage`／`noGapsScanScope`／`rescanAction`／
`cancelScanAction`／`gapsScanningProcessedCount`／`gapSectionCount`／
`openedExternallyMessage`／`sourceFileNotFoundSnackbarMessage`）已由先前
票（元件庫、W1 系列）預先建立，本票只消費。
