1. **一次失效 13 處**：`SPEC-003:761` 這一個定位符被 13 份 ticket 引用，SPEC-003 一次改版後全數指向錯誤位置。失效不是逐一發生、可逐一察覺的，是一次全倒。
2. **其中一處掛著 live trigger**：該引用是 `decision-trigger-binding` 規則要求的延後決策 trigger，行號失效使 trigger 指向無關段落——規則層的強制機制被一個定位符靜默斷開。
3. **第 14 處（SPEC-004 的行號引用，位於 0.1.0-W3-169.md）在首輪掃描中漏抓**，由 graph-project-docs-manager-86 補上，改用原文錨點「回饋通道子表（提案）」（grep count = 1）。漏抓本身即證據：行號引用沒有可機械窮舉的形態特徵，掃描漏一處是常態。

### 素材：為何是規則 10 的同族，而不是另立一類

規則 10（可變計數不實例化）的主張是「不要把一個會變動的值寫死進敘述，改引用權威名稱」。行號是同一個主張的另一個實例——一個會變動的定位符。差別只在變動的觸發源：計數在集合增減成員時變，行號在檔案任何位置插入或刪除行時變（後者的觸發面更大）。

### 素材：失效訊號的可鑑別性（由 graph-project-docs-manager-86 提出，本票要寫進規則）

- 原文錨點（如「回饋通道子表（提案）」）在**被引用的內容實質改變**時才失效。那是訊號，不是腐化——讀者應該去看那段變成什麼了。
- 行號在**任何無關的插入**下也會失效。
- 兩種失效在讀者端**同形**：都是「指過去發現不是那個東西」。行號因此讓「該去看」與「不必去看」不可區分，把一個有訊息量的失效降級為雜訊。

這一段是規則 11 的 Why，不是附註——沒有它，規則只是一條沒有理由的禁令。

### 邊界（規則 11 要明寫，否則會被讀成禁止所有位置引用）

- 釘在不可變版本上的引用不受限（以 commit hash 取檔案內容的形式）——該 hash 之下的行號永遠有效。
- 機器產生的定位（traceback、linter 輸出、帶行號的搜尋結果）不受限——生產者與消費者是同一次執行，不跨版本。
- 受限的是**人寫進文件、預期後續版本仍能定位**的那一類。

### 落地時的自指陷阱（規則 8 會擋住本票自己的證據）

上述素材全部以本專案 ticket ID 標定來源，但規則 11 的載體是 `.claude/references/reference-stability-rules.md`，受同檔規則 8（框架文件禁引用專案層級識別符）管轄。寫入時證據要去識別化——留下形態（「一個定位符同時被十餘處引用，改版後一次全失效，其中一處是規則層要求的延後決策 trigger」），不留票號。本票的 Problem Analysis 是證據的保存處，不是要被逐字搬進框架檔的草稿。
### 修正：錨點的可鑑別性論證有個窄前提，直接推廣會製造新的失效類別

由 graph-project-docs-manager-86 於後續訊息中細分。前一段所採的「錨點失配是訊號」結論**成立，但成立的原因很窄**，不可直接推廣。

**原例為何成立**：那處引用的對象**就是錨點裡的狀態標記本身**（要問的是「誰該解除這個提案標記」）。標記被解除 → 錨點失配 → 失配正好告知「已解除」。指涉對象與錨點文字是同一個東西，失效與訊號因此重合。

**換一個引用目的，同一個錨點就誤報**：若引用的是該子表的**內容**（有哪幾類），錨點仍寫成含狀態標記的完整標題，則他人解除標記時錨點失配，而被引用的內容一個字都沒改。讀者收到「去看那段變成什麼」的訊號，去看，發現什麼都沒變——**這就是行號那種無訊息量的失效，只是換了個機制產生**，且更難察覺，因為錨點看起來「已經照規則寫了」。

**因此規則 11 的錨點要求是兩個獨立判準，不是一個**：

| 判準 | 保證什麼 | 不保證什麼 |
|------|---------|-----------|
| 唯一性（grep count = 1） | 找得到，且只找到一處 | 失效時有訊息量 |
| 穩定性（相對於所指涉的對象） | 失效即代表指涉對象真的變了 | 錨點不重複 |

穩定性的判準寫成一問：**這個錨點裡的每一個字，是否都是你要指涉的內容的一部分？** 錨點含描述狀態、階段、版本的成分而指涉的不是那個狀態本身時，把該成分排除在錨點外。

**這一層與已採用的 Why 同源**：唯一性只保證「找得到一處」，穩定性才決定「失效時是否有訊息量」。只查唯一性會篩掉重複錨點，篩不掉語意錯配。

**原例本身不改**：那處引用的確實是標記本身，含狀態成分是正確的。本節是把特例與通則分開，免得規則 11 把特例寫成通則。
