## Task Summary

現行 ux 計分點只驗判定方向（通過／不通過），對「讀者引了哪一款」零鑑別力。0.1.0-W3-597 證明正向字面通路（墊高正確率）與反向吸引子（壓低正確率）對讀數的影響方向相反，而兩者的差別只在依據款次上看得見——18 個改動後輪次中，判定全對但出現三處款次錯置（兩輪引 7.2(4)「本項與第 2 項各自判定」來說明第 7 與第 8 的分工、一輪把 7.2(4) 的文字標成 8.3(2)），判定報告皆記錄而未計不通過。本票設計：(a)「依據款次」欄的記錄規格（逐子問記該輪實際引用的款次，與答案鍵的正解款次並列）；(b) 錯置的分類（指向反向吸引子所在款／指向無關款／出處標註錯誤但引文正確）；(c) 據此可算出的兩個新讀數——正向通路被取用率、反向吸引子被取用率；(d) 該欄與既有計分點的關係（是否計不通過，或只作歸因用）。
