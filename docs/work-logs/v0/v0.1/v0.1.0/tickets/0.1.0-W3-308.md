### W3-296 詳述

**事實**：W3-296 的 `how.strategy` 寫定了具體的檔案重組結構（step-1 至 step-5 加 appendix 與 addresses），並指定了具體內容分配。`source_ticket` 為 W3-294（量測可理解性的 ANA 票）。

**判定**：

- W3-296 的策略未顯式寫出證據狀態。它未說「此結構已由 W3-294 的探針驗證」或「此結構為 W3-294 的結論」——只在 frontmatter 的 `source_ticket` 欄位指向 W3-294。

- 條文的 Action 說「同時寫下」，意謂證據狀態應與修法並列出現在 `how.strategy` 中，而非僅靠 `source_ticket` 欄位的隱式引用。

**結論**：**W3-296 的證據鏈在 `source_ticket` 欄位中存在，但未依條文要求在 `how.strategy` 中顯式寫出證據狀態。** 這是一個輕度不合規——修法確有分析依據，但票面形態不符條文的「同時寫下」要求。對比 W3-304 的顯式寫法，落差清晰。
