### PM 裁決：本票改為改檔前 baseline，W3-536 blockedBy 本票（原訂次序已翻轉）

建票時本票 blockedBy W3-536（改檔後才跑）。**已翻轉**：本票先跑，W3-536 等本票。

理由：案 C 的標的正是「題幹不交出同一性時讀者做不做得到正規化」這個硬案。UX-Y7a 的題幹替讀者做完了同一性判定，所以它量到的是軟案。若本票只在改檔後跑，硬案就沒有改檔前讀數——**案 C 在硬案上是否生效將無從歸因**，只能看到一組孤立的改檔後數字。

這與 doc 線 W3-533 → W3-534 的次序紀律同源：先改後量，量到的是「條文還沒到位」或「孤立值」，都不是改動效果。本線前期兩次淨負（W3-491、W3-514）皆因缺改前讀數而延遲發現。

### 本票與 UX-Y7a 的分工

| | UX-Y7a（W3-537） | 本票 |
|---|---|---|
| 題幹 | 逐字寫出兩者畫的都是一枚繭 | 只描述兩端各自的所繪外觀，無共有名詞 |
| 量到的 | 軟案：讀者不必做正規化 | 硬案：讀者做不做得到正規化 |
| 改檔前讀數 | A 3／B 0，自覺率 0/3，三輪皆引題幹 | 本票產出 |

兩題並列才分離得出「讀者做不到」與「讀者不必做」。單有 UX-Y7a 時兩者同形。

### 出題約束（本線第三次踩到事實槓桿後新增）

**凡受測款次含一個判定步驟，題幹不得以任何形式交出該步驟的結論。** 本票的受測步驟是圖形同一性判定，故題幹不得出現任何指涉兩端為同一種東西的共有名詞，亦不得宣稱「兩者除顏色外相同」「輪廓完全相同」這類等同陳述——後者與直接給共有名詞等效。

### 實驗執行

#### 一、題幹逐詞自檢（acceptance 第 1 項對應）

逐詞檢查對象為題目檔的「**題目**：」到「請引用依據句。」之間的全部文字。先列機械計數，再逐類說明。

機械計數（等同陳述關鍵字，逐詞 byte-exact）：

| 關鍵字 | 命中數 | 命中處是否為跨兩端的等同陳述 |
| --- | --- | --- |
| 相同 / 唯一 / 兩者 / 除顏色 / 完全 / 同一 / 一致 / 同形 | 各 0 | 不適用 |
| 一樣 | 1 | 否——「上下兩條弧線鼓出的幅度一樣」，比較的是**同一端自己的兩條弧線** |
| 相等 | 1 | 否——「兩條鼓出的幅度相等」，同上，在待翻塘端自己的描述內 |
| 都是 | 1 | 否——「兩個尖角都是銳角」，同上，在已起藕端自己的描述內 |

逐詞列出題幹的全部名詞，分五類，逐類說明為何不構成共有名詞交付：

| 類別 | 名詞 | 為何不構成「指涉兩端為同一種東西」 |
| --- | --- | --- |
| 領域名詞 | 藕塘、輪作、塘口、清單、畫面、列、口、列首 | 指的是列所代表的事物與版面位置，不是兩枚圖示所繪之物 |
| 角色／類別名詞 | 圖示、圖形 | 「圖示」是位置與載體的角色名（列首的那一個），條文 7.1(1) 自身即以此為射程類別；說兩端都是圖示，等同說兩端都佔同一個版位，不含「畫的是同一種東西」。「圖形」只出現在末句「畫面上沒有其他圖形」，是對畫面其餘部分的否定存在陳述，未被用來指涉兩端 |
| 零件與幾何屬性名詞 | 弧線、尖角、銳角、輪廓、邊界、開口、線條、幅度、橫寬、直高、比、兩倍半、五比二、一半、二分之一、左緣、最左端 | 全部是零件名與量測名，且每一個都出現在**某一端自己的描述段內**。零件名在兩段描述中重疊不構成同一性交付——「弧線」對一彎新月與一片葉子同樣為真，共用零件名推不出共用整體 |
| 語意側名詞 | 已起藕、待翻塘、狀態、動作、語意、文字 | 這一側的共有名詞是「狀態」：題幹明寫兩者都是狀態。這是**語意類別**的共有名詞，不是**所繪之物**的共有名詞，作用是關閉 7.2(5)② 的分支選擇（受測步驟是圖形同一性，不是語意類別同一性）。UX-Y7a 同樣這樣寫，兩題在這一維度上無差異 |
| 其他 | 顏色、鴉青色、緗色、按鈕、可點元素、兩類 | 「兩類」數的是列，不是所繪之物；顏色名兩端各異 |

**題幹全篇沒有任何一個名詞用來同時指涉兩端的所繪之物。** UX-Y7a 中扮演這個角色的是「繭」，本題無對應詞。

### 實驗發現

已驗證的事實：

- **讀法完全翻面：3/3 落在讀法 B（兩個圖形、不違反第 7 項、零缺口）**，讀法 A 零輪，讀法 C（明寫無法裁決）零輪。
  UX-Y7a 的同一組子問在同一模型下是 A 3／B 0。**同一份條文、同一組子問、同一種圖形關係，只因題幹交不交出同一性，三輪輸出從一端全部翻到另一端。**
- **條文在同一性那一步的貢獻，兩題都是零（0/3 與 0/3）。** 移除題幹的同一性交付並沒有把讀者推向條文；
  三輪沒有任何一輪引 8.2(3) 的顏色維度排除句（路 i）或 7.2(3)「描邊與實心變體算同一圖形」（路 ii）。
- **依據來源分佈與 UX-Y7a 完全相同（條文 0／題幹 2／略過 1），但題幹的用法不同。**
  UX-Y7a 的 2 輪是**甲型**（引用題幹交出的共有名詞與等同陳述，直接取結論）；本題的 2 輪是**乙型**（引用題幹的兩段外觀描述，自行比對後得結論）。
  乙型代表讀者確實動手做了正規化那一步——但三輪都沒有把它做完（見下）。
- **正規化被啟動但沒有一輪做完。** 九個維度中無一輪逐項對應：r1 與 r3 只比「構成」一維即下結論；
  r2 比到構成、端點、封閉與比例四維。等價形式的換算 3 輪中只有 1 輪執行——比例（兩倍半 vs 五比二）僅 r2 換算為 2.5，
  大小（一半 vs 二分之一）**零輪**提及。兩端敘述順序不同即足以讓 2/3 輪判為「形狀明顯不同」。
- **r1 出現不對稱正規化：對一端自行補上類名，另一端保留零件敘述，再比對兩個層級不同的描述。**
  r1 全篇稱已起藕端為「鴉青色橢圓形圖示」——「橢圓」是題幹沒有的詞，由 r1 自行歸類；
  待翻塘端則保留為「緗色上下弧線圖示」。一個是類名、一個是零件清單，比對必然得出「不同」。
- **r2 在同一份作答內對同一組圖形做出兩次相反的同一性裁決，且零自覺。**
  子問 1 寫「若將兩圖示顏色全換成相同，形狀特徵（都為上下鼓起、左右各一銳角的閉合圖形，寬高比均為 2.5）仍相同」——這是「同一圖形」的裁決；
  子問 2 卻寫「已起藕圖示在全畫面只用於代表『已起藕』語意……沒有任何圖形同時承載兩個不同的語意」——把兩者當成兩個圖形處理。
  第 (3)／(4) 欄皆答否。**8.2(2) 第一點的換色比對事實上是一套可用的圖形同一性程序，而 7.2 缺的正是這一套；兩者並存、方向可相反、且條文無任何交互指引。**
- **自覺率 1/3，高於 UX-Y7a 的 0/3，但登記的是相反方向的假設。**
  僅 r1 登記，且登記在第 (4) 欄兩處：子問 1「假設『鴉青色橢圓形圖示』與『緗色上下弧線圖示』是題目敘述中的兩個不同圖形」、
  子問 2「假設題目敘述的『鴉青色圖示』與『緗色圖示』在畫面上是視覺上清晰可辨的不同圖形（而非同一圖形的不同色彩變體）」。
  r1 明確意識到「同一圖形的不同色彩變體」是另一種可能，卻在第 (3) 欄答「否」——**假設被登記，兩種判定沒有被登記。**
- **子問 3 的 7.2(4) 誤指派在本題重現，比率與 UX-Y7a 相同（2/3）。** r1 與 r3 都以 7.2(4)（該款講的是第 **2** 項）類推到第 7 項與第 8 項的交界；
  r3 另自行加註「雖提及第 2 項，但同理亦適用於第 8 項的關係」。此缺口已由 `0.1.0-W3-544` 追蹤，本題提供第二組實證。
- **計分點命中率 3/3（100%）。** 三輪在兩側共有的步驟上全數通過；兩項記為依據不全（見 Test Results）。
