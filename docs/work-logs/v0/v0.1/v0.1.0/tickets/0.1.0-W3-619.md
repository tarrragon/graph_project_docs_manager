## Solution
### 一、四項的逐項界定

全部四項的共同形態是同一個：**這一關的輸出由執行者當場裁量**。四項的處置也是同一個——把裁量對象換成一份事先定稿、可被第二人逐字複核的文字，讓判斷離開執行迴路。這與 4.6 把第 (iii) 類由語意判準改為位置判準是同一手法。

### （一）遮蔽單位：改為「遮蔽 span ＝ 答案鍵依據句欄逐字，扣除判定對象 span」

原條文「受測步驟所在的最小編號單位」在表格儲存格與目內單句上指不出唯一切法。新判準含三條硬性要求：兩個 span 於跑推導之前定稿並寫進答案鍵（與 4.6 判定語 span 同批）、判定者側的外部驗證使用**同一份 span 逐字**（不得自行指名再自行切）、守恆式對帳（兩者相加逐字等於依據句全文）。

**為何判定對象不遮**：遮掉判定對象，讀者連題目在判什麼都推不出，本關對每一題輸出「推不出任何結論」而恆綠。這與原條文已擋過的「遮整款會把替代理由一併遮掉」是同一失效方向——遮得越多，假綠越多。新判準在有編號載體上嚴格強於原表述（替代理由若在同款次前段，它不在依據句欄內，故不被遮，動機案例仍被涵蓋）。

**為何守恆式不可省**：把規範內容靜默挪進判定對象 span 即可讓本關轉綠。守恆式讓這個挪動留下痕跡，是 4.4 第二項在本關的套用。

### （二）「確定結論」的粒度：改以本題計分欄對照兩問

拿遮蔽後推得的結論去對照答案鍵的計分欄，逐問兩次——足以得分者判紅（同向）、足以被判不通過者判紅（反向，回 Step 1），兩問皆否才綠。**「這算不算一個確定結論」是語意判斷，計分欄是事先定稿的文字，拿結論對照它是比對而非裁量。**

**反向約束（防單向省事）**：計分欄收窄可使本關轉綠，故收窄後須重跑 1.3——收窄後的計分若使正解本身推不出，該題依 1.3 改列缺口題或放棄；計分放寬則本關判紅。兩個方向各有代價。計分欄與兩個 span 同批定稿，時序可由檔案時間覆驗。

### （三）走 (d) 的題：**計入** Step 3 布林分母（本票的優先項）

**計入**。理由是退出有兩個失效方向：該題失分時不再使布林反向（一道本該不通過的輪次被判通過，違反停損判準第二列）；全輪皆 (d) 時分母為空，布林無定義而空集合恆真。計入保留它的否決力。

覆蓋率的損失改由三處承接，缺一則極端情形無人擋：

| 承接處 | 內容 |
|---|---|
| 布林語意寫死 | true 的意思是**本輪出的題全數達標**，不是「本輪改動全數被驗證」 |
| 產出增列覆蓋比 | 有覆蓋題且該題達標的改動數 ／ 本輪改動總數；**布林不得單獨引用**，一律與覆蓋比並列 |
| 下界 | 本輪改動全數落在零覆蓋清單時**不得產出布林**，Step 3 不執行，回 Step 1 |

**極端情形的布林語意**（acceptance 明列）：整輪全走 (d) 時，下界生效——不是「布林為 true」也不是「布林為 false」，而是**不產出布林**。理由是此時 Step 3 沒有受驗對象，跑出來的任一個值對改動零資訊；給它一個值會讓它被引用。

**信心折扣**：布林 true 之下，未被任何覆蓋題驗到的改動數即零覆蓋清單的長度，該數字須與布林同時出現。

### （四）外部驗證的裁決力：兩側相反時以較嚴的一邊為準

紅勝綠；反向紅勝同向紅。出題者側不得以自己的推導覆蓋判定者側。

**憑什麼不被覆蓋**（PM 指定必答）：設立外部驗證的理由，條文自己已經寫了——出題者側有系統性偏誤（知道正解、實際輸出偏向形式化打勾）。讓有偏誤的一方裁決無偏誤的一方，等於取消本機制；而取消之後它與「本來就沒問題」在紀錄上同形，正是規則 E2 的失效方向。原條文寫「是本關唯一的外部訊號」卻未寫效力，於是該句名不副實——本票的處置是寫死效力，不是刪句。

**判定者側判紅而 Step 2 已放行時的處置**：該題三輪計分照常完成（已觀測到的讀數不得登記成沒觀測到，L14），但該題不得列為任何改動的覆蓋題；反向紅者該輪結束後回 Step 1 改條文，不論布林為何；同向紅者依四條出路處置。

### 三、3.1 與 4.6 碰撞的界線

**界線只有一條：3.1 交出的是結論（一個事實狀態），不是條文的字串。** 題幹以自己的措辭陳述該結論，即同時滿足兩關。

碰撞的成因是改文者為求對症，最自然的措辭就是複述前置句的用詞；題幹逐字沿用時該串字落在受測款次的判定語 span 內，被 4.6 判 (iii)。`0.1.0-W3-618` R2-Q02 初版即命中（逐字引「先數兩端各屬哪個元件，再選列」），改寫為「兩端各自長在誰身上」後 class (iii) 歸零而 3.1 登記不變。

四格處置已寫入規格 3.1：逐字沿用者判 (iii) 並改寫題幹（**不因「為履行 3.1 而寫」而豁免**）；改寫後前置結論仍成立即兩關同時滿足；改寫使前置結論不再成立者等於刪句，3.4 已禁，改題材；該前置結論的唯一可能表達即落在 span 內（例如它是一個專名）時換題材，仍不行則放棄該題，**不放寬 4.6**。

**為何不給豁免**：豁免的觸發條件是「這句話是為履行 3.1 而寫」，那是出題者的意圖陳述，無法由第二人複核，與 4.6 把第 (iii) 類改為位置判準所要離開的那一格同形。改寫措辭在拋棄式題庫下成本為零，不需要這條出路。

### 四、`0.1.0-W3-618`「通過」的最終讀法

> **布林 true 成立；覆蓋比 1/2。讀作「本輪出的三題全數達標」，不讀作「兩條改動都被驗證」。**

|---|---|---|
| D1（第二列管轄欄補指涉） | R2-Q01，3/3 | **有覆蓋且達標**。該條改動已被驗證 |
| D2（第二列依據欄補 disjunction 拆分註記） | R2-Q02，3/3 但依 1.7 (d) 不得列為覆蓋題 | **零覆蓋**。三個讀數只證明該題的讀者答對且處理了選擇結構，不證明他取用的是 D2 依據欄；D2 未被驗證 |

三點限定：

1. **不得把 R2-Q02 描述為「題目有效」**（L25 明文）。1.7 判紅的實質語意是該題對受測步驟沒有鑑別力，(d) 免掉的是處置義務，不是回復鑑別力。
