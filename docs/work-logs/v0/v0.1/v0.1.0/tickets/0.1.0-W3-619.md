4. （丙）類的當場判準與承擔者未界定。本票只給了與 1.7 的事後雙向對帳作為更正管道，並把 Step 1 的（丙）降為預判；Step 1 的首次執行即為其驗證。

## Solution
### 一、四項的逐項界定

四項同源：**這一關的輸出由執行者當場裁量**。處置也同一——把裁量對象換成一份事先定稿、可被第二人逐字複核的文字，讓判斷離開執行迴路。這與 4.6 把第 (iii) 類由語意判準改為位置判準是同一手法。

### （一）遮蔽單位：遮蔽 span ＝ 依據句欄中屬受測款次的規範字串，扣除不遮 span

原條文「受測步驟所在的最小編號單位」在表格儲存格與目內單句上指不出唯一切法。依據句欄逐字拆為三個互斥登載項——遮蔽 span（遮）、不遮 span（受測步驟的判定對象，不遮）、欄內佐證（引自其他款次者，不遮）。

四條硬性要求，各擋一條繞道：

| 要求 | 擋的是 |
|---|---|
| 依據句欄須為極小集合（刪任一句即推不出正解） | 裁量從「當場切」上移到「欄位要登哪些字」——1.3 只要求充分性，超集同樣滿足，欄位寫越寬遮越多越容易轉綠 |
| 遮蔽 span 不含其他款次的引句 | 遮掉別的款次不服務「受測**步驟**不得可省」這個命題，只製造假綠 |
| 三個登載項寫成獨立於答案鍵的檔案，與計分欄同批，早於推導 | 同寫一檔時 mtime 只反映最後一次寫入，「事先標定」無從複核 |
| 分區由第二人複核（判定者回報「不遮 span 內有無施加義務／給出判定結果／規定順序的字」） | 把規範內容挪進不遮 span 即可轉綠，而該挪動不改變字數總和——逐字登載本身不會翻紅，會翻紅的是第二人讀到它 |

**為何判定對象不遮**：遮掉它，讀者連題目在判什麼都推不出，本關對每一題輸出「推不出任何結論」而轉綠。這與原條文已擋過的「遮整款會把替代理由一併遮掉」是同一失效方向——遮得越多，假綠越多。原表述的動機案例（替代理由在同款次前段）在新標定下仍被涵蓋：該段不在依據句欄內。

### （二）「確定結論」的粒度：以本題計分欄對照，落入互斥窮盡的三格

足以得分 → 紅（同向）；**與正解牴觸**（讀者採納它會給出被計分判為錯的答案）→ 紅（反向，回 Step 1）；其餘（推不出任何結論，或推得出的結論既不得分也不牴觸）→ 綠。

**第三格須明寫。** 本票第一版把第二格寫成「足以被判不通過」，代入 R2-Q01 即翻反向紅——該題計分欄明寫粗粒度答案記不通過，而遮後推得的正是那句粗粒度答案。任何非空而不完整的結論都滿足「會被判不通過」，於是只有「推不出任何結論」才判綠，三分退化為二分，退化方向是把大量題目誤判為條文缺陷並逼回 Step 1。**不完整與牴觸是兩件事**，判準必須分得開。

**Why（用計分欄而不用「確定結論」）**：「這算不算一個確定結論」是語意判斷，同一題可得相反判讀。計分欄是事先定稿的文字，拿結論去對照它是比對而非裁量。

**反向約束（防單向省事）**：計分欄收窄可使本關轉綠，故收窄後須重跑 1.3——收窄後的計分若使正解本身推不出，該題依 1.3 改列缺口題或放棄；計分放寬則本關判紅。兩個方向各有代價。

### （三）走 (d) 的題：**計入** Step 3 布林分母（本票的優先項）

**計入**。退出有兩個失效方向：該題失分時不再使布林反向，即一道本該不通過的輪次被判通過（〈收納判準〉中「本該不通過的題被判通過」該列，屬開票級）；全輪皆 (d) 時題集為空，布林的量詞範圍為空而 vacuously 為 true、覆蓋比分母為零而無定義，兩者都不能被引用。計入保留它的否決力。

覆蓋率的損失由四處承接，缺一則極端情形或中間地帶無人擋：

| 承接處 | 內容 |
|---|---|
| 布林語意寫死 | true 的意思是**本輪出的題全數達標**，不是「本輪改動全數被驗證」 |
| 覆蓋比 | 分子＝改動總數 − 零覆蓋清單長度（單一定義）；**布林不得單獨引用**，一律與覆蓋比並列；只在本輪內有意義，不跨輪比較 |
| 零覆蓋清單改為活清單 | 跨 Step 1／2／3 累加，三處當場回填並註明成因與時點。清單若凍結在 Step 1，全部改動都在 Step 3 才失去覆蓋時清單仍為空，下界不觸發 |
| 下界（先於判準列判定） | Step 3 結束後改動全數落在零覆蓋清單時**不得產出布林**，回報形態為「不摺成布林，附各題計分與零覆蓋清單全文，回 Step 1」 |

**極端情形的布林語意**（acceptance 明列）：整輪全走 (d) 時，下界生效——不是 true 也不是 false，而是**不產出布林**。理由是此時 Step 3 沒有受驗對象，跑出來的任一個值對改動零資訊；給它一個值會讓它被引用。回報形態明寫，是為了不與 L14 衝突：讀數保留，只是不摺成布林。

**信心折扣**：布林 true 之下，未被任何覆蓋題驗到的改動數即零覆蓋清單長度，該數字須與布林同時出現。

### （四）外部驗證的裁決力：兩側相反時以較嚴的一邊為準

紅勝綠；反向紅勝同向紅。出題者側不得以自己的推導覆蓋判定者側。

**憑什麼不被覆蓋**（PM 指定必答）：設立外部驗證的理由，條文自己已經寫了——出題者側有系統性偏誤（知道正解、實際輸出偏向形式化打勾）。讓有偏誤的一方裁決無偏誤的一方，等於取消本機制；而取消之後它與「本來就沒問題」在紀錄上同形，正是規則 E2 的失效方向。原條文寫「是本關唯一的外部訊號」卻未寫效力，該句因此名不副實——處置是寫死效力，不是刪句。

**落地管道（缺則裁決力無從觸發）**：判定者 brief 的必備項四條——夾帶三個登載項逐字與計分欄、分區複核一句、**粒度敏感度一句**、零覆蓋回報欄。

第三條是本票在審查後補上的，理由值得記：`0.1.0-W3-618` 唯一一次有價值的外部訊號，正是判定者**自行切了較窄的粒度**才產生的。把兩側綁死在同一份 span 上（第（一）項的要求）會使兩側依建構而一致，裁決力條款幾乎不再被觸發——修好了粒度歧義，同時關掉了訊號源。「改遮哪一段會得到不同判讀」這一句把訊號源接回來，成本是一行。

**判定者側判紅而 Step 2 已放行時的處置**：三輪計分照常完成（L14），該題不得列為任何改動的覆蓋題並當場回填零覆蓋清單；反向紅者該輪結束後回 Step 1 改條文，不論布林為何；同向紅者依〈同向紅燈的處置〉表處置。

### 二、逐條驗證（以 R2-Q01／Q02／Q03 回測新界定）

完整代入過程見〈重現實驗結果〉。結論：

| 題 | 新界定下的判讀 | 與 `0.1.0-W3-618` 原判讀的差異 | 兩側是否一致 |
|---|---|---|---|
| R2-Q01 | **綠**（不得分，但不與正解牴觸——它是正解的一部分而缺列名，落第三格） | 相同（原亦判綠，但當時附「歧義回報」） | 是 |
| R2-Q02 | **紅（同向）**，走出路 (d) | 相同 | 是 |
| R2-Q03 | **紅（反向）→ 回 Step 1 改條文** | **相反**（原判綠、記為「零條文改動」） | 是 |

R2-Q03 翻紅有兩條路徑，但**兩者是接替不是備援**：

1. 遮蔽 span 逐字同源——項目清單不在答案鍵的依據句欄內，故本就不在遮蔽範圍；兩側遮同一串，皆推得出牴觸正解的結論。
2. 外部驗證的裁決力——兩側仍遮不同範圍時取較嚴的一邊，即判定者甲的反向紅。

路徑 1 生效後兩側依建構而一致，路徑 2 的觸發頻率趨近於零；且兩者共同的上游都是出題者寫的依據句欄，故不獨立。這正是第（四）項補上「粒度敏感度一句」的理由。

R2-Q01 的唯一判讀來自三格對照。**本票第一版的判準在此題上是錯的**——寫成「足以被判不通過」時它翻反向紅，與答案鍵相反。審查抓到後改寫為「與正解牴觸」並明寫第三格，Q01 落第三格判綠。

**回測暴露的一項既有分類錯誤**：(d) 的射程改錨在 Step 1 的（丙）複述型之後，D2 在 `0.1.0-W3-617` 被標為（甲）改判準內容而 1.7 判它同向紅，依新增的雙向分類對帳屬分類有誤，應更正為（丙）。這不改變 D2 零覆蓋的事實，改變的是零覆蓋的**成因記載**——從「甲類改動碰巧拿不到覆蓋題」改為「丙類改動依 L25 的演繹本就拿不到」。

### 三、3.1 與 4.6 碰撞的界線

**界線只有一條：3.1 交出的是結論（一個事實狀態），不是條文的字串。** 題幹以自己的措辭陳述該結論，即同時滿足兩關。

碰撞的成因是改文者為求對症，最自然的措辭就是複述前置句的用詞；題幹逐字沿用時該串字落在受測款次的判定語 span 內，被 4.6 判 (iii)。`0.1.0-W3-618` R2-Q02 初版即命中（逐字引「先數兩端各屬哪個元件，再選列」），改寫為「兩端各自長在誰身上」後 class (iii) 歸零而 3.1 登記不變。

四格處置已寫入規格 3.1：逐字沿用者判 (iii) 並改寫題幹（**不因「為履行 3.1 而寫」而豁免**）；改寫後前置結論仍成立即兩關同時滿足；改寫使前置結論不再成立者等於刪句，3.4 已禁，改題材；該前置結論的唯一可能表達即落在 span 內（例如專名）時換題材，仍不行則放棄該題，**不放寬 4.6**。

**為何不給豁免**：豁免的觸發條件是「這句話是為履行 3.1 而寫」，那是出題者的意圖陳述，無法由第二人複核，與 4.6 把第 (iii) 類改為位置判準所要離開的那一格同形。改寫措辭在拋棄式題庫下成本為零，不需要這條出路。

三點限定：

3. **布林不得單獨引用**。往後引用 `0.1.0-W3-618` 的結論一律寫成「通過（覆蓋比 1/2，D2 零覆蓋）」。
