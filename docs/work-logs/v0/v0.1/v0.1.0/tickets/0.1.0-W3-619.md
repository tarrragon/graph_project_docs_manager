## Problem Analysis
### 問題根因

`docs/probes/probe-authoring-spec.md` 1.1.0 的 1.7（遮蔽推導）在 `0.1.0-W3-618` 首次執行時暴露四個未界定處，四者同源——皆是「這一關的輸出是什麼」沒有被寫死，於是由執行者當場裁量：

| # | 未界定處 | `0.1.0-W3-618` 的實測 |
|---|---|---|
| 1 | **遮蔽單位**：「受測步驟所在的最小編號單位」在無編號載體（表格儲存格、目內的單一句）上指不出唯一切法 | R2-Q03：出題者遮整個乙目 → 推不出任何結論（綠）；判定者甲改遮乙目的窮盡要求句 → 推得出**反向**結論（依判讀表屬條文缺陷，須回 Step 1 改條文） |
| 2 | **「確定結論」的粒度**：以正解粒度判或以任何結論判 | R2-Q01：遮掉第二列管轄欄後可推出粗粒度同向結論「屬本元件的組合規則」，但推不出具體落點。前者判紅、後者判綠 |
| 3 | **走 (d) 的題是否計入 Step 3 布林的分母** | 1.7 (d) 只寫「不記紅」「不得列為覆蓋題」，未寫是否退出分母。`0.1.0-W3-618` 讓 R2-Q02 留在分母且計入布林——極端情形下一輪全部改動皆為位置前移型、全走 (d)，布林可為 true 而零改動被驗證 |
| 4 | **1.7 外部驗證的裁決力**：判定者側與出題者側判讀相反時以何者為準 | `0.1.0-W3-618` 由出題者側的粒度選擇覆蓋了判定者甲的反向結論。1.7 明寫該機制是「本關唯一的外部訊號」，卻未寫它的效力，於是它可被它要驗的那一方覆蓋 |

### 影響範圍

`docs/probes/probe-authoring-spec.md` 的 1.7 全節、§7 第 21 項通過條件、以及 Step 3 布林分母的定義（第 3 項）。

**已驗證的事實**：四處皆在 `0.1.0-W3-618` 有實例，第 1、2、4 項有兩側判讀相反的直接紀錄。
**仍未驗證的假設**：第 3 項的極端情形（整輪全走 (d)）本輪未發生，本輪是二分之一（D2 零覆蓋）。

### 相關 Error Pattern

不適用。本票的知識來源是 `docs/probes/probe-known-limitations.md` 的 L13（未明文否決等於留給判定者自行決定）與 L25，以及規則 E2（守衛的失效方向是放行，而放行與「本來就沒問題」同形）——第 4 項正是 E2 在本規格的實例：外部驗證這道守衛目前對它要擋的東西零鑑別力。
