## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
`page_title.dart` 刪除私有 `_PageTitleText`，改直接引用 `AppText`（4.1）：
title -> `AppText(title, variant: AppTextVariant.subtitle)`；
subtitle -> `AppText(subtitleText, variant: AppTextVariant.body, secondary: true, maxLines: 1)`。
subtitle 沿用 `AppTextVariant.body` 而非 `subtitle`，因既有測試斷言副標非
`Semantics.header`，`AppText.subtitle` 變體固定標記為 header，改用 body+secondary
符合契約註解「body + secondary 承載副標」且維持測試通過。

### 自檢結果
Phase 4 結論：無需重構。改動純粹替換私有 widget 為既有 AppText 元件，無新增
