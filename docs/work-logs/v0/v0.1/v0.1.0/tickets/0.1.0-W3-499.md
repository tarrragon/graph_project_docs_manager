## Problem Analysis
<!-- Schema[DOC/Problem Analysis]: 選填（若 DOC 起因於缺陷或盤點結論可填）（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因

j2 判定報告（`judge-b11-tdd-j2.md`〈6. 歸因與修法建議〉建議 1）指出：b11 兩題（TDD-11d／11f）雖皆 3/3，
但三名讀者中的 j2 本人，在 11d(c)、11f(a) 兩度將同一交界（「該依賴屬流程步驟呼叫者，判定為『是』後是否
仍須檢查建構需求」）標為條文歧義，即使兩處最終判定與依據句皆正確。答案鍵已寫明排他語「建構受測對象是否
需要它在此不被詢問」，但該句只存在於答案鍵、條文正向出口句本身未載明，讀者須自行從「不進入以下兩分支」
反推排他效果。此射程限定句活在判定者註而不在條文的機制，與 TDD-11c 當初失敗的機制相同。

j1 判定報告未就本點提出修法建議（其〈4.3 修法建議〉僅涉及題目側「自行假設」界定與 11e 重測設計，未觸及
正向出口排他語）。

### 影響範圍

`.claude/skills/tdd/references/bdd-behavior-testing.md`〈判定不拆分 Module〉條件 2 判定順序句（第 169
行，單一長句）。僅正向出口句尾一處新增，不涉及其他行。

### 相關 Error Pattern

無新增；沿用 W3-488／W3-490 同一節的判定機制與復驗流程。

## Solution
<!-- Schema[DOC/Solution]: 免填（DOC 類型以變更摘要取代）（.claude/pm-rules/ticket-body-schema.md） -->
### 變更檔案

`.claude/skills/tdd/references/bdd-behavior-testing.md`〈判定不拆分 Module〉條件 2（唯一改動行）。判準
內容不變，僅在正向出口句尾補一句既有排他語的明文化。

### 前後對照

- 改前：「判定為『是』時，該行直接計入 Given 設置行數，不進入以下兩分支；判定為『否』時，才依序檢查
  兩分支：」
- 改後：「判定為『是』時，該行直接計入 Given 設置行數，不進入以下兩分支——建構受測對象是否需要它在此
  不被詢問；判定為『否』時，才依序檢查兩分支：」
- 措辭逐字取自 j2 判定報告〈6. 歸因與修法建議〉建議 1 的建議句，未另行改寫。

### 出處表

| 修改點 | 出處 | 讀法是否改變 |
|---|---|---|
| 正向出口句補排他語 | j2 判定報告〈修法建議〉建議 1（j1 判定報告未提出本項修法，其〈4.3 修法建議〉僅涉及題目側界定與 11e 重測設計） | 否——「不進入以下兩分支」本就等同「建構是否需要它不再是判定依據」（分支 (1)(2) 才會檢查建構需求），新句只是把既有排他效果從隱含改為明文，未新增或變更判準 |

### 措辭重疊登記

新增句「建構受測對象是否需要它在此不被詢問」逐字取自答案鍵既有措辭（`grep -rl` 命中
`key/W3-417-b11-tdd-1.md`、`key/W3-417-b10-tdd-1.md`，以及 j2 對 b8／b11 兩批判定報告的引用）。此措辭
原本只存在於答案鍵、條文未載明，即本票修法標的本身；納入條文後，答案鍵與條文正向出口句在此交界的用字
將完全一致。

**受影響題號**：TDD-11d(c)、TDD-11f(a) 型子問（正向出口分支：依賴屬流程步驟呼叫者、建構是否需要它不
再是判定依據）。此類子問下一輪重測時，讀者可直接從條文逐字覆誦排他語作答，「是否需要從『不進入以下
兩分支』推得排他效果」這一項鑑別維度將消失；但該子問另有「是否正確判定該依賴屬流程步驟呼叫者、是否
正確計入行數」等其餘鑑別維度不受影響。此重疊為本票修法的直接且預期效果（消解 j2 記錄的歧義來源），非
意外繼承其他題材，故不視為需另立豁免或改寫的問題，僅依 W3-417 規則登記受影響題號供下一輪出題參考。

### 條件 2 全句長度評估（僅記錄，未動手重構）

補句後條件 2 仍為單一長句（約 1450 餘字元，含判定順序、正向出口、兩分支、回程指標四層）。此長句體量在
W3-488／W3-490 兩票已由判定者記錄「已是單一超長句」「邊際收益為負」，本票依派工方指示僅加此一句、不
重構。就可讀性主觀評估：新增句以破折號另起一個從屬子句，未改變既有的巢狀邏輯結構，插入點在正向出口
分支的句尾（非句中），閱讀時的斷句位置與既有「不進入以下兩分支」處一致，未額外增加巢狀深度。**建議**
（不動手）：若未來仍有新交界待補，本段落應考慮拆為條列式（判定順序 / 正向出口 / 分支 (1) / 分支 (2) /
回程指標各自成行），而非持續在單一句內插入子句；本次因派工範圍限定僅此一句，不在本票執行。
