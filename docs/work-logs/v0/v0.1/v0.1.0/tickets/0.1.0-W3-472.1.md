## Problem Analysis
### 問題根因

W3-472 修 doc 第 5 批讀歪點時，DOC-19a（組合規則「作為表格或列表一欄時」可否填內距）因查無非範例出處未落檔，轉草稿交本票評估。

**事實更正（本票查證）**：W3-472 NeedsContext 記「該定義原僅存在於已刪範例（commit 4aec4afc5 引入，後續風險 13 清理時移除）」。實測 HEAD 該範例仍在，未被移除——`git grep -Fn "內距是元件邊界內部的空間" HEAD -- .claude` 命中 `.claude/skills/doc/examples/component-library-chained-examples.md:601`，節名〈組合規則「作為表格或列表一欄時」內距與「不得另定間距」的分界〉亦仍在（第 577 行），範本第 357 行的範例路由句指得到，非斷鏈。正確描述是 W3-417 既有的風險類別「依據只在範例內」，不是「依據已被刪除」。兩者處置相反：前者把既有依據提升為條文（範例留作示範），後者要重新起草依據。本票依前者辦理。
