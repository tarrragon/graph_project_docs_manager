## Problem Analysis
### 問題根因

舊帶入判準為一句：「逐輪檢查兩題的依據句是否互相複製（**引句組合或推理措辭**）」。三個獨立缺陷疊加：

| 缺陷 | 後果 |
|---|---|
| 兩個獨立訊號（引句組合／推理措辭）併在一句、以「或」連接、皆無門檻 | 判定者各自取其中一個訊號即可下結論；兩人取不同訊號即得相反判定 |
| 「引句組合複製」未扣除結構性重疊 | 兩題正解同落第五列，引用同一行是**題目設計要求的結果**。此訊號對正常情形恆真，鑑別力趨近零（`test-assertion-design-rules` 規則 E2 所述「守衛的失效方向是放行，而放行與輸入本來就沒問題在輸出上同形」的鏡像） |
| 「推理措辭複製」無可核對的字面依據 | 「同一句式模板」須判定者主觀比對，相似度閾值因人而異 |

兩位判定者的分歧正是這三個缺陷的直接結果：j1 主要用引句層訊號（截點、超量末句），j2 主要用措辭層訊號（句式模板、共用補語），且 j2 對 r3 明寫「引句重疊屬結構性」而扣除該訊號——兩人各自只覆蓋一半。

### 相關 Error Pattern

`test-assertion-design-rules` 規則 E2（守衛的測試必須含正向對照輸入）在本票的對應形態為**鑑別力複驗**：一個帶入訊號若對每一組配對都命中，它與「沒有訊號」等價。本票因此對全卷 12 個子問的 198 組配對實跑，證明訊號 1 在最寬門檻下仍有 83% 的配對不命中。舊判準從未做過此複驗，其「引句組合複製」一項實測即屬恆真型。

`PC-165`（測試綠燈不等於 runtime 正確）的對應形態為「兩位判定者計分逐題一致，不代表判讀層一致」——b21 的計分零分歧，分歧全部落在判讀層，而判讀層決定的是有效樣本數本身。
