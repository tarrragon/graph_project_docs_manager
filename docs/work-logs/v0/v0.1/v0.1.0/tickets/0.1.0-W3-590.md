# Execution Log

## Task Summary

b21 的帶入檢查對三輪給出兩組相反判定：j1 判 r1「否」（截取範圍隨各自判定而異）、r2「是」、r3「是」（引句逐字全等且截點相同）；j2 判 r1「是」（推理措辭同一句式模板、兩題都附加依據句中未被引用的同一補語）、r2「是」、r3「否」（引句重疊屬結構性、輸出分支相反故無模板沿用）。分析判準「依據句是否互相複製（引句組合或推理措辭）」的歧義點並改寫為可逐條機械核對的形態

## Problem Analysis
### 問題根因

舊帶入判準為一句：「逐輪檢查兩題的依據句是否互相複製（**引句組合或推理措辭**）」。三個獨立缺陷疊加：

| 缺陷 | 後果 |
|---|---|
| 兩個獨立訊號（引句組合／推理措辭）併在一句、以「或」連接、皆無門檻 | 判定者各自取其中一個訊號即可下結論；兩人取不同訊號即得相反判定 |
| 「引句組合複製」未扣除結構性重疊 | 兩題正解同落第五列，引用同一行是**題目設計要求的結果**。此訊號對正常情形恆真，鑑別力趨近零（`test-assertion-design-rules` 規則 E2 所述「守衛的失效方向是放行，而放行與輸入本來就沒問題在輸出上同形」的鏡像） |
| 「推理措辭複製」無可核對的字面依據 | 「同一句式模板」須判定者主觀比對，相似度閾值因人而異 |

兩位判定者的分歧正是這三個缺陷的直接結果：j1 主要用引句層訊號（截點、超量末句），j2 主要用措辭層訊號（句式模板、共用補語），且 j2 對 r3 明寫「引句重疊屬結構性」而扣除該訊號——兩人各自只覆蓋一半。

### 相關 Error Pattern

`test-assertion-design-rules` 規則 E2（守衛的測試必須含正向對照輸入）在本票的對應形態為**鑑別力複驗**：一個帶入訊號若對每一組配對都命中，它與「沒有訊號」等價。本票因此對全卷 12 個子問的 198 組配對實跑，證明訊號 1 在最寬門檻下仍有 83% 的配對不命中。舊判準從未做過此複驗，其「引句組合複製」一項實測即屬恆真型。

`PC-165`（測試綠燈不等於 runtime 正確）的對應形態為「兩位判定者計分逐題一致，不代表判讀層一致」——b21 的計分零分歧，分歧全部落在判讀層，而判讀層決定的是有效樣本數本身。

## 重現實驗結果
### 實驗方法

以 b21 的三輪作答（`a/W3-417-b21-doc-1-r{1,2,3}.md`）、題目檔（`q/W3-417-b21-doc-1.md`）與兩份判定書為材料，不重跑探針、不改條文。兩支新器材對答卷直接解析，判定者不重打字串：

| 器材 | 用途 |
|---|---|
| `tools/carryover_check_b21.py` | 訊號 1 對受測對（DOC-19d × DOC-19c(a)）逐輪機械核對 |
| `tools/carryover_control_b21.py [MIN_LEN]` | 訊號 1 對全卷 12 子問兩兩配對（198 組），供噪音門檻扣減與鑑別力複驗 |

**訊號 1「共用未引用詞」的機械定義**：字串 `t` 為某子問的未引用詞，當 `t` 逐字出現於該子問**判定**欄、且逐字不出現於該子問**依據句**欄全文、且逐字不出現於該子問**題幹**。兩題的未引用詞集合取交集後取極大字串。

### 實驗執行

**第一步：受測對逐輪跑訊號 1。** `python3 tools/carryover_check_b21.py`，RC=0：

| 輪 | 共用未引用詞（極大） | 長度 |
|---|---|---|
| r1 | 「的排列不變式」／「最小間距」 | 6／4 |
| r2 | 「循判別問句判定」 | 7 |
| r3 | 「判定步驟應先確認兩個」 | **10** |

**第二步：鑑別力複驗（規則 E2 的正向對照）。** `python3 tools/carryover_control_b21.py N`，RC=0：

| MIN_LEN | 命中配對數／總配對數 | 受測對命中的輪 |
|---|---|---|
| 3 | 33 / 198 | r1、r2、r3 |
| 5 | 19 / 198 | r1、r2、r3 |
| 7 | 8 / 198 | r2、r3（r1 的 6 字串被門檻濾掉） |

**第三步：噪音層辨識。** 命中數 >= 3 的字串全數為全卷層級的答題格式或當輪詞彙習慣，逐字為：「不成立」「撰寫者的主張不成立」「可以填在」「不可以填在」「格位契約承載」。這些字串與特定一對無關，構成噪音門檻的扣減對象。

**第四步：訊號 2（引文層）人工逐段核對。** 扣除結構性必引段（第五列條件欄／該題所選分支的值段／判別問句）後的候選段，逐段以「段內所有 >=4 漢字實詞是否出現於該題判定欄」判定無作用：

| 輪 | 19d 候選段 | 19c(a) 候選段 | 共用無作用段 |
|---|---|---|---|
| r1 | 無（截於分支一，全部為結構性必引） | 分支二段（判定欄以條件子句用到，非無作用） | 無 → 不命中 |
| r2 | 末句「兩端各自的組合規則均不得另定這段間距。」（19 字） | 同一末句 | **有** → 命中 |
| r3 | 分支二段（無作用） | 分支一段（判定欄含「共同上層」，非無作用） | 兩段不同 → 不命中 |

### 實驗發現

**已驗證的事實：**

1. **訊號 1 具鑑別力**：最寬門檻（MIN_LEN=3）下仍有 165／198 組配對不命中，訊號不是恆真。
2. **三輪受測對在 MIN_LEN=5 皆命中，且三個命中字串的同輪配對命中數皆為 1（僅受測對）**，全數通過噪音門檻。
3. **兩位原判定者各漏一半**：j1 漏掉 r1 的「的排列不變式」（措辭層），j2 漏掉 r3 的「判定步驟應先確認兩個」（10 字逐字共用，措辭層——j2 以「輸出分支相反」為由判否，但該理由屬分支內容，不能反證措辭未被沿用）。
4. **命中不等於不可判讀**：共用成分落在哪裡決定效力。r1 的「的排列不變式」與射程判定表第一列承載者值「容器的排列不變式（最小間距）」逐字重疊 6 字，屬**判定路徑**；r2 的「循判別問句判定」與 r3 的「判定步驟應先確認兩個」皆為**作答程序敘述**，與承載者指派無字面關係。
5. **MIN_LEN=5 為可操作門檻**：MIN_LEN=7 會濾掉 r1 的 6 字命中，而該字串正是 j2 判定 r1 帶入的逐字依據；MIN_LEN=3 會讓 4 字條文通用詞（「最小間距」「容器元件」）進入，該類詞兩題可各自獨立自節錄檔取得，不構成共用內部狀態的證據。

**仍未驗證的假設**：新判準的跨批穩定性。本票只對 b21 一批回測；門檻值（5 字、命中數 <= 2、10 字無作用段）在其他批次是否同樣分離出受測對，未測。

## Solution
### 分析結論

帶入判準改寫為**兩個獨立訊號＋兩個門檻＋一個分型**，全文落於 `probes/w590-judgelayer-manifest.md` 第一節，供下批逐字併入。

| 項目 | 內容 |
|---|---|
| 訊號 1（措辭層） | 共用未引用詞——`t` 出現於判定欄、不出現於自列依據句、不出現於題幹；兩題取交集 |
| 訊號 1 門檻 A（長度） | 極大字串 >= **5 漢字**。4 字以下多為條文通用詞，兩題可各自獨立取得 |
| 訊號 1 門檻 B（噪音） | 該字串在同輪全卷兩兩配對的命中數 <= **2**。>= 3 者為答題格式或當輪詞彙習慣 |
| 訊號 2（引文層） | 共用無作用引文段——扣除結構性必引段後，存在兩題逐字全等、>= **10 漢字**、且對兩題皆無作用的同一段 |
| 結構性必引段（不列入候選） | 第五列條件欄／該題所選分支的值段／判別問句 |
| 合成 | 任一訊號命中即判「是」，兩訊號須**各自登記**（合併成一句正是舊判準的失效原因） |
| 分型甲（判定路徑帶入） | 共用成分與第五列任一分支的承載者指派句、或射程判定表任一列的承載者值，有 >= 3 漢字逐字重疊 → 該輪**不可判讀** |
| 分型乙（程序措辭帶入） | 其餘命中 → 該輪**可判讀**，但須逐輪登記乙型並在結論標明 |

**分型的必要性**：帶入命中只證明兩題作答之間有非獨立產生的成分，不自動證明分支選擇非獨立。不分型會讓一句程序措辭的回音銷毀整輪分支讀數；不設甲型則承載者指派本身被複製時仍會被當成獨立讀數採計。

### 四格重寫（並同 `0.1.0-W3-589`）

四格失效的根因是**把「通過與否」當成「選對分支」的代理**，而通過是 (選對分支) AND (輸出收斂) 的合取；r3 逐字否證該代理（19c(a) 已斷言分支二核心成分「該處缺一個容器元件」，卻因承載者選言含「頁面根堆疊」記不通過）。

修法：**拆兩軸**。軸一為分支輸出對（四值：分支一／分支二／併陳／未取第五列），六列判讀表取代四格，**表中無任何一列以通過與否為條件**；軸二為通過與否，只用於計分與失分歸類，禁止參與分支判別推論。「併陳」與「承載者選言」的分界只看**分支條件是否被斷言**，不看承載者有幾個候選。全文見 `w590-judgelayer-manifest.md` 第二節。

**不採「補第五格」**：四格仍以通過與否為軸，補格等於為每一種新出現的失分形態各補一格，格數無上限增長；且第五格仍無法表達「兩題輸出相反分支」——那是兩題之間的**關係**，四格的軸上沒有它的位置。

### 不可判讀的正式定義與作廢門檻

**不可判讀是器材看不到，不是讀者沒做。** 僅兩型：帶入-甲型、缺件型（缺判定欄或依據句欄，或依據句未引任何本批餵入節錄檔的文字）。**併陳、未取第五列、分支極性讀反三者不是不可判讀**——它們是關於讀者行為的讀數，計為不可判讀等於把觀測到的事實登記成沒觀測到。

| 有效輪數（三輪批次） | 處置 |
|---|---|
| 0 或 1 | **整批作廢**，只保留形態登記與帶入訊號登記 |
| 2 | 讀數可用，但結論須兩輪方向一致；不一致降為形態登記 |
| 3 | 2/3 以上一致即可下該方向結論 |

一般化（n 輪）：**有效輪數 < ceil(2n/3) 即整批作廢。**

### 設計層張力的回應

**張力**：配對判讀需要同批，同批製造帶入。

**前提被誤述，故張力可解**。兩項生效條件的實質是「同一份節錄檔（同 sha256）」與「同一條文 HEAD」，**同批只是這兩者的充分條件、不是必要條件**，兩者皆已由 `build_excerpts.py` 與 `verify_head.py` 獨立機械保證。

**帶入的真正來源是派發形態，不是配對形態**。b21 為單次請求答全卷（`probe_answer_format_b21.md` 一檔六題、題序固定），題目檔規則 5 明寫「同一題的各子問互相獨立…不得以另一個子問的填法、缺漏或結論作為本子問的理由」——**這條規則的存在即證明器材已知跨題污染會發生，而現行處置只是以文字勸阻，等同把防護放在被測者手上**。

| 形態 | 帶入 | 保留的證據形態 | 代價 |
|---|---|---|---|
| 1. 同批、逐題獨立 context | 結構性消除 | 失去「同一實例對兩題輸出相反分支」（b21 的 r3 即此形態） | 請求數 × 題數 |
| 2. 跨批配對（sha256 + HEAD + model 三者相同） | 消除 | 同上失去 | 批間變異進入讀數 |
| 3. 同批同 context（現行）+ 甲乙分型 | 事後偵測，甲型輪作廢 | 保留最強形態 | 每輪須跑帶入檢查 |

**建議**：同一批同時跑形態 1（主讀數）與形態 3（對照），兩組讀數之差即帶入幅度——帶入由「污染」變為**被量測的量**。此即 `opinionated-default-design` 的直接套用。已成票 `0.1.0-W3-600`。

**誠實的邊界**：**帶入不能由判準完全隔離。** 判準能做的是把不可隔離的部分縮小到甲型；乙型的分支讀數仍帶一個未被排除的替代解釋（讀者沿用程序措辭時是否也沿用了分支選擇），該替代解釋只能由派發形態消除。

### 歧義點拆解為具名訊號（acceptance 2）

舊判準的括號「（引句組合或推理措辭）」是唯一的訊號說明。拆解後四個具名訊號逐一給出處置——**兩項採用、兩項明文否決**，否決本身是判準的一部分（未明文否決即等於留給判定者自行決定，b21 的分歧正出於此）：

| 具名訊號 | 處置 | 門檻／理由 |
|---|---|---|
| **1. 引句集合**（兩題引用的條文段落集合是否相同） | **否決，不得單獨採計** | 兩題正解同落第五列，引用同一行是題目設計要求的結果。對正常情形恆真，鑑別力趨近零。改以**扣除結構性必引段後的殘餘**（訊號 2）取代 |
| **2. 截點**（兩題引用同一行時的起訖位置是否相同） | **否決，不得單獨採計** | 截點相同可由「兩題選同一分支」與「兩題都整行照搬」兩種相反成因產生，其一是被測變數本身。j1 在 r3 採計截點相同、j2 不採計，即此訊號無定義所致 |
| **3. 未被依據句支持的補語**（出現於判定欄、不出現於自列引文、不出現於題幹的字串） | **採用（訊號 1）** | 兩題取交集後取極大字串；門檻 A 長度 >= 5 漢字，門檻 B 同輪全卷兩兩配對命中數 <= 2。由 `carryover_check_b21.py` 與 `carryover_control_b21.py` 機械產出 |
| **4. 輸出分支是否相同** | **否決，且為必須否決的一項** | 分支選擇正是本配對要測的變數。以它作帶入判準會使「19c(a) 失分形態 (i)（與 19d 同落分支一）」的每一輪自動判為帶入、自動不可判讀，第二格與第三格永遠讀不到——判準吃掉被測量 |
| **5. 共用無作用引文段**（本票新增，不在原四項內） | **採用（訊號 2）** | 扣除結構性必引段（第五列條件欄／該題所選分支的值段／判別問句）後，存在兩題逐字全等、>= 10 漢字、且對兩題皆無作用的同一段 |

**訊號 1 與訊號 2 為兩個獨立訊號，各自登記、任一命中即判「是」。** 舊判準以「或」把訊號 1 的前身與訊號 2 的前身併為一句，是分歧的直接成因。

**訊號 4 的否決另有一個副作用須明記**：否決之後，「兩題同落分支一」不再自動作廢，而是落在新判讀表第二列（與單一輸出模板不可分辨）——它變成一個**讀數**而非一個**作廢理由**。這是兩軸分離（`0.1.0-W3-589`）在判準層的對應面。
