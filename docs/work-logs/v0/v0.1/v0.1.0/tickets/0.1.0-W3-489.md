### 四處前後對照

### 1. 兜底句升格為射程判定表第五列（`component-library-bidirectional-constraint-methodology.md`〈容器亦為元件〉）

改前（表外散文句）：
「兩端皆非上列四種組合者（如兩個容器之間），對兩者的共同上層重問一次同一判別問句，由該層承載。」

改後（表內第五列，三欄對齊，接續既有四列）：
「皆非上列四種組合（如兩個容器之間）｜對共同上層重問一次本節判別問句，由該層承載｜本節判別問句段」

表外不再另存散文版。

### 2. 內容角色補計數單位（`component-library-spec-template.md`〈條目標頭與內容角色〉）

判定順序引言最末段新增：「本欄填的是角色類別，同一角色不因由多個內容部分或多個 slot 承載而重複計列」，
與既有「角色與 slot 不必一一對應：同一角色可由多個 slot 承載」同向並列，緊接於其前。

### 3. 判定順序改編號兩步 + 可操作辨識法

改前：判定順序以連續散文表述（「判定順序：先問……成立者直接歸同一角色……不成立時才逐一問……」）。

改後：拆為「步驟 1」「步驟 2」兩段。步驟 1 內補「判準：兩部分的值同步變動、且取自同一個量或同一次量測者，
即為描述同一件事」可操作辨識法；原「拿掉任一部分，另一部分仍完整表達」句保留，標為「可操作驗證」附註。

### 4. 佔位符路由句改向

改前：`{標題 / 內文 / 標籤 / 數值 / 動作 / 容器；複合角色判定見下方引言}`（只指向「何時並列」）

改後：`{標題 / 內文 / 標籤 / 數值 / 動作 / 容器；先判斷多個內容部分是否合併為同一角色，再判複合角色，兩者見下方引言}`
（先指向「何時合併」，再指向複合角色判定）
