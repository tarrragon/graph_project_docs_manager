## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### 修復方式

新增 lib/components/segmented_control.dart：`SegmentedControl`（StatelessWidget，
segments/selectedIndex/onChanged 三個 slot）+ `SegmentItem`（label/semanticLabel/testKey）。
命名注意：契約原文欄位型別 `Segment` 與 `package:flutter/material.dart` 內建
`Segment<T>`（`SegmentedButton` 用）撞名，改名 `SegmentItem` 避免同檔匯入歧義，
語意不變（已於檔頭 doc comment 記錄本次命名差異）。

實作要點：
- 軌道底 `AppColors.surfaceSegmentTrack`（Radius.md），段選中底 `surfaceBase`、
  字 `accentStrong` 半粗（FontWeight.w600）；未選段透明底、字 `textPrimary`
  （皆依 SPEC-004 §4.0.2 表 1 已核定對比值，無新色）。
- 命中高度 `LayoutSize.hitTargetMin`；段內距 `Space.md`（水平）/`Space.xs`
  （垂直）；軌道內距 `Space.xxs`；段間距 `Space.xxs`。
- 已選段 `onTap` 傳 `null`（InkWell 停用點擊但不做 disabled 視覺，語意為
  「無狀態改變」而非停用態，符合 4.10 互動反應表）。
- 焦點裝飾依 §4.0.1：`DecoratedBox` 邊框僅聚焦時可見（`AppColors.accent`）。
- 無障礙：`Semantics(button, label, hint, selected)` 包外層，內層 `Text`
  以 `ExcludeSemantics` 排除（否則 Text 自身語意會與外層 label 合併為
  「矩陣\n矩陣」重複，測試過程中發現並修正）。
- 每段包 `Flexible`：段的固有寬度契約在無父層約束時可放任成長；當放入
  有限寬度容器（如 `SplitRow.header` 右格）時才需截斷，`Flexible` 讓
  `TextOverflow.ellipsis` 在有限寬度下生效，同時避免無約束時觸發
  `RenderFlex` 溢位（測試 `TestCopy.longToken` 案例以 `SizedBox(width: 200)`
  模擬容器限寬）。

components.dart 依既有慣例（字母序）於 `section.dart` 後插入一行
`export 'segmented_control.dart';`，未重排既有行。
