# Execution Log

## Task Summary

評估 UX-09a「明顯」正向定義第二版：與畫面實際按鈕比較，且填色文字 chip 仍合格

---

## Problem Analysis
### 問題根因

W3-457.2 的第一版草稿以「構成要素」絕對判定（文字或圖示＋區塊，缺任一項即屬 (a)），推導結果是填色文字 chip 不屬 (a)。用戶裁示（W3-417〈UX-09a 定義第二輪用戶裁示〉）否決此結論：U1 填色文字 chip 仍屬合格；U2 判定時與同一畫面上實際的按鈕比較，不單獨判定指示本身；U3 例示措辭用「不加底色與外框的純文字」。

第一版不能讓 chip 合格的直接原因：填色 chip 與按鈕的構成要素相同（都有文字、都有區塊），兩者剩下的差別是底色深淺、圓角、尺寸。前兩項落在理由句「描邊 vs 實心不是可靠的互動性訊號，不能單靠外觀圓角或邊框區分」的排除範圍內。因此第二版若要讓 chip 合格，必須在構成要素之外另立一個不屬描邊、實心、圓角、邊框的比較軸。本票的候選軸為區塊高度，依據是用戶指定的判否反例本身以「尺寸與按鈕相同」為特徵。

### 影響範圍

- `.claude/skills/ux-design-evaluation/references/interaction-feedback-component-semantics.md`〈六項判準〉第 2 項，與同檔〈三段鏈式範例：第 2 項——非互動指示與按鈕形態的判斷〉
- W3-417 探針答案鍵：b2、b2x 批 UX-09b 預期判定句的補救建議；b2y、b2z 批 UX-09a 引文⟪(a) 明顯非按鈕形態（文字 chip、圓點）⟫與判定者註；scratchpad `probes/excerpt/` 六項判準節錄檔

已驗證：第 2 項現行全文（HEAD）；鏈式範例第 2 項輸入未寫「刪除」按鈕的形態與 chip 的高度；UX-09a（b2z 題幹）與 UX-09b（b2x 題幹）原文；答案鍵四處引用 chip 的位置；`.claude/` 內「文字 chip」字樣只出現在本檔第 2 項與鏈式範例第 2 項。
未驗證：落檔後 UX-09a 重跑結果；主流設計系統 chip 高度一般低於按鈕（依知識，未用工具核對，本草稿不以此為依據，改在定義內直接寫明 chip 的高度條件）。
