**改動 1（本體）**：〈產物欄的五種合法答案〉「待定」列「何時使用」欄，於既有禁令句之後插入一句。

改前（該欄全文）：

> 該維度**該判而未能判**：權威缺席，或說不出它要防的失效在本專案長成什麼樣子。**判不出來一律填「待定」，任何情況下都不得以「無」代之**。權威存在但無可用部分屬判準層，另標「無判準」，單獨不構成填「待定」的理由（見〈權威缺席時〉）——那是判準層的結論，不是產物欄的答案，兩層分開填

改後（插入句以粗體標示位置，前後兩句一字未動）：

> 該維度**該判而未能判**：權威缺席，或說不出它要防的失效在本專案長成什麼樣子。**判不出來一律填「待定」，任何情況下都不得以「無」代之**。**本列的合法答案是「待定：缺 `<什麼>`（補票 `<ticket-id>`）」整串，「待定」二字單獨不是答案**——沒有票號的「待定」與填「無」一樣不會有人回來補，差別只在它自稱未完；票在答這一格的當下就建，三段缺任一段者該格視同未填。權威存在但無可用部分屬判準層，另標「無判準」，單獨不構成填「待定」的理由（見〈權威缺席時〉）——那是判準層的結論，不是產物欄的答案，兩層分開填

「必須附帶」欄未動：`缺的是什麼 + 一張補它的票；該維度的地基票 blockedBy 它`。

**改動 2（一致性連帶）**：〈權威缺席時〉「權威是框架資產但執行本流程的 session 未安裝」列的字面示例。

改前：`產物欄填「待定：權威缺席」，**不得填「無」**。`
改後：`產物欄填「待定：權威缺席（補票 <ticket-id>）」，**不得填「無」**。`

理由：改動 1 定義的合法答案含補票號，該處原示例若不補即成為新形態下的不完整實例，兩處相牴觸。既有子字串「待定：權威缺席」保留，屬插入不屬改寫。

版號：`metadata.version` 6.6.24 → 6.7.0；`CHANGELOG.md` 同批新增 6.7.0 條目（依 reference-stability 規則 8，框架檔案內不寫票號，來源改記日期與描述性標籤）。

### 方向選擇與理由

兩條可行方向中採**「前半不可獨立取用」**，不採「為必附項加第二載體」。

理由是兩者消除的東西不同層級：加第二載體只提高必附項被抄到的機率，而 W3-628 觀測到的那個狀態——**產物欄答對、必附項缺席**——仍然是一個可表達的狀態，下一輪仍可能出現，只是機率較低。把合法答案定義為含缺口與補票號的整串之後，該狀態不再可表達：答對與附齊是同一個動作，寫不出補票號就等於這一格沒答。守衛的失效方向是放行（鑑別力規則 E2），能把失效狀態變成不可表達的手段優先於降低其機率的手段。

附帶效果是它同時也構成第二載體（必附項的內容現在同時出現在「何時使用」欄與「必須附帶」欄），但那是結果不是目的。

### 四條紀律的逐條對照

1. **插入不重組**：兩處改動皆為插入，既有句子零刪除、零改寫；表格無編號款次，既有粗體字串（「判不出來一律填『待定』，任何情況下都不得以『無』代之」、「待定：權威缺席」）原樣保留，可繼續作引用錨點。
2. **未增加「何時使用」欄的冗餘**：新增句的內容是必附項（缺口＋補票號），不是觸發條件。觸發條件的既有三處載體（本列禁令句、同節「『無』與『待定』是本表最容易填錯的一組」整段、`references/dimension-product-notes.md` 的「答不出時標『待定』」）數量與文字皆未動。
3. **方向擇一並寫明理由**：見上節。
4. **交互作用原樣保留**：低套用率不全歸條文。同輪子問已依零洩題複核刪去「且必須附帶什麼」，另一半成因屬測驗設計，兩者在 W3-628 的資料上無法分離。本票的改動記錄（含 CHANGELOG 6.7.0 條目與 `probe-known-limitations.md` L46）皆逐處寫出這一點，未把該低讀數寫成純條文缺陷。
