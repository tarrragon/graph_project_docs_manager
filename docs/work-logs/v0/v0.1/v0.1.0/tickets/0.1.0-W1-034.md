### 基座 API（`test/helpers/helpers.dart` 單一入口）

| 模組 | API | 用途 |
|------|-----|------|
| `window_sizes.dart` | `WindowSize.min` / `WindowSize.design`、`setWindowSize(tester, size)`、`testWidgetsAtEachSize(desc, (tester, size) async {...})` | 兩種測試尺寸（SPEC-004 §1 核定，引用 `kMinWindowSize` 960x640 / `kDesignSize`），每尺寸各註冊一支 testWidgets，測試名帶尺寸標籤 |
| `pump_harness.dart` | `pumpHarness(tester, child:, overrides:, size:, locale:, disableAnimations:, settle:)` → `ProviderContainer` | 單一呼叫完成「狀態注入 + App 同構外殼渲染」；`overrides` 即 `ProviderScope.overrides` 狀態注入點；回傳 container 供 `read` 觀察狀態轉換 |
| 同上 | `pumpApp(tester, size:, locale:, overrides:)` | 以真實 `DocsManagerApp` 起導覽殼 |
| 同上 | `pumpContract(tester, Motion.xxx)`、`expectNoOverflow(tester)`、`kTestLocales` | 假時鐘推進的具名入口；溢位斷言前移；zh/en 兩語系集合 |
| `anchors.dart` | `Screen`（六頁 + `switcher`）、`Anchor.state/action/mode/scroll/drag/badge/panel/card/cell(screen, name)`、`Anchor.navItem/navPage/projectSwitcherEntry`、`AnchorFinder.*` | 依 SPEC-003 §2.9 組 Key / Finder，`<screen>` 取 `AppDestination.name` |
| `test_copy.dart` | `TestCopy.longZh/longEn/longToken/nodeTitle/.../gapDescription`、`TestCopy.longCopies` | SPEC-004 §4.0.4 表的 Dart 形式 |

外殼順序 `ProviderScope → ScreenUtilInit(kDesignSize) → MaterialApp(l10n) → MediaQuery(disableAnimations) → Scaffold(body)`，與 `lib/main.dart` 同構，`.w/.sp`、`AppLocalizations`、`Motion.*(context)` 求值與正式執行一致。

### 示範測試（`test/widget/harness/`）

- `state_injection_demo_test.dart`：以本檔私有的最小狀態替身 + `StateProvider` 注入，逐列斷言 SPEC-003 §4 #3 正常·矩陣、#8 schema 不相容（阻擋態：浮層入口 enabled、`action-domain-schema-detail → panel-domain-schema-detail`）、#2 載入中（`settle: false`；`action-domain-cancel-load` → `pumpContract(Motion.cancelDeadline)` → #1 `state-domain-unset`，並經 container 讀回狀態）。
- `component_matrix_demo_test.dart`：元件票寫法範本「全變體 × 兩語系 × 三條最長文案 × 兩尺寸」（24 支）、`disableAnimations` 透過 MediaQuery 抵達元件、`pumpApp` 起真實 `AppShell` 兩尺寸不溢位。

### 與票面的落差

- acceptance 第 2 條「四種視窗尺寸」：票面建立時依 `integration_test` 的 `kViewports`；SPEC-004 §1（2026-09-02 核定）定元件 widget test 尺寸集合為兩種（`kMinWindowSize`、`kDesignSize`），不加第三種。基座依 SPEC-004 提供兩種，最小尺寸 960x640 條件成立；四尺寸仍由 `integration_test/app_test.dart` 承載畫面級整合驗收。
- 職責註記：本票由測試建築師執行 `test/` 下基座撰寫（PM 派發），不含任何 `lib/` 元件實作。
