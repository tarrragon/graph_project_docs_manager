### Task Reference

### Rationale Chain
- 0.1.0-W3-094 why: 實機執行時側欄的導覽項文字**上下被裁切**：工作區名「graph_proje…」字形頂部被切、六個導覽項的中文字（Domain 視圖／UC Flow／追溯視圖／Ticket 清單／破洞報告／節點詳情）字形上下緣皆有裁切。用戶目視發現（2026-09-08）。

機制（PM 已讀原始碼確認）：`nav_item.dart` 外層為 `SizedBox(height: LayoutSize.hitTargetMin)`（token 值 28），內層 `Padding(vertical: Space.sm)`，文字可用垂直空間為 28 減去兩倍 `Space.sm`。中文字形的 ascender／descender 範圍比拉丁字母高，在此餘裕下超出容器。

**測試為何全綠**：`SizedBox` 對超出的子項是**靜默裁切**，不拋 `FlutterError`；而 `expectNoOverflow`（`test/helpers/pump_harness.dart:124`）的實作是 `expect(tester.takeException(), isNull)`——它只能攔截會拋例外的 `RenderFlex` overflow。`nav_item_test.dart` 有八個以上的「不溢位」測試（含 zh/en 六個 key × 兩種視窗尺寸），全數通過，對這個形態零鑑別力。

`hitTargetMin` 是**命中區**下界（可點區域大小），不是文字容器高度上界。把它當固定高度用，等於讓無障礙的最小點擊尺寸反過來限制排版。
