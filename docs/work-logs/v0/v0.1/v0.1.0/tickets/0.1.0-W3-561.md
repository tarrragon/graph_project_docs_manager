### 裁決一：案 C 的核心成立，但 `0.1.0-W3-553` 為它選的形態否決，改採純插入的前置關

**採案 C 的核心：把 8.2(4) 前置為不可繞過的關卡，且該關卡具終止效力。** 理由不是條文結構的美感，是讀數——8.2(4) 六輪全被引用，硬案三輪引完之後仍判它無作用。既然它已經被讀到，任何以「讓它更容易被看到」為目的的改法（換措辭、換段落、加粗、再寫一次）都不會改變任何一輪的輸出。要改變輸出，只能改變它在程序中的**執行順序**：讓它在產生終局判定的那一步之前綁定。
