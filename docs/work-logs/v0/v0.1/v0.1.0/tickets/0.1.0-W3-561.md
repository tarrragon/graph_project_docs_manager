### PM 裁決：本票與 W3-559 併案處理，且我先前的取捨已由讀數判錯

**讀數**：排除句六輪零引用；硬案子問 1 的 8.2(4) 取回 **0/3**，三輪全在第一點退出，其中兩輪正是排除句的正面標的（r1 甚至在假設句前後自相矛盾，r2 逐字寫「此差異屬 8.2(3) 清單內的『文字內容』項…故第一點不成立」＋「8.2(4) 沒有發揮關鍵作用」）。軟案 3/3 取回靠的是題幹的等同陳述，不是排除句。

**排除句在軟案不被需要、在硬案不被取回。**

#### 根因：位置，不是措辭

排除句寫在 8.2(3) **引言**。讀者判定「文字內容」時直接進 ③，不會回頭讀引言。這與本線已記錄三次的形態完全相同：

> 條文的效力取決於它在讀者的行走路徑上，不取決於它寫得多清楚。

（前三例：W3-510 讀者取字面可匹配者而非抽象規則；W3-532 讀者在表內取到可填的值即停止；W3-541 的 8.3(2) 停在 8.2 就收斂、九輪零引用。）**本次是第四例，而且是我在明知這條規律的情況下批准的。**

#### 我的取捨錯在哪裡

W3-553 評估四案時，案 C（把 8.2(4) 前置為關卡並與第二點合併）判為**條文結構最乾淨**，因翻兩道凍結題而否決，改採案 D。我批准了，並在 W3-559 記下「讓量測器材約束條文設計」的張力與 trigger。

現在讀數說話了：**案 C 之所以乾淨，正是因為它把 8.2(4) 放在讀者必經的路徑上；案 D 把同樣的內容放在路徑外，於是零引用。** 兩案的差別不是風格，就是這條規律本身。我當時把它看成「結構乾淨度」的偏好，沒有看出那正是生效與否的判準。

#### trigger 已如期觸發

W3-559 的 trigger 指定為 **W3-548 完成**——該票已 complete（`33c343c5`），兩道凍結題的最後一次用途已結束，保住它們的理由消滅。案 C 現在可用。

**本票與 W3-559 併案**：兩者是同一個問題（8.2(4) 該放在哪裡），分開處理會得到兩個各自合理而互不相容的答案。已互掛 relatedTo，W3-559 升 P1。

處置要求：以案 C 為主案重評，並須回答「若仍不採 C，8.2(4) 要放在讀者的哪一步會經過的位置」——不接受第三次把內容放在路徑外的方案。凍結題若因此翻面，逐題列出並評估重出成本，那已是可付的代價。
