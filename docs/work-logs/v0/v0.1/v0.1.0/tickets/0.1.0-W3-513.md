### 一、改後 7.2 全文（commit 11c477d79）

```
### 7.2 判定

- (1) 同一圖形在全畫面只承載一個語意。
- (2) 比較對象是畫面上所有圖形，不限指示與可點元素之間；兩個可點元素用同一圖形表達不同語意，也違反 (1)。
- (3) 「語意」指圖形代表的事物或動作，不含可點與否：同一圖形只差可點與否、代表的事物相同時，不違反 (1)。描邊與實心變體算同一圖形。語意不同指的是所指的事物或動作本身不同（例如「篩選」與「匯出檔案」）。
- (4) 本項與第 2 項各自判定，第 2 項的結論不改變本項的結論。
- (5) 兩個圖形的語意是否同一，依下列三步判，不得跳步：
  - ① 把兩端各自寫成一句。代表動作的寫成「對 X 做 Y」，X 是被作用的對象、Y 是動作；代表事物或狀態的寫成「X 的 Y」，X 是所指的對象、Y 是它的狀態、屬性或類別。兩句寫不出來就不算完成本步。
  - ② 依 ① 的兩句形態選分支，只能選一條：
    - 一句是「對 X 做 Y」、另一句是「X 的 Y」：走 (6)。
    - 兩句都是「X 的 Y」：X 與 Y 都相同才語意同一；只要有一格不同，就是兩個語意。
    - 兩句都是「對 X 做 Y」：先比 Y。Y 不同即是兩個語意，到此為止，不再比 X；Y 相同而只有 X 不同時，動作本身相同，屬語意同一。
  - ③ ① 的兩句之外的任何相似都不構成語意同一，下列三者皆不得作為判語意同一的理由：共用同一個名詞（該名詞須在兩句落在同一格才算數）、同屬一個主題或功能領域、兩端各自與同一個第三方圖形語意同一。
- (6) 一端是狀態指示、另一端是造成、設定或解除該狀態的動作時，代表的事物相同（例如「已套用篩選」的指示與「開啟篩選面板」的按鈕）。本款只在 (5)② 的第一條分支下可用；兩端都是動作時一律回 (5)② 的第三條分支，不因兩端各自與同一個狀態指示語意同一而彼此語意同一——造成某個狀態的動作與解除該狀態的動作，動作本身不同，是兩個語意。本款所稱造成、設定或解除該狀態的動作，須是該狀態成立與否會隨這個動作改變者；動作改變的只是該狀態的參數——程度、數量、設定值等該狀態成立之後才有的屬性——而該狀態成立與否不隨它改變時，不屬本款所稱的動作，本款不成立。
```

耦合改動：7.4(2) 對 7.2(3) 的引用已失效（該句的「動作施加不同對象、動作本身相同」判準已移入 7.2(5)②），改為「兩者都是『對 X 做 Y』形態，Y 相同（分享）而只有 X 不同，依 7.2(5)② 動作本身相同、語意同一，不違反 (1)」。7.4(1) 不受影響（未引用具體條號）。
