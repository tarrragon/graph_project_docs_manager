## Problem Analysis
### 問題根因

`0.1.0-W3-575`〈選款能力計數〉表末列把「條文 ／ 主張 ／ 哪一 ／ 寫出 ／ 這兩 ／ 的內 ／ 為兩 等」一併記為「多處／分散／無選款能力」。`0.1.0-W3-584` 的機械復驗與本票的獨立復驗一致：**「主張」全節錄 1 次、「條文」2 次，兩者全部落在 8.2(3)⑤ 的同一行，選款能力為唯一**；「哪一」5、「寫出」7、「這兩」3、「為兩」3 維持分散。

一個命中被記為「分散」即在逐題判定的選款步被略過，被記為「唯一」則須逐題檢查三步是否齊備。表列失準的方向是**低估通路數**。

**本票的關鍵在形態，不只在重判十題**：受影響的十六個題號中，正解落在 ⑤ 的只有兩個（UX-W8u、UX-W8v）；其餘題的字面把讀者帶到 ⑤，而 ⑤ 治的不是那些題。此即 `0.1.0-W3-575` 第四段 (E) 對 UX-C8g 記下的「指向錯誤款次的字面吸引子」形態，本票稱之為**反向吸引子**，並在條文側做了全量盤點。
