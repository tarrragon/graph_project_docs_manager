## Problem Analysis

### 執行前 WRAP 三問

- **W（Widen）**：兩個可用組態。候選一為**兄弟容器配對**（兩個容器同屬一個容器 C，問兩者之間的間隔）——否決，理由見下節「為何不能用兄弟容器配對」。候選二為**跨層配對**（兩端分屬不同容器，兩容器同屬一個上層容器）——採用，與本票 title 的「跨層配對」一致。
- **A（Attain distance）**：機會成本是 doc 下一批出題順延；但單邊題組下 19c(a) 的 3/3 不支持任何關於分支判斷的結論（W3-545 已把 19c(a) 對逐列排除的鑑別力判為歸零），不先補對照子問，下批讀數對本缺口無效。
- **P（Prepare to be wrong）**：最可能的失敗是**新題的正解與誤走第一列在結論句上同形**（兩者都指向同一個承載者），使本題也變成不鑑別。防護有二：(i) 題幹明示兩端分屬不同區塊，第一列的條件（同一容器內）在題面即不成立；(ii) 答案鍵的判定者註明文要求以依據句落在哪一列計分，不以結論句計分，並把「套用第一列但終點相同」列為不通過形態。

### 為何不能用兄弟容器配對（本票的關鍵設計約束）

`0.1.0-W3-529` 把第一列收窄為「同一容器內的兩個子件」之後，**同屬一個容器的兩個容器就是該容器的兩個子件，落第一列**，不落第五列。若對照子問用兄弟容器配對，會同時踩到兩個問題：

1. **它其實不落分支一，而落第一列**，與本票 acceptance 第 1 項「確認不與第一列重疊」直接衝突。
2. **就算讀者誤走第五列分支一，結論句仍是「由該容器承載」**，與走第一列的正解在承載者上完全相同——以承載者計分的子問對這條誤讀零鑑別力。

故對照子問必須是**跨層配對**：兩端分屬不同容器，兩者不是任何單一容器的兩個子件，但其共同上層是一個容器元件。此性質另衍生一項發現（第五列括號例示「如兩個容器之間」在收窄後對兄弟容器組態失準、且該失準不可由現行題型觀測），已建 `0.1.0-W3-576`。
