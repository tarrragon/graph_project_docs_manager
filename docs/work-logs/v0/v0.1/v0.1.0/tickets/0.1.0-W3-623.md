## Solution
<!-- Schema[ANA/Solution]: 必填（.claude/pm-rules/ticket-body-schema.md） -->
### 一、前置問 1：前兩輪零覆蓋的兩條成因在本輪不成立

| 成因（W3-621 所列） | 本輪 | 依據 |
|---|---|---|
| 同輪補測必然與當輪覆蓋題的題材交集非空，違反 2.2 | **不成立** | 2.2 的條件是「同一輪的題目彼此題材零交集」，檢查方式是逐對取交集。本輪只出一題，題目對數為 0，逐對條件在空的對集合上平凡成立。前兩輪的衝突來自「①乙 的題要與另一道測 ② 的覆蓋題同批」，本輪沒有那道題 |
| ①乙 無改動、無覆蓋題身分，加進來會在不測任何改動的情況下影響布林 | **形態改變，不再是同一個問題** | 前兩輪的問題是稀釋——一道不覆蓋改動的題混進一批覆蓋改動的題裡。本輪改動總數為 0，沒有任何一道題覆蓋改動，不存在稀釋；問題轉為「改動總數為 0 時覆蓋比與下界怎麼適用」，見第二節 |

### 二、前置問 2：改動總數為 0 時，覆蓋比與下界如何適用

**照字面套用的結果**：覆蓋比分母＝改動總數＝0，分子＝0−0＝0，**0/0 無定義**；
下界的條件「本輪改動全數落在零覆蓋清單」在空的改動集合上 vacuously 為真，**下界觸發、不得產出布林、回 Step 1**。

**這是規格缺口。** 下界的理由逐字是「沒有受驗對象時產出的任一個值對改動零資訊」——該理由在零改動輪成立，
但推不出它的處置：本輪布林的受驗對象不是改動而是既有條文，布林仍帶資訊；而「回 Step 1」的語意是去改條文，
本輪並不打算改。根因是規格 §6 的形態寫死為「批次改文一次 → 現出題一次 → 驗一次」，Step 1 的產出定義為改動清單，
**零改動輪不在射程內**——而它是規格自己製造出來的需求（L4 要求零觀測必須補測，補測既有條文必然零改動）。

**本輪處置**：不產出改動驗證布林、不產出覆蓋比；改產出回歸讀數並逐項寫明它證明什麼、不證明什麼（第三節）；
下界的觸發如實記錄並註明它在本輪是誤擋。**停損判別**：不使任一道題的計分改變，依收納判準不開票
→ 已記入 `probe-known-limitations.md` 的 **L33**。

### 三、Step 3 產出（回歸讀數，非改動驗證布林）

| 項 | 值 |
|---|---|
| 各輪計分 | R1 **不通過**（裁決後，見第四節）／R2 通過／R3 通過 → **2/3** |
| 引用讀數 | **3/3**（三輪皆逐字引到 S2 或 S3） |
| 套用讀數 | **3/3**（三輪皆把乙目六項與兩份紀錄逐一對照並指名缺項） |
| 1.7 判讀 | **紅（反向）**——判定者甲判反向紅、出題者側判綠，依裁決力條款取較嚴的一邊，出題者側不得覆蓋 |
| 覆蓋比 | **無定義**（分母＝改動總數＝0） |
| 下界 | 字面上 vacuously 觸發；本輪判定為誤擋並記 L33 |
| 布林 | **不產出**（本輪為回歸讀數輪，無改動可供布林承載語意） |
| 零覆蓋清單 | 長度 0，但那是因為沒有元素可放（無改動），不是因為覆蓋完整 |

**三輪讀數證明什麼**：在本題材、本條文狀態（C1' 已落地）下，7.2(3-2)①乙 的窮盡要求句
**被三輪讀者全數引用且全數套用**，並且是三輪各自判定的決定性條款。它不是零效力條文，
位置上讀者走得到（1.4 登記的末句風險本輪未被觸發）。

**不證明什麼**（逐項）：

1. **不證明條文改動有效**——本輪無改動，布林與覆蓋比皆不適用。
2. **不證明「C1' 沒有影響 ①乙 的被套用率」**。本輪讀數確實取自 C1' 已落地的 HEAD，故它支持
   「C1' 落地後 ①乙 仍被套用」這句話；但這**不是對照實驗**——沒有 C1' 落地前的同題讀數，
   而拋棄式題庫不做跨輪比較（規格附錄已捨棄歷輪對照）。它支持的是狀態陳述，不是因果陳述。
3. **不證明其他題材下也會被套用**。單一題材、三輪樣本，L5 明列探針個體差異不可控。
4. **不排除字面對應**。受測步驟屬 L20 第一類（某份逐項清單有沒有寫完），題幹必須實例化清單項名，
   交集為空不可滿足；三輪的引用與套用帶一個未排除的「題幹字面把讀者領到乙目」的解釋。
5. **不構成正向對照**。本輪無反例輪次，這批讀數證明的是受測款次被引到且被套用，
   不證明器材分得出「不套用者」（鑑別力規則 E2 的同型限制）。本題的鑑別力結論來自 1.7 的遮蔽推導。

### 四、兩名判定者對 R1 的分歧與裁決

**分歧**：判定者甲判 R1 通過（並自行標記為邊界、註明嚴格讀法會改記 N5）；判定者乙判 R1 不通過。
兩人指的是同一段文字——R1 第三條依據句下的補強段：

> 「即使有人主張已進入 ②，整項未寫的項屬『無從比對』…落在『有項無從比對而無項比出不同』，
> 本款同樣不輸出『是不是同一個圖形』的結論。」

**成因是判準留白（L13），不是判定者品質問題**：本輪 brief 的「什麼不算問題」第 1 條寫
「依據句多引了與判定相容的其他款次（例如 ② 的合成條款），只要受測步驟確實被套用」，
而計分欄 C3 寫「未把那一項當成 ② 的『略去不比』或『無從比對』**而據以**宣告同一圖形或宣告本款不輸出結論」。
兩條對「多引且該引用的推理本身與該款要件牴觸」這一格沒有分工。

**裁決：R1 記不通過。** 依據兩項，皆為比對而非裁量：

1. **計分欄逐字命中**。C3 的失效條件是「把那一項當成…『無從比對』而據以…宣告本款不輸出結論」，
   R1 的補強段兩個關鍵詞逐字皆在。計分欄是事先定稿的文字，brief 的豁免清單是本輪自訂的補充。
2. **規格 5.5 明文**：「逐點推理或補述與條文牴觸者記不通過，不論落在哪一欄」，其理由是
   「結論正確而推理相反的答案不會泛化——同一讀者換一個輸入就會給出錯的答案」。
   ② 對「無從比對」的界定以「該項只有一端寫出內容」為要件，R1 引用時引了含該要件的原句、
   套用時捨去該要件。豁免第 1 條的射程是「多引」，不及於此。

**判定者甲的反面理由已逐條看過**：(i) 該句寫在反事實分支之下——但 5.5 明文「不論落在哪一欄」，
且其理由關心的是推理會不會泛化，與它落在哪個分支無關；(ii) 同段末句以「不得跳步」把正解路徑指回 ①——
主判定正確不免除補述的牴觸，這正是 5.5 要擋的形態；(iii) 豁免清單為明文否決且不得自行擴充——
同意不得擴充，但也不得放寬，而本處不在其字面射程內。

**這個分歧本身是一項發現**（第五節第 2 項），已開票。
