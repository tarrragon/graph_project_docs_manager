### 問題根因

7.2(3-2)①乙 的窮盡要求句（「本目所列的每一項都要寫，兩端都要寫；材料看不出某一項時，該項寫
「看不出」，不得略過。漏寫任一項者本步未完成，不得進 ②。」）自 `0.1.0-W3-620` 的 C1 落地後
連續兩輪零觀測：W3-620 與 W3-621 的覆蓋題受測的都是 ②。

W3-621 不補測的成因有兩條，皆為結構性：同輪補測必然與當輪覆蓋題的題材交集非空（違反規格 2.2）；
且 ①乙 該輪無改動、無覆蓋題身分，加進來會在不測任何改動的情況下影響布林。W3-621 因此自我約束：
第三輪若仍未測，處置不得再是「明寫本輪設計看不到」。

本輪以 ①乙 為受測款次另起一輪，兩條成因逐條核對（見「重現實驗結果」第一節）：成因 (1) 逐字不成立
（本輪只出一題，2.2 的逐對條件在空的對集合上平凡成立）；成因 (2) 形態改變——本輪改動總數為 0，
不存在「稀釋布林」的問題，轉為「改動總數為 0 時覆蓋比與下界怎麼適用」，而那是規格缺口。

   遮掉之後 ② 即露出無格區。**同一缺口在真實作答中已造成失分**：R1 的補強段把兩端皆未寫歸入
