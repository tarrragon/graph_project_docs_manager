### PM 裁決：acceptance 3 的建議措辭作廢，改以 W3-538 的 DOC-19d 實際措辭為準

本票 acceptance 3 原建議題幹用「同放在一個 X 容器元件之內」一類措辭。**該建議是我轉達 W3-545 發現時寫的，比它該有的嚴格度低一級，已由 W3-538 的承辦者指出並在實作中超越。**

問題：若題幹寫出「一個 X 容器元件」，該詞**逐字對上分支一條件「共同上層是一個容器元件者」**——選支仍可純字面完成，W3-545 判定 19c(a) 歸零的同一機制只是換個字面復發。而且該措辭本身就是一句「直接宣告共同上層是不是容器元件」，正是我在派發時禁止的類別。

**DOC-19d 的實際措辭不使用「共同上層」「容器元件」「容器」三詞**，改以組態描述（面板內由左而右排著兩個區塊，各區塊內由上而下排著元件）讓讀者自行判定。兩版不互斥——19d 滿足本票的全部禁止項，只是多禁一詞。

**照本票原建議改回去的代價**：把「一塊『託運明細』面板」改成「一個『託運明細』容器元件」，會使存在性判斷**由推導降為抄寫**。不採。

本票執行時，acceptance 3 的判準改為：題幹不得與第五列共用任何可直接對上的字串，**包括分支條件本身的用詞**；驗證法採 W3-545 的窮舉極大子字串比對（`scratchpad/w3545/isocmp.py`），不採人工挑詞清單。

### 另一項須一併記載的判定

W3-538 發現第五列括號例示「如兩個容器之間」在 W3-529 收窄後對兄弟容器組態失準，且**該失準不可由以承載者計分的子問觀測**——兩條路徑（第一列、第五列分支一）指向同一個承載者，計分上同形。W3-528 原把它記為「跨七批零觀測、屬推論風險」，**那是不可觀測而非尚未觀測**，性質不同。已成票 W3-576。
