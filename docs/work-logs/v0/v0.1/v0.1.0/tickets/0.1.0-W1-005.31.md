## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
依 SPEC-004 4.42（十一欄位）與 5.16（子件契約、排列不變式）實作 `SwitcherOverlay`：

- **slot**：`title`（選填，預設 `switcherTitle`）、`items`（`List<RecentProjectItem>`，0..無上限）、`chooseOther`（`AppButton`）、`onDismiss`、`maxHeight`（選填，呼叫端依入口位置計算後傳入，未傳則不限高）、`testKey`、`scrollKey`。
- **狀態**：容器本身不持有收合態（依契約「收合態不是本容器的狀態」）——掛載即展開、卸載即收合；`items.isEmpty` 時只渲染標題與按鈕（無 Divider、無捲動容器）。
- **互動**：`TapRegion.onTapOutside` 處理點外部；`CallbackShortcuts` 綁 Esc；`FocusScope` 自建作用域，`initState` 後一幀顯式 `requestFocus()` 搶焦（`autofocus` 僅在掛載前無任何焦點持有者時生效，實測掛載前通常已有入口持有焦點，故需顯式搶焦）；`dispose()` 交還掛載前的焦點持有者。
- **動畫**：`_SwitcherOverlayEntrance`（`TweenAnimationBuilder`）在掛載時播放一次淡入 + 向下位移，`duration` 取 `Motion.overlay(context)`，不依賴外部 `isExpanded` 旗標。
- **尺寸**：寬固定 `LayoutSize.overlayWidth`；`maxHeight` 傳入時裁切並讓 items 區改為內部 `SingleChildScrollView`（`scrollKey`）捲動。

### 技術細節（實作中發現）
1. `Semantics(scopesRoute: true)` 須同帶 `explicitChildNodes: true`，否則觸發 framework assertion（`scopesRoute` 必須搭配 `explicitChildNodes`）。
2. `CallbackShortcuts` 與 `FocusScope` 的巢狀順序：`CallbackShortcuts` 必須是外層（key 事件沿 `primaryFocus` 往「祖先」方向冒泡，`FocusScope` 若在外層則其內部的 `CallbackShortcuts` 永遠收不到事件，因為它是 primaryFocus 的後代而非祖先）。
