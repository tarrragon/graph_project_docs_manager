## Task Summary

評估 8.2(3) 可區分差異八項的射程、2.8(1) 動作列兩來源皆不成立時的出口

---

## Problem Analysis
### 問題根因

兩案皆為「結論放在讀者取不到的位置」，不是條文缺少敘述。

**案一（8.2(3) 八項射程）**：真正的根因不是八項各自沒有射程定義，而是 **W3-514 寫入 8.2(2) 的「兩側封閉」句與 8.2(3) 的清單身分互相衝突**。

- 8.2(2) 現文把「顏色以外那一側」逐項寫成與 8.2(3) 相同的八項，這讀起來是一個**二分宣告**：任一差異不是落在顏色那一側被歸一，就是落在顏色以外那一側的八項之中。
- 但第一點的問法是**白名單問法**——「是否還剩下 8.2(3) 清單內的任一項差異」。白名單允許清單外的差異存在且不算數。
- 兩者對「清單外但非顏色」的差異給出相反指示。答案鍵自己的推導即暴露此點：它先說落影偏向「不在顏色那一側的五個維度內，也不在顏色以外那一側逐字列出的八項內」，再說「兩側都是封閉的……沒有第三個地方可放」——前半句已經指出有第三個地方。

**因此八項的射程之所以被追問，是因為二分宣告強迫讀者為每個非顏色差異找一格**；射程未定義只是這個強迫的落點，不是起因。

**案二（2.8(1) 出口）**：2.8 的產物是「是／不是動作列」，而 (b) 的判定值在 2.1(2)。讀者必須自行完成一次雙重否定的轉換（兩來源都不成立 → 不是動作列 → 移出動作列 → 屬 (b)）。轉換點無條文承接，UX-N2r 的 r1、r3 兩輪在此翻極性。

- 移除二分宣告後，讀者是否仍會自行把「落影偏向」歸入「位置」。草稿只移除驅動因素，不裁決八項射程；充分性須由下一批同型邊界題量測（承接票見 Solution 的 Spawn 規劃）。
- UX-N8x 子問 1、2 在刪除複述後的實際鑑別力等級（部分回復或仍歸零），須下一批重新判定。

### 結論

兩案皆判**應改**，且兩案的改法同型：**把結論搬到讀者取得到的位置，不新增論述**。兩案都不是補句——案一是刪一段複述並改寫清單的身分，案二是把既有出口下推成判定步驟的末格。

### 案一：8.2(3) 八項射程

### 候選方案與取捨

| 方案 | 內容 | 判否／採用理由 |
| --- | --- | --- |
| A1 不動 | 保留現狀，下一批加同型邊界題量命中率 | **不採**。缺口不是觀測不足，驅動因素已有逐字證據；不動等於讓已知會誘發誤讀的句子續留 |
| A2 補射程定義句 | 為「位置」補一句「指元素本體在畫面上的位置」 | **不採**。只封一項。換一項即重開——外發光的擴散範圍對「大小」、漸層分佈對「填滿與否」、端點造型對「線條樣式」皆同型。八項須各補一句才封得完，而補句正是 W3-510 已證實最易失效的手段（同節連四次補句、兩次淨負向） |
| A3 改清單身分 | 刪 8.2(2) 的八項複述；8.2(3) 清單加「逐項封閉」身分句與第一點問法澄清 | **採用**。見下 |
| A4 分類判準取代列舉 | 以「元素本體屬性 vs 元素投射出的視覺效果」取代八項列舉 | **不採**。硬誤傷：明度、深淺、對比皆屬元素本體屬性，取代列舉即直接重開明度逃逸路徑——該路徑連三批未封、本輪（C8g、M1）首次歸零 |
| A5 分類判準與列舉並存 | 列舉保留，另加一條分類判準 | **不採**。任何具體化都須寫出效果名稱；「落影」在題目檔命中 1（即 UX-W8s 本身），「陰影」語義等同，寫入即使該題整題歸零。以本批鑑別力最高題的歸零換一項邊界的封閉，不划算 |
| A6 表格化八項邊界 | 八項各附一句邊界問句 | **不採**。A2 的表格版，字數最多，每句都可能命中未來題材 |

### 為何採 A3：根因不在射程，在兩句互相衝突

8.2(2) 現文把「顏色以外那一側」逐項寫成與 8.2(3) 相同的八項，讀起來是**二分宣告**；而第一點的問法「是否還剩下 8.2(3) 清單內的任一項差異」是**白名單問法**。白名單允許清單外的差異存在且不算數，二分宣告不允許。兩者對「清單外但非顏色」的差異給出相反指示。

答案鍵自己的推導即暴露此點：先寫落影偏向「不在顏色那一側的五個維度內，也不在顏色以外那一側逐字列出的八項內」，再寫「兩側都是封閉的……沒有第三個地方可放」——前半句已經指出有第三個地方。

r2 的依據鏈逐字重現了二分宣告的驅動：先引「顏色以外那一側一動不動——形狀、大小、位置、圖示……」，緊接著指派「『落影偏向哪一邊』屬於『位置』差異」，且第 (3)(4) 欄皆答「否」——沒有讀出第二讀法、不認為需要自補假設。**二分宣告在該輪是被當成充分依據使用的。** j2 讀答案鍵前的盲推落入同一讀法。

**PM 交辦的背景判讀成立且是本案主軸**：W3-514 的兩側封閉句，在明度軸（C8g、M1）三輪零取用（該軸零逃逸靠的是 8.2(3) 既有的維度排除句），而它**唯一被實際取用的地方（W8s）正是暴露缺口的地方**。兩側封閉句與八項清單的關係不只是缺口來源之一，它是唯一有證據的驅動因素。刪除「顏色以外」那半句的實測成本為零。

**收窄範圍的理由**：只刪「顏色以外」那一半，保留「顏色那一側全部歸一」整句（含「出現這種敘述表示換色沒有執行完，不得作為第一點不成立的理由」的執法子句）。C8g 的答案鍵明文引用該執法子句，明度逃逸的歸零與它同批落檔；雖然三輪未逐字引用，證據不足以支持一併刪除。證據到哪裡，刀切到哪裡。

### 八項是否應保留列舉形式：保留

三個理由：

1. **清單的主要工作不是窮舉「顏色以外」，而是當白名單把顏色維度擋在外面。** 移除列舉會把 W3-514 之前的明度逃逸路徑放回來，而該路徑是連三批未封、本輪首次歸零的項目。
2. **分類判準只是把射程問題搬家。** 「元素本體屬性」本身也是無射程的詞——明度是本體屬性嗎？讀者仍須自行裁決，且這次連可逐字比對的清單都沒有了。
3. **列舉是可機械比對的，且已實測生效。** UX-N8x 在 W3-514 之後，r1、r3 逐字比對即答對。

保留列舉，改變的是**它被引用的次數與身分**：清單只在 8.2(3) 出現一次，身分明訂為逐項封閉的白名單（不宣稱窮舉「顏色以外」）。

### A3 的誠實邊界

A3 移除誤讀的**驅動因素**，不裁決八項射程。讀者若仍自行主張「落影偏向 = 標記的位置」，A3 不阻止——但該主張必須正面成立，而題幹直接寫明「兩種標記……在列上的位置……完全相同」（r1、r3 皆看見這一點）。充分性須量測，不預判。這是本案刻意不做的事：射程的裁決只有 A2／A4／A5 三條路，三條的代價都已列出且都高於缺口本身。

### A3 的措辭陷阱（必守）

身分句若只寫「只有清單列出的項目算數」而不回指 8.2(3) 引言的對應關係要求，**UX-C8t 會翻面**（讀者把「45 分」當文字內容差異，判不違反）。該題目前 3/3。草稿中「且各項仍須通過本款引言的對應關係要求」一句為此而設，**不可省**。

### 案二：2.8(1) 與 2.1(2) 未連起來

### 候選方案與取捨

| 方案 | 內容 | 判否／採用理由 |
| --- | --- | --- |
| B1 在 2.8(1) 末補一句 | 「兩個來源都不成立即為移出動作列，指示屬 (b)」（j2 建議） | **不採**。補句形態，且只補正向一側；反向（任一來源成立 → 不屬 (b)）仍須讀者自行推。誤讀的是轉換本身，不是其中一個方向 |
| B2 出口下推成判定步驟末格 | 2.8(1) 改寫為 ①②③ 三格，③ 直接輸出屬／不屬 (b) | **採用**。見下 |

| B4 不動 | 判定值未受影響，記為已知瑕疵 | **不採**。本題的判定值正確是因為題幹的列上恰好有按鈕；換一題（K1、AB 這類屬 (b) 的正向題）同一推理會直接失分。這是 `test-assertion-design-rules` 規則 E2 所述的形態——失效方向與正常輸出同形 |

### 為何採 B2

2.8 的產物是「是／不是動作列」，(b) 的判定值卻在 2.1(2)。讀者必須自行完成雙重否定轉換（兩來源都不成立 → 不是動作列 → 移出動作列 → 屬 (b)）。UX-N2r 的 r1、r3 在此翻極性，寫出「兩個來源都不成立 → 不是動作列 → 不屬 (b)」。

**先例已實測生效**：W3-515 對 2.2(2) 做的正是同一件事——③「讀 ② 的表：只要有任何一列記『否決 (a)』，指示就不屬 (a)……全部列都記『不否決』，指示才屬 (a)」把結論下推成步驟末格。實測結果：R5 由 b12 的 0／3 轉為 3／3、W2f 3／3、多數決讀法零例。B2 是把同一形態套到 2.8。

B2 另有一個附帶效果：① 把「列上有沒有可點元素」置於第一格，r1、r3 原先的事實誤讀（誤稱兩來源皆不成立，而該列確有「全部歸還」按鈕）更可能在該格暴露。

### 案二的鑑別力讓渡：零

③ 新增的是「來源 → (b)」那一格。該轉換在現有 25 題中從未被設為得分點——N2r 的矛盾推理正因判定值正確而不計分。UX-R4 子問 3 與 UX-N2r 子問 4 雖逐字問「算不算動作列」，但只問到動作列、不問 (b) 的對應，鑑別力不變。
