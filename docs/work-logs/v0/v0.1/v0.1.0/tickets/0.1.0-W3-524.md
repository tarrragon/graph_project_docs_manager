## Task Summary

評估 8.2(3) 可區分差異八項的射程、2.8(1) 動作列兩來源皆不成立時的出口

---

## Problem Analysis
### 問題根因

兩案皆為「結論放在讀者取不到的位置」，不是條文缺少敘述。

**案一（8.2(3) 八項射程）**：真正的根因不是八項各自沒有射程定義，而是 **W3-514 寫入 8.2(2) 的「兩側封閉」句與 8.2(3) 的清單身分互相衝突**。

- 8.2(2) 現文把「顏色以外那一側」逐項寫成與 8.2(3) 相同的八項，這讀起來是一個**二分宣告**：任一差異不是落在顏色那一側被歸一，就是落在顏色以外那一側的八項之中。
- 但第一點的問法是**白名單問法**——「是否還剩下 8.2(3) 清單內的任一項差異」。白名單允許清單外的差異存在且不算數。
- 兩者對「清單外但非顏色」的差異給出相反指示。答案鍵自己的推導即暴露此點：它先說落影偏向「不在顏色那一側的五個維度內，也不在顏色以外那一側逐字列出的八項內」，再說「兩側都是封閉的……沒有第三個地方可放」——前半句已經指出有第三個地方。

**因此八項的射程之所以被追問，是因為二分宣告強迫讀者為每個非顏色差異找一格**；射程未定義只是這個強迫的落點，不是起因。

**案二（2.8(1) 出口）**：2.8 的產物是「是／不是動作列」，而 (b) 的判定值在 2.1(2)。讀者必須自行完成一次雙重否定的轉換（兩來源都不成立 → 不是動作列 → 移出動作列 → 屬 (b)）。轉換點無條文承接，UX-N2r 的 r1、r3 兩輪在此翻極性。

### 影響範圍

**已驗證的事實**：

- `excerpt/ux-design-evaluation--interaction-feedback-component-semantics--八項判準.md`（HEAD 401e81e3）為本次判讀的條文基準；對應正本 `.claude/skills/ux-design-evaluation/references/interaction-feedback-component-semantics.md`。
- 案一的誤讀由二分宣告直接驅動，有逐字證據：`a/W3-417-b14-ux-C3-r2.md` 子問 1 依據欄先引「顏色以外那一側一動不動——形狀、大小、位置、圖示、存在與否、填滿與否、線條樣式、文字內容」，緊接著寫「『落影偏向哪一邊』屬於『位置』差異（落影的方向位置）」。該輪第 (3)(4) 欄皆答「否」——沒有讀出第二種判定、不認為需要自補假設。二分宣告在該輪是被當成充分依據使用的。
- 四個獨立讀者的分佈：r2 完整誤判、j2 讀答案鍵前的盲推同樣把落影偏向歸入「位置」（`judge-b14-ux-j2-derivation.md` C3 條目）、r1 明列兩讀法並在第 (4) 欄自補假設才避開、r3 直接判「視覺效果參數，不在清單內」。2 完整誤判、1 需自補假設、1 乾淨。
- 兩側封閉句的實測取用分佈（judge-b14-ux-j1）：僅 C3 三輪、C2-r2、B1-r2 取用。**明度軸（C8g、M1）三輪皆未取用**，該軸本輪零逃逸靠的是 8.2(3) 既有的維度排除句（r3 引用）。
- 案二的誤讀在 UX-N2r 不影響判定值（該列確有「全部歸還」按鈕，正解就是不屬 (b)），故不計分，由 j2 單獨登記為條文風險。

**仍未驗證的假設**：

- 移除二分宣告後，讀者是否仍會自行把落影偏向歸入「位置」。本案的處置只移除驅動因素，不裁決射程本身（理由見 Solution 案一）；是否足夠須由下一批同型邊界題量測。
