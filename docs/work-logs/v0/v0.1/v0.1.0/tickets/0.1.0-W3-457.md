**用戶裁示**
- U1：填色 chip 合格，前提是區塊高度低於按鈕。
- U2：與畫面上實際的按鈕比較。
- U3：例示寫「不加底色與外框的純文字」。
- U4-B：理由句改寫，列出不可靠的訊號（描邊 vs 實心、圓角、底色深淺），並寫明比較只看構成要素與區塊高度。
- U6-C 加徽章條款：指示多出的構成要素，只有在畫面上另有按鈕具備該要素、且指示與那個按鈕不同時，才算不同；附在按鈕上的徽章另列豁免。
- U9：高度差設門檻，以專案尺寸 token 階梯為準，至少低一階。專案沒有尺寸 token 時，高度軸不成立，只看構成要素。
