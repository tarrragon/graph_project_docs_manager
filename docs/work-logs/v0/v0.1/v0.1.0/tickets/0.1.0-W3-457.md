### 修改摘要（interaction-feedback-component-semantics.md 六項判準第 2 項）

判準本身（(a)(b) 兩種合格形態、與是否同列無關）未變，只修兩處讀歪點：

1. 括號「（文字 chip、圓點）」補「，非窮舉」，明寫括號內兩例為例示非窮舉清單。
2. 理由句前補「（僅適用於未達成 (a)(b) 的情況）」，並在理由句後重述一次
   「指示只要符合以上兩種形態之一即合格，且與是否和按鈕同列無關」，
   使理由句不再能被讀成蓋過前段合格結論的反向判準。
