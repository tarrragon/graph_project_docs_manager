### 問題根因

`hook-completeness-check.py` 掃描 `.claude/hooks/*.py` + `.claude/skills/*/hooks/*.py`，
以「檔名是否出現在 settings.json 的 hooks config」作判準，但輸出用詞是「未註冊」——
這是比量測結果更大的結論。實查確認兩個具體受害案例（皆非缺漏）：

1. `git-ref-transaction-content-guard.py`：非 settings.json 直接註冊，而是由已註冊的
   `git-ref-transaction-guard-install-hook.py` 於 SessionStart 安裝為原生 git
   `reference-transaction` hook shim（`.git/hooks/reference-transaction`）觸發，鏈路自洽。
2. `ticket/hooks/handoff_session_mgmt.py`：非獨立 hook 進入點（掃描全庫確認為
   `.claude/hooks/*.py` 與 `.claude/skills/*/hooks/*.py` 中唯一沒有 `__main__` guard 的
   檔案），是已註冊的 `handoff-auto-resume-stop-hook.py` 匯入的共用模組，因與該 hook
   緊密耦合而置於 `hooks/` 目錄。掃描器以「誰在目錄裡」而非「誰在執行」盤點，才會誤判。

盤點方法：`grep -L '__main__'` 全庫掃 `.claude/hooks/*.py` 與 `.claude/skills/*/hooks/*.py`，
確認 `handoff_session_mgmt.py` 為唯一非進入點檔案；`grep` 全庫比對 install-hook 型 docstring
（`shim`/`reference-transaction`/`.git/hooks`）確認 `git-ref-transaction-content-guard.py` 為
唯一經 installer 間接註冊的案例，兩者為目前僅有的已知替代註冊管道。

## Context Bundle

**需求摘要**: 讓 hook 完整性檢查說出它量到的東西，而不是說出一個更大的結論；檔名與訊息一併處理。

**實查證據（可直接重現）**

```
$ grep -c "git-ref-transaction-content-guard" .claude/settings.json
0
$ ls -la .git/hooks/reference-transaction
-rwxr-xr-x  ...  Sep  3 12:29
$ cat .git/hooks/reference-transaction
#!/bin/sh
# git-ref-transaction-content-guard shim -- 由 .claude/hooks/git-ref-transaction-guard-install-hook.py 產生，勿手動修改。
```

`git-ref-transaction-guard-install-hook.py` 在 `settings.json` 內，SessionStart 時回報 `[OK]`——**鏈的起點就在檢查器唯一讀的那個檔案裡**。

**第一層的定位：這是正確的終點，不是止血**

改訊息使其陳述量測結果，對**所有未來的替代註冊機制**都成立，不需要每出現一種就回來補一次。改完之後 `git-ref-transaction-content-guard.py` 出現在該清單裡是**正確的**（它確實不在 `settings.json`），讀者看到的是事實而非錯誤結論。

第二層（認得 installer 型註冊）是**噪音優化，不是正確性補完**。標成選配才不會有人覺得欠著——而那個「欠著」的感覺會製造壓力去做一件做不完整時比現狀更糟的事：讀者會信任一個宣稱認得替代機制的檢查器。

**盤點判準（acceptance 第 4 條）**

用「誰在執行」盤，不用「誰在目錄裡」盤。`.git/hooks/` 下的 shim 不在 `.claude/hooks/` 內，若以目錄列舉為起點，**盤點本身會重演同一個錯誤**。

**改名影響面是具名檢查項，不是「盤點影響面」（acceptance 第 3 條）**

「盤點影響面」是無法否證的驗收條件——執行者說做了就是做了，驗收方無從反駁。故 acceptance 逐項具名，每一項都可以被打開查看。其中 `.claude/hook-logs/` 底下的同名目錄最容易漏，因為**它不是引用而是產物**：改名後舊目錄孤兒化，而孤兒目錄不會報錯。

**約束**
