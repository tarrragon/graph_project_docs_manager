## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因

lib/app/shell.dart 為 lib/components/app_shell.dart（AppShell，SPEC-004 §4.27）等元件到位前的雛形實作，持有一份平行的側欄／標題列／導覽項骨架（_kSidebarWidth、_NavItem、_ProjectSwitcherEntry、_ReturnToHeader），與元件庫落地後的正式元件重複。

### 影響範圍

- lib/app/shell.dart：改為委派 components.AppShell 組裝六組 slot
- lib/app/router.dart：未修改（returnToProvider／NavIntent／visitedDestinationsProvider／firstVisibleProvider 語意不變，僅供 shell.dart 讀取）

### 相關 Error Pattern

無新增；查詢 /error-pattern 無直接相關項目。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
lib/app/shell.dart 改寫為 ConsumerStatefulWidget：不再自建 Scaffold／側欄／標題列，改組出 components.AppShell 所需六組 slot（switcherEntry: ProjectSwitcherEntry、navItems: 六個 NavItem、pages: 六個 PageColumn 包 buildDestinationPage、overlay: 開啟時的 SwitcherOverlay 空殼）。删除 _kSidebarWidth、_NavItem、_ProjectSwitcherEntry、_ReturnToHeader 四個私有實作；既有 testKey 錨點（shellKey、projectSwitcherEntryKey、nav-item-<d>、action-<d>-back）名稱與行為不變——後者由 components.AppShell 內部 _MainArea 承接（讀 returnToProvider、呼叫 consumeReturnTo），不再需要本檔自繪返回列。

導覽項圖示（NavItem.icon 必填 slot）：SPEC-004 §4.7 未限定圖示集，依畫面語意各自挑一個 Material icon（純裝飾，semanticLabel 為 null，朗讀內容由 label 承載）。

專案切換浮層：本票範圍不含近期專案資料串接（PROP-004 定案為後續票），僅接上最小可用狀態機（本地 bool _isSwitcherOpen 控制 ProjectSwitcherEntry.isExpanded 與 AppShell.overlay），開啟時渲染空殼 SwitcherOverlay（items: [] + chooseOther 按鈕 dismiss），取代原本的 AlertDialog 佔位。

修 bug：components.AppShell 不含 Scaffold／Material 祖先（純骨架容器），main.dart 的 MaterialApp(home: child) 不自動提供 Material，導致 InkWell 系元件（ProjectSwitcherEntry／NavItem）建置期拋 "No Material widget found"。在本檔（非 main.dart）補上唯一一層 Material 包住 components.AppShell 輸出，維持 main.dart 零改動。

lib/app/router.dart：未修改。

### 元件庫 API 缺口

無。AppShell / NavItem / SwitcherOverlay / ProjectSwitcherEntry / PageColumn 契約皆足以接線，overlay slot 依既有註記以 Widget? 承接 SwitcherOverlay，型別相容。

Phase 4 結論：程式碼品質 A（單一委派層，無私有骨架重複；委派後 shell.dart 從 248 行降至約 100 行）。技術債務：無新增；本票範圍外的專案切換近期清單資料串接維持既有已知延後項（PROP-004 定案，非本票 acceptance 範圍）。無需額外重構。
