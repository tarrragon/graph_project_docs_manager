## Problem Analysis
### 問題根因

### 影響範圍

範圍界定（本票依票名「spec/UC 轉測試段落」收斂）：

未納入：tdd 其餘 Phase 0-4 規則、cases/、scripts/hooks（非 spec/UC 轉測試段落）。已驗證事實：以上檔案全文已讀。未驗證假設：phase1/rules.md〈行為場景（Given-When-Then）〉與 phase2/rules.md〈GWT 格式〉是否與 doc-handoff 的 GWT 粒度一致，未比對。
