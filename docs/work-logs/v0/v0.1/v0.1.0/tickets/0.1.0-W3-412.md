- 處置表（三項確認欄皆是／任一項為否）未改：新表仍為 3 個判斷型欄位（引文位置在範例之外、判定詞逐詞對照、驗證段無程式語法／框架名），欄數與原表一致。

### 本節自身範例：新表自填結果

**正例**（問句改為「候選『省略輸入段』的判定是什麼？」，預期答案「違規」，取代原「是否違規？預期：是」——原問法的預期答案「是」非實詞片語、扣掉引文字串後不剩任何判定詞，依新規則 4 第二款會被判為自證問句，故改問法）：

| 欄 | 自填結果 |
|---|---|
| 情境前提 | 「候選描述：範例只寫【產出】與【驗證】兩段，省略【輸入】段」——逐字出自本則【輸入】段 |
| 引文 | 「範例固定分三段，段名與標記固定，三段皆不可省略」——`grep -F` 命中 `chained-examples.md` 第 11 行（〈三段鏈式格式〉表格前導句），命中位置在本範例之外 |
| 引文位置在範例之外？ | 是 |
| 判定詞逐詞對照 | 判定詞「違規」：引文提供規則（三段皆不可省略）、情境前提提供事實（省略【輸入】段），依規則 3a 規則在引文、事實在情境前提，兩者皆備，非橋接 |
| 驗證段無程式語法／框架名？ | 是 |
| 判定 | 三項確認欄皆是，合格 |

**反例**（沿用原情境：提交按鈕停用／資料態／表單驗證結果通常寫入共用狀態）：

| 欄 | 自填結果 |
|---|---|
| 情境前提 | 「候選描述：某元件的提交按鈕在特定狀態下停用」——逐字出自本則【輸入】段 |
| 引文 | 「表單驗證結果通常會寫入共用狀態」——`grep -F` 命中僅在本範例【產出】段理由欄自身，範例之外零命中 |
| 引文位置在範例之外？ | 否 |
| 判定詞逐詞對照 | 判定詞「不成立」：引文只給「通常」慣例，未定義「值的儲存位置」判準，也未定義「表單驗證結果」與「共用狀態」的關係，無規則可循，屬橋接 |
| 驗證段無程式語法／框架名？ | 是 |
| 判定 | 兩項確認欄為否（引文位置在範例之外、判定詞逐詞對照），缺引導，非缺範例 |
