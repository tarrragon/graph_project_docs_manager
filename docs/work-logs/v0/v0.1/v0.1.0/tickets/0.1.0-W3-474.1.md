## Problem Analysis
### 問題根因

第 2 項 2.11「同一圖形在全畫面只承載一個語意」與 (a)(b) 判定互不引用，條文推不出 2.11 違反時第 2 項是否不合格（W3-474 NeedsContext）。根因是 2.11 從來源搬入時失去了「第二層問題」的定位：

- 來源：`cffdda1df`（框架導入，1.2.0 版「元件語意與版面」檢查層）單句「指示用明顯非按鈕形態（文字 chip、圓點）或移出動作列，同一圖形全畫面只承載一個語意。」該層取自 blog 案例 U.C18（`blog/content/ux-design/cases/status-icon-mistaken-for-button.md`，commit `29818cc0`）。
- U.C18 原本射程：〈判讀〉3「圖示語意撞名是第二層問題……同一個圖形承載兩個語意，即使解決了可點性、語意混淆仍在。圖示選擇要全畫面去重。」〈策略〉1（改形態／移出動作列）與〈策略〉2（圖示全畫面去重）分列兩條。撞名的「語意」指圖示代表的事物（「查書籍資料」vs「實體書」），不是可點與否。
- 演變：`054ee3f2a` → `0c21b9420` → `4244e912a` → `2250c6c37` 皆把此句留在 (a)(b) 句尾；`d992edf59`（W3-471）獨立為 2.11；`2bcd3bcb7`（W3-474）補 2.11(2) 圖形範圍。沒有任何一版寫過它與 (a)(b) 的關係。
- skill 內其他相關條文：`interaction-feedback-checklist.md`〈檢查清單〉「非互動指示與動作按鈕形態可區分、圖示無撞名？」——兩件事以頓號並列；反模式表「狀態圖示與動作按鈕同形混排」處置只列「改非按鈕形態、移出動作列」，沒有圖示去重。
- W3-457.5 #4 傾向 4-A 時曾寫「異列同形是另一種危害（外觀模仿），與 2.11 較接近」並標盲點「2.11 射程沒定義，D4 型畫面可能兩條都攔不下」；用戶裁示 4-A 時接受代價「與可點元素同形的指示放到別列就合格」。

## Solution
### 一、結論

- 2.11 的來源射程是「圖示撞名」，與 (a)(b) 處理的可點性是兩層問題（U.C18〈判讀〉3、〈策略〉1／2 分列；checklist「形態可區分、圖示無撞名」頓號並列）。候選 A、B 都把 2.11 併進第 2 項的合格判定，與來源分層不符。
- 建議方案 C：2.11 與 (a)(b) 各自判定，違反 2.11 不改變指示是否合格，另記缺口；同時補「比較對象不限指示」「語意」「顏色」三個定義。
- 09f 在 1.11.9 已無鑑別力（2.11(2) 使文字＋區塊不在射程），優先序問題的鑑別題須改用 K1、K2、K3。
- 與用戶裁示 4-A 相容：C 不改變任何既有輸入（22＋3 組、UX-09 六題）的合格判定。

### 五、建議改文（方案 C，【】為用戶偏好）

替換 2.11 小節：

```
### 2.11 同一圖形

- (1) 同一圖形在全畫面只承載一個語意。
- (2) 本項的「圖形」範圍同 2.3(3) 所指的圖示與純幾何形狀（2.3(3)：「其他圖形一律算圖示」）。
- (3) 比較對象是畫面上所有圖形，不限指示與可點元素之間；兩個可點元素用同一圖形表達不同語意，也違反 (1)。
- (4) 「語意」指圖形代表的事物或動作，不含可點與否：同一圖形只差可點與否、代表的事物相同時，不違反 (1)。描邊與實心變體算同一圖形。【P2】
- (5) 只差顏色的圖形算同一圖形；每個顏色旁都有文字標明語意時，算不同圖形。【P3】
- (6) 2.11 與 (a)(b) 各自判定：指示是否合格只依 2.1(2)，違反 2.11 不改變這個結果，另記為一項缺口；處置是更換其中一方的圖形，不是改指示形態或移出動作列。【P1】
- (7) 例示：同一畫面兩顆可點按鈕都用放大鏡圖示，一顆開啟搜尋、一顆放大檢視圖片，違反 (1)；此結果與畫面上有沒有指示無關。
```

同步（落檔票處理）：`interaction-feedback-checklist.md` 反模式表可增一列「同一圖示承載兩個語意｜解決可點性後仍混淆｜更換其中一方圖形」；09f 答案鍵計分點「以 2.11 判不合格者不通過」與 C 一致，不需改。
