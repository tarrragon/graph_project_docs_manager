**A / B 的影響是硬性且立即的，不是理論風險**：方法論〈元件契約判準〉L67 明寫「**缺任一欄即契約不完整，元件票不得驗收，畫面票（實作單一畫面或頁面的 ticket）不得引用該元件**」。SPEC-004 §1.22 起 42 條目已全數落成、可被畫面票引用（`L580`）；新增欄位或新增必填段會使這 42 條目同時退回不齊全，連帶擋住引用它們的全部畫面票。這正是票面 `how` 引述的 `0.1.0-W3-106` 教訓，實際半徑在此。

**C 有現成先例**：〈元件文字歸屬（i18n-first）〉（`L198`）即為此形狀——它是獨立 `###` 節，規範跨元件的通用規則，由「slot 契約」欄以一句「使用者可見文字依〈元件文字歸屬〉三層規則處理」引用，本身不是欄位，因此不進入齊全判準的枚舉。本條款「有顯示就要有紀錄」同屬跨元件通用約束，形狀與之相符。

**若判定採 A 或 B**：`L351` 檢查清單那一行的 12 個欄位名是逐字枚舉，與 `L67` 欄位表構成兩份平行清單——只改其一即自相矛盾，須同步（此即 `reference-stability-rules` 規則 10「可變計數不實例化」的同型問題，該行已是實例化的枚舉）。
