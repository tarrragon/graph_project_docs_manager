### 已完成

- `lib/l10n/app_en.arb`／`app_zh.arb` 新增 `ticketsFiltersClearedSnackbarMessage`、
  `undoAction`（SPEC-004 §4.26 既定義未落檔的 key），重跑 `fvm flutter gen-l10n`。

  `targetTicketId`（帶目標跳入的目標票 ID）與 `targetFiltersAutoCleared`
  （一次性旗標，防止「復原」後目標再次被舊篩選隱藏時重新觸發清除，見程式碼
  註解），`copyWith` 同步支援。
- `lib/screens/ticket_list/ticket_list_screen.dart`：
  - `_ReadyListView.build` 內：目標存在於已載入票但被搜尋詞／篩選隱藏時，
    以 `WidgetsBinding.instance.addPostFrameCallback` 排程清除
    `searchQuery`／`statusFilter`／`priorityFilter`（`order` 不變），並呼叫
    `AppSnackBar.show`（`variant: withAction`、`actionLabel: undoAction`）；
    `onAction` 還原清除前的三個欄位值（不撤銷定位，`targetTicketId` 與
    `targetFiltersAutoCleared` 皆保留）。
  - `update()` 改為讀取 `ref.read(ticketListStateProvider)` 的**目前**值而非
    build 時閉包捕捉的 `state`——「復原」的 `onAction` 在較晚一輪呼叫，若沿用
    舊 `state`，會把中途已寫入的 `targetFiltersAutoCleared: true` 覆寫回
    `false`，使一次性清除誤判為未清除而重新觸發（實測踩中，詳見 Test
    Results）。
  - `isLocated` 接線位置保留（`_ticketRow` 簽章維持不含 `isLocated`），見
    Problem Analysis 元件缺口說明。
