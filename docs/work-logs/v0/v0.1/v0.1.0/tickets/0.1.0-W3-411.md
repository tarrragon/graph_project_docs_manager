### 4. 判準寫法草稿（取代〈驗證段機械檢查：依據句可溯性〉表頭與規則 3、4）

**表頭**：問句｜情境前提（逐字出自【輸入】）｜引文（逐字，可多句）｜出處｜引文位置在範例之外？｜判定詞逐詞對照｜驗證段無程式語法／框架名？

- **規則 3**：預期答案先拆成判定詞。判定詞的定義是：除問句已出現的詞以外，預期答案中的每個實詞片語，包含修飾語與行為者。每個判定詞的對照格只能填以下三種之一：
  - 引文中逐字出現的字串
  - 情境前提欄中逐字出現的字串
  - 「橋接」

  任一格填「橋接」即判否。同義改寫一律算橋接。
- **規則 3a**：【輸入】裡的事實可以當作推導材料，但從前提走到判定詞所用的規則，必須在引文內。只有前提、沒有規則，算橋接。
- **規則 3b**：引文指引文欄列出、且各自能被 `grep -F` 命中的句子。沒列出來的同格或同節前後文，不算引文。
- **規則 3c**：問句問的是本輸入的值時，預期答案須為封閉值。寫成條件式即判否。
- **規則 3d**：預期答案與【產出】矛盾時判否，以【產出】為準修正預期答案。
- **規則 4**：自證問句包括兩種，都從表中刪除：
  - 問句在問「能不能追溯」
  - 預期答案扣掉引文字串後，沒有剩下任何判定詞
- **條文唯一性**：票內另訂的判定規則，要寫回本節才生效。複核只依本節現文判定。
