**2-A（cadence）**：五檔一批，只看句型同骨化在跨篇同位置的分佈，以「位置 × 檔」的表回報。廢話前綴、口語修辭、地區用語歸 Round 1-A 已跑，本輪不重複。已知形態：方法論十一節每節皆為「判準／它回答的問題／為何這樣定」三欄表，interview-questions 六步皆為「問題／為什麼問」兩欄表，templates 六步皆為「表格＋填表提醒」——三份各自內部高度同骨，須判定這是規範長出來的形狀（該整批重寫並回頭改規範）還是體例一致（合規）。

**2-C（題目範圍＋跨 surface）**：產出逐段標表（段標／在不在標題範圍內／判定為在的理由或處置），**沒有列出段標的「已對齊」不成立**。五檔的每一個 `##` 與 `###` 都要進表。另查跨 surface 三角對齊：方法論標題、skill 六步流程表的步驟名、templates 六份產出物標題、interview-questions 六步標題——同一組步驟在四處各命名一次，名稱是否逐字一致。

**2-B（讀者旅程）**：三件事先固定——讀者是誰、從哪一篇起步、帶著什麼問題。走**三條路線**：(1) 後端工程師從 `saas-tech-selection` 的 async-queue 維度撞到「不可丟 event」被路由過來；(2) PM 從 `foundation-design` 的事件流仲裁維度進來要填地基產物；(3) 讀 spec 的人從 `/spec validate` 維度 5「資源競爭」被指來。產出逐跳表（帶著什麼問題離開前一篇／後一篇的前三段有沒有接住／走完那個問題答了沒有）。**術語知識卡覆蓋**：假裝讀者是不熟本框架的後端工程師，逐一掃文中術語，任何要去查的都是缺卡候選。宣告核對不進本 frame（Round 1-C 已跑）。

**2-B′（冷讀）**：兩層都要跑，同一 reviewer 執行。篇章層——假裝經搜尋直連落在單檔、零脈絡，逐檔問「這裡突然冒出的 X 是什麼」與「這一篇讓我具備什麼能力」（答不出或列出兩種以上互斥可能即命中）。句子層——**逐格判定表為必附產出**，單位是消費單位（一列含鍵欄、一個 checklist 項），每格記錄**復原出的命題**而非只記通過與否；判準是資訊充足四條件（命題完整／指涉閉合／實詞可反推／一句一命題），同步 invoke `compositional-writing` 取完整定義。表格鍵欄與標題是檢索鍵位，命題完整不適用，逐格掃鍵欄會產生假陽性。已知高風險格：方法論九格表的三個「不可棄」格、templates 六份範本的「填表提醒」段、interview-questions 的「為什麼問」欄。另帶兩問：讀起來累不累（要同時記住幾個未具名指涉）、卡住的讀者有沒有被接住（用到前置概念處有無主動提醒與路由）。

**2-B″（可執行走查）**：假裝讀者從零照做六步，每一步問「下一個動作是打開什麼檔案、輸入什麼指令、填哪一格」。任一步答不出即工具缺口，產出逐步表。**環境分支**：同一步在不同執行環境（後端服務／Flutter 桌面／訊息消費者）對應不同工具路徑，只寫一種環境會讓另一種的讀者卡住；六步各自標明是否有環境分支、有的話三種環境各自的動作是什麼。已知 Round 1 已命中「閾值初始值無素材」與「六份表寫進哪裡」兩處，本 frame 若再命中須標為重疊。

**2-B‴（情境可想像性）**：假裝讀者沒有高負載服務的實務經驗，逐一掃**機制陳述**（描述機制屬性、承擔判準、但沒說什麼時候會用到的句子），問「他想不想像得出什麼情況會需要這個」。三個成分逐條查：**系統形態**（什麼樣的系統會遇到）、**觸發事件**（什麼事件會逼出這個動作）、**微案例**（走到這裡出事會長什麼樣，三四句無身分短敘事）。微案例查四拍齊不齊（當初為何這樣做／何時開始出問題／**為何沒被及時發現**／止血代價），第三拍最不可省且是唯一推不出來的一拍，寫得比其餘三拍概括即為沒有來源的痕跡。挑的形態要是後果最不直觀的那幾個。本批已有 `worked-examples.md` 三場景，先掃出它涵蓋哪些節、當本批的參照樣本；方法論十一節中未被三場景涵蓋的節是本 frame 的主要對象。**不適用三形態**（分流型入口、純參考、程序型）判定時要指出該節哪一段構成該形態，以其中一節把整檔判為不適用是本 frame 最省力的關機鍵。

**2-D（體例與定位一致）**：拿定位宣告（Agent 指令／規範，讀完的動作落在世界上）逐節問體例。掃的是**裝置**不是語氣，七種：表徵對映清單、檢查順序的指示、配比與參數數字、順序關鍵加上顛倒的後果、可執行的操作判準、具體器具與工具作法、**序列連接詞（先、之後、最後）**。產出逐節表（節名／體例判定／命中哪些裝置／處置）。本批的預期是全數判為手冊而合規；**要找的是反向命中**——有沒有哪一節其實在做「在腦中重新歸類」的教材工作而混進了操作手冊，方法論的「為何這樣定」欄是主要嫌疑處。合規邊界五條見 `round-2-cadence.md` 2-D 節末。

**探針三支（2-B⁗ 低階 model 理解、2-B⁵ 翻譯、2-B⁶ 術語）**：定義與派發契約見 `.claude/skills/multi-round-review/references/round-2-probes.md`。2-B⁗ 因審查對象是規則類文件，報告加「第一個具體動作」欄；自評欄與比對欄分開讀。2-B⁶ 的可疑高頻詞候選：通道、卸載、佔用量、留痕、讓步、搶佔、等待型／自發型／推送型、不可棄／須留痕／可棄；**同批必須混入控制詞**（取自框架既有且語義穩定的詞，如「依賴方向」「回饋契約」），控制詞不收斂則該批結果不採用。
