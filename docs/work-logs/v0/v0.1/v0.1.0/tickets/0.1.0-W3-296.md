### 複驗批次的派發前登記（2026-09-11，改寫落於 d2fe8f46 之後）

**新 SKILL.md 的作者意圖清單（九項，B′ 批差集的分母）**

1. 產出是一份 L3 元件庫規格檔，落在專案 spec 目錄；目的是讓畫面票只剩「選件與排位」
2. 判準在方法論、形狀在範本、程序在本 skill，三者分屬三處（**上一輪 3/3 全漏的那一項**）
3. 全程是起手加五步，每一步有指定的檔案

### 依步驟重排時才浮現的一項根因（支持重切的證據）

原「模式 A 步驟 6／7／8」（填契約／完整性檢查／回填與建票）**就是全程的 step 3／4／5**，模式 C 的步驟 6／7 同理——同一件事在兩個層級各編一次號，而沒有任何一處說明。這是 F3「走完不知道下一步」的真正成因：讀者走完「步驟 8」以為結束，實際上跨了三個層級。改成依步驟切之後，三條路徑各自收斂為 5 步以內，交棒點自然浮現，複驗 F3 隨即由 3/3「沒說」轉為 3/3「有說」。

**這一項只有重切才會發現**——依角色切的結構看不到層級混疊。PM 於裁示前的保留意見（建議只加導航層）因此被本次執行推翻其中一半：邊界確實可用（Q3 4/4 全對），但邊界之內的編號層級不可用。
