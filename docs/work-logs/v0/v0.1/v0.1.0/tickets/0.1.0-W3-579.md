## Problem Analysis
### 問題根因

`0.1.0-W3-550` 的六輪重測中 8.2(3) 的 ③（文字內容界定）與 ⑤（預設值）零被引，成因是題材：該批兩題的誘因項（擺放方位、輕晃）落在 ①②④ 的字面射程內，讀者用界定句即可結案。`0.1.0-W3-575` 續查出 ③ 的最順手承接題 b17-A1（UX-Z8a）其 ③ 通路為純字面，並建議以 UX-W8s／UX-W8u 承接 ⑤。

本票逐項復驗後的直接原因分兩層：

1. **③ 的題材問題是字面自帶結論**：③ 句逐字列舉五個詞（字形、字重、字距、字級、大小寫），而「字形」「文字寫出」「都是同」在整份餵入節錄中各只出現一次且全部落在 ③。誘因項只要用到這五個詞之一，選款、選支、輸出三步皆可字面完成。
2. **⑤ 的題材問題不是字面，是承重款次**：⑤ 是舉證責任條款，只有在「有人把一項清單外的差異指派給清單內某一項」時才承重。8.2(3) 清單八項中，形狀、位置、文字內容三項已由 ①②③ 界定句處置，指派到這三項者由界定句否決，⑤ 不承重；大小、圖示、存在與否、填滿與否、線條樣式五項無界定句，指派到這五項者才只剩 ⑤ 可用。W3-575 建議的 UX-W8s 其誤指派標的正是「位置」，落在前一組。

### 影響範圍

- 受檢條文：`.claude/skills/ux-design-evaluation/references/interaction-feedback-component-semantics.md` 第 8 項（探針餵入範圍為該節錄檔的「只讀第 8 項」段）
- 受檢題材：b17-A1（UX-Z8a）、UX-W8s、UX-W8u、UX-W8v，以及本票新提的三個 ③ 候選誘因項
- 下游：`0.1.0-W3-552` 的出題與計分設計；`0.1.0-W3-541`「線條樣式／填滿與否以 ⑤ 為終局處置」決策的可驗證性

**已驗證的事實**：清單八項的界定句有無（逐項讀條文）；候選誘因項在全節錄與第 8 項範圍內的逐項命中數與所在款次（機械計數）；UX-W8s／W8u／W8v 三題改文前三輪作答的第 (4) 自行假設欄逐輪內容；b15 批次條文基準 `caee074f` 早於 W3-541 的 `a0ab92a94`（commit date 比對）。

**仍未驗證的假設**：⑤「清單的字面」一句採讀法甲時該款是否真能擋下指派（本票判定為兩讀，裁定另票）；候選誘因項的實際讀數（本票不出題不跑探針）。
