## Problem Analysis
### 問題根因

`0.1.0-W3-575` 第四段 (A) 記「UX-W8s（落影深淺與落影偏向）與 UX-W8u（顏色飽和與邊界柔邊）的誘因項在全部界定句中零字面命中，正解必須走 ⑤ 的舉證責任」。該句把「誘因項零字面命中」直接推到「⑤ 承重」，中間少了一步：**⑤ 的承重範圍由誤指派的標的決定，不由誘因項的字面決定**。

⑤ 是舉證責任條款，只在「有人把一項清單外的差異指派給清單內某一項」時承重。8.2(3) 清單八項中，形狀、位置、文字內容三項已有 ①②③ 界定句，指派到這三項者由界定句直接否決，⑤ 不承重。UX-W8s 的誤指派標的正是「位置」——其改文前三輪的第 (4) 自行假設欄逐輪寫的都是「我對『位置』這個項名的理解」，而 `0.1.0-W3-541` 的 ② 正是為這件事補的界定句。

### 影響範圍

- 受影響的落檔：`probes/w578-ux-manifest.md`〈逐題判定總計〉末段；`key/W3-417-b17-ux-A3c.md` 與 `A3c-post.md` 的〈承接題的兩項待復驗〉；`key/W3-417-b14-ux-C3.md`、`b15-ux-C3.md`（UX-W8s）與 `b15-ux-C4.md`（UX-W8u、UX-W8v）
- 下游：`0.1.0-W3-552` 的 ⑤ 量測承接題選擇與計分設計
- 條文：`.claude/skills/ux-design-evaluation/references/interaction-feedback-component-semantics.md` 的 8.2(3)（只讀不改）

**已驗證的事實**：清單八項的逐字順序與各項界定句有無（逐項讀 8.2(3) 現行條文）；三題的誤指派標的與指派主張來源。
**仍未驗證的假設**：⑤ 的「清單的字面」一句有兩讀，採讀法乙時該款在其唯一射程內失效（`0.1.0-W3-585` 裁定中，不在本票射程）。

### 相關 Error Pattern

`test-assertion-design-rules` 規則 E2：⑤ 本身是一道守衛，其失效方向是放行，而放行與「讀者本來就沒想到要指派」在判定值上同形——量測必須含一個已知該被擋下的指派。承接題若選到標的有界定句的那一題，量到的是別的款次擋下的結果，等同以錯誤的正向對照輸入驗證守衛。
