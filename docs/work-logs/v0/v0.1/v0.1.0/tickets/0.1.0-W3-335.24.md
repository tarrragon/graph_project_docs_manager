#### V1-09 未生效分析

題目：§1 禁依寬度自動切版 vs §4 尺寸契約選項含「換版型」。s1 與 s3 均指出兩句衝突（§1 禁令 vs §4 選項含被禁值）。s2 認為兩者分屬不同層級（元件級 vs 容器級）可同時成立。矛盾的核心在於 §4 的選項列表中仍保留「換版型」——即使 §1 禁止依寬度自動切版，選項的存在本身暗示該值合法，形成「禁令與選項並存」的結構性矛盾。修補票（W3-335.1 或相關矛盾統一票）可能已修正 §1 的措辭但未刪除 §4 的選項或加註排除條件。
