## Solution
### 分析結論

新條文在 #97 上**有實質作用但不完整**：三問中的「反例已試」給出了與直覺不同且更對的答案（類別 2 共三項），而「範圍已量」在本 issue 的實際輸入下給出錯誤的通過，兩檔擴散面表在本端不是區段擁有者、以及在「限本 consumer」的判準上，各有一處給不出答案。條文的射程止於「修法移進 issue」，issue 端沒有對應的證據狀態閘門，於是 #97 目前選定的修法（候選 E）帶著一個部分未驗證的承重點，任何一端的條文都不會擋它。

### F1 — 兩檔處置表第二檔的動作，本端執行不了

- **失效的句子**：擴散面處置表第二列的處置欄「修法形狀移至 framework issue 區段決定，發現票降為分析票（ANA）」。
- **失效的步驟**：走完三問判定候選 E 不豁免之後的下一步。
- **實際輸入**：#97 的 `show` 輸出顯示 6 個區段 owner 全為 `flutter-balance-77`；本端派發票未提供 owner 識別，依 `comment-as-section-protocol.md` 只能 `observe`。
- **後果（已發生，非假設）**：288 那一輪的統整因同一條件落在觀測流（comment 5629167716），該 comment 逐字寫明「本則不建立區段（派發未提供 owner 識別，依協定不得以代理人名替代）」。觀測不進 body 索引，`show` 的區段清單看不到它，`check` 的索引一致性也不涵蓋它。「移至 issue 區段決定」在此退化為「貼一則可能沒有人整合的觀測」。
- **條文缺的東西**：非擁有者時的落地形態（observe + 何時由誰整合進區段），以及 owner 識別未提供時該停手還是該續做。

### F2 — 修法進了 issue 之後，條文射程結束，終點無閘門

- **失效的句子**：同上一列的處置欄（issue 區段被當成修法定案的終點）。
- **失效的步驟**：候選 E 已在 issue 選定之後，本 consumer 要開實作票的那一刻。
- **實際輸入**：5629167716 第六節「本選擇的承重點（單一事實）：每個會寫狀態的呼叫端，其 state root 來源是一個模組級的選擇」，且自述「該承重點目前**部分未驗證**：93 檔可指名、其餘 66 檔未判定」。
- **後果**：條文對發現票要求證據狀態，對 issue 區段內的修法不要求。5629167716 自己寫了「實作票的第一步應是對它們分類，而非直接改 `lib/`」——這是作者自發的紀律，不是條文產物。若作者沒寫，讀者從 issue 只會讀到「候選 E（選定）」。
- **條文缺的東西**：區段內寫修法時的證據狀態標註要求（與發現票欄位同一要求，對象換成區段）。

### F3 — 第三問「範圍已量」對本 issue 的核心失效模式無鑑別力

- **失效的句子**：三問表第三列「涵蓋的呼叫點／檔案／consumer 數是量到的數字，而非估計？」
- **失效的步驟**：把三問套回 288 之前的時點（原「方案評估」寫下判斷二、以及本 consumer 早前的實作票成形時）。
- **實際輸入**：原區段記「15 個呼叫端只靠 import 來源與零星註解區分」；前一則觀測記漏接率 `163/164`。兩者都是量到的數字，第三問答「是」。
- **實際結果**：288 以跨行掃描複驗後更正為 `316/320`（成因：`project_root=` 寫在呼叫的次一行，單行 grep 掃不到），且指出「錯配不只一類」——類二的 12 個呼叫檔完全不在舊分母內。
- **後果**：條文只區分「量到 vs 估計」，不問分母的定義是否涵蓋全部已知失效類別、也不問量測手段自身的前提是否成立。**這正是 #97 的主題**（量測手段的前提不成立時，輸出與正確同形），條文在此對自己要治的病沒有免疫。
- **條文缺的東西**：第三問需要一個子問——分母怎麼定的、量測手段假設了什麼、該假設驗過沒有。

### F4 — 第一問「消費端已觀測」是二值問，實際輸入是連續量

- **失效的句子**：三問表第一列「修法要改的東西，誰讀它、在什麼條件下執行，是已觀測而非推定？」
- **實際輸入**：159 個呼叫檔中 93 檔 root 來源可指名、66 檔未判定（5629167716 第六節）。
- **後果**：58% 算不算「已觀測」，條文無門檻。兩個 session 對同一份輸入可得出相反判定，而兩份票面的外觀完全相同——這正是條文原則一要消除的那種不可分辨（「票面的修法敘述外觀不會顯示這個落差」）。
- **條文缺的東西**：部分觀測時的處置（例如：未判定的部分必須逐項列出並成為實作票的第一步），而非一個是／否。
