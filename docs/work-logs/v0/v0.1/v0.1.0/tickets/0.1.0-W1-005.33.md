## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### 修復方式

依 SPEC-004 4.14 十一欄位契約實作 `TableColumnHeader`，三個具名建構子
對應三個變體（`plain` / `sortable` / `twoLine`，變體名 `static` 改
`plain` 避開 Dart built-in identifier 疑慮）：

- `plain`：一行 caption（`textSecondary`、半粗），`Semantics.header`。
- `twoLine`：第一行重用 `AppText.mono`（UC ID），第二行 caption（名稱），
  行間 `Space.xxs`；朗讀標籤「{ID}，{名稱}」。
- `sortable`：StatefulWidget（`_SortableHeader`），Tab 進入焦點順序、
  Space / Enter 觸發 `onSort`（沿用 `ExpanderIcon` 的 Focus +
  Shortcuts/Actions + InkWell 樣式）；`order` 為 `asc`/`desc` 時渲染
  `AppIcon.sm`（`accentStrong`）指示；`Semantics.button` label 為
  `l10n.sortA11yLabel(label, orderText)`；本元件不循環 `order`，下一個
  值由呼叫端依 SPEC-003 §3.4 S1–S2 決定（元件只呈現值 + 回呼）。

SPEC-004 4.14 同步更新（version 1.11 → 1.12）：互動反應表、狀態矩陣
exit path、無障礙「狀態變化播報」列，依 SPEC-003 §3.4 S1–S7（已由
`0.1.0-W1-057` 補齊）填入具體值並移除「待決」文字；§4.0.9 待決清單
移除 4.14 一列（餘 4.13 `FilterDropdown`，非本票範圍）。

token 引用：色彩取 `AppColors.textSecondary` / `accentStrong` /
`textPrimary`（經 `AppText.mono`）；間距取 `Space.xxs` / `Space.xs`；
圓角 `Radius.sm`；尺寸 `LayoutSize.hitTargetMin` / `iconSm`；字級
`AppFontSize.caption`；無硬編碼數值。i18n 取 `l10n.sortA11yLabel` /
`sortNone` / `sortAscending` / `sortDescending`（既有 key，`0.1.0-W1-056`
已建）。
