  textSecondary 用於 caption 字級（AppFontSize.caption）的次要文字、徽章、欄首、副標，全部是小字，未達 AA 一般字級。畫布實測值即此色（gray500，116 次），屬設計端 token 值問題，非個別元件問題。SPEC-004 §4 各元件的對比欄暫記「含 textSecondary 者未達 AA，待本票核定」，不阻擋元件契約消費（對比要求是 a11y 子節的一列，非待決欄）。
