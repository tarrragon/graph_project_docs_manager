### `<itemId>` 取值規則（.65 範圍外發現）

`0.1.0-W3-335.65` 範圍外發現 3：V4R4-04 G13 `<itemId>` 取值未定義。查
`lib/screens/gap_report/gap_report_models.dart`，`GapReportItem.id` 已是
「穩定識別碼，供 `card-gaps-<itemId>` 錨點使用」的資料模型欄位，只是規格未
載明取值規則。已於 §2.9〈動態 ID 段取值〉段內補：`<itemId>` 取
`GapReportItem.id` 字面值，0.1 由 fixture 直接給定；並在 §3.5〈破洞項的指向
節點〉補一句交叉引用，明確「該項指向哪個節點」（CLAUDE.md §6「破洞分類」
待決）與「itemId 本身的取值規則」是兩件事，後者不受前者待決影響。
