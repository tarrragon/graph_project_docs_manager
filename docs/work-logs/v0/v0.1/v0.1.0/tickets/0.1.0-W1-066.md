## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因

`lib/components/blocked_state.dart` 的 `withDetail` 變體需為「檢視詳情」
動作按鈕附加 `Semantics(expanded: isDetailExpanded)`，但 SPEC-004 4.4
AppButton slot 契約無語意標籤參數；包裹 Semantics 後型別不再是
`AppButton`，`ButtonRow.children` 型別限定為 `List<AppButton>`
（SPEC-004 4.34），代理人只能在 `blocked_state.dart` 以等價 `Wrap`
（同 spacing／alignment token）重排繞過 `ButtonRow`，使排列不變式失去
單一來源。

### 影響範圍

`docs/spec/ui/SPEC-004-component-library.md`（4.4 契約）、
`lib/components/app_button.dart`、`lib/components/blocked_state.dart`、
對應測試檔。

### 相關 Error Pattern

無對應既有 error-pattern，屬「子件契約缺參數導致容器被繞過」家族
（與 0.1.0-W1-064 AppText 語意色案同源）。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### 契約先行

SPEC-004 4.4 AppButton slot 契約新增 `semanticExpanded`（`bool?`，
`null` 時不附加旗標），無障礙「狀態變化播報」列補一句說明；版本
1.12 → 1.13，變更歷史新增一列。frontmatter `version`/`updated`
同步更新。

### 實作

`app_button.dart`：新增 `semanticExpanded` 建構參數；`semanticExpanded`
非 `null` 時以 `Semantics(container: true, button: true, label:
widget.label, enabled: widget.enabled, hint: widget.disabledReason,
expanded: semanticExpanded, child: ExcludeSemantics(child: result))`
明確擁有語意節點（對齊 SPEC-004 4.7 NavItem 既有寫法：
`container: true` + 內部 `ExcludeSemantics`）。實測 `container: false`
（預設）的屬性向上併入祖先節點而非本元件自身按鈕節點，無法承載
`expanded` 旗標——此為初版嘗試（外層 `Semantics(expanded: ...)` 不指定
`container`）在測試階段暴露的落差，改採明確擁有節點的寫法後
`flagsCollection.isExpanded` 正確回報。

`blocked_state.dart`：移除本地 `Wrap`，`withDetail` 動作列改回
`ButtonRow`，「檢視詳情」鈕改以 `semanticExpanded: isDetailExpanded`
傳遞展開語意；移除未使用的 `flutter_screenutil` import（`Wrap` 移除後
`.w`/`.h` 不再直接使用）。

### 測試

`app_button_test.dart` 新增兩則測試：`semanticExpanded` 為 `null` 時不
附加旗標、`semanticExpanded: true` 時 `flagsCollection.isExpanded` 為
`true` 且 `label` 仍等於傳入值。

`blocked_state_test.dart` 新增一組「組合規則」測試：`plain`／
`withDetail` 動作列皆存在 `ButtonRow`（`Wrap` 恰一個，來自 `ButtonRow`
內部實作，非本地繞道）；`withDetail` 檢視詳情鈕的 `expanded` 語意等於
`isDetailExpanded`。

### Phase 4 結論

BlockedState 回收 ButtonRow，無需進一步重構。
