### 一、四列管轄表落點

落方法論 `component-library-bidirectional-constraint-methodology.md`〈容器亦為元件〉，接在
「子件的組合規則不得另定間距，以容器的最小間距為準。」句後、原「框架容器……」句之前。
表格三欄（距離的兩端｜管轄｜依據）、四列，第四列標「（本次新增）」；表後接兜底句
「兩端皆非上列四種組合者（如兩個容器之間），對兩者的共同上層重問一次同一判別問句，由該層承載。」

### 二、四檔各自改動

| 檔案 | 改動 |
|---|---|
| `methodologies/component-library-bidirectional-constraint-methodology.md` | 新增四列管轄表 + 兜底句（見上） |
| `skills/doc/templates/component-library-spec-template.md` | 〈組合規則〉引言補一句：「內距與『不得另定間距』的分界看這段距離的兩端各是什麼，判定表見方法論〈容器亦為元件〉『不得另定間距』射程判定表。」——寫出判別問句本身，不只給檔名 |
| `skills/component-contract-design/references/step-3-fill-contract.md` | 組合規則列「常見空格與來源」欄補：「內距與鄰件間距常混填同一格——分界看這段距離的兩端各是什麼，判定表見方法論〈容器亦為元件〉『不得另定間距』射程判定表」 |
| `skills/doc/examples/component-library-chained-examples.md` | 該節【驗證】段兩問的「預期」改為引用四列表的第一、二列判定，刪除原自帶判準句「內距是元件邊界內部的空間，兩者不同」 |
