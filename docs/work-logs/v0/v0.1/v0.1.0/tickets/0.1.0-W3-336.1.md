### 第二階段：矛盾裁決草稿（不改檔，待 WRAP 評估）

#### C08：handoff-mode「命名：值不變」vs examples.md「萃取不等於照抄」（值會歸納改變）

- **矛盾位置**：`handoff-mode.md`〈接手模式〉四步程序步驟 2「命名」 vs `examples.md`〈萃取不等於照抄〉
- **兩方原文**：
  - handoff-mode.md：「2 命名　逐一給名字，值不變」
  - examples.md：「同一份畫布的間距實測出七種值，那是產生器輸出而非設計過的尺度。token 化時歸納為離散具名階並記錄映射；照抄會把雜訊固化成規格。」
- **建議以哪方為準**：兩者不是對等的相反規則，而是各自站在判斷鏈的不同位置——建議在 handoff-mode.md 補回「值是否可信」的判斷，而非整條改押其中一方。預設仍是「值不變」，但補一句例外：來源經 handoff-mode.md 自身〈萃取的前提是既有 artifact 可信〉表判定為「artifact 由產生器輸出」（該表既有列）時，改依 examples.md 的歸納做法。
- **理由**：handoff-mode.md 本文已列「artifact 由產生器輸出」為萃取前提不成立的四種情形之一，要求「須先驗證來源」；examples.md〈萃取不等於照抄〉的畫布間距案例，本質就是這一情形的具體示範（「那是產生器輸出而非設計過的尺度」），不是與 handoff-mode 相反的另一條規則。目前「命名」步驟的措辭把「值不變」寫成無條件陳述，沒有指回同檔已有的這個分岔，讀者才會分裂成甲（逐一命名、值不變）與乙（歸納為離散階、值改變）兩種讀法。
- **改後文字草稿**：
  - handoff-mode.md 步驟 2 改為：「2 命名　逐一給名字。值本身是否維持不變，取決於來源是否可信（見下方〈萃取的前提是既有 artifact 可信〉表）：既有語意決策的值維持不變；經判定為量測雜訊或產生器輸出者，改依歸納為離散具名階（範例見 `references/examples.md`〈萃取不等於照抄〉）」
  - 「萃取的前提是既有 artifact 可信」表「artifact 由產生器輸出」列的處置補一句：「…驗證為產生器輸出或量測雜訊者，命名時歸納為離散具名階而非逐值保留（見 `examples.md`〈萃取不等於照抄〉），與步驟 2『值不變』的預設不同」

#### C09：dimension-product-notes「無可用部分時標無」vs SKILL.md「判不出來一律待定」

- **矛盾位置**：`dimension-product-notes.md`〈非 SaaS 專案的形態轉換〉 vs `SKILL.md`〈產物欄的五種合法答案〉表下方強調段
- **兩方原文**：
  - dimension-product-notes.md：「確認無可用部分時，改指專案自身 CLAUDE.md 技術選型記錄，或依 `SKILL.md`〈產物欄的五種合法答案〉標『無』+ 理由。」
  - SKILL.md：「判不出來一律填『待定』，任何情況下都不得以『無』代之」（並稱此為「本 skill 唯一一種會讓整張盤點表失效的填法」）
- **建議以哪方為準**：以 SKILL.md 為準。dimension-product-notes.md 的「確認無可用部分時」原意應是指「已完成改寫產物的嘗試、且能具體說出不適用的理由」，屬於判定完成的「無」，不是「判不出來」；但現有文字沒有把「確認」等同於「已完成判斷」寫清楚，才會被讀成兩種相反做法（.7 F15 記錄的甲標無、乙標待定）。
- **理由**：SKILL.md 對「無」與「待定」的區分軸是「有沒有做完判斷」（無＝判定後不產出，待定＝該判而未能判），不是「有沒有找到可用的部分」。dimension-product-notes.md 目前把「無可用部分」直接等同於可以標「無」，跳過了「是否已完成判斷」這一步，才會與 SKILL.md 的強調衝突；修法後兩處條文改用同一判斷軸，不再各自表述。
- **改後文字草稿**：
  - dimension-product-notes.md〈非 SaaS 專案的形態轉換〉段尾改為：「…確認無可用部分時，先問『能不能具體說出這個維度對本形態不適用的理由』：答得出時改指專案自身 CLAUDE.md 技術選型記錄，或依 `SKILL.md`〈產物欄的五種合法答案〉標『無』+ 理由 + 重評條件；答不出時（例如不確定是否遺漏權威中的某個判準），依 `SKILL.md`〈權威缺席時〉『框架內確實無承接者』標『待定』，不得以『無』代之。」

以上兩則僅為建議草稿，未落地到檔案；本票 where.files 範圍內僅第一階段 X1/X2（含 SKILL.md 一併修正）已實際變更。
