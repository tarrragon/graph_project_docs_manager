## Problem Analysis
### 問題根因

現行 doc 探針為**單次請求答全卷**：一輪＝一個 agent 讀 `q/<批次>-doc-1.md`（b21 為六題、題序固定）
後一次寫出全部作答。受測配對 DOC-19d × DOC-19c(a) 因此必然共用同一個 context，跨題帶入是派發形態的
**結構性結果**，不是偶發污染。

題目檔規則 5（「同一題的各子問互相獨立…不得以另一個子問的填法、缺漏或結論作為本子問的理由」）是現行
的唯一處置，形態為**文字勸阻**——防護放在被測者手上。這條規則的存在本身即證明器材已知跨題污染會發生。

`0.1.0-W3-590` 已把判準層能做的事做完（兩訊號＋甲乙分型），並明寫其邊界：**帶入不能由判準完全隔離**，
乙型輪的分支讀數仍帶一個未被排除的替代解釋（讀者沿用程序措辭時是否也沿用了分支選擇），該替代解釋
只能由派發形態消除。本票承接的即是這個殘餘。

### 實驗發現

**已驗證的事實：**

1. 配對分母守恆，198 為 66 × 3，器材輸出與推算一致，無差集。
2. 獨立臂的節錄檔讀取次數為全卷臂的 2.2 倍（11 對 5），此為成本估算的機械底數，非推估值。
3. 既有帶入器材可以最小改動（一個可選後綴參數）同時服務兩臂，且預設行為不變使 b21 原讀數維持可複驗。
4. 節錄檔位元同一性與作答 model 兩項登記缺口確實存在（器材零 sha256 輸出、manifest 零 model 欄位），
   已成票 `0.1.0-W3-609`。

**仍未驗證的假設**：逐題獨立 context 是否真使訊號 1 不命中。本票只寫定回測與其否證路徑

## Solution
### 分析結論

派發形態裁定為**雙臂同批**：逐題獨立 context 為主臂，全卷 context 為對照臂。
全文（切題／派發／合併／核對四段可直接執行的步驟、成本表、降級表、回測步驟與否證路徑）落於
`probes/w600-dispatch-form-manifest.md`，供下批逐字併入。

| 項目 | 裁定 |
|---|---|
| context 粒度 | **一題（含其全部子問）**。子問級切分須把前言複製進每個子問檔，即改寫題幹，會斷開題幹凍結鏈（b10→b21 逐字全等，sha256 `0c2c3e8fe0958a28`）並使全部跨批位移讀數失去基線 |
| 主臂派發 | 每題每輪一個 **fresh agent**（禁用 fork——fork 繼承派發者完整對話 context，污染量級遠大於全卷帶入）。prompt 只給單題檔路徑、節錄檔目錄、作答格式檔、輸出路徑，不得提及其他題號或本批題數 |
| 合併 | 六個單題答卷依 canonical 題序合併為 `a/<批次>-doc-1-r{N}-indep.md`，既有判定流程與帶入器材零改動吃到獨立臂讀數 |
| 器材改動 | 兩支 carryover 器材各加一個可選檔名後綴，預設空字串＝現行行為（b21 原讀數維持可原指令複驗） |
| 題目檔規則 5 | **保留，逐字不動**；但記載地位改為「題內子問的殘餘防護」，不得再被當作跨題帶入的處置 |

### 對 `0.1.0-W3-590` 建議的修正（本票的主要結論）

W3-590 §五建議「兩組讀數之差即帶入幅度」。**該式在分支輸出對這一軸上沒有定義**，本票改寫之。

兩臂至少差五項，不只差在跨題 context：

| # | 差異 | 作用 |
|---|---|---|
| D1 | 卷內位置資訊消失（「這是一份六題的卷子」本身即提示，讀者可能更用力區分兩題，也可能趨同） | **雙向，方向未知**；與被測量同向可加可減，無法以符號約定排除 |
| D2 | 檔頭「題數」欄必須改（`6`→`1`），規則 5 在單子問題變空洞 | 小，已列為唯一允許的檔頭差異 |
| D3 | 節錄檔讀取次數與時點不同（全卷臂共用一次讀取，獨立臂每題重讀） | **訊號 2 在獨立臂結構性不可能命中**，其不命中不構成證據 |
| D4 | 作答格式漂移（全卷臂受前題節奏約束，獨立臂只靠格式檔） | 訊號 1 的定義完全依賴判定欄／依據句欄的切分 |
| D5 | 抽樣單位不同（全卷臂一輪＝一實例答六題；獨立臂一輪＝六個獨立實例） | 兩組計分的變異結構不同，單純相減無統計意義 |

**正面回答**：

1. 分支輸出對這一軸上兩臂測的是**兩個不同的量**——獨立臂的兩題由不同實例產生，回答「題面的存在性
   事實是否使輸出隨之改變」（群體層）；對照臂由同一實例產生，回答「同一讀者是否做分支判別」（個體層）。
   相減等於把兩個不同問題的答案相減。
2. 帶入訊號這一軸上兩臂對照**成立**——訊號 1 是字面字串的存在性，不依賴分支判別的內容，D1–D5 皆不
   改變其定義。對照臂命中而獨立臂不命中者＝可歸因於共同 context；兩臂皆命中者＝模型層共同語彙，
   **不得歸因於帶入**。
3. 故對照臂的功能不是減出帶入幅度，而是 (a) 訊號 1／2 的命中對照與偽陽性基線、(b) 保留「同一實例
   對兩題輸出相反分支」這一獨立臂結構上產不出的形態（b21 的 r3 即此形態）。

**降級 A（受測配對獨立）**：只有 19d 與 19c 跑獨立臂，probe agent 9。失去三項：其餘四題無獨立臂對照；
**訊號 1 門檻 B 在獨立臂失去載體**（獨立臂只剩 3 子問＝3 配對，全量為 12 子問 66 配對，噪音層無法扣減）；
失去獨立臂作為訊號 1 偽陽性基線的用途。**降級 B（棄對照臂）不採**——拿掉唯一能驗證帶入訊號有效性的
對照，等於回到判準說了算。

### 回測（以 b21 既有三輪為對照臂）

材料凍結核對先行：`selfcheck.py b21-doc-1` RC=0／47 引文／failures=0；**不重跑 `verify_head.py`**
（HEAD 已前進，回測讀的是已凍結的節錄檔檔案）。步驟：切題（sha256 六題自比對）→ 派發 18 個 fresh
agent → 合併三檔 → `carryover_check_b21.py -indep` 與 `carryover_control_b21.py 5 -indep` → 與對照臂
三個命中字串（6／7／10 字，命中數皆 1）並列。

**否證路徑（事先寫定）**：獨立臂若仍命中同量級字串（≥5 字、命中數 ≤2），則訊號 1 量到的不是 context
帶入而是模型層共同語彙，`0.1.0-W3-590` 對 r1 的甲型判定與由此導出的「b21 有效輪＝2」全部須重判。

**回測不改 b21 結論**：b21 既有三輪屬對照臂；獨立臂讀數只支持或否證「題級切分是否消除訊號 1」，
不併入 b21 的分支輸出對方向判定。b21 的「有效輪 2、方向不一致、降為形態登記、不下結論」維持不變。

### 候選方案

| 案 | 內容 | 利 | 弊 |
|---|---|---|---|
| **A（採用）** | 雙臂同批、題級粒度、兩臂各自報告、禁止相減 | 主讀數無跨題帶入；帶入訊號有對照與偽陽性基線；最強形態由對照臂保留 | 成本 ×4；判定工作量 ×2 |
| B | 只改主臂、廢對照臂 | 成本 ×3 | 帶入訊號是否由 context 產生無從驗證；失去「同一實例兩題相反分支」形態 |
| C | 維持全卷、只靠 W3-590 判準 | 零成本 | 乙型殘餘不可消（W3-590 自述的邊界），分支讀數永遠帶一個未排除的替代解釋 |

**採 A。** B 拿掉的正是本票唯一能證明派發形態有效的對照；C 是本票的起點，其邊界已由來源票寫定。
