### Task Reference
- 0.1.0-W3-590 what: b21 的帶入檢查對三輪給出兩組相反判定：j1 判 r1「否」（截取範圍隨各自判定而異）、r2「是」、r3「是」（引句逐字全等且截點相同）；j2 判 r1「是」（推理措辭同一句式模板、兩題都附加依據句中未被引用的同一補語）、r2「是」、r3「否」（引句重疊屬結構性、輸出分支相反故無模板沿用）。分析判準「依據句是否互相複製（引句組合或推理措辭）」的歧義點並改寫為可逐條機械核對的形態

### Rationale Chain
- 0.1.0-W3-590 why: 帶入檢查是四格讀數的前置閘門——判為「是」的輪其四格填不可判讀、不併入計分。b21 兩位判定者各自判出一輪「否」兩輪「是」，但「否」的那一輪不是同一輪（j1 是 r1、j2 是 r3），故兩人算出的有效樣本完全不重疊。判準現行措辭「引句組合或推理措辭」把兩個獨立訊號併在一句裡且未給門檻：兩題同落第五列時引句重疊屬結構性必然，而「推理措辭複製」無可核對的字面依據。不修則下一批的四格有效樣本數仍不可重現
