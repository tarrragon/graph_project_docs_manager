### 結論

三項門檻中兩項生效、一項未生效。逐項數據與歸因在「重現實驗結果」，此處只記結論與方法層面的收穫。

**生效**：V2（〈判定起點〉的「被掏空感」3/3 → 0/3）、V3（「方法論」的缺料命中 3/3 → 0/3）。

**未生效**：V1（F7 仍 3/3 命中），且命中的其中一項是 3.0.1 修法自己造成的事實錯誤，不是讀者誤讀。

### 方法層面的三點

1. **門檻先寫死是這一輪唯一擋住自我感覺良好的東西。** 若沒有派發前登記「0/3 才算生效」，第三輪的結果（方向性誤讀 0/3、結構修法確實奏效）完全可以被寫成「F7 已改善」——因為它確實改善了一半。門檻把「改善」與「達標」分開。

2. **修法會製造新缺陷，而新缺陷與舊缺陷長得不一樣。** F7 兩次修法各失敗一次、方式不同：第一次改段落沒改結構，第二次改對結構但陳述範圍大於事實。只驗「舊問題還在不在」會漏掉第二種；本輪能抓到是因為探針問的是「有哪些位置有兩種以上讀法」而不是「F7 好了嗎」。

3. **變項單一才有因果結論。** 第二輪的實驗組同時改了兩件事，只能說「對照組無效」；本輪把「方法論」單獨移組、只改指路方式，才得到「行內指路有效」。設計對照時把手段拆開，是能不能下結論的分水嶺。

### 自檢結果

- **acceptance 1（F7 與第二輪比對並下判定）**：3/3 對 3/3，判未生效；命中內容已分解為四類並逐類標明是消失、新增、還是持平。
- **acceptance 2（判定起點與第二輪比對並下判定）**：3/3 對 0/3，判生效；疲勞點移動位置已記錄並處置。
- **acceptance 3（方法論與第二輪比對並下判定）**：3/3 對 0/3，判生效；變項單一性已論證，據此補上第二輪缺的因果歸因。
- **acceptance 4（新 finding 完成歸因並分處置與不處置兩類）**：處置七項（V1 迴歸、V2 密度、相鄰資產表移位與改欄名、列舉不是判定、拆／併 topic sentence、foundation-design 與 token 表的行內指路、「此時」與「出口」兩處語意）；不處置兩項並記理由（第一個具體動作由 3/3 降為 2/3 屬 portable 宣告的必然代價；`addresses.md` 與 `SKILL.md` 被 1/3 指為「沒給路徑」屬對同目錄相對檔名的過度要求）。
- **未做而應說明者**：本輪的九項處置全部未經第四輪量測。V1 已連續兩輪未達門檻，第三次修法是否生效同樣只有再跑一批才知道——這與前兩輪的教訓相同，不宜以「這次看起來對了」代替量測。是否再跑第四輪屬 PM 與用戶的排程判斷。
