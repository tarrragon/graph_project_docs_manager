**變更摘要**：`.claude/skills/ux-design-evaluation/references/interaction-feedback-component-semantics.md` 改寫 8.2(2)、8.2(3) 兩處。

**8.2(2) 全文（改後）**：
「只有顏色」依序判兩點，兩點都成立才算違反，第一點不成立即結束判定，判不違反，不進第二點：第一點，把這些元素承載語意的顏色全換成同一個顏色後，還分不分得出哪個是哪個；分不出，第一點成立。換色只換色值，不改變文字內容、填滿與否、形狀、大小、位置——換色後仍在的差異，依 (3) 判。（轉灰階是本問法的近似手段，不是判準：灰階保留明度，只差明度的兩色轉灰階後仍可區分，不足以據此判第一點不成立。）第二點，各自旁邊沒有文字標明它代表什麼。

封堵句「換色只換色值，不改變文字內容、填滿與否、形狀、大小、位置」位於第一點內、緊接「分不出，第一點成立」之後——與 0.1.0-W3-482 誤傷實驗（實驗 2）驗證過的位置一致，確保換色的思想實驗只拿掉顏色這個資訊通道，不連帶抹平填滿與否、文字內容等其他通道。

**8.2(3) 全文（改後）**：
本清單各項依 8.1(1)，須是使用者用來分辨這些語意所依據的差異；與語意無對應關係者不算。灰階後仍可區分者不違反 (1)。可區分的差異有：形狀、大小、位置、圖示、存在與否、填滿與否、線條樣式、文字內容。明度、深淺、對比強弱、彩度、色相都不在本清單內——它們是顏色的維度，不是顏色以外的訊號。

句首「本清單各項依 8.1(1)……」為 0.1.0-W3-482 乙-2 甲案（回指 8.1(1)），非乙案總限定；乙案「兩個實例各自排列所在的位置不算」未採用，草稿中不含該句。
