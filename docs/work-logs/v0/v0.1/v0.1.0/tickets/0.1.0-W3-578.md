### WRAP 三問（認領時）

- **W（Widen）**：候選一，四段結論全部寫進新建的 `w578-ux-manifest.md`，答案鍵不動；候選二（採），manifest 承載比對表與兩票重判，降級／但書／判定者註各自落到對應答案鍵，使下批不讀 manifest 也會在答案鍵就地看到。採候選二的理由是 acceptance 第 2、3 條逐字要求「寫入對應答案鍵」與「寫入判定者註」，候選一不滿足。
- **A（Attain distance）**：本票擠壓的是 `0.1.0-W3-579`／`W3-580`／`W3-581` 三張 W3-575 衍生票的排序。本票為 P0 且是下批 ux 出題的前置（不落檔則 A3 軸仍會被當可證偽讀數使用），三張衍生票皆非下批阻擋項。
- **P（Prepare to be wrong）**：最可能的失敗是新增條目引入 `⟪⟫` 而改變答案鍵的 quote 集合，使 `selfcheck.py`／`verify_head.py` 的比對項數變動、與既有基線不可比。防護：逐字引用一律用 `⟦⟧`（沿 `0.1.0-W3-555` 的保留法），落檔前後對同一 HEAD 各跑一次兩支工具做差集。實測差集為空（見 Test Results）。
