## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因

Wave A 四票依 SPEC-004 v1.8 實作；`0.1.0-W1-060` 將 SPEC-004 升至 v1.9，
新增 `AppColors.textDisabled` 供停用態文字/圖示與純裝飾箭頭圖示使用，並刪除
`BadgeTone.secondary`（`textSecondary`/`surfaceChip` 對比 4.02:1 未達 AA）。

### 影響範圍

- `lib/components/app_button.dart`：disabled label/icon 前景色、
  `disabledForegroundColor` 由 `textSecondary` 改 `textDisabled`
- `lib/components/badge.dart`：刪除 `BadgeTone.secondary`；`_statusToneMap`
  的 `rejected`/`superseded`/`revised` 改對映 `BadgeTone.neutral`
- `lib/components/expander_icon.dart`：箭頭圖示色改 `textDisabled`
- `lib/components/app_icon.dart`：`color` 參數型別為 `Color`，已可接受
  `AppColors.textDisabled`，無需改動
- `test/unit/components/badge_test.dart`：`status 對映表` 測資與
  `toneForeground` 對照表同步改 `neutral`

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
依 SPEC-004 v1.9 逐項回填：

1. `AppButton`：disabled 態的 label/icon 前景色與
   `TextButton.styleFrom(disabledForegroundColor: ...)` 皆改引用
   `AppColors.textDisabled`（原 `textSecondary`）。`disabledReason` 說明文字
   維持 `textSecondary`（§4.0.1 契約不變）。
2. `Badge`：`BadgeTone` enum 移除 `secondary` 成員；`_toneColors` 對照表
   移除對應項；`_statusToneMap` 的 `rejected`/`superseded`/`revised` 三值改
   對映 `BadgeTone.neutral`（§4.0.2 帶色表面規則：`textPrimary` 後與
   `neutral` 視覺無差異）。檔案頭 doc comment 同步更新，移除「待後續票移除」
   的暫定敘述。
3. `ExpanderIcon`：箭頭圖示色由 `textSecondary` 改 `textDisabled`（純裝飾
   箭頭，§4.0.2 表 2）。
4. `AppIcon`：`color` 參數本為 `Color` 型別（非限定 enum），已可直接傳入
   `AppColors.textDisabled`，無需修改。
5. `page_title.dart` 依約束未觸碰（另票並行）。

### 自檢結果（Phase 4）

- 變更僅涉及色彩 token 引用切換與 enum 成員刪除，無新增邏輯分支、無新增
  複雜度；函式/類別結構未變。
- 重構需要：否。技術債務：無新增（原 badge.dart 檔案頭「待前置調色票回填」
  的技術債務標記已隨本票消除）。
- 程式碼品質：A（沿用既有 token 化與 slot 契約設計，無需重構）。
- 結論：無需進一步重構。
