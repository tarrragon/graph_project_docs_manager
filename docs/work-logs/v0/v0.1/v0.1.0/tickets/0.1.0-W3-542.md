### PM 裁決：本票升 P1，且是 W3-541 的前置（原僅 P2 獨立票）

兩位判定者對 A3b 殘留二階訊號的判讀分歧：J1 判共用名詞「六邊形」承重（**唯一答對的那一輪由它起步**），J2 判為未被使用的弱訊號。

**這項分歧不是措辭潔癖，它決定 baseline 的數值。** 若 J1 為真，A3b 的真實通過率是 **0/3** 而非 1/3——也就是拆掉全部槓桿後，8.2(3) 的射程條文效力為**零**，而不是三分之一。

後果落在 W3-541 的驗收上：改文後重測若得 2/3，對照 1/3 是「提升一輪」，對照 0/3 是「從零到二」。兩者對修法是否足夠的結論不同，而 baseline 一旦被改文覆蓋就再也回不去。故本票須在 W3-541 之前定案，已設 W3-541 blockedBy 本票。

**兩位判定者一致的部分不在本票爭點內**：一階槓桿已移除、A3b 零輪以題幹事實作決定性否決、證否成立。本票只裁二階訊號的效力，不重開證否。

處置要求：改題幹或不改皆為合法終態，但須寫明理由並給出該終態下 A3b 的定案 baseline 數值（0/3 或 1/3），供 W3-541 引用。
