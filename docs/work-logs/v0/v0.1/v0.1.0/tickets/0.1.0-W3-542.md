### 二階訊號承重實驗（A2c／A3c 第三版）

### 一、權衡結論：改（以新增第三版的形式，不動 A3b）

票面的第一項工作是「A3b 共用圖形名詞『六邊形』的改或不改」。結論為**改**，但改法有三項限制，
使「接近改變題意」的代價降到可接受：

1. **不動第二版。** A3b／A2b 逐字保留（mtime 皆停在 `10:03:16`），第三版另立 A3c／A2c 兩檔，兩版可逐輪並列。
2. **只撤圖形的名稱，不撤可觀察屬性。** 「六邊形」是圖形的名稱且以單數量詞使兩類共指一個圖形；
   第三版改為兩類各自描述一次「由六條直邊圍成」——屬性不宣告兩者是同一個圖形。
   完全不提邊數會使爭點由「同一圖形轉角度」變成「兩個真正不同的圖形」，那是另一道題，不採。
3. **其餘逐字不動。** 四個子問、餵入欄、五條作答規則、其餘五條前提句一字未改；
   建置由 `tools/b17_ux_c_build.py` 執行（複製 + 指定字串替換 + 逐檔 unified diff），A3 三處、A2 兩處改動（另各一處檔頭與題號）。

### 二、兩位判定者效力判讀分歧的採信理由

採 **J2**（未被使用的弱訊號），不採 J1（承重）。採信依據是實驗結果，不是原文的再一次解讀——
兩種讀法都能由 A3b 的原文支持，再讀第三次不會收斂，這正是本票改做實驗的理由。

J1 的主張可拆為兩句：(a) A3b-r2 確實由「六邊形本身的幾何形狀相同」起步；
(b) 因此撤走該名詞後該輪也會失守，A3b 的真實通過率是 0/3。

- **(a) 成立**，J1 對事實的判讀正確，J2 低估了該句與題幹名詞的關聯。
- **(b) 不成立**。撤走名詞後仍有一輪否決誤指派（A3c-r3），且三項計數與第二版逐項相同：
  正面命中 2、否決 1、以題幹事實作決定性否決 0 輪。
- 兩人分歧的是**效力**，而 baseline 依賴的正是效力，故採 J2。

**佐證：撤走名詞後沒有任何一輪重建「同一個圖形」的前提。** A3c 三輪對「六條」「直邊」「形狀相同」「幾何」
四個詞的使用次數皆為 0——本版保留的邊數描述完全未被援引。唯一的否決者 r3 走的是另一條路線：
封閉清單論證加自陳的射程假設（(4) 欄逐字「需假設『方向/方位（尖角朝上 vs 平邊朝上）是否屬於 8.2(3) 清單中的「形狀」項』——條文未明確定義此邊界」），
題幹事實引用為零。也就是說，第二版 r2 那條倚賴名詞的路線消失後，讀者換了一條不倚賴題幹的路線，否決仍然發生。

### 三、A2b「以自身中心」比照處理

撤走該四字後 A2c 三輪仍全數通過、正面命中 0，與第一版（3/3）、第二版（3/3）持平。
兩位判定者原本一致的判讀（未被援引的弱訊號）獲得直接驗證。

三輪對「輕晃」的否決一律不靠題幹，靠條文封閉清單加**條文沒有的**靜態／動態界定：
r3 於 (4) 欄自陳「假設：8.2(3) 清單的『位置』指靜態位置，不包括動態位置變化」，
r2 以「運動狀態而非靜態位置」處理，r1 直接斷言「動畫/輕晃不在清單內」且 (4) 欄答「否」（未自陳的自備前提）。
這一項維持 W3-530 的判讀：A2 軸的 3/3 不構成條文獲得證成。

### 四、A3c-r3 子問3 的計分爭議（不擇一隱去）

r3 子問3 判定欄逐字為「違反第 8 項，判至 8.2(2) 第一點即結束」，正文則逐條判過第一點（成立）與第二點（成立）。
key 的計分點列有「(3) 答『判到第一點就結束』者不通過」，r3 字面命中；
但該條件與相鄰的「(3) 判不違反者不通過」同組，針對的是誤指派路徑（第一點不成立 → 結束 → 不違反），
而 r3 判的是**違反**。第一版 J1 對 A2-r3 已建立先例（正文兩點都判過即計通過並記表述不精確），
r3 與該先例的差別只在它逐字寫了「第一點」。故 A3c 通過率記為 **1/3（依先例）或 0/3（依字面）**，兩者並列。

**本票的結論在兩種計分下相同**，理由三條：

1. 爭議落在「判到第幾點」，不在射程指派。r3 在子問2 否決主張、子問3 判違反、子問4 判會改變——三個實質計分點全部與 key 同向。
   A3 欄命中數在兩種計分下都是「正面 2、否決 1」。
2. 若記 0/3，該下降由一句程序表述造成，與共用名詞無關；把它算進名詞的效力，等於用一個與被測訊號無關的誤差去支持該訊號承重。
3. `0.1.0-W3-541` 的驗收比對的是 A3 欄命中數，該欄三版為 1 → 2 → 2，第二與第三版相同。
