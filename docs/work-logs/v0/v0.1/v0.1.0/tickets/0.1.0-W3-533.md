### PM 裁決（W3-532 案 A 經獨立覆核後修正）：採修正後案 A，措辭以本段為準

獨立覆核（未 claim 票的第三方）推翻了 W3-532 提出的措辭，理由是原措辭把成敗押在讀者已證實做不到的那一個判斷上。**本票落地的措辭以下列為準，不採 W3-532 Solution 內的案 A 草案。**

管轄欄第五列改為：

> 共同上層是一個容器元件者，由該層承載；找不到這樣的容器元件（兩端直接放在頁面上）者，該處缺一個容器元件，須先補上該容器元件，由它承載。兩端各自的組合規則均不得另定這段間距。

三項改動理由，逐條對應覆核的發現：

1. **判別子換成存在性判斷**。原草案的分支條件是「該層是不是容器元件」——而 j1 第 8 項 (ii) 欄的判讀逐字是「(ii) 的讀者並不會走到第一列，他直接把頁面填進第五列的『該層』」，讀者失敗的正是這個判斷。把分支押在同一個判斷上，等於預期讀者這次會做對他上次做錯的事。改為「找不找得到這樣的容器元件」是存在性判斷，三輪讀者已證實做得到（他們都正確排除了一至四列）。
2. **兩分支主詞統一**。原草案分支一以「該層」為主詞、分支二以「判別問句的答案」為主詞，讀者須自行認定兩者同指，而條文沒寫這個等同關係。現兩分支皆以共同上層為主詞。
3. **移除管轄欄內的程序句**。「對共同上層重問一次本節判別問句」這句程序留在管轄欄會把讀者推回表外——r2 正是被這句框成「判定步驟應重問判別問句」而停在頁面。依據欄本就指向該段，不需在管轄欄再指一次。

此寫法不觸發 W3-532 判否案 C 的第 2 條：管轄欄仍輸出一個承載者，不是一個動作。
