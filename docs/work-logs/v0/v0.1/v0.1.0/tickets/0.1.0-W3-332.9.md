### §1 Domain 視圖——盲推導（9 狀態）

### 狀態 1：未選專案

**選件與排位**：`PageColumn[EmptyState[提示文字, ActionButton(選擇資料夾)]]`

**契約關鍵欄**：
- EmptyState：語意＝「這裡目前沒有東西」；slot＝訊息文字（i18n key）＋至少一個前進動作按鈕（FR-03）
- ActionButton：錨點 `action-domain-choose-folder`；觸發＝開啟系統資料夾選擇器（ExternalOpener 同族？）

**Given/When/Then**：
- Given App 首次啟動無已存路徑 / When 畫面渲染 / Then `state-domain-unset` findsOneWidget，`action-domain-choose-folder` 存在且 enabled
- Given 未選專案 / When 點選擇資料夾並取消 / Then 仍為 `state-domain-unset`，無 SnackBar

**猜測點**：無。SPEC-001 §1 與 SPEC-003 §3.1 已充分描述。

### 狀態 2：載入中

**選件與排位**：`PageColumn[LoadingState[SkeletonLayout(矩陣版位), ProgressText(已處理節點計數), CancelButton]]`

**契約關鍵欄**：
- LoadingState：進度型別＝indeterminate＋計數文字（SPEC-003 §2.6）；骨架 shimmer 循環 `Motion.skeletonCycle`
- CancelButton：錨點 `action-domain-cancel-load`；取消契約 C1–C8 適用（§2.5）；目標態 `state-domain-unset`
- ProgressText：更新間隔 ≥ `Motion.progressTick`；分母未知故不顯示百分比（§2.6 誠實性硬規則）

**Given/When/Then**：
- Given 已選專案 / When 載入中 / Then `state-domain-loading` 存在，取消錨點 enabled＝true（C1）
- Given 載入中 / When 按取消 / Then `Motion.cancelDeadline` 內 `state-domain-unset` 出現（C4）
- Given 載入中 / When 切至其他導覽項再切回 / Then 載入繼續、顯示當時進度（L1）

**猜測點**：無。

### 狀態 3：正常 · 矩陣

**選件與排位**：`PageColumn[Toolbar[ModeSwitch(矩陣/泳道), DomainSelector], SplitRow[MatrixScrollable[MatrixGrid], Panel.scrollable(右欄格詳情卡區)]]`

**契約關鍵欄**：
- MatrixGrid：二維捲動，錨點 `scroll-domain-matrix`，委派 `two_dimensional_scrollables`；列首與欄首釘選
- Panel.scrollable（右欄）：未選格時顯示 `panel-domain-cell-detail-empty`（提示文字 `l10n.cellDetailPrompt`）；右欄常駐不隱藏
- ModeSwitch：`mode-domain-matrix` / `mode-domain-swimlane`，互斥存在
- DomainSelector：`action-domain-select-<domainId>`，選中態

**Given/When/Then**：
- Given 載入完成有節點 / When 渲染 / Then `state-domain-matrix` 存在，`panel-domain-cell-detail-empty` 存在，`scroll-domain-matrix` offset 可改變
- Given 正常矩陣 / When 二維拖曳 / Then 水平與垂直 offset 皆改變
- Given 正常矩陣 / When 捲動矩陣 / Then 右欄 offset 不變（連動禁令）

**猜測點**：

| # | 位置 | 猜測內容 | 缺口類別 | 說明 |
|---|------|---------|---------|------|
| G1 | 右欄寬度 | 右欄與主欄的寬度比或固定寬度值未知，猜為固定寬度 | spec 未描述 | SPEC-001 §1 註記說「右欄固定寬度在最小視窗下壓縮矩陣可用寬」但未給數值；SPEC-003 §3.1 互動反應表無寬度欄。查 component-contract-design step-3 的尺寸契約欄，需「最小尺寸」與「尺寸模式」兩值，此處皆無 |

### 狀態 4：已選格（疊加於正常 · 矩陣）

**選件與排位**：`正常·矩陣 + Panel.scrollable(右欄)[CellDetailCard[標題, 關係種類, 說明?, 編號步驟?, 事件標籤?, GotoSwimLaneButton, CloseButton]]`

**契約關鍵欄**：
- CellDetailCard：標題恆在（`<domain 名> × <UC id>`）、關係種類恆在、說明/步驟/事件三區塊可缺
- GotoSwimLaneButton：`action-domain-cell-goto-swimlane`，jump 至泳道
- CloseButton：`action-domain-cell-clear`，與 Esc 效果相同
- 選中態：該格與所在列呈選中態；`scroll-domain-cell-detail` 錨點，獨立捲動

**Given/When/Then**：
- Given 正常矩陣 / When 單擊一格 / Then `panel-domain-cell-detail` 出現，標題等於預期，`panel-domain-cell-detail-empty` 消失
- Given 已選格 / When 按 Esc / Then 右欄回 `panel-domain-cell-detail-empty`
- Given 已選格 / When 點另一格 / Then 內容換選，`scroll-domain-cell-detail` offset 歸零
- Given 已選格 / When 點「在泳道中檢視」 / Then 切至泳道且該格對應列 rect 與 viewport 有交集

**猜測點**：

| # | 位置 | 猜測內容 | 缺口類別 | 說明 |
|---|------|---------|---------|------|
| G2 | CellDetailCard 的事件標籤排列 | 不確定事件標籤用並排還是換行堆疊 | spec 未描述 | SPEC-001 §1 顯示欄寫「事件標籤」，SPEC-003 §3.1 格詳情卡內容契約只說「每個事件一個標籤，前綴 emits 或 consumes」但未指定排列。component-contract-design step-2 路徑 A 步驟 4 要求列出排列方向，此處無來源 |

### 狀態 5：正常 · 泳道

**選件與排位**：`PageColumn[Toolbar[ModeSwitch, DomainSelector], SwimLaneCanvas[DragGesture, SwimLaneRows]]`

**契約關鍵欄**：
- SwimLaneCanvas：錨點 `drag-domain-swimlane`（拖曳）與 `scroll-domain-swimlane`（捲動），共用同一 offset
- 拖曳比例 1:1，邊界生硬停止無回彈（SPEC-003 §1.3）
- 0.1 為靜態版型寫死座標（SPEC-001 設計約束）

**Given/When/Then**：
- Given 正常泳道 / When drag / Then offset 改變，比例 1:1
- Given 泳道 / When 拖至邊界 / Then 停止，無回彈
- Given 由矩陣切入泳道 / When 切回 / Then 矩陣 offset 與選中格保留

**猜測點**：

| # | 位置 | 猜測內容 | 缺口類別 | 說明 |
|---|------|---------|---------|------|
| G3 | 泳道列的視覺結構 | flow 橫向穿過 domain 泳道的具體視覺——泳道列高度、步驟節點形狀、邊線樣式皆未知 | spec 未描述 | SPEC-001 §1 只寫「flow 橫向穿過 domain 泳道」，設計約束明寫「0.1 的泳道只做靜態版型」。但靜態版型的結構仍需描述：每個 domain 一橫列、步驟節點放在對應 domain 列內、邊連線——這些全是推測。component-contract-design step-2 需要知道「佈局結構」與「全部子件」才能建容器候選表 |

### 狀態 6：空圖

**選件與排位**：`PageColumn[EmptyState[訊息「此專案尚無圖譜節點」, ActionButton?(開啟 docs 目錄，條件渲染), ActionLink(導覽至破洞報告)]]`

**契約關鍵欄**：
- EmptyState：FR-03 要求至少一個非返回的前進動作

- 導覽至破洞報告：`action-domain-goto-gaps`，jump 至 `nav-page-gaps`

**Given/When/Then**：
- Given 解析成功節點數 0、docs 存在 / When 渲染 / Then `state-domain-empty` 存在，`action-domain-open-docs` 存在
- Given 解析成功節點數 0、docs 不存在 / When 渲染 / Then `action-domain-open-docs` 不存在
- Given 空圖 / When 點導覽至破洞報告 / Then jump 至 `nav-page-gaps`，`returnTo` 等於 domain

**猜測點**：無。
