## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
在 `lib/app/shell.dart` 的 `didChangeAppLifecycleState` 補上 `developer.log`：

- 記錄前先以 `ref.read(appLifecycleStateProvider)` 讀出轉換前的值（provider
  尚未被本回調更新，讀到的即是舊值），與新值一併寫入同一行
  `生命週期狀態轉換：$previous -> $state`，可區分 `inactive -> resumed` 與
  `hidden -> resumed` 兩種路徑。
- 沿用 `lib/services/macos_scan_notifier.dart` 慣例：`dart:developer` 的
  `developer.log`、`name: _tag`（新增 `const String _tag = 'AppShell';`）、
  字串標 `i18n-exempt`。
- 級別：專案既有 log 呼叫僅在錯誤/警告路徑顯式標 `level: 900`，其餘為預設
  0（info）。本票要求 debug 級別，選用 `level: 500`（logging 慣例 FINE，
  低於 900 且與既有 info/warning 兩級區隔）。

因保護分支規則，改動實際落在 `/worktree create 0.1.0-W3-093` 建立的
worktree（`../graph_project_docs_manager-0.1.0-W3-093`，分支
`feat/0.1.0-W3-093`），不影響 PM 主工作區正在跑的 `flutter run -d macos`。
