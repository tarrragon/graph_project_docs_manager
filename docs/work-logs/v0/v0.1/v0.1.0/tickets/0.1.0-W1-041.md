### 變更內容

檔案：`.claude/methodologies/component-library-bidirectional-constraint-methodology.md`（1.8.0 → 1.9.0）

新增〈元件契約判準〉章，插入於〈命名與通用元件判準〉之後、〈元件文字歸屬〉之前，含三個子節：

| 子節 | 內容 |
|------|------|
| 九欄位表 | 語意與內容角色 / 變體 / 狀態集 / 尺寸契約 / 內容政策 / slot 契約 / 組合規則 / 測試契約 / 反例，每欄附「回答的問題」與「缺失後果」；欄位順序即填寫順序 |
| 容器亦為元件 | 排列關係無元件承載即缺容器元件；頁面直接用原生佈局原語排列元件視同自製元件；排列不變式三項（不重疊 / 最小間距 / 空間不足策略三選一）；判別問句 |
| 派發語言 | 畫面票 how 只述「元件 + 變體 + 容器 + 格位」；acceptance 含「import 只來自統一匯出入口」；缺件停手建元件票 |

同步修改：分層架構表 L1 / L3 內容列、執行步驟 4（補容器盤點與九欄位填寫）、檢查清單新增三項、Reference 補 doc 範本一列、版本歷史。

- 狀態集欄不重述 ux-design-evaluation 的狀態矩陣填法，只要求元件層級也要有，避免兩處判準漂移。
- slot 契約的文字規則指向既有〈元件文字歸屬〉，不複寫。
- 九欄位的產物形狀交由 doc 範本承載（後續票擴充範本），方法論只定判準不定表格版面。
- 未在 Reference 列尚未存在的 component-contract-design skill，待該 skill 建立後由其票回填引用。
