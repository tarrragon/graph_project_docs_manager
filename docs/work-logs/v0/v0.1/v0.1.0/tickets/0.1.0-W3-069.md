### WRAP 三問（認領時）

- **W（Widen）**：候選一，只改 §3.1 該列名 + 三處錨點（最小改動）；候選二，順帶統一 SPEC-003 全檔「選中」→「選取」（SPEC-004 已於 W3-065 統一）。採候選一——候選二屬用語統一，與本票「標籤自足」不同源，且會擴散至數十處與多個跨檔錨點，應另票。
- **A（機會成本）**：本票佔用的是 SPEC-003／004 同檔序列，會延後其他同檔票；但錨點同步必須與列名同一次改，不可拆。
- **P（最可能失敗）**：改了 SPEC-003 列名卻漏掉某處 SPEC-004 逐字錨點，造成引用斷鏈。防護：改完以 grep 對新舊字串各做一次全 spec 掃描，確認舊字串只殘留於變更歷史列。

### 列名判定表（SPEC-003 全檔）

判準（DOC-GPD-004）：標籤裡每個名詞讀者知道是哪一個嗎；每個動詞知道主詞是誰嗎；限定語須補回標籤本身而非依賴鄰欄。「同子節自足」指讀者不需離開該子節（含其緊鄰的元素／狀態表）即可判定指涉。

| 位置 | 列名 | 判定 | 理由 |
|------|------|------|------|
| §3.1 動畫提示 | 格選中態出現 → **矩陣格的選取標記出現** | **改** | 三個限定語被壓縮：哪種格（須跨查 §3.1 標題與 `MatrixCell`）、選取標記為持續性標記（須查同表其他列語意）、「出現」的主詞（選取標記，非格本身）。還原一次需兩次跨節查詢。新列名三個名詞與一個動詞在「轉換」欄語境內皆自足 |
| §3.1 動畫提示 | 矩陣首次渲染 / 矩陣 → 泳道的定位 / 載入中的骨架 | 保留 | 名詞皆帶限定語（矩陣、泳道），動詞主詞明確 |
