此處，亦不改產品碼。

`no-proposal` 為刻意的語意精確化例外，改 SPEC-003 對應處為 `state-traceability-no-proposal`
並於命名慣例段落註記此例外理由。兩案皆需 PM 或 SA 裁決優先方向。
