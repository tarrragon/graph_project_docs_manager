### 併入：同檔的第二個缺項（`0.1.0-W3-300` 發現，PM 已複核，2026-09-11）

`agent-self-check-template.md` 第 174 行寫「若自檢無任何發現，**可省略** `### 自檢結果` 子章節；無需強制記錄『零違規』」，**未帶票型限定**。而 `ticket_validator.py` 的 `_SELF_CHECK_GATE_TYPES = {"IMP", "ANA"}`（行 713，消費於行 782）使該子章節對 IMP 與 ANA 型為必填硬阻擋，僅 DOC 型豁免。

**PM 複核記錄**：上述常數值與行號、以及 template 第 174 行的原文，皆由 PM 以 `grep` 與 `sed` 直接讀取確認，非採信轉述。

**對本票的兩點影響**：

1. **缺陷形狀改變**：這不是「敘述錯誤」而是**缺少型別限定詞**——同一句話對 DOC 正確、對 IMP／ANA 錯誤。修法形狀因此與「補上一個缺項」不同，但**本票仍不決定修法**（依用戶 2026-09-11 裁示與 `escalation-flow.md`〈修法時點分離〉）。
2. **本票 acceptance 第 1 項的射程需要分辨**：`_SELF_CHECK_GATE_TYPES` 證明的是「該 template 描述的 `### 自檢結果` 子章節**存在與否**被強制層消費」，**不等於**「該 template 的合法 H2 清單被消費」。兩者是同檔內的不同斷言。第 1 項問的是後者，仍未答。**不得以前者的查證結果宣稱後者已查證。**

**已實際發生的後果**（`0.1.0-W3-298` 執行期）：執行者依 template 判斷可省略該子章節，`ticket track finish` 以 `[Error] 未填寫的必填章節：Solution > ### 自檢結果` 硬阻擋，須回頭補寫。
