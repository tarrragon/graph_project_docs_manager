### Task Reference
- 0.1.0-W3-553 what: 8.2(3) 清單含「文字內容」，W3-541 增列的界定句 ③ 只寫「指文字寫出來的是哪些字」，未限定為承載語意的那個元素本身的文字；而 8.3(1) 明寫比較對象是畫面上承載語意的所有元素、不限元件邊界。兩者合併的結果：凡是符合 8.2(4) 的相鄰標明文字，同時也構成 8.2(3) 的「文字內容」差異，換色後仍在，第一點恆不成立，依「第一點不成立即結束判定，判不違反，不進第二點」結束——8.2(4) 與 8.2(2) 第二點在所有有標籤的情形下都不會被走到，成為死條文。本票須裁決：文字內容是否限承載語意的元素本身寫出的字，或 8.2(4) 的相鄰文字是否排除於該項之外，並附既有題組誤傷實驗。
