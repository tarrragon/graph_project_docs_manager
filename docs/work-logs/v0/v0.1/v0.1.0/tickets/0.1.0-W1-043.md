### 設計取捨

- 互動反應、design token、a11y 三個既有子節不在九欄位內，保留為範本額外承載的實作契約，檔頭註解明寫對應關係。
- 原「尺寸 / 變體」子節拆為「變體」（前移至狀態矩陣前，與九欄位順序一致）與「尺寸契約」。
- 容器元件獨立成章而非併入第 4 章：容器同時需要第 4 章條目與排列不變式，分章使「每個容器都有第 4 章條目」可被驗收標準檢查。
- 章節編號順延影響既有以此範本產出的專案 spec 的章節引用，屬各專案回填時自行對齊，範本不保留舊編號。
