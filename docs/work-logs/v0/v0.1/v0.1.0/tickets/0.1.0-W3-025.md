#### 本票要回答的根本問題

六支都是「改了內容卻沒 bump 版號」。**版號在這種情況下不只是無鑑別力，而是誤導性的**
——它主動宣稱兩邊一致，使分歧不會被例行檢查發現。判完方向之後應一併問：是否需要在
`skill-sync push` 加一道「內容變更但版號未變」的閘門。
