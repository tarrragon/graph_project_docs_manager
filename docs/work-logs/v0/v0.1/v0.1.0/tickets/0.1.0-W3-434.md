### 查證補充

- 拋棄式 repo 實測（git 2.50.1）：CAS 基準過期時 update-ref 錯誤文字含 `cannot lock ref`（`is at X but expected Y`），被 `_is_lock_contention` 判為撞鎖，以同一過期 old_head 重跑一次必然失敗。W3-433 未提此點。
- `git-index-lock-cleanup-hook.py` 會自動移除過期 index.lock，與 ticket CLI「不移除任何鎖」立場不一致，已寫入 #77 觀測。
- 觀測內容不含本專案名與 ticket ID；首行 session 標記由工具寫入。未 init、未改他人區段或 body。
