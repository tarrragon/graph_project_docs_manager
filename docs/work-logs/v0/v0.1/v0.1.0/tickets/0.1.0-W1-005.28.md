## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### 契約來源

SPEC-004 §4.25 LoadPrompt：單一變體，訊息 `AppText.subtitle`
（`ticketsLoadPrompt`，N 代入）+ `ButtonRow`[開始載入 primary]，填滿
父容器內容置中，返回動作由頁面框架承載（不在本元件範圍）。

### 實測發現的契約不成立

`AppText`（4.1）subtitle 變體渲染邏輯（`_isSingleLine = variant != body`）
恆為單行，不接受 `maxLines` 覆寫。原 §4.25 內容政策標「message 可換行、
最大行數 2、末行截斷」與同條目「最小尺寸」列（訊息一行）及本身選用
`AppText.subtitle` 三處自相矛盾。已停手改 SPEC-004，見 Solution。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### 契約修訂

SPEC-004 §4.25 內容政策 `message` 列改「不可換行 / 最大行數 1 / 末端
省略」，測試點「最長測試文案兩行末截斷」同步改「最長測試文案單行末端
省略」；變更歷史新增 1.10。無其他條目受影響（AppText 本身未修改）。

### 實作

`lib/components/load_prompt.dart`：`LoadPrompt` StatelessWidget，
`count`（必填）/ `onStart`（必填）/ `testKey`（必填，state-tickets-
unloaded）/ `startKey`（必填，action-tickets-start-load）/ `message`
（選填覆蓋）五個 slot。`Center(key: testKey)` 落實「填滿父容器內容
置中」契約（有界時擴滿、無界時退化為內容大小，Center 原生行為即
契約落成值，未額外硬編尺寸）；訊息 `AppText.subtitle` 包 `Semantics
(liveRegion: true)`；間距 `Space.lg.h`；動作 `ButtonRow`
（`ButtonRowAlignment.center`）+ 單一 `AppButton`（primary，預設）。
`lib/components/components.dart` 依字母序插入一行 export。

### 自檢結果

- 十一欄位契約：用途/內容角色/何時不用/出現畫面/層級（文件層，SPEC
  已載）、變體（單一 default）、狀態矩陣（default 一列，無互動瞬態
  無需重複）、互動反應（開始載入呼叫 onStart，交由呼叫端切換狀態，
  cross-fade 屬呼叫端／頁面框架職責，不在元件內）、操作機制（依
  §4.0.7 點選列）、尺寸契約（Center 落成）、內容政策（message 單行
  末端省略，已修正）、slot 契約（五欄位全部落實）、token（`Space.lg`
  間距、經 `AppText`/`AppButton` 色彩字體、無圓角、動畫屬呼叫端）、
  i18n（`ticketsLoadPrompt`/`startLoadAction` 皆既有 key，非硬編碼）、
  無障礙（header 經 AppText 內建、liveRegion 已加、按鈕經 AppButton
  焦點路徑、對比依 §4.0.2 不重算）。
- 零裸值：色彩/字體/圓角全數經 `AppText`/`AppButton`/`ButtonRow` 承接
  token，本檔僅直接引用 `Space.lg`。
- 未新增 `hasFlag` 用法，semantics 斷言改用 `flagsCollection`。
- `fvm dart analyze lib test`：新檔 0 issue（既有 6 則 `hasFlag` info
  屬 expander_icon_test.dart / issue_marker_test.dart 既存，非本票
  範圍）。
- Phase 4 結論：單一 StatelessWidget、零狀態、全數委派既有元件
  （AppText/ButtonRow/AppButton）承載視覺與 token，無重複邏輯、無
  巢狀分支，無需重構。品質等級 A。技術債務：無新增。
