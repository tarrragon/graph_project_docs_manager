### 問題根因
建立 SPEC-004 §4.27/§5.1 定義的根框架容器 AppShell（lib/components/app_shell.dart），既有 lib/app/shell.dart 為漂移中的舊實作雛形，本票不觸碰。

### 影響範圍
新增 lib/components/app_shell.dart；lib/components/components.dart 追加一行 export；新增 test/unit/components/app_shell_test.dart。未修改 lib/app/、tokens/、其他元件檔。

### 設計要點（契約字面未涵蓋、依既有慣例補完的判斷）
- overlay slot 契約型別為 `SwitcherOverlay?`（4.42），該容器尚未實作於 lib/components/；比照 AppButton.leading 對 AppIcon 未就緒時的既有慣例，改以 `Widget?` 承接，型別相容，SwitcherOverlay 建立後可直接代入。
- AppShell 依 §2（L2 決策，行 83）定案為唯一的 ConsumerWidget 容器，直接 watch lib/app/router.dart 的 selectedDestinationProvider / returnToProvider（唯讀 import，非本票修改範圍）。
- 返回鍵注入：契約寫「注入當前 PageColumn 的頁面級動作列」，但 pages slot 是呼叫端已建構完成的 List<PageColumn>，容器無法改寫其內部。沿用既有 lib/app/shell.dart 的 _ReturnToHeader 佈局慣例，改以獨立返回列疊於 IndexedStack 內容之上，對外行為（action-<screen>-back 錨點存在/消失）與契約一致。
- 側欄與主區分隔線：SPEC-004 4.3 Divider「何時不用」明列「側欄與主區之間（AppShell 內部）」，故不借用 Divider 元件，直接以 DecoratedBox 邊框承載，token 沿用 AppColors.border。
- overlayOpen 態「背景導覽項不可點、焦點限制於浮層」：以 ExcludeFocus + IgnorePointer 包裹背景（側欄 + 主區），浮層本身在 Stack 另一分支不受影響。
- title 使用 AppText(variant: body) 時，body 變體預設可多行；契約內容政策要求單行截斷，需顯式傳入 maxLines: 1（AppText 的 body 變體不會自動單行，與 title/subtitle 變體行為不同）。
