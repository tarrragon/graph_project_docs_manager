## Problem Analysis
### 問題根因

### UX-Z8c 系列為何判為能（三步逐步）

**第一步，選款。** 題幹子問 1 逐字為「標記朝哪一個方位擺放」。「方位」「擺放」「擺放方位」在整份餵入節錄中**各只出現一次**，全部落在 8.2(3)①。題幹主張句逐字為「一個尖角朝上、一個平邊朝上」，「角朝上」同樣**全節錄唯一**，落在 ① 的「哪一條邊或哪一個角朝上時」。純字面匹配即命中 ①，**逐款排除不需發生**。

**第二步，選支。** ① 對這些情形的處置是單一支（「不算形狀差異」），無分支可選，選支成本為零。

**第三步，輸出。** 子問 1 問「這項差異怎麼處理」、子問 2 問「那句主張是否與條文相符」。① 的後半逐字為「不算形狀差異，不得據以說第一點不成立」——兩個子問的通過門檻所要求的內容，逐字都在 ① 裡，照抄即通過。

三步串起來：讀者可在不執行換色步驟、不枚舉換色後剩餘差異、不做任何清單比對的情況下產出通過的作答。

### 第三段：重判 `0.1.0-W3-550` 與 `0.1.0-W3-567` 的核心結論

分類定義：**走了判定步驟**＝該輪的否決倚賴一個字面通路無法供給的步驟，且該步驟對否決是承重的；**字面對應**＝字面通路單獨即足以產出該輪的否決，且該輪未出現字面無法供給的承重步驟；**分不出來**＝字面通路單獨即足，而該輪另有的敘述無法排除為事後補述。
