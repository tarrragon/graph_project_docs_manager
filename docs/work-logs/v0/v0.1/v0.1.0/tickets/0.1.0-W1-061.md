## Problem Analysis
<!-- Schema[DOC/Problem Analysis]: 選填（若 DOC 起因於缺陷或盤點結論可填）（.claude/pm-rules/ticket-body-schema.md） -->
### 問題根因

4.1 `AppText.subtitle` 變體恆標記 `Semantics.header`；4.11 `PageTitle` 副標依既有無障礙列不得為 header。實作（`lib/components/page_title.dart`）已改用 `AppText.body` + `secondary: true` + `maxLines: 1`，但契約 4.1 變體表未明寫 subtitle 的 header 語意與替代寫法，4.1 `caption` 何時選用仍列「副標」，4.11 內容角色只寫「subtitle slot」未說明渲染變體，token 字體列未區分畫面名／副標各自變體，且 W1-064 新增 `tone` 軸後未說明副標著色寫法應取 `secondary` 或 `tone`。

### 影響範圍

`docs/spec/ui/SPEC-004-component-library.md` 4.1（變體表三列）、4.11（內容角色、狀態矩陣、token 字體列、無障礙朗讀標籤列）、變更歷史與 frontmatter version。

### WRAP 三問

- W：候選 (a) 契約改為 body + secondary（採，與實作一致、副標非 header）；(b) 契約維持 subtitle 並改 4.1 讓 subtitle 可關閉 header（否決：擴大 4.1 API 面、違反 4.1 測試點「subtitle header 為 true」）；(c) 改用 `tone: textSecondary`（否決：結果同色，tone 依 4.1 優先序只在需覆蓋時傳入，實作亦用 secondary）。
- A：擠壓其餘 Wave B 空檔票，成本一份文件改動。
- P：最可能失敗是 4.11 文字與 page_title.dart 漂移，防護為 Test Results 的 grep 對照。
