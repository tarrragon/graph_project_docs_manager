### 由 W3-600／601 承接的兩項結論（該兩票已關閉，結論保留於此）

W3-600 設計的「雙臂同批」（主臂逐題獨立 context、對照臂全卷 context，兩臂之差即帶入幅度）**在新做法下不採**：成本為 probe agent ×7，且該票自己已否證其前提——「兩臂測的是兩個不同的量，相減等於把兩個不同問題的答案相減」。

但其中兩項結論在拋棄式題庫下仍然成立且更便宜，須寫進本票的出題規格：

1. **context 粒度 ＝ 一題（含其全部子問），不是一子問。** 子問共用前言，切到子問級必須把前言複製進每個子問檔，即改寫題幹。拋棄式題庫沒有題幹凍結鏈的顧慮，但切到子問級仍會改變題目本身，不採。
2. **每題每輪一個 fresh agent，禁用 fork。** fork 繼承派發者的完整對話 context，污染量級遠大於全卷帶入。prompt 只給四項：單題檔路徑、節錄目錄、作答格式、輸出路徑；不得提及其他題號或本批題數。

**新做法下不需要對照臂**：對照臂的用途是量出帶入幅度，而逐題獨立 context 直接消除帶入。不需要知道幅度，只需要它不存在。這一項省掉的正是 W3-600 成本的大部分。

W3-601（判定者接口）的四處草稿同此處置——四格判讀表在新做法下不再使用（它的存在理由是跨題配對的歸因需求），判定者接口改由本票的驗收流程一次寫定。
