### 由 W3-600／601 承接的兩項結論（該兩票已關閉，結論保留於此）

W3-600 設計的「雙臂同批」（主臂逐題獨立 context、對照臂全卷 context，兩臂之差即帶入幅度）**在新做法下不採**：成本為 probe agent ×7，且該票自己已否證其前提——「兩臂測的是兩個不同的量，相減等於把兩個不同問題的答案相減」。

但其中兩項結論在拋棄式題庫下仍然成立且更便宜，須寫進本票的出題規格：

1. **context 粒度 ＝ 一題（含其全部子問），不是一子問。** 子問共用前言，切到子問級必須把前言複製進每個子問檔，即改寫題幹。拋棄式題庫沒有題幹凍結鏈的顧慮，但切到子問級仍會改變題目本身，不採。
2. **每題每輪一個 fresh agent，禁用 fork。** fork 繼承派發者的完整對話 context，污染量級遠大於全卷帶入。prompt 只給四項：單題檔路徑、節錄目錄、作答格式、輸出路徑；不得提及其他題號或本批題數。

**新做法下不需要對照臂**：對照臂的用途是量出帶入幅度，而逐題獨立 context 直接消除帶入。不需要知道幅度，只需要它不存在。這一項省掉的正是 W3-600 成本的大部分。

W3-601（判定者接口）的四處草稿同此處置——四格判讀表在新做法下不再使用（它的存在理由是跨題配對的歸因需求），判定者接口改由本票的驗收流程一次寫定。

#### 據此得出的出題規格條文（納入本票 acceptance 1）

1. **題幹不得使用任何款次的獨佔詞。** 判準以條文側為起點：掃出每個款次在全節錄中只出現於該款的實詞，題幹與之交集須為空。
2. **獨佔性檢查的順序固定為「先與題幹交集、交集後才極大化」**，不得由實作者自選。先極大化會使短詞被長串吸收而消失，而讀者用的正是短詞。
3. **「不得成為任何款次的獨佔詞」與「不得與題庫共用」不可同時照字面滿足**——任何條文裡沒出現過的新措辭加進某款即為該款的獨佔詞。可操作判準是**獨佔詞與題幹交集為空**，不是獨佔詞不存在。
4. **通用句型須逐家族檢查**。至少兩個家族：通用陳述句（「畫面上沒有任何文字寫出……」）與通用問句（「……的是哪一項？」）。檢查其一不涵蓋其二。
5. **方向由題材決定的詞須逐輪重判**：同一個獨佔詞在某題是正向（帶到對的款）、換個題材即成反向（帶到錯的款）。不得沿用上一輪的方向判定。

### 分析結論

三份產出已落檔：

### 結論一：可比性需求消失後，七項器材缺陷剩兩項，且兩項都不需修

盤點確認五項缺陷（隔離檢查單向自查／引文固定比對 HEAD／節錄檔同名覆蓋／歷輪對照欄落後一批／自檢對「前寫」與「損壞」同形）的共同根因是「器材預設只有當前這一批，而累積下來器材有一大半是凍結的歷史」。拋棄式題庫讓「當前 ＝ 全部」這個等式永遠成立，五項當場消失。

剩下兩項——過濾條件靜默丟棄、掃描步驟順序（先極大化 vs 先交集）——與批次數無關，是工具本身的設計缺陷。兩項都已轉為出題規格的條文（§4.4 的 `dropped` 欄與守恆式、§4.2 第 3 步的順序硬性規定），不需另修既有器材（既有器材隨題庫拋棄）。

### 結論二：拋棄式題庫改變了處置成本，使三類發現的處置從「改條文」降為「換題材」

反向吸引子、正向吸引子（鑑別力歸零）、修法措辭繼承實例題材，這三類在累積式題庫下都需要改條文或另設分離題（因為題目是資產、不能隨便換）。拋棄式下每輪本來就現出題，換題材成本為零。W3-615 因此併入本票、不另開票；W3-603 找到的三條反向吸引子改由出題規格 §4.3 第 3 條（方向由題材決定的詞須逐輪重判）承接。

### 結論三：舊做法「約一半的工作花在讓歸因成立」，而歸因不是預設產出

出題規格 §6 把歸因收窄為三種情況（Step 3 不通過、同一款次連續兩輪不通過、改判準內容類改動翻綠），其餘一律不歸因。這是本次成本削減的主要來源。

### 結論四：既有做法中與可比性無關的部分必須原樣保留，不可一併丟棄

四欄作答格式、3/3 門檻、第 (3)(4) 欄不套嚴格計分、逐點推理與條文牴觸者記不通過、節錄檔每輪由 HEAD 重建、兩名判定者先獨立從條文推正解——這六項都不依賴跨批次可比性，且每一項都對應一個已實測的失敗形態。已全數寫入出題規格 §5。

### 候選方案與取捨

### 方案 A（採用）：拋棄式題庫 + 整體通過 + 批次改文 + 二分定位

- **利**：驗證成本由 O(既有題目 × 既有答案鍵 × 既有節錄) 降為 O(本輪題數)，且與歷史規模無關，存在收斂點。五項器材缺陷消失。規格是恆定大小的資產，題庫不是。
- **弊**：失去「這一句改動有沒有效」的答案。失敗時的定位成本由 O(1) 升為 O(log2(改動數))，但只在失敗時付。無法回答「條文這半年變好了多少」這類跨時間問題。
- **取捨依據**：需要知道的只是「這份條文現在讀得懂嗎」，那是及格級判定；「這一句改動有沒有效」是歸因級，需要單變數實驗，而單變數實驗的定義就是一次只准動一個變數，N 次改動必然要 N 次全量驗證。用歸因級標準做及格級的事，是舊做法發散的根因。

### 方案 B（不採用）：保留累積題庫，修補五項器材缺陷

- **利**：跨批次讀數可比，能回答「哪一句改動有效」，既有 140 個題目檔與 118 份答案鍵不浪費。
- **弊**：修補只是把發散速率降低，不改變分母持續成長而分子固定的結構。實測已有一張設計票（四模式共用原語）試圖一併解決四項缺陷，但它解決的是「器材跟不上歷史」，解決不了「每改一句就要全量重驗」。
- **不採用的決定性理由**：五項缺陷是症狀不是病。拿掉可比性需求，它們自己消失；保留可比性需求，修完還會長出第六、第七項（本線實際已從四項增至七項，每次都是新位置的同一個預設）。

### 方案 C（不採用）：保留累積題庫但只在版本邊界做全量回歸

- **利**：日常改文不付全量成本，只在版本收尾時付一次。
- **弊**：全量回歸的那一次仍是 O(全部)，且屆時失敗的歸因範圍是整個版本的全部改動，二分定位的區間比方案 A 大一個數量級。等於把發散成本延後而非消除。
- **不採用的決定性理由**：它保留了題庫作為資產，因此保留了全部五項器材缺陷的維護面；而這些器材在兩次全量回歸之間無人使用、無人發現它們已經落後。
