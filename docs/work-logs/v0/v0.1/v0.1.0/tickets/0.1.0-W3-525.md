### 改後 8.2(2)(3) 全文

- (2) 「只有顏色」依序判兩點，兩點都成立才算違反，**第一點不成立即結束判定，判不違反，不進第二點**。第一點，把這些元素承載語意的顏色全換成同一個顏色後，是否還剩下 8.2(3) 清單內的任一項差異；不剩，第一點成立。換色這個操作的兩側都是封閉的：**顏色那一側全部歸一**——色相、明度、彩度、深淺、對比換完後一律相同，不存在「換色後仍有明度差／深淺差／對比差」這種狀態，出現這種敘述表示換色沒有執行完，不得作為第一點不成立的理由；**顏色以外那一側一動不動**——換色前是什麼，換色後還是什麼。換色後仍在的差異，逐項對照 (3) 的清單。第二點，各自旁邊沒有文字標明它代表什麼。
- (3) 本清單各項依 8.1(1)，須是使用者用來分辨這些語意所依據的差異；與語意無對應關係者不算。本清單逐項封閉：只有清單列出的項目算數，且各項仍須通過本款引言的對應關係要求。換色後仍在但不在清單內的差異，不使第一點不成立——第一點問的是有沒有剩下清單內的項目，不是有沒有剩下任何差異。可區分的差異有：形狀、大小、位置、圖示、存在與否、填滿與否、線條樣式、文字內容。**明度、深淺、對比強弱、彩度、色相都不在本清單內——它們是顏色的維度，換色後一律相同，不會成為「換色後仍剩下的差異」。**

顏色那一側全部歸一整句與 8.2(3) 維度排除句一字未動，僅刪 8.2(2) 的八項複述、改一句銜接語，並在 8.2(3) 前加一句身分句。
