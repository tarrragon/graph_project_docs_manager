### Context Bundle

**審查對象（四檔，全部唯讀）**

**定位（frame 判斷標準的輸入）**

這是**查閱型參考文件**，不是照著跑的操作手冊——與本專案前一次審查的對象（component-contract-design，操作手冊）定位不同。讀者有兩種：(a) 正在建立或修改一個 skill 的人／agent，帶著具體問題來查一節；(b) 審查別人寫的 skill 的人，把 §12 檢查清單當閘門走一遍。讀完之後的動作落在世界上（改一個 skill 的 frontmatter、拆一份檔案、重寫一段 description），但**不是照第 1 節走到第 13 節**。體例應為查表 + 判準，不是編號流程。

**為什麼這七個能同時存活**：writing-the-body.md:120 那一段自陳「本節條文寫成後隨即套回
本文件自身，抓到三處違規」——自我套用**確實做了**，做的是引用形式那一條。自我套用的粒度是
**單條規則**，而不是「這份文件的全部規則 × 這份文件的全部內容」。一旦某一節留下了自我套用的
宣告，後續審查就不會再查那一節，於是其餘條文對它的違規獲得永久豁免。

**裁決：以 Round 1 的宣告為準**（查閱型參考文件，體例為查表 + 判準）。Round 2 的措辭把
兩件事併成了一件——「讀者的動作落在世界上」（兩者皆同意）被寫成了「文件本身是循序手冊」
（Round 1 明確否定）。前者是定位，後者是體例，不可互推。
