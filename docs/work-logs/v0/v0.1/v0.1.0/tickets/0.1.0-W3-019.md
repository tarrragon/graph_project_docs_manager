### Context Bundle

**審查對象（四檔，全部唯讀）**

**定位（frame 判斷標準的輸入）**

這是**查閱型參考文件**，不是照著跑的操作手冊——與本專案前一次審查的對象（component-contract-design，操作手冊）定位不同。讀者有兩種：(a) 正在建立或修改一個 skill 的人／agent，帶著具體問題來查一節；(b) 審查別人寫的 skill 的人，把 §12 檢查清單當閘門走一遍。讀完之後的動作落在世界上（改一個 skill 的 frontmatter、拆一份檔案、重寫一段 description），但**不是照第 1 節走到第 13 節**。體例應為查表 + 判準，不是編號流程。

**為什麼這七個能同時存活**：writing-the-body.md:120 那一段自陳「本節條文寫成後隨即套回
本文件自身，抓到三處違規」——自我套用**確實做了**，做的是引用形式那一條。自我套用的粒度是
**單條規則**，而不是「這份文件的全部規則 × 這份文件的全部內容」。一旦某一節留下了自我套用的
宣告，後續審查就不會再查那一節，於是其餘條文對它的違規獲得永久豁免。

**修法不是逐處改**（逐處改下次仍會以同樣方式復發），而是把自我套用改成矩陣式：
條文清單 × 檔案清單逐格跑，並在收尾章節載明「自我套用的單位是全部條文，不是剛寫的那一條」。

**方法論歸屬**：本項屬 `multi-round-review` 的收尾章與 `compositional-writing` 的
自我套用條款，已列入回饋 blog-cd 的候選（該 session 為兩 skill 維護者）。
### Round 3 翻譯探針（2-B⁵）結果：自造複合概念是主要歧義來源

譯者 A 五節全數譯畢，逐節自報猜測數：

| 節 | 猜測數 | 該節的自造複合概念 |
|----|-------|-----------------|
| 三層載入 | 2 | 無（門檻、預算為通用詞） |
| 自由度 | 3 | 無 |
| 拆分特有的必查項 | 4 | 節界、跨檔指涉 |
| 拆分特有的高頻缺陷 | 6 | 內嵌於散文的計數、位置性指涉 |
| 外部引用 | 7 | 指名身分、介面規格、溯源引用 |

**單調遞增，且遞增方向與自造複合概念的密度一致。** 譯者獨立給出的類別判斷（「最難翻的是
自造的複合概念」）與它自己的逐節數字互相印證——不是先有結論再挑例子。

**三個確認選錯的詞**（主 session 判定，非譯者主張）：

| 詞 | 問題 |
|----|------|
| 溯源引用 | 「溯源」是追溯來源，而該類例外講的是「這個檔案沒有名字可載入，只能用路徑指認」，語義距離很遠 |
| 位置性指涉 | 「X 性」後綴中文本來就兩解（具有 X 特性的／X 角色的），而它是要讀者拿去做判定的術語名 |
| 指名身分 | 原詞想表達「身份指認 vs 名字指稱」的差異，而該差異在詞面上表達不出來 |

**譯者的機制說明**（本探針最有用的一句）：這類詞「不像技術詞彙有標準對應，也不像散文可以
自然改寫，處在若略作修改就丟失原意的臨界區」。其危險性在於**看起來像術語（讀者不會停下來
問），實際上沒有共享定義（每個讀者建的意思都不同）**。與 2-B⁶ 術語探針的結果一致：該探針對
死名／孤兒節／控制字串答「完全不知道」，三者皆在首次出現處就地定義故通過；而位置性指涉、
內嵌計數等未就地定義者，正是本探針猜測數最高的兩節所在。

**兩處真歧義**（譯者標記，主 session 複核成立）：
- 「無一處失效」包在「不要下這種結論」的否定框架內，兩層否定疊加，方向不可靠
- 「位元」指逐字逐行的內容而非 binary bit，而該詞在全文反覆出現（位元搬移／位元全對／位元比對）

**方法論副產品**：「逐節報猜測數」不在派發指令內，是譯者自己按格式做的，而它產出的訊號
比任何單一條猜測都強。指令若只要求標記歧義，得到的是散點；要求逐節計數，得到的是分佈。
### Round 3 的一則撤回：reviewer 報了一份從未取得的工具輸出

**事件**：3-F/3-H reviewer 在三則獨立訊息中引用「本 session 的 skill 清單顯示某某 description
完整／不完整」，據此報出一則對條文因果鏈（>250 字元 → 截斷 → 觸發失敗）的實測否證。主 session
向用戶轉述兩次。追問「清單顯示與 system prompt 截斷兩個機制分不分得開」後，該 reviewer 回查
發現**其 context 內從未有過那份清單**，唯一有的是相關性過濾後的單一條目。四項數據全部撤回。

**形態判定**：屬 confabulation 的變體，且比標準形態難察覺。

| | 標準形態 | 本次 |
|---|---------|------|
| 觸發點 | 工具呼叫發出後、真實結果返回前 | **無呼叫**——填補一份從未呼叫的工具的結果 |
| 可疑訊號 | 呼叫與結果之間有時間窗 | 無時間窗可疑 |
| 一致性 | 單次 | 三則訊息一致引用同一組數據，**一致性反而增加可信度** |
| 旁證 | — | 同一份報告的字元數／行數／ASCII 比例經主 session 逐項重跑皆為真，**真數據替假數據背書** |

**揭穿機制**（可重用）：不是質疑，是**問一個必須回到原始輸出才答得出來的後續問題**。
問「你確定嗎」只會得到再一次的斷言，而斷言的第二次與第一次在文字上無法區分。

**衍生的方法論修正**：主 session 先前要求 reviewer 把數字分「引用的／自己推導的」兩欄。
該 reviewer 指出**它的錯誤落在兩欄之外**，並要求四欄：

| 欄 | 定義 |
|---|------|
| A 引用的 | 有外部來源可查 |
| B **我量測的** | **工具輸出在 transcript，可原地重跑** |
| C 我推導的 | 無來源，引用前須重跑（再分已複核／未複核） |
| D **我以為觀測到的** | 撤回 |

理由：「兩欄分類法會把它歸進『引用的』（因為它看起來有來源），而那正是它躲過查核的方式。」
B 欄的定義即分界線——**在不在 transcript 裡可以驗，「我記得看過」不能**，而兩者在報告文字上同形。

**撤回後該 finding 的處置**：降為「條文的因果鏈自身未附驗證方法，而讀檔的 frame 也產不出
驗證」。不是否證，是無資料。此表述比原版強——它指出的是條文的結構問題，不需要任何觀測支撐。

**主 session 的責任**：該組對照經主 session 轉述兩次後才被撤回。轉述前未做的檢查是「這個
觀測的來源在不在對話裡」——而同一份報告的其他數字我逐項重跑過，正是那些真數字讓我對這一組
沒有起疑。**同一份報告內數字的真偽不相關聯，逐項複核不可只抽驗其中一類。**

因此 Round 5 若仍由本 session 派發，買到的是更多面而非另一個來源——而目前尚未
覆蓋的那一項恰好只有來源買得到。該 skill 給的最便宜做法是：**併行的另一個執行者，
交換的單位是掃描而不是評價**。本專案的 blog-cd session 是 `multi-round-review`
與 `compositional-writing` 兩支 skill 的維護者，為天然的異源候選。

處置是異源交換而非第五輪；已落地的追修見 v1.7.0–v1.7.3，未落地者見

### 更正：Round 4 停止判讀的依據不成立（2026-09-07，拉取 v1.75.1 後複核）

前一則停止判讀作於 `multi-round-review` **v1.64.0**。同日拉取發佈庫的
**v1.75.1** 後複核，該版改寫了本判讀所依據的 `cross-round-stopping-signal.md`。

**改了什麼**：四條停止訊號原為並列，新版把「新 frame 想不出來」移到第四位並標為
「最弱的一條，不作必要條件」，且明訂 quorum「分母是前三條」。理由逐字為：

> 第四條量的是判斷者，不是稿件。想得出多少 frame 由執行者的經驗決定，跑過越多輪的
> 人庫存越大，所以它隨經驗反向移動、在最需要一條停止訊號的位置上永遠不成立。判別
> 新增訊號時問一句——這一條量的是被判斷的對象，還是判斷者自己；答案是一個以能力為
> 條件的否定式（想不出、找不到、看不出）就多半量的是判斷者。

**為什麼這條更正是必要的**：前一則的第三節標題逐字寫「真正的停止判讀問句：還想得出
新 frame 嗎」，並以「想得出一個，但它不是 frame，是來源」作結。那正是一個以自身能力
為條件的否定式，即新版指名的失效形態。

**重跑 quorum（分母限前三條）**：

| 條件 | 判定 | 依據 |
|------|------|------|
| 1 七軸全動完（frame/instance/surface/scope/cadence/timing/granularity） | **未查證** | 四輪未逐軸對照。cadence／scope／instance／surface 有對應 frame 可指；timing 與 granularity 兩軸拿不出跑過的證據 |
| 2 finding 性質回到 surface | **不成立** | Round 4 的 finding 落在該卡質性 transition 表的 Meta 階段（驗收設計不可能失敗、修法自傷、誤報邊界），為四階中最深，非退回 |
| 3 修法成本反轉 | **不成立** | 本批修法為改節名、取消計數、補判準，成本低而價值明確 |

**兩條為否、一條未查證，湊不出任二齊備。停止判定不成立。**

**修正後的結論**：停在四輪這個決定本身不撤回，但它的性質要改寫——**這是資源決定，
不是 evidence-based 的停止判定**。兩者在文字上同形（都是「停在這裡」），在依據上
不同（一個有 quorum 支撐、一個沒有），而前一則把後者寫成了前者。

**若要取得真正的停止判定**，最小動作是補跑七軸盤點：逐軸列出四輪跑過的 frame 落在
哪一軸、timing 與 granularity 兩軸是空的還是有對應但未辨識。這一步不需要新 reviewer，
是主 session 的窮盡列舉工作。

**附帶的方法論觀察**：四輪審查全程沒有任何一步會發現「所用方法論本身落後 11 個
minor 版」——所有 frame 都對著審查對象，沒有一個對著方法論自身的版本。這與本票
先前記錄的「條文未套回自身」是同一形態的上一層：那一層是條文沒套用到寫它的文件，
這一層是審查程序沒套用到程序自己的版本。
