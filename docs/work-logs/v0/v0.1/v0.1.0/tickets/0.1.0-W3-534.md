### PM 裁決：三項配套依獨立覆核收斂為一項阻擋級 + 兩項降級

W3-532 原判「三項配套缺一即不可觀測」經獨立覆核判定過強。本票的執行範圍依下表收斂：

| 配套 | 本票處置 | 依據 |
|------|---------|------|
| 通過門檻收緊 | **執行，阻擋級** | 舊門檻對「停在頁面」判通過；W3-533 落地後答案不變仍 3/3，改動效果零可觀測性 |
| 零變數對照組再指定 | **不另指定，改為一次確認** | b16 答案鍵已載明對照組由 DOC-27a 接任，27a 餵入的是 doc 範本節錄檔，與 W3-533 的改動零接觸，下批可續任。本票要做的是**確認該範本檔在下批出題前未被其他票改動**（比對 HEAD），而非另找對照組 |
| 觀測欄分三欄 | **只新增一欄** | 門檻收緊後「判別問句結論未走到底」即是不通過條件本身，與計分重複。仍具獨立價值的只有 j2／j1 口徑分歧的「是否把頁面當容器」一欄 |

### 追加一項原三項未涵蓋、但屬必要的處置

19c 的可比鏈因門檻改變而第三次中斷。**不要試圖靠對照組修補**——可比鏈中斷無法由任何對照組還原。本票只需寫一行基線重起宣告，載明 19c 自下批起以新門檻為基線、與 b16 以前的讀數不可直接相比。

### 與 W3-539 的關係：必須同批

W3-539 改的是同一份答案鍵 DOC-19c(a) 的**預期判定欄**與兩句**判定者註**。本票只改通過門檻。**兩票分批落地會使同一份答案鍵內三處口徑互斥**（通過門檻已收緊、預期判定仍停在頁面、判定者註仍寫「指出由該層承載即通過」），判定者得自行選邊——那正是本線在診斷的型別落差形態，在器材層複製一次。

### 分支一對照子問不在本票

W3-538（為第五列增設落在分支一的對照子問）與本票同批上線但是獨立票。理由見 W3-417：現行全部 doc 題組無任何子問落在分支一，單邊題組下「選對分支」與「一律輸出補容器」在計分上同形，屬 test-assertion-design-rules 規則 E1 的同型缺口。


### 執行前 WRAP 三問

- **W（Widen）**：候選一為照 W3-532 原判做滿三項配套（否決——PM 裁決已覆核為過強，對照組再指定與第三觀測欄皆無獨立價值）；候選二為依 PM 裁決表只做一項阻擋級 + 兩項降級 + 一項追加宣告（採用）。
- **A（Attain distance）**：機會成本是 W3-538（分支一對照子問）與下批出題順延；但門檻不收緊則 W3-533 的條文改動零可觀測性，下批讀數作廢，順延成本較低。
- **P（Prepare to be wrong）**：最可能的失敗是門檻收緊後，19c 的失敗被「讀者根本沒看到分支二」與「看到了但停在承載層」兩種成因混在同一格計分。防護為本票保留絆腳索表兩欄分開計數，並於基線重起宣告載明量尺已變、跨基線不可相減。
