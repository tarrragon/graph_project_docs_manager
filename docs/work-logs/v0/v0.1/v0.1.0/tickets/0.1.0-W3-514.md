### 改後全文（8.2(2)(3)(4)、8.5(1)(2)）

- (2) 「只有顏色」依序判兩點，兩點都成立才算違反，**第一點不成立即結束判定，判不違反，不進第二點**。第一點，把這些元素承載語意的顏色全換成同一個顏色後，是否還剩下 8.2(3) 清單內的任一項差異；不剩，第一點成立。換色這個操作的兩側都是封閉的：**顏色那一側全部歸一**——色相、明度、彩度、深淺、對比換完後一律相同，不存在「換色後仍有明度差／深淺差／對比差」這種狀態，出現這種敘述表示換色沒有執行完，不得作為第一點不成立的理由；**顏色以外那一側一動不動**——形狀、大小、位置、圖示、存在與否、填滿與否、線條樣式、文字內容，換色前是什麼，換色後還是什麼。換色後仍在的差異，依 (3) 判。第二點，各自旁邊沒有文字標明它代表什麼。
- (3) 本清單各項依 8.1(1)，須是使用者用來分辨這些語意所依據的差異；與語意無對應關係者不算。可區分的差異有：形狀、大小、位置、圖示、存在與否、填滿與否、線條樣式、文字內容。**明度、深淺、對比強弱、彩度、色相都不在本清單內——它們是顏色的維度，換色後一律相同，不會成為「換色後仍剩下的差異」。**
- (4) 各自旁邊有文字標明語意者不違反 (1)，即使換色後沒有剩下 8.2(3) 清單內的任何差異。該文字須與所標語意同時可見；須先觸發才出現者（tooltip、長按提示、說明彈窗）不算。
- (1)（8.5）表單畫面：必填欄位的標籤以橘色顯示、選填欄位的標籤以一般文字色顯示，兩者旁邊都沒有星號或「必填」字樣。違反 8.2(1)：把兩種標籤的文字色全換成同一個顏色後，兩者沒有剩下 8.2(3) 清單內的任何差異（第一點成立），且旁邊沒有文字標明（第二點成立）。處置是為必填欄位補星號或「必填」字樣。
- (2)（8.5）同一份表單改為必填欄位標籤後加一個橘色星號、選填欄位無星號。不違反：使用者區分兩類欄位所依據的差異是星號的存在與否，屬 8.2(3) 的「存在與否」，換色後仍剩下「存在與否」這項差異。**星號本身是橘色不構成違反**——8.2(1) 問的是使用者可依據的差異是不是只有顏色，此處的差異不是顏色。

全檔「灰階」「所有維度」「換色只換色值」「不得以轉灰階」四個字串 byte-exact 計數皆為 0（`grep -cF`）。8.2(2)「顏色以外那一側」清單與 8.2(3)「可區分的差異」清單逐項比對（Python list 相等），兩份清單皆為 `形狀、大小、位置、圖示、存在與否、填滿與否、線條樣式、文字內容` 八項，完全對齊。
