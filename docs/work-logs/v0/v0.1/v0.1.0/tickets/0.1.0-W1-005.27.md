### 契約落差與處置

`progressA11yLabel(int parsed, int total)` 需要離散計數，但 slot 契約只提供 `progress: double?`（比值）。判斷此落差不需修改 SPEC-004 4.24（未動其他條目），採用比值轉百分比的等價語意：`progressA11yLabel((progress*100).round(), 100)`，即「進度 45 / 100」讀作 45%，是螢幕報讀器對百分比進度條的常見慣例，不需額外的 parsed/total 分項欄位。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
新增 `lib/components/loading_state.dart`：`LoadingState` StatefulWidget，兩個具名建構子 `.skeleton`（SkeletonLayout matrix/sections）與 `.progressBar`（determinate double progress）。取消鈕經 `AppButton.secondary`，`isCancelling` 驅動 enabled/label 切換（cancelInProgressAction）；`disabledReason` 傳空字串以滿足 AppButton 必填 assert，避免與鈕文案重複渲染。骨架用 `ListView.separated`（NeverScrollableScrollPhysics）承載固定 12 列，高度不足時自然裁切不觸發 overflow；shimmer 以 `AnimationController`（duration = `Motion.skeletonCycle(context)`，`disableAnimations` 時為 zero 則不建立 controller，改靜態不透明度）驅動。進度條用 Flutter `LinearProgressIndicator`，`isCancelling` 時 value 強制為 null（C3 indeterminate）。`components.dart` 依既有慣例插入 `export 'loading_state.dart';`（維持字母序，未重排既有行）。

測試 `test/unit/components/loading_state_test.dart`，28 案例全綠：兩變體 × 兩狀態 × 兩尺寸矩陣、TestCopy 最長文案、zh/en 既有 key、C1/C2/C3(×2)/C4/C8（C5-C7 為呼叫端責任，元件本身無 SnackBar/Dialog 邏輯故不需額外斷言）、indeterminate 誠實性（無 % 字元、無 LinearProgressIndicator）、progressBar value 精確等於 progress、最短顯示、disableAnimations 靜態、cancelLabel 覆寫。
