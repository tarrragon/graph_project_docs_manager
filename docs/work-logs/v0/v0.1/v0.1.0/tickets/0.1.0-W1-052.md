### Context Bundle
main.dart 內原有 24 處裸尺寸字面值（fontSize/toolbarHeight/padding/SizedBox/BorderRadius/Icon size），逐一比對 lib/tokens/{spacing,typography,layout}.dart 定義的離散階。

### WRAP 三問
W：候選方案（1）逐一比對現有 Space/Radius/AppFontSize 精確值，僅換有精確匹配者（採用）；（2）為無匹配值就近湊整改用最接近的 token（未採，會偷改視覺尺寸，非本票授權範圍）。
A：機會成本——本票不擴充 tokens/，故留下 11 處無 token 覆蓋的字面值，後續若要收斂需另立票新增/調整 token 定義並經 PM 核定（比照 layout.dart 既有的收斂方法）。
P：預想失敗點——main.dart 是唯一示範頁，未來會被真正畫面取代，過度投資此檔 token 化 ROI 低；已控制在「精確匹配才換」範圍內，避免過度工程。
