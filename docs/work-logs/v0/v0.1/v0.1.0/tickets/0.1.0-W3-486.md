### 落地內容

依用戶裁決落地兩處變更，皆於 `.claude/skills/ux-design-evaluation/references/interaction-feedback-component-semantics.md`：

**乙-3（採 B 窄版）**：
- 2.2(1) 句末補：「整列可點時，該列本身不進入本款的比較集合，依 2.8(1) 判定為動作列，列上元素依 2.5 處理。」
- 2.5 句末補：「整列可點時，列上沒有自身動作的元素（按到它與按該列其他位置結果相同）比照本條，不是本項的指示，不做比較。」
- 2.8(1) 句末補：「整列可點時，該列本身即為動作列。」

**乙-4（納入「解除」）**：
- 7.2(3) 句末補：「狀態指示與造成、設定或解除該狀態的動作，代表的事物相同（例如「已套用篩選」的指示與「開啟篩選面板」的按鈕）；語意不同指的是所指的事物或動作本身不同（例如「篩選」與「匯出檔案」）。」

### 前後對照

| 條文 | 改前 | 改後新增句 |
|------|------|-----------|
| 2.2(1) | 可點元素定義 + 全畫面比較範圍句 | + 整列可點時列本身不進入比較集合，改判 2.8(1) 動作列、列上元素依 2.5 處理 |
| 2.5 | 徽章不做比較 | + 整列可點時列上無自身動作的元素比照本條 |
| 2.8(1) | 動作列定義 | + 整列可點時該列本身即為動作列 |
| 7.2(3) | 只排除「可點與否」這一維度 | + 狀態與其造成/設定/解除動作代表事物相同；語意不同定義為事物或動作本身不同 |

### 2.9(1) 連鎖是否已切斷：已切斷

原連鎖路徑（W3-482 實驗 3）：2.2(1) 字面把整列可點的列算入可點元素 -> 2.9(1)「畫面上只要有一個不帶區塊的可點元素」被整列可點的列（無區塊）觸發 -> 全畫面所有純文字指示一律判不屬 (a)。

現改後 2.2(1) 明文「該列本身不進入本款的比較集合」，即整列可點的列不再算入 2.2/2.9 的可點元素比較集合，2.9(1) 的觸發條件不再被這類列滿足。連鎖已切斷；未涉及該列的其他純文字指示回到逐一與畫面上其餘可點元素比較的正常路徑。

2. **UX-C7v（實驗室漏斗；餵料原文見 probes/q/W3-417-b6-ux-4.md，答案鍵見 probes/key/W3-417-b6-ux-4.md）**：原判定 (1) 不違反——頁首實心漏斗（「已套用篩選條件」狀態）與工具列描邊漏斗按鈕（「開啟篩選條件面板」動作）代表的都是篩選這件事，只差可點與否。此情境恰為 7.2(3) 新句的範例原型（「已套用篩選」指示與「開啟篩選面板」按鈕）。套新句：開啟篩選面板即是造成/設定「已套用篩選」狀態的動作，代表事物相同，仍判**不違反**——與原判定一致。(2) 匯出用漏斗按鈕與另兩個漏斗比較：匯出動作不造成、不設定、也不解除「已套用篩選」狀態，兩者所指事物不同（篩選 vs 匯出），新句不適用，仍判**違反**——與原判定一致。**符合**。
