### 落地前自走的條文推導（不照抄 W3-553 草案）

在改文前先以 UX-Y7a（b18-A1）／UX-Y7b（b19-A1）的題面逐步走過一次新句，確認 8.2(4) 取得對象、第一點回到成立：

1. 8.1(2) 不觸發——兩題題面皆明寫畫面上有兩類靠視覺差異分辨的狀態。
2. 新句適用條件逐項比對題面：題面寫「每一列的圖示右側緊接著一行文字，標明這一列的圖示代表什麼」（對應「各元素旁邊另有一則文字標明它代表什麼」）、「該文字與圖示同時可見，不需長按、停留或另開彈窗」（對應「與所標語意同時可見」）。四項齊備。
3. 該文字依新句不列入清單任一項，換色後不再有清單內差異剩下（讀法 A 下兩枚圖示逐維度對應）→ 第一點成立。
4. 第二點「各自旁邊沒有文字標明它代表什麼」→ 有文字 → 第二點不成立。
5. 兩點未皆成立，判不違反；8.2(4) 在此成為直接命中的明文，取回對象。

另正向查核 8.4 第二條處置：改文前，補上標明文字會經由「第一點不成立」得出不違反（走錯路徑）；改文後補文字使第一點維持成立、由第二點與 8.2(4) 接住，處置回到條文本來設計的通道。
