### 與 0.1.0-W3-585 草案的差異（一處，非照抄）

草案末分句為「該項名列在清單上，只支持那一項在清單內，不足以充當這一句」，落地時主語補「這件事本身」四字。

理由：草案末分句的主語串「該項名列在清單上」存在一條 garden path——可被讀成「該項名（那個列在清單上的）……不足以充當這一句」，即連第一支（項名本身即指這項差異）一併否定。該讀法會使四格既有的字面支持格（`UX-N8x`(1)(3)、`UX-W8s`(4)、`UX-W8u`(4)、`UX-Z8a`(4)）由不違反翻為違反，是本次改文唯一可能的誤傷方向。補「這件事本身」使被否定的對象逐字限定為「列入清單這一事實」，與第一支的「項名的字面指涉」分屬兩事。

未採「這一點」作主語補語：本檔「第一點／第二點」已是 8.2(2) 的專用詞，會與判定步驟撞名。
