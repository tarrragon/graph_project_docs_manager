### Task Reference
- 0.1.0-W3-585 what: 8.2(3) 第五款寫「主張某項差異落在本清單某一項的人，須指出是哪一項，且該歸屬須有直接支持：清單的字面，或本款以上的界定句」。「清單的字面」有兩種讀法：讀法甲，字面須支持這個歸屬本身（清單要寫出「表面紋理算填滿與否」之類的話才算支持），此讀法下該款生效；讀法乙，被指派的那一項有列在清單上即算支持（「填滿與否」確實逐字列在清單內），此讀法下任何指派到清單既有項的主張都自動取得直接支持，該款在它唯一要擋的那一格完全失效。本票裁定採哪一讀，並決定條文是否需改寫以關閉讀法乙
