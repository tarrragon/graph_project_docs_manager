### 逐條改動（改動摘要 → 來源票 → 甲乙分類 → 指名覆蓋題）

### UX 檔（interaction-feedback-component-semantics.md）

1. **7.2(3-2)①**（W3-573，**乙**）：(a)(b)(c) 由被動條件改為明示步驟——「兩句寫完之後、進 ② 之前，先逐項檢查下列 (a)(b)(c)，並把檢查結果逐項寫出來」，未檢查即進 ② 者本步未完成。(a)(b)(c) 三目逐字未動。
   覆蓋題：受測 7.2(3-2)①——判定兩端寫出的甲名稱是否觸發 (a)，並寫出檢查結果。
2. **7.2(3-2)①乙**（W3-563，**甲**）：補「本目所列的每一項都要寫，兩端都要寫；看不出的寫『看不出』，不得略過。漏寫任一項者本步未完成」。
   覆蓋題：受測 7.2(3-2)①乙——判定一份只寫了部分輪廓項目的比對是否完成本步。
3. **7.2(3-2)②**（W3-563，**甲**）：補等價形式換算要求與「看不出」項的處理。原有例示未動，新增句不帶例示。
   覆蓋題：受測 7.2(3-2)②——判定兩端以不同表述寫出的同一數值是否算內容不同。
4. **7.2 新增 (4-2)(4-3)**（W3-544 + W3-547，**乙**）：(4-2) 第 7／8 項雙向各自判定、第 8 項的文字豁免不外溢、兩項都命中依 8.3(2)；(4-3) 第 8 項的判定步驟不得用以回答本項的圖形同一性。被路由到的 8.3(2)／8.3(5) 逐字未動。
   覆蓋題：受測 7.2(4-2)——判定兩端旁邊各有標明文字時第 7 項是否因此不違反。
5. **8.2(2) 整段重寫**（W3-572 **乙** + W3-543 **甲** + W3-551 **甲**）：
   - 拆為三個編號步驟（前置關／第一點／第二點），原「不比對 8.2(3) 清單內的任何差異」由長句末句析出為前置關的獨立子目 (乙)，並加上「不得作為並列理由、補充理由或供參考的附帶論述」（W3-572，乙）。
   - 第二步新增子目 (乙)：把 8.2(3) 引言的對應關係**要件內容**寫進第一點，不是路由過去——W3-543 實測純路由擋不住 r1 的失分（甲）。
   - 廢除「成立／不成立」：各步結果改直述，並明寫「本款不用『成立／不成立』描述各步的結果」（W3-551，甲）。「第一點／第二點」保留為編號指涉，8.3(5)／8.5 的既有引用不失效。
   覆蓋題：前置關末句一題（受測 8.2(2) 第一步 (乙)——前置關擋下後是否仍寫出兩點的判定結果）；對應關係一題（受測 8.2(2) 第二步 (乙)——換色後剩下的差異與語意有無對應）；極性一題（受測 8.2(2) 第二步 (丙)——剩下清單內項目時的下一步是什麼）。
6. **8.2(3) 引言／①／⑤ 的極性詞連帶更新**（W3-551 連帶，**甲**）：三處「不使第一點不成立」（雙重否定）改為直述。不改則 8.2(2) 改了而讀者在 8.2(3) 仍取到舊極性詞，改文效力被抵銷。
7. **8.2(3)①**（W3-562，**甲**）：補禁自造類名——不得先替兩端各取整體名稱再比名稱，一律以能否重合判；重不重合看不出來時本項不算有差異。寫成 8.2(3)① 自身的寫法要求，不援引 7.2。
   覆蓋題：受測 8.2(3)①——判定一份以自取名稱得出「形狀不同」的主張是否成立。
8. **8.2(3)⑤**（W3-599，**甲**）：「本款以上的界定句」→「本款之內、本目之前的界定句」，並明寫限於 8.2(3) 引言與 ①②③④；8.2(3) 以外的語句（含第 2 項、第 7 項、2.3 各款）不算。W3-599 的 (b) 已查：7.1(1) 逐字引 2.3(3) 是條文自己寫出的引用、不是讀者自行取用，不衝突。
   覆蓋題：受測 8.2(3)⑤——判定以 8.2(3) 以外的界定句支持某項歸屬是否算數。
9. **8.2(4)**（W3-571，**甲**）：界定「旁邊」——須是與元素並列的另一則文字；元素自己寫出來、位於其邊界之內的字不算本款的標明文字，依 8.2(3) 的文字內容項判。此即 W3-566 刪去的排除句所帶的澄清，改置於 8.2(4)。同段補明 8.2(4) 的全稱量詞（只有一部分元素有的，本款不符合，前置關不擋下）——前置關已是終局判定的唯一來源，其入口條件不得留未界定處。
   覆蓋題：受測 8.2(4)——判定元素邊界之內的字是否使前置關擋下。
10. **8.3(2) 拆為三目**（W3-565 **甲** + W3-554 **甲**）：① 明寫本款只管兩項都命中後怎麼記、**不是缺口的成立要件**，只有一項命中時那一項照記（565）；② 保留原計數規則；③ 涵蓋主張限於「補形狀」那一條處置——選補文字結案或補的差異不是形狀時，第 7 項的違反仍在，須另依 7.3 換圖形（554）。
    覆蓋題：計數一題（受測 8.3(2)①——只有一項命中時記幾個缺口）；處置一題（受測 8.3(2)③——兩項都命中而以補文字結案時該缺口能否關閉）。
11. **8.3(5)**（W3-551 連帶，**乙**）：「第一點成立與否」→「第一點判定結果」；補指第 7 項側的同款條文為 7.2(4-3)。
12. **8.5(1) 例示**（W3-551 + W3-543 連帶，**甲**）：改為依新三步逐步敘述，並示範對應關係篩選。

### doc 檔（component-library-bidirectional-constraint-methodology.md）

15. **框架容器句 + 判別問句**（W3-588 形態 (ii)，**甲**）：框架容器句由「另承載」改為「**只**承載」，並補「**框架容器不是容器元件**：沒有元件契約、沒有排列不變式、不承載子件之間的間距，不得作為第五列的承載者」；判別問句的觸發答案由「頁面本身」擴為「頁面本身／頁面根堆疊／殼層」。此即 W3-588 指出的「缺口不在判別問句的可見性」——舊文正面把頁面根堆疊命名為一種容器。
    覆蓋題：受測第五列承載者資格——兩元件之間只隔著頁面根堆疊時由誰承載。
