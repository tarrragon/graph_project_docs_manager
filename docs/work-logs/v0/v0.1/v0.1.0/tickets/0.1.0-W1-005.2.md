## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
建立 lib/components/app_icon.dart（AppIcon，含 IconSize.sm/md/lg 尺寸階 enum，映射 LayoutSize.icon*）與 lib/components/divider.dart（Divider，SizedBox(width: double.infinity, height: 1) + DecoratedBox border 實作，class 名照 SPEC-004 契約用 `Divider`，非 `AppDivider`）；lib/components/components.dart barrel 新建並匯出兩者。

實作依 SPEC-004 §4.2/4.3 十一欄位：AppIcon 無變體、semanticLabel null 時 ExcludeSemantics（裝飾性）、非 null 時 Semantics(image:true) 唸出全文；Divider 無 slot、恆 ExcludeSemantics（裝飾性）、顏色固定 AppColors.border。皆零裸值，色彩/尺寸 token 全引用 lib/tokens/。

契約無需修訂，未偏離 §4.0 通用約定與條目本文。
