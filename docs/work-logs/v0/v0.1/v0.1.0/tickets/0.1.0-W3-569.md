## Task Summary

8.2(2) 第二點逐字為「各自旁邊沒有文字標明它代表什麼」，其不成立只需一個元素旁邊有文字（存在量詞）；8.2(4) 與 0.1.0-W3-561 裁決的前置關逐字要求「各元素旁邊都有」（全稱量詞）。只有一部分元素旁邊有標明文字時，前置關不擋下、8.2(4) 不給豁免，但第二點不成立仍使兩點未皆成立而判不違反——同一個事實在兩款得到不同的資格。本票判定該不對稱是否須以條文明文切開，或屬刻意設計（部分標明本來就足以區分，故不違反）。
