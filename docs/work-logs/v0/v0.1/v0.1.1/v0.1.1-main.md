## 前情提要

0.1.0（Shell）於 2026-09-23 發版，tag v0.1.0。發版時未完成的票依建票動詞前移：72 張到本版、5 張到 0.2.0；本版另有 7 張是實作期衍生的票，合計 79 張。

本版的定位由 todolist 定義：它是固定容器，不再收新票，主軸是 0.2.0（Gate）。patch 是該 minor 實作期的副產品（PROP-005 原意），minor 發布後其 patch 就不再收新件。本版發版時，剩餘票前移至 0.2.0，不開 0.1.2。

## 發版條件

1. **整合測試**：0.1.0 的整合測試仍全數通過（`fvm flutter test integration_test/ -d macos`），單元測試 100% 通過。本版沒有自己的整合測試，只有上層 minor 的整合測試。
2. **無契約 blocker**：`version-release check` 對 0.1.1 沒有帶 scope_blocker 的 pending 票。
3. **剩餘票不擋發版**：沒做完的票在發版時前移至 0.2.0，本版是「做多少算多少」。
4. **不開 0.1.2**：前移目標是開放中的後繼版本 0.2.0。「溢出目標優先選最近的開放後繼版本」這條機械防線由 `0.2.0-W1-016` 實作。
