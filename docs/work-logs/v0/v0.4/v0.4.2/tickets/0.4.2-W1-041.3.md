## Solution
### 修復方式

- 新增 `.claude/lib/liveness_session_isolation.py`，提供三個函式：
  - `new_test_session_id`：產生 `pytest-<pid>-<uuid8>` 格式的 session id。
  - `find_leaked_liveness_files`：只檢查 `pytest-` 前綴檔是否存在；目錄不存在時視為乾淨。
  - `apply_leak_sentinel`：偵測到洩漏時把 `session.exitstatus` 設為 1，並寫 stderr。
- ticket skill 根目錄另存一份逐字相同的複本，沿用 `testpaths_coverage_warning.py` 的做法，因為 skill 自成一個測試根。兩份以 `cmp` 驗證相同。
- conftest 修改：
  - hooks 與 ticket 的 conftest：在 `pytest_configure` 設定 `CLAUDE_CODE_SESSION_ID` 為 pytest- 前綴值，`pytest_unconfigure` 還原；新增 `pytest_sessionfinish` 作為洩漏哨兵。
  - 新增 `.claude/lib/tests/conftest.py`，處理 lib-only 的隔離。
- `hook-liveness-summary-hook.py` 的 `_most_recent_completed_liveness_file` 改為略過 pytest- 前綴檔，其餘讀取與解析語意不變。
- ticket skill 升為 2.44.36。實作 commit 為 54c84866d（thyme-python-developer，worktree），由 PM 合併。執行者漏補 CHANGELOG 條目，PM 另以 commit 補上。
