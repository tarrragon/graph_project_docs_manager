## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### PM 複核與合併（2026-09-30，83）

- 合併 3cd0771b3（merge f7650bef4）。`--force` 只在「含 `ticket track complete` 與本票 ID 的那一條語句」上才算數，所以 `git push --force && ticket track complete X` 不會觸發旁路。解析沿用 W1-065 修過的共用管線；解析失敗或例外一律維持 deny（fail-closed）。
- **第三道判定的結論**：`acceptance_auditor.validate_children_completed` 只被 `ticket track audit` 呼叫，不在 complete 路徑上，所以 complete 只經過 hook 與 CLI 的 Step 3.7 兩道檢查。
- **附帶瑕疵**：`commands/track_dashboard.py` 註解寫「complete 時會被 acceptance_auditor.validate_children_completed」，與上述結論不符。移交 0.4.0-W1-068.3 修正，與該票的參考文件修正同批處理。

### 自檢結果

- **本 session 實地觸發（acceptance 5）**：以 W1-068 本身為標的，這張票的 children 未完成、acceptance 也未勾選。
  - 不帶 `--force`：被 deny。新訊息寫明 `--force` 只旁路 children 檢查，且會寫入稽核；checklist 第 5 項正確顯示「ANA 已有後續 ticket」，修正前這裡會誤顯示「非 ANA」。
  - 帶 `--force`，並用不符的 `--as` 確保不會真的結案：hook 放行 children 檢查，additionalContext 列出被旁路的 3 張 children；接著 CLI 的 identity-guard 拒絕。W1-068 維持 in_progress。
- **liveness（acceptance 6）**：`hook-logs/acceptance-gate/` 於 21:14:37 記錄 `FORCE_BYPASS ticket=0.4.0-W1-068 旁路 3 個未完成後代: …`。
- **測試**：新增 13 案，修正前 13 failed；修正後同檔 41 passed。hooks 與 lib 全套件 5247 passed、0 failed。
