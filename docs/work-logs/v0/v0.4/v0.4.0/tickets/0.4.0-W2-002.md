## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
實作：TypeTable 新增 edgeTypes（Map<String,EdgeTypeDecl>?，null=缺 edge_types 鍵）；codec 解碼 edge_types（缺 class/forward_field/layer 拒收並 log，缺 forward_cardinality 保留 null）；edge_type.dart 提供 EdgeTypeEntry、EdgeTypeResolution（activeEdgeTypes = established 扣 domain_dependency）、resolveEdgeTypes（缺 edge_types 或缺基數：版本 isWithinKnownSchemaRange 則由內建補，否則 versionOutOfKnownRange／missingForwardCardinality 原因碼）。node_types 解碼未動（S6-10）。
Phase 4 評估：重構需要 否；技術債務 有一項——TypeTable 仍持 edgeTypes 原始宣告而 resolve 在 edge_type.dart，edge_type.dart 與 type_table.dart 互相 import（Dart 允許，型別只放兩處）；程式碼品質 A；結論：無需重構，循環 import 若日後擴張再拆檔。
