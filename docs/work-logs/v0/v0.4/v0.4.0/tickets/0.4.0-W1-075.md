## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### PM 複核與合併（2026-09-30，83）

- **推導來源**：票庫根目錄取自 ticket skill 的 `constants.WORK_LOGS_DIR`，預設為 `docs/work-logs`，未寫死 `docs/`。hook 以檔案路徑載入 constants.py；載入失敗時退回預設值並寫日誌（fail-open）。
- **第一版有 blocker，PM 實地觸發時發現**：scratch repo 的 `.gitignore` 只有框架預設的 `.claude/**/*.lock`，hook 卻判定已涵蓋、不提示。
  - 根因：`_normalize_ignore_token` 會剝掉 `.claude/` 與 `**/`，`.claude/**/*.lock` 因此變成 `*.lock`，被誤判為全域涵蓋。本票要處理的正是這個情境，結果被自己的比對規則吃掉。
  - 單元測試沒抓到：原本的 E1 與 E2 案例都沒放這一行。
  - 第二版改用專用比對：只有不帶目錄前綴的萬用寫法算全域涵蓋；帶前綴的寫法，前綴必須是票庫根目錄或它的祖先才算。另補 E2 案例 `.claude/**/*.lock`、`.claude/*.lock`、`other/**/*.md.lock`、`docs/*.lock`，修正前這組為紅燈。
- **合併**：1816c5e64 與 e59b5935f。

### 自檢結果

- **本 session 實地觸發**：以 hook 註冊的命令加 SessionStart stdin 直接執行，因為 SessionStart hook 只在 session 啟動時觸發。
  - scratch repo，`.gitignore` 只有 `.claude/**/*.lock`：提示缺少 `docs/work-logs/**/*.md.lock`（E2）。
  - scratch repo，`.gitignore` 為 `**/*.md.lock`：不提示（E1）。
  - 本專案：`suppressOutput: true`。
- **liveness**：`hook-logs/session-start-gitignore-check-hook/` 記錄「票庫根目錄取自 constants: docs/work-logs」與「票庫 lock 必要項 docs/work-logs/**/*.md.lock -> 已涵蓋」。
- **測試**：該測試檔 17 passed；hooks 與 lib 全套件 5256 passed、48 skipped、0 failed。
