## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
### PM 複核與合併（2026-09-30，83）

- 合併 463d2f1af，ticket 版本 2.44.9。
- 新增 `lib/ana_coupling_hint.py`，提供兩個函式：`hint_parent_is_ana` 與 `hint_blocked_by_ana`。
  - 提示只寫 stderr，前綴 `[HINT]`，不改變 exit code。
  - create 在建票成功後呼叫這兩個函式；set-blocked-by 只在加入依賴時呼叫，`--remove` 不觸發。
- 依賴者只計入非終態的票，因為已終態的票不在等待。反查方式是以 `list_tickets(version)` 掃描 blockedBy，因為目前沒有現成的反查函式。

### 自檢結果

- **live 驗證**：對 PM 自己的 W1-070 執行 `set-blocked-by --add 0.4.0-W1-068`。
  - 輸出 `[HINT] ANA 將保持開啟：0.4.0-W1-068 尚有 2 張非終態 children（0.4.0-W1-068.3, 0.4.0-W1-068.4），本票 0.4.0-W1-070 會等到它們全部終態後 ANA 才能 complete`，rc=0。
  - 接著 `--remove` 還原：沒有提示，這是對照組。W1-070 的 blockedBy 回到 []，工作區沒有殘留差異。
- `create --dry-run` 沒有產出提示，原因是提示掛在建票成功之後，dry-run 不走到那一步。這屬於預期範圍，沒有另行驗證。
- **全套件**：合併後在 main 重跑 `uv run --directory .claude/skills/ticket pytest -q`，4247 passed、5 deselected。
- **紅燈與綠燈**：新增 11 案，修正前 3 個提示案為紅燈，修正後 11 案全綠。
