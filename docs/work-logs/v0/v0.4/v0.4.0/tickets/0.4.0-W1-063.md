# Execution Log

## Task Summary

--blocked-by 為單值參數（逗號分隔，help 有寫），但同一 parser 的 --acceptance 可重複給；--blocked-by 重複給時 argparse 預設覆寫，只保留最後一個值且無警告。0.4.0-W2-009 以四個 --blocked-by 建立，建完只剩 W2-008，事後以 set-blocked-by --add 補齊（271b57a8d）。

---

## Problem Analysis
<!-- Schema[IMP/Problem Analysis]: 選填（小型 IMP 可留 placeholder；大型 IMP 建議填寫）（.claude/pm-rules/ticket-body-schema.md） -->
### PM 前置（2026-09-30，83）

- **判準 (1) 抽象可攜：是。** 任何 consumer 以重複旗標建票都會靜默丟值，與專案無關。
- **判準 (2) 根源在 `.claude/` 通用資產：是。** `ticket_system/commands/create.py` 中，`--blocked-by` 與 `--related-to` 是單值參數，沒有設 `action`；只有 `--acceptance` 用 `action="append"`。
- **dedup**：e1 查重命中 #23（`--blocked-by` 建票後 blockedBy 為空）。兩者同一領域、機制不同：#23 是解析到組裝之間漏傳，本票是 argparse 重複給時覆寫。關係判為引用，修完在 #23 附觀測。
- **修法定案**：採 `action="append"`，並相容逗號分隔，兩種寫法結果相同。不採「重複給就報錯」，因為同一 parser 的 `--acceptance` 已是 append 慣例，兩種慣例並存本身就是陷阱來源。
- **盤點範圍**：ticket skill 內所有 help 標為「逗號分隔」的單值參數，目前 5 處，含 create 的 `--where`，實作者須逐一列出。每處必須二選一：比照處理，或在 Solution 記下不處理的理由。
- **版號**：ticket skill 2.44.3 → 2.44.4（CHANGELOG 與 SKILL.md）。

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
create.py 的 --blocked-by/--related-to/--where 改 append，共用 expand_list_arg. 盤點5處: create --where 已處理; set-where --files 不處理(語意為直接覆寫,改 append 變更語意); add-spawn-request --files 不處理(非建票路徑); batch-claim/batch-complete ticket_ids 不處理(positional); bulk-create --targets 不處理(目標名稱可含逗號,非本票範圍)

### PM 複核與合併（2026-09-30，83；本節取代上方單行的盤點結論）

**盤點表（最終）**：

| 位置 | 處理 | 理由 |
|------|------|------|
| create `--blocked-by`、`--related-to`、`--where` | 已處理 | 同一命令的多值參數，重複給會靜默丟值 |
| track set-where `--files` | 已處理 | 首版以「覆寫語意」為由不處理，理由不成立：整次呼叫仍整體覆寫票面，argparse 重複給丟值是另一層問題，PM 退回後補上 |
| track add-spawn-request `--files` | 已處理 | 同上，重複給一樣丟值 |
| bulk-create `--targets` | 不處理 | 目標名稱本身可能含逗號語意，非本票範圍 |
| batch-claim／batch-complete `ticket_ids` | 不處理 | positional 參數，沒有重複旗標問題 |

- **helper**：`expand_list_arg` 放在 `ticket_system/lib/list_args.py`，create、fields、track_acceptance 共用。
- **合併**：兩個 commit f72fa2142、a43049f61，合進 main，推送於 552271a6c。

### 自檢結果

- **live 驗證**：`--dry-run` 不輸出 blockedBy；實際建票會留下垃圾票，所以沒做。E1 對照由 `test_create_repeated_list_args.py` 18 案承擔，含重複與逗號同結果、混合保序去重。
