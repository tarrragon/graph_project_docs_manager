### 問題根因

### 證據與時間線（2026-09-29，+0800）
- hook log：16:19:57 "跳過: 非 git commit 命令" 後接 "Hook execution time: 394.17s"。該次走最早的 skip 路徑（僅 stdin 讀取與字串判斷，無子程序、無 git、無 uv run doc）。

- pmset -g log：16:13:22 "Entering Sleep state due to Clamshell Sleep"；16:19:51 "Wake from Deep Idle"。睡眠 389 秒，涵蓋該次執行。
