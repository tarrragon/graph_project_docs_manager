# Execution Log

## Task Summary

W1-070 實測：現行 shim（由 git-ref-transaction-guard-install-hook 產生、以 exec uv run --quiet 啟動 guard）在 uv 無法解析依賴（離線且快取冷，rc=1）或 uv 不存在（rc=127）時，git 以 fatal: ref updates aborted by hook 中止所有 ref 寫入（update-ref rc=128），與 guard 宣告的 fail-open 設計相反。guard 阻擋時也回 rc=1，shim 無法分辨是 guard 判定阻擋，還是 uv 啟動失敗。
