# Execution Log

## Task Summary

settings.json 有 77 個 hook 的 timeout（5000 到 30000）以毫秒數值寫成，平台單位為秒，實際等於 83 分鐘以上。直接除以 1000 會讓 26 支 hook 的實測最大耗時超過或逼近新值，被平台終止時為 non-blocking，守衛會靜默失效。改為依 hook log 實測分佈逐支設定秒數，並更正 hook-specs 文件的單位說明

---

## Problem Analysis
### 問題根因

`.claude/hook-specs/claude-code-hooks-official-standards.md` 以毫秒示範 hook timeout，而平台單位為秒。settings.json 共 77 筆註冊照此文件填寫，實際上限變成 83 分鐘到 8.3 小時。查證紀錄見 0.4.0-W1-044 Solution。

### 框架問題判準（兩條 AND）

1. 抽象可攜：是。settings.json 經 sync 散佈（只排除 settings.local.json），錯誤示範文件也隨框架散佈。
2. 根源在 `.claude/` 通用資產：是。

### 查重與 canonical

用戶已授權開 canonical issue：tarrragon/claude#112（2026-09-30，由 e1 開立）。本票完成後在 #112 附加觀測。

### 修法約束

不可直接除以 1000。hook-logs 實測中，26 支 hook 的最大耗時超過原意值的一半。PreToolUse 逾時不會阻擋工具呼叫，timeout 設得過窄，守衛會在負載下靜默失效，比現狀更差。
