### 派發決策（PM）

- **新測試放新檔**：schema 層的新測試放 `test/unit/schema/edge_type_undirected_test.dart`，不放 `edge_type_decoding_test.dart`。後者是 W4-004 的目標檔，兩票並行派發。
- **兩個例外集中到 `lib/schema/edge_type.dart`**：`domain_dependency` 排除與 `association` 無向認定都在這一檔。Graph 內不得再出現 `association` 字面值，`undirectedEdgeName` 常數刪除，`_edgeOf` 與 `_multiSourceDefects` 一律改讀 `EdgeTypeEntry.isUndirected`。
- **規格不需改**：SPEC-007 D6／FR-05 只寫「程式內鍵名例外兩處」，沒有指定所在檔案，搬移後仍是兩處。S6-13 的描述「Graph 認定為無向的邊型集合恰為 {association}」由建圖結果驗證，與測試設計相符。若搬移後發現規格文字需要改寫，寫進 NeedsContext，不動規格。
- **註解**：本票搬移或改寫的程式碼，註解要一併寫正確，包括 D6 兩個例外與 FR-05〈無向的判定〉。與 W4-002 (1)(2) 重疊的部分由本票處理，W4-002 最後派發時會再核對。
- **§1.3**：`test/unit/schema` 不得 import graph。S6-13 仍留在 `test/unit/graph/`。

### 自檢結果

- Graph 內無 association 字串比對，`undirectedEdgeName` 已刪；`_edgeOf` 與 `_multiSourceDefects` 讀 `EdgeTypeEntry.isUndirected`
- D6 兩個鍵名例外（domain_dependency 排除、association 無向）集中在 `lib/schema/edge_type.dart`，檔頭註解已更新
- `toEntry` 增加 `isUndirected` 具名參數（`lib/schema/type_table.dart`）；未動 type_table_json_codec.dart、edge_type_decoding_test.dart、lib/diagnostics/
- 規格不需改
