## Task Summary

3.13.0 的單子件佈局輔助判準定義的是『包裝節點』，未涵蓋不包任何子件的空節點。本專案 W3-001 依 3.13.0 掃描頁面層命中 7 處 SizedBox.shrink()：4 處為狀態不符時 build 回傳空白，3 處為表頭無標題欄的空白格。用戶裁決（2026-09-30）：不包子件的空節點不是佈局輔助——作為 build 的空回傳不計；在容器或元件的格位中頂替元件時，計為元件層缺口（該元件缺空白變體，例 TableColumnHeader 缺空白格變體）。
