### 變更摘要（實作 525419eb0，合併 b0619e076）

- 提交：`_migrate_ticket_files` 只寫工作區並回傳 (rc, record)，提交由 `_commit_migrations` 以 `commit_ticket_mds_reporting` 完成。
  - 提交路徑：仍存在的新檔排第一，接著是舊檔與各引用者。
  - topic 以 `append_lines` 只提交追加行。
  - 批次 `--config` 收齊成功項後只提交一次；提交最終失敗回 exit 75，`[WARNING]` 列出全部路徑。
- 改寫範圍新增 `discovered_during`、`closed_by`（字串或清單），以及任何票中 `chain.root`／`chain.parent` 等於舊 ID 者。
