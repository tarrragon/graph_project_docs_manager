## Task Summary

hooks-test-gate 以 uv run --project 執行每個對應測試檔，逾時以總耗時計（含 uv 啟動）。flutter_balance 於 v2.71.0 取樣 content guard 測試 5 次（load 20～30）：總耗時 19～51 秒、pytest 自報 18～36 秒，兩者差距最多約 20 秒，即 gate 自身的 uv 啟動開銷吃掉單檔預算的三分之一。測試本身已兩輪縮短，剩餘餘裕主要卡在 gate 開銷。分析：開銷來源（解析環境、同步依賴、冷快取）、是否可預熱或重用環境、逾時是否應只計 pytest 執行時間，各方案對 gate 鑑別力與 fail-closed 語意的影響。
