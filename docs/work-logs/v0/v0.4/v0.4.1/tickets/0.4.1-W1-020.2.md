## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
實作位置 migrate.py：_collect_subtree（ID 前綴收集）、_remap_ticket_refs 與 _map_ref（old 到 new 單趟映射）、_subtree_preflight（碰撞、MAX_TICKET_DEPTH 深度並列出票 ID 與深度、目標版本註冊）、_migrate_subtree（寫入、舊檔刪除、子樹外引用單趟改寫、根票父 children 同步、各成員 topic 追加）。_MigrationRecord 新增 subtree 欄位，_commit_migrations 展開後走原單一隔離提交。無子孫的票走原單票路徑不變。
設計取捨：parent_id 指向來源但 ID 不在前綴下的票無法映射新 ID，不納入子樹，僅其 parent_id 引用被改寫（初版曾列為 preflight 失敗，會擋掉既有 W11 重組情境，已改）。子樹遷移碰撞不自動改號，直接 preflight 拒絕。
commit aa6a7c595474bd3a2bbba473f2d3631605959c49；文件同步 references/migrate-command.md、CHANGELOG（2.44.x 待合併取號）、SKILL.md 版號。

設計偏差說明：票面寫「以 ID 前綴與 parent_id 收集子樹」，實作改為子孫只以 ID 前綴收集。parent_id 指向來源、但 ID 不在前綴下的票無法由前綴映射新 ID，不算子樹成員，只改寫其引用（parent_id）。理由：初版把這類票列為 preflight 失敗，擋掉既有 W11 重組情境（test_migrate_reverse_refs），且 ID 前綴即階層的約定下這類票本就是歷史遺留。另已更新 tests/test_migrate_autocommit.py 兩個既有斷言（子票改斷言舊 ID 為 D、新 ID 為 A；結構欄位改讀新 ID 子票），語意未放寬。
