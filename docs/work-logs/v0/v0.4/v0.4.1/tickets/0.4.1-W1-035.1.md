## Task Summary

## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
_run_pytest 新增 except OSError：logger.error 寫日誌檔、stderr 輸出錯誤類型/訊息/命令、回傳 red 走既有 deny 路徑。fail-open 改 fail-closed。commit e9204a399。

### 自檢結果（PM）

- 合併 92751f479，只動兩個檔：`_run_pytest` 新增 `except OSError`，判 red 並走既有 deny 路徑，同時寫 `logger.error` 與 stderr（含錯誤類型、訊息與命令）。`run_hook_safely`、gate 上限、TOTAL_BUDGET 均未改。
- 日誌檔測試的鑑別力由 PM 補驗：執行者回報該測試從未紅過。PM 在 worktree 暫時刪除 `logger.error` 那一行，該測試翻紅，deny 與 stderr 兩項仍綠；驗完以 git checkout 還原，worktree 乾淨。
- 產生路徑盤點已寫入 how.strategy。其中「gate 主流程其他例外仍放行」未覆蓋，另開 0.4.1-W1-036（ANA P3）。

### Phase 4 重構評估

- 重構需要：否
- 技術債務：已記錄。主流程其他例外的失敗語意交由 W1-036 處理。
- 程式碼品質：A
- 結論：新的 except 分支與既有 TimeoutExpired 分支同層，回傳同一組狀態型別，沒有新增控制流層級。
