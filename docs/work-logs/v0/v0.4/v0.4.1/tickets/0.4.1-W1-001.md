## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->

### 派發決策（PM）

- **拆環**：拆完後 `lib/schema` 內不得有任何循環 import。Solution 須附拆環前後的 import 有向圖，每個檔案列出它 import／export 的 schema 檔，並逐一確認沒有環。
- **`EdgeTypeDecl` 與 `EdgeTypeEntry` 維持兩個型別**：前者的基數可空，代表「剛解碼」；後者的基數必有值，代表「已決議」。兩者的差別是型別狀態，不是重複。本票只消除兩者之間的雙向依賴，不合併。
- **`isGraphAvailable`**：移除，測試改讀 `unavailableReason == null`（版本契約已預告）。
- **`schemaVersionOf`**：`resolveEdgeTypes` 與 `resolveSchemaSource` 共用這個輔助函式，放在 `schema_version.dart`。
- **0.4.1 Graph 派發排程**（PM，依實際觸及檔案修正 e1 排程，順序不入 blockedBy）：先並行 W1-001、W1-006、W1-007、W1-008；接著 W1-003（同時觸及 W1-006 的 `reference_classification.dart` 與 W1-002 的 `graph_builder.dart`）；然後 W1-002 與 W1-004 並行；最後 W1-005。
- **契約基線**（docs/todolist.yaml 0.4.1 第 2 欄）：測試數只增不減，基線為 `flutter test` 1971 項、`test/integration/` 66 項；0.4.0 IT-1～3 凍結值、G9 計數、建圖日誌事件不變。

### 實作（parsley）

- type_table.dart：移除 `EdgeTypeDecl.toEntry` 與對 edge_type.dart 的 import；`EdgeTypeEntry` 的建構移到 edge_type.dart 的 `_entryFromDecl`。
- schema_version.dart：新增 `schemaVersionOf(Map?)`；`resolveEdgeTypes` 與 `resolveSchemaSource` 共用。
- edge_type.dart：移除 `EdgeTypeResolution.isGraphAvailable`；edge_type_decoding_test.dart 改讀 `unavailableReason` isNull／isNotNull。
- `EdgeTypeDecl`／`EdgeTypeEntry` 維持兩個型別，未合併。

### import 有向圖（A -> B 表示 A import B）

拆環前：
- edge_type -> schema_version, type_table, type_table_json_codec；edge_type export type_table 的 EdgeCardinality
- type_table -> edge_type（環 1：edge_type <-> type_table）
- type_table_json_codec -> type_table
- 環 2：edge_type -> type_table_json_codec -> type_table -> edge_type
- schema_source_resolver -> schema_version, type_table, type_table_json_codec
- carrier_path_lookup -> type_table；schema_version 無 schema 內 import

拆環後：
- type_table -> （無 schema 內 import）
- type_table_json_codec -> type_table
- schema_version -> （無）
- carrier_path_lookup -> type_table
- schema_source_resolver -> schema_version, type_table, type_table_json_codec
- edge_type -> schema_version, type_table, type_table_json_codec

逐一確認：type_table 與 schema_version 是葉；json_codec 只指向 type_table；carrier_path_lookup、schema_source_resolver、edge_type 只指向上述節點，且無人指回它們。無環。

### 自檢結果

- 預期紅燈表：兩列皆符（移除 isGraphAvailable 與測試改讀同批變更後轉綠；全套通過數與基線相同），無表外紅燈。
- 範圍：只動 where.files 所列 6 檔中的 5 檔（type_table_json_codec.dart 無需改動）。
