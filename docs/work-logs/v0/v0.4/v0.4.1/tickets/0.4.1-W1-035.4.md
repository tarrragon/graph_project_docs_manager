## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
commit 609b01393。gate 在 subprocess.run 前建暫存計時檔並以環境變數 HOOKS_TEST_GATE_TIMING_FILE 傳入；conftest.py 僅在該變數有值時才定義 pytest_configure/pytest_unconfigure（未設時模組不含這兩個 hook，E1 對照）。外掛記 configure 時刻 + load1_start、unconfigure（終端摘要之後）時刻 + load1_end，並於 configure 註冊 atexit（LIFO，盡量排最後）記 python 退出時刻。gate 記 spawn 與 subprocess 返回牆鐘時刻，四段首尾相接：spawn_to_configure / configure_to_summary / summary_to_pyexit / pyexit_to_uvexit，另輸出 segment_sum、sum_residual（total 為 monotonic，與牆鐘差即誤差來源，實測 -0.000s）。時刻檔缺漏/毀損、外掛寫檔失敗只記 warning（外掛端寫 stderr），欄位記 n/a，判定不變；timeout 路徑讀部分時刻。只改 where.files 三檔，無其他檔。
