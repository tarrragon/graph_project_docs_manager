## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
修正：git_ops.commit_files_isolated 範圍自檢改為 changed 是 expected 的子集，僅清單外變更判 failed（訊息附範圍外路徑）；changed 為空由既有空 tree 短路回報 empty（no-op、exit 0）。版號 2.44.22（main 現行 2.44.21 + 1）。測試 tests/test_commit_isolated_subset_scope.py。

W1-009 exit 75 歸因：不屬本根因。append-log 的提交路徑清單只有單一路徑（本票 md，commit_ticket_md_reporting 無 extra_paths）。單一路徑淨變更為零會在 commit_files_isolated 的空 tree 短路回 empty（no_change），走不到範圍自檢；且 append-log 每次寫入含時間戳與內容，不會淨變更為零。故嚴格相等在 append-log 不可能觸發，該 exit 75 應另有成因（如 ref 鎖殘留，需 e1 當時 WARNING 原文判定；本票無該證據）。本修正涵蓋多路徑寫入（add-child／set-parent 等），不涵蓋 append-log 情境。
