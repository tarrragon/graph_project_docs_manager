## Solution
<!-- Schema[IMP/Solution]: 選填（.claude/pm-rules/ticket-body-schema.md） -->
採 (a)：ticket 包 requires-python 由 >=3.9 提高為 >=3.10，uv.lock 重鎖（移除 3.9 專屬分支條目，pytest 8.4.2 與 filelock/iniconfig 舊版 pin 隨之更新，225 行 diff 多為刪除）。
理由：未見 3.9 依賴（skill-sync 同步範圍僅 skills 檔案，不涉直譯器；框架內 hooks/scripts/mermaid-ascii/version-release 等包皆 >=3.10 以上，無文件或程式碼約定 3.9）。實測 ticket_system 在 3.9 下 import 失敗（paths.py 模組層 Path | None 拋 TypeError），3.10 下全部模組 import 成功。
skill-sync：無依賴，3.9 下全部模組 import 成功，宣告 >=3.9 屬實，不改宣告，只加同型測試。
測試：ticket/tests 與 skill-sync/tests 各新增 test_python_floor_declaration.py（subprocess uv run --python --no-project 實際 import 全模組；宣告下限必成功；下限減一版必失敗；探針正向對照；無直譯器 skip）。
版號：CHANGELOG 與 SKILL.md 寫 2.44.x（待合併取號）。
