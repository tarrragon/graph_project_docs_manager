### 派發決策（PM）

- **`buildGraph`／`buildGraphFromInputs` 的公開簽章不變**：`adjacency_query_test`、`graph_log_events_test` 與 test helper 都直接呼叫它們，W1-004 和 W1-005 會同時改這些測試檔。若不改簽章就降不到 5 個直接依賴：停手，寫進 NeedsContext 回報，不擴大範圍。

  - 目前直接依賴 7 個模組：corpus_scanner、graph_built_event、graph_log_event、reference_classification、edge_type、type_table、type_table_json_codec。
  - `type_table` 已由 `edge_type` re-export，直接 import 屬於多餘。
  - `typeTableFromJson` 的節點型別解碼可以改由 Schema 端提供入口，入口放在 `lib/schema/`。實際形狀由實作決定，Schema 不得 import Graph。
- **where.files**：若需要動 `lib/schema/` 的檔案，先在 Solution 列出，再動手。這些檔案與 W1-004 沒有交集。
- **契約基線**（docs/todolist.yaml 0.4.1 第 2 欄）：測試數只增不減，基線為 main 77e061427 合併後的通過數（W1-003 覆核值）；0.4.0 IT-1～3 凍結值、G9 計數與建圖日誌事件的欄位和值都不變。
- **排程**：W1-002 與 W1-004 並行（兩者沒有共用檔），W1-005 在 W1-004 合併之後派。
