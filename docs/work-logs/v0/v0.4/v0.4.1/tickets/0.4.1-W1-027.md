## Solution

### 派發決策（PM）

- **做法**：`TicketDetail.fromRawNodes` 建構時，把 frontmatter 遞迴深層複製並凍結：`List` 與 `Map` 逐層換成 unmodifiable 副本，純量原樣保留。這樣同時切斷與 RawNode 的共用引用。
- **類別註解**：`TicketDetail` 類別註解裡「只凍結第一層」那句要同步改寫。
- **不碰 Graph**：本票不改 `lib/graph/`。
- **契約基線**：測試數只增不減，以 main 98700ea4f 的覆核值為準（1985／66）；0.4.0 IT-1～3 凍結值不變。
