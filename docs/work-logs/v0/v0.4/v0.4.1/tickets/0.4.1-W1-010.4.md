### Task Reference
- 0.4.1-W1-014 what: W1-055 結論（候選 4）：git_ops._stage_appended_blob 目前以「HEAD 版本 + 本次追加行」提交 append-only 檔（topic-assignments.txt、topics registry）。兩個寫入者都在任一方提交前完成追加，且提交順序與追加順序相反時，HEAD 與工作區行序不一致，檔案會一直顯示 ' M'，只能整檔提交才能消除。改為：從工作區各行中，以 multiset 方式取出「HEAD 各行 + 本次各行」，保留工作區順序；工作區缺檔或不是超集時，退回現行做法。scratchpad 原型已驗證：6 種交錯順序全部乾淨，也不會吸入他人尚未提交的行。（來源已完成，結論見 Solution）
