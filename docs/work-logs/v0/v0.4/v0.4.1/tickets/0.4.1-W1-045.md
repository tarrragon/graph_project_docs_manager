### 修法（執行者 556c22dc3，PM 代寫票面：執行者依派發禁令未在 worktree 執行票務寫入）

- `_collect_subtree` 只收 status 不在 `("completed", "closed")` 的子孫。留下的子孫不進入映射；它們的 `parent_id` 與 `chain.parent`／`chain.root`，由既有的「子樹外引用單趟改寫」改寫為新 ID。
- 祖先鏈上有被留下者的子孫，不論本身 status 一律跟著留下（只改寫 `chain.root`）。理由：若把這類 pending 孫票搬走，新 ID 會是 `<新根>.<c>.<g>`，而其父 `<新根>.<c>` 並不存在。PM 確認採此詮釋。
- `references/migrate-command.md` 子樹遷移段新增「子孫狀態／處置」表與取捨說明。

### 取捨

已完成歷史票的 ID 前綴會與新父不一致。接受這個代價，換取歷史紀錄（worklog、CHANGELOG、版本完成清單）的穩定：完成的票留在完成時所屬的版本。

### 已知限制（由 0.4.1-W1-046 承接偵測）
